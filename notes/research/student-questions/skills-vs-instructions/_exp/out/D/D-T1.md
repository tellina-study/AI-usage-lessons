# Slash-команда vs Хук в агентном харнесе

**Date:** 2026-10-02 · **Issue:** #217-EXP

## Различие по назначению и триггеру

**Slash-команда** (`/skill-name`) — явный инструмент пользователя. Вызывается вручную в интерпретаторе, выполняет разовую задачу, требует сознательного выбора. Хук (`on-event` в settings.json) — автоматический триггер, срабатывает при наступлении условия (например, после каждого коммита или перед сборкой), выполняет рутину без явного запроса.

**По кто-инициирует:** slash-команда — оператор инициирует действие; хук — система инициирует на основе правила.

**По частоте использования:** slash-команда удобна для нечастых, одноразовых операций (sync-library раз в день); хук — для повторяющихся, критичных автоматизаций (git pre-commit валидация).

| утверждение | источник | тип |
|---|---|---|
| Slash-команды не требуют предварительной конфигурации (есть ли команда в `.claude/skills/` → работает) | CLAUDE.md § Working Conventions / Orchestration Rule | факт архитектуры |
| Хуки требуют регистрации в settings.json с явным условием и скриптом | CLAUDE.md § update-config skill docs | процедурное правило |
| Одно из фундаментальных отличий: slash-команда блокирует пользователя (синхронна), хук может быть асинхронным | по памяти, не проверено | паттерн |
