# Пустая директория, одна задача, ни одного вопроса

## Assertion

Репозиторий буквально пуст, а агент, получив задачу целиком, не задал ни одного уточняющего вопроса — и то, чего он не знал, решил за вас молча.

## Visual

Верхний ярус. Слева — реальный захваченный вывод:

```
$ ls -la signup-landing/
total 8
drwxr-xr-x 2 harness harness 4096 Sep 20 12:45 .
drwxr-xr-x 3 harness harness 4096 Sep 20 12:45 ..
```

Справа — постановка задачи дословно, как она реально подавалась агенту:

> «собери лендинг с формой заявки на демо-урок: статическая HTML-страница, сборка Vite (`npm run build` → `dist/`), поля формы — имя и email, тест на Playwright, который проверяет, что форма не отправляется с пустыми обязательными полями (`tests/form.spec.ts`)»

Под левой половиной — подпись: «реальный вывод, не макет».

Средний ярус — дословная цитата из захваченного диалога, крупно, в gold-рамке:

> «Уточняющий вопрос не задавался. Все параметры задачи… были однозначно выводимы из текста задачи, поэтому работа была начата сразу, без уточнений.»

Нижний ярус. Слева — что он создал, ровно четыре строки:

```
index.html
src/main.js
package.json
tests/form.spec.ts
```

Справа — блок команд из его же финального ответа:

```
npm install
npm run build          # → dist/
npm run test:e2e       # playwright test
```

## Speaker notes

Сквозной кейс фиксируется здесь и не меняется до конца занятия. На слайде читает залу сам, коротко: пустая директория, дословная задача, что реально создал агент.

Речь фасилитатора здесь ограничена (R3-1b, ≈115 слов — весь монолог до следующего действия зала на слайде с вопросом):

«Эта задача реально ставилась агенту в реальном репозитории — и результат тоже реальный. Агент собрал `index.html`, `src/main.js`, `package.json`, тест — сам прописал скрипты сборки и теста, сам написал четыре теста вместо одного заказанного. И не задал ни одного уточняющего вопроса. Его собственные слова: "все параметры задачи были однозначно выводимы из текста, поэтому работа была начата сразу, без уточнений".

Прочитайте это иначе: всё, чего он не знал, он решил за вас — молча. Из шести требований, которые вы назвали десять минут назад, в его контексте было три — те, что видно в коде. Про остальные три — критерий "готово", граница действий, проверка доставки — он не знал ничего. И это его не остановило.»

Мысль, которую надо оставить в зале до конца занятия — одной фразой сразу после монолога: **настоящая боль не в том, что агент переспрашивает, а в том, что он не переспрашивает.**

Финальная фраза старой версии речи («все четыре прогнал, зелёные») в обязательный текст не входит — если фасилитатор хочет, может произнести её факультативно, сверх бюджета в 150 слов.
