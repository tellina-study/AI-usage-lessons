# Учебный центр подключает весь нормативный корпус

## Assertion

Пока база — несколько десятков инструкций центра, резка по предложениям работает без видимых проблем. Проблема появляется, когда к ней подключают тысячи нормативных документов, на которые эти инструкции ссылаются.

## Visual

> **Потребность.** Бот-помощник по технике безопасности должен отвечать по всему корпусу: по инструкциям центра и по приказам, ГОСТам, пунктам нормативных актов, на которые эти инструкции ссылаются.

Версия 1 — рецепт, унаследованный от прошлого занятия без изменений: резать документ по границам предложений, кусок хранит только свой собственный текст — ни раздел, ни сам документ, из которого он взят.

> На MVP, пока документов — несколько десятков, этот рецепт работал. Что происходит, когда документов — тысячи, проверяем дальше.

## Speaker notes

Студенты и преподаватели Ольгиного центра перед практикой и лабораторной работой спрашивают бота, что делать при проливе реактива, какой допуск нужен для работы со станком, какой режим действует в конкретной аудитории. Пока в базе лежали только внутренние инструкции центра — несколько десятков документов, — резка по предложениям, которую прошлое занятие проверило и одобрило, справлялась без видимых проблем: база маленькая, и даже не идеальный кусок почти наверняка оказывался единственным похожим на вопрос.

Проблема появилась, когда к ответам бота подключили не только инструкции центра, но весь корпус нормативных документов, на которые эти инструкции ссылаются, — приказы, ГОСТы, отдельные пункты по каждому виду работ. База перевалила за тысячи документов.

Сцена не выдуманная: это перенос реального документированного случая на сюжет курса, тем же приёмом, которым прошлое занятие перенесло открытый набор вопросов и ответов на заявки Ольги. Команда ИИ-ассистента по охране труда строила похожего промышленного помощника: на MVP, на нескольких десятках документов, наивная резка компенсировалась маленькой базой — кривая нарезка была скрыта ровно так, как скрывается любой дефект на лёгком случае. Когда база перевалила за тысячи нормативных документов, систему начало выдавать ответы, которые заставляли экспертов по охране труда хвататься за голову: похожие по смыслу, но разные по юридической сути инструкции начали перекрывать друг друга в поиске. Методисты Ольгиного центра, проверяющие ответы бота перед тем, как их увидит студент, оказываются в точно той же роли.

Версия 1 — рецепт, который этот центр унаследовал от прошлого занятия без единого изменения: резать документ по границам предложений, кусок хранит только свой собственный текст. На схеме сверху видно, куда именно вмешивается сегодняшний кейс: сама резка уже стоит и работает, тронут узел между поиском и ответом — разбор дальше, после голосования.
