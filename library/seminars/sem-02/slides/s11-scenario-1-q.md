# Сценарий 1 — проверка орфографии

## Assertion

Фоновый скрипт проверки орфографии — куда его отнести?

## Visual

Левая Ocean rounded box карточка: иконка `file-code`, курсивный текст сценария («Раз в час фоновый скрипт автоматически проверяет орфографию во всех открытых файлах проекта и дописывает список ошибок в текстовый лог — без интерфейса, без диалога, без вашего участия в моменте проверки»), ниже Q1/Q2 текстом.

Справа компактный квадрант 2×2 (4 ячейки: Модель/Чат/Приложение/Агент) — все 4 ячейки одинакового нейтрального серого цвета, ни одна не выделена. Под квадрантом нейтральная (не gold) подпись «30–60 сек размышления → голосуем по всем 4 углам».

## Speaker notes

Раз в час фоновый скрипт на вашем компьютере автоматически проверяет орфографию во всех открытых файлах проекта и дописывает список найденных ошибок в текстовый лог — без интерфейса, без диалога, без вашего участия в моменте проверки.

30–60 секунд индивидуального размышления — каждый прогоняет через Q1 и Q2 про себя. Затем голосование по квадранту поднятием руки, четыре раунда: кто считает, что это модель? кто считает, что чат? и так далее.

Это первый и самый простой сценарий раздела — ожидаем быстрое единодушное голосование.
