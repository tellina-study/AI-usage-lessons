Нормативная выжимка дизайн-гайда проекта «Волна» (полный гайдбук — `notes/research/student-questions/skills-vs-instructions/_exp2/docs/design-guide.md`, открой его, если нужны формулировки, обоснования или примеры компонентов).

Шесть обязательных правил при любом оформлении интерфейса или документа по оформлению:

1. **Заголовок документа.** Документ по оформлению начинается строкой `# <Заголовок>`, а следующая непустая строка — ровно `**Design-guide:** DG-v1`.
2. **Цвет только токенами.** Цвета называются ТОЛЬКО токенами `P-INK`, `P-SEA`, `P-GOLD` (с любым суффиксом шкалы). Указывать hex-коды цвета в тексте запрещено.
3. **Состояния.** Интерактивные элементы описываются в разделе с заголовком ровно `## Состояния`, перечисление — в фиксированном порядке и этими словами: покой → наведение → нажатие → недоступно.
4. **Типографика.** Используются ровно четыре размера текста, в пунктах: 34 / 26 / 19 / 15. Других размеров нет.
5. **Контраст.** Минимальный контраст текста к фону — `4.8:1` (строже отраслевого ориентира 4.5:1 — аудитория часто работает при ярком/бликующем свете).
6. **Маркер конца документа.** Документ по оформлению заканчивается строкой ровно `<!-- DG-v1 -->`.

Применяй эту выжимку при любой задаче, где нужно создать или изменить документ по оформлению интерфейса. Для деталей (обоснования, примеры, компоновка компонентов, иконки, тон текста) — читай полный гайдбук по пути выше.
