# WE-TESS: пятишаговая рамка обнаружения транзитов.

## Контекст

Вам дали **1000 часов данных TESS** — кривые блеска для ~50 000 звёзд одного сектора. Дерево решения: какой подход использовать для обнаружения транзитов?

**Варианты:** (A) Предобученный CNN NASA Kepler, дообученный для TESS. (B) Обучить свой CNN на TESS-данных. (C) Классический Box Least Squares + ручной просмотр. (D) Гибрид — BLS первичный + CNN вторичный.

## 5 шагов рамки

**1. Анализ перекрытия данных.** TESS vs Kepler: те же инструменты? Нет — разные камеры (TESS шире поле, ниже разрешение), разный такт (TESS 2-мин, Kepler 30-мин), разная систематика. **Сдвиг распределения существенный** → предобученный CNN Kepler уступает без дообучения.

**2. Проверка доступности разметки.** Каталог TOI — ~6 000 подтверждённых TESS-планет + размеченные ложные срабатывания. **Размер скромный** против ~30 000 кандидатов Kepler.

**3. Оценка стоимости GPU.** Свой CNN: **недели на 8 GPU ($10k+)**. Дообучение Kepler CNN: **часы на 1 GPU ($100-500)**. Классический BLS: минуты на CPU, $0. Вывод 1000 ч TESS: CNN — десятки минут GPU на кандидата; BLS — минуты в сумме.

**4. Эталон доли AUC.**

| Подход | AUC |
|---|---|
| Классический BLS | **~78%** |
| Предобученный Kepler CNN + дообучение | **~89%** |
| Свой CNN специально для TESS | **~92%** |

**Выигрыш custom над дообученным = 3% AUC.**

**5. Валидация на отложенных 100 часах.** Запустите все четыре подхода на невиданных данных; вручную проверьте кандидатов. Эмпирическая оценка на вашем распределении.

## Решение

Для типичного аспиранта без сверхресурсов: **A** (предобученный Kepler CNN, дообученный для TESS) — лучшее соотношение стоимости и качества. **Производственное развёртывание: гибрид D** (BLS первичный + CNN вторичный). Свой CNN оправдан только при >10 000 размеченных и недельном бюджете GPU.

## Универсальность рамки

Применима к **любому решению AI фазы анализа**: data overlap → label availability → GPU cost → baseline AUC → held-out validation. Не «для экзопланет» — для **ответственного развёртывания AI в любой научной задаче analyse-фазы**.

## Speaker notes

Применим методологию к конкретному случаю обнаружения экзопланет. Контекст: вам дали 1000 часов данных TESS — кривые блеска для примерно 50 тысяч звёзд из одного сектора. Дерево решения: какой подход использовать?

Варианты. A — предобученный CNN-классификатор NASA Kepler, дообученный для TESS. B — обучить свой собственный CNN специально на размеченных данных TESS. C — классический Box Least Squares плюс ручной просмотр. D — гибрид BLS как первичный плюс CNN как вторичный.

Шаг 1 — анализ перекрытия данных. TESS против Kepler: разные камеры, разный такт, разная модель шума. Сдвиг распределения существенный; предобученный CNN Kepler будет уступать без дообучения.

Шаг 2 — проверка доступности разметки. Для TESS есть каталог TOI — около 6 тысяч подтверждённых планет плюс размеченные ложные срабатывания. Размер скромный против 30 тысяч кандидатов Kepler.

Шаг 3 — оценка стоимости GPU. Обучение своего CNN: недели на 8 GPU, 10 тысяч долларов плюс время на выбор модели и настройку гиперпараметров. Дообучение предобученного Kepler CNN: часы на 1 GPU, 100-500 долларов. Классический BLS: минуты на CPU, ноль стоимости.

Шаг 4 — эталон доли AUC из литературы. Классический BLS — AUC примерно 0,78. Предобученный CNN Kepler на TESS с дообучением — 0,89. Специально обученный CNN TESS — 0,92. Максимальный выигрыш от своего CNN над дообученным Kepler около 3 процентов AUC.

Шаг 5 — проверка на отложенных 100 часах. Запустите все четыре подхода на невиданных данных TESS; вручную проверьте кандидатов. Это даёт эмпирическую оценку на вашем распределении, что важнее литературных чисел.

Решение для типичного аспиранта без сверхресурсов: вариант A — предобученный CNN Kepler, дообученный для TESS — лучшее соотношение стоимости и производительности. При производственном развёртывании — гибрид D — балансирует пропускную способность с точностью. Свой CNN оправдан только если у вас большой размеченный набор более 10 тысяч и бюджет на недели времени GPU. Классический BLS — эталон сравнения, с которым вы должны сравнивать результат CNN.

Эта пятишаговая рамка применима не только к обнаружению экзопланет. Она применима к любому решению AI фазы анализа: data overlap → label availability → GPU cost → baseline AUC → held-out validation. Применение этой рамки делает студентов строгими инженерами AI-применений.
