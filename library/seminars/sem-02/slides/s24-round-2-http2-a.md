# Раунд 2 — HTTP/2, ответ

## Assertion

Вариант Б — подделка: HTTP/2 работает поверх TCP, не UDP.

## Visual

Две одинаковые по формату Ocean rounded box карточки (А/Б, только текст). Вариант Б обведён gold-рамкой. Ниже — gold reveal-панель: «Подделка: вариант Б», объяснение, строка «Что проверить первым: номер RFC на ietf.org».

## Speaker notes

Подделка — вариант Б. Подтверждено: HTTP/2 работает поверх TCP, не UDP — переход на UDP произошёл позже, в HTTP/3, RFC 9114, 2022 год, поверх протокола QUIC. Мультиплексирование в варианте А — реальная ключевая черта HTTP/2. Вариант Б смешивает реальный факт, RFC 7540 и 2015 год, с придуманным техническим утверждением, которое неспециалисту может показаться правдоподобным — классический паттерн: синтаксически и стилистически безупречная неправда.

Что бы вы проверили первым? Ожидаемое направление — проверка номера RFC на ietf.org.
