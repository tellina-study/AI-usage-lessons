# Тело: пять шагов и команды этого репозитория

## Assertion

Тело без литеральных команд не решает задачу, а переносит её: угадывание переезжает из файла инструкций внутрь скилла.

## Visual

```
наивное тело — годный текст, скилл сработает:

1. Собрать проект.
2. Прогнать тесты.
3. Опубликовать.
4. Проверить, что всё работает.

чем собирать — npm run build? vite build? make? — не сказано.
задача угадывания не решена, а переехала внутрь скилла
```

```
рабочее тело — пять шагов, у каждого названо действие целиком:

1. Собрать: npm run build — код выхода должен быть 0.
2. Проверить форму: npx playwright test — должно быть зелёным.
3. Опубликовать: wrangler pages deploy dist --project-name signup-landing.
4. Открыть адрес на проде, вручную отправить форму с верными данными —
   заявка должна дойти.
5. Записать в .tasks/active/ГГГГ-ММ-ДД-описание.md: что выложено,
   когда и какой командой.
```

> Официальное правило с другой стороны: не предлагать несколько способов без необходимости. Не «можно этим, а можно тем», а ровно один — тот, что в этом репозитории действительно работает. Шагов пять, литеральных команд три: четвёртый и пятый шаг исполняются руками, и выдуманной команды у них нет.

## Speaker notes

Описание решает, откроется ли файл. Тело решает, что произойдёт после.

Первая карточка — наивный вариант, и он коварнее, чем кажется. Текст годный, скилл сработает, пункты по-русски осмысленные. Дефект в том, чего в нём нет: чем именно собирать. Тем, этим или третьим — не сказано. Модель угадает заново или возьмёт устаревшую команду. То есть задачу угадывания мы не решили, а перенесли из файла инструкций внутрь скилла, где её труднее заметить.

Вторая карточка — рабочее тело. Пять шагов, и у каждого названо действие целиком, а не намерение. Сборка — вот команда и вот ожидаемый код выхода. Проверка формы — вот команда и вот критерий «зелёное». Публикация — команда с именем проекта, потому что без имени она не та.

Честно про арифметику: шагов пять, литеральных команд три. Четвёртый шаг — руками открыть адрес и отправить форму, пятый — записать, что выложено. Команды у них нет, и придумывать её незачем.

Правило внизу — с другой стороны, и оно про соблазн быть полным: не предлагать несколько способов без необходимости. Один способ, тот, что в этом репозитории работает.
