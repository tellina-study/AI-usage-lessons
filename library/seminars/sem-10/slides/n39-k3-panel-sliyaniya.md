# Настоящая панель: код узла слияния

## Assertion

Слияние — тринадцать строк кода без единого обращения к модели: формула Reciprocal Rank Fusion, k=60.

## Visual

> Строка 8 — вся идея узла: `rrf(d.keyword_rank, d.vector_rank, 60)`. Два уже готовых списка складываются в один по правилу «чем выше документ в обоих списках, тем выше в объединённом».

## Speaker notes

Это настоящая панель настройки узла слияния, в развёрнутом виде редактора — весь код виден целиком, ни одна строка не обрезана серединой.

Сердце узла — функция `rrf`, строки со второй по седьмую. Она берёт два списка документов, уже отсортированных каждый по своему критерию, и присваивает каждому документу очко: единица, делённая на сумму константы `k` (здесь — шестьдесят) и позиции документа в списке. Если документ встречается в обоих списках — а это обычное дело, оба способа поиска смотрят на один и тот же корпус, — его очки от обоих списков складываются. Чем выше документ в обоих ранжированиях, тем больше у него суммарных очков, и тем выше он окажется в объединённом списке.

Строка восемь — это и есть вся идея узла в одну строку: `rrf(d.keyword_rank, d.vector_rank, 60)`. `d.keyword_rank` и `d.vector_rank` — это два списка, которые уже посчитали предыдущие узлы холста, тот самый поиск по словам и поиск по смыслу, которые мы только что видели. Шестьдесят — константа `k` из формулы: число, подобранное так, чтобы позиция документа в начале списка значила заметно больше, чем в конце, но без резких скачков.

Строки девять-двенадцать берут первые десять документов объединённого рейтинга — ровно столько, сколько дальше увидит необязательный узел реранка, — и подставляют к каждому id его полный текст из корпуса, который форма держала при себе с самого начала холста. Последняя строка упаковывает результат — сам объединённый ранг, список из десяти id и их текст — и передаёт дальше.

Обратите внимание на то, чего в этом коде совсем нет: ни одного вызова HTTP, ни одного обращения к OpenRouter. Reciprocal Rank Fusion — классическая, не-ИИ формула, и именно это делает её бесплатной: она ничего не стоит и не добавляет задержки сверх самого исполнения кода. Два единственных числа, которые здесь решает сам код, без единого вызова модели, — это `k=60`, сглаживающая константа самой формулы, и `TOP_N=10` — сколько кандидатов из объединённого списка передать дальше, тому самому необязательному узлу реранка. Как устроен он — следующей панелью.
