# Кейс D. Поиск по картинкам

## Assertion

По чему искать фотографию: по тому, что про неё записали, — или по ней самой?

## Visual

> **По чему искать фотографию: по тому, что про неё записали, — или по ней самой?**

## Speaker notes

Три предыдущих кейса этого занятия разными способами отвечали на один вопрос: чем и как описать картинку, чтобы по записи можно было её найти. Документы читала модель-зрение и OCR, фотографии получали рассказ, поля по схеме и теги общим детектором, запрещённое искали нулевым выстрелом. В каждом случае результатом было ОПИСАНИЕ — текст, поля, метка.

Этот кейс берёт готовые описания и спрашивает: а работает ли поиск по ним? Архив фотографий учебного центра уже размечен — рассказом модели, структурными полями. Но описание и возможность найти по нему — не одно и то же. Можно описать фотографию подробно и всё равно не найти её по правильному запросу, если слова не совпали. А можно обойтись вовсе без описания — искать по самой картинке, сравнивая, что на ней видно, с тем, что спрашивают.

Отсюда вопрос дивайдера: искать по записи о фотографии или по самой фотографии? У обоих подходов есть цена, и у обоих есть случаи, где они проигрывают сопернику с разгромным счётом. Разница между этими двумя путями не абстрактная: подпись словами превращает поиск по картинке в задачу, которую уже умеют решать текстовые базы предыдущих занятий, — а поиск по самой картинке требует другой модели и другого устройства сравнения, и выигрывает именно там, где подпись промолчала.

Следующий кадр показывает, зачем этот выбор понадобился конкретному человеку — Ольге, которая всё это занятие ведёт архив учебного центра, — а не абстрактному инженеру, рассуждающему о поиске в вакууме. Цена нерешённого вопроса для неё не теоретическая: архив растёт, и без поиска каждый новый запрос превращается в ручной просмотр всего, что уже накоплено.

Дальше — вопрос залу: три способа искать, и у каждого есть настоящий довод за него, прежде чем вскрыть, какой из них на какой вопрос отвечает лучше. Ни один из трёх не назван слабым заранее — весь смысл сегодняшнего разбора в том, что победитель меняется вместе с тем, что именно спрашивают у архива.
