# Готовый файл — по тем же пяти частям

## Assertion

Собранный барьер — одна запись в файле настроек, и каждая её часть ложится на свой блок структуры: событие, матчер, четыре шага команды, ответ и таймаут.

## Visual

```json
  ┌─ [2] событие
  "PreToolUse": [ {
  ├─ [2] матчер
    "matcher": "Bash",
    "hooks": [ { "type": "command", "command":

  ├─ [3] шаг 1 — достать команду из описания вызова
      jq -r '.tool_input.command' | { read -r cmd;
  ├─ [3] шаг 2 — это вообще коммит?
      if echo "$cmd" | grep -qE '(^|[;&|]\s*)git\s+commit\b'; then
  ├─ [3] шаг 3 — а репозиторий тут есть?
        if ! git rev-parse --is-inside-work-tree >/dev/null 2>&1; then
  ├─ [4] ответ 1 — репозитория нет: спросить человека
          echo '{… "permissionDecision":"ask" …}'; exit 0; fi
  ├─ [3] шаг 4 — какая сейчас ветка?
        branch=$(git symbolic-ref --short HEAD 2>/dev/null)
  ├─ [4] ответ 2 — ветка защищённая: запретить
        if [ "$branch" = "main" ] || [ "$branch" = "master" ]; then
          echo '{… "permissionDecision":"deny" …}'; exit 0; fi; fi; },
  └─ [1] таймаут
    "timeout": 10 } ] } ]
```

> Файл целиком: `github.com/tellina-study/signup-landing-demo`, ветка `seminar-5-hook`. Склонируйте — барьер уже стоит, ставить ничего не надо.

> На пустом репозитории без коммитов: `git rev-parse --abbrev-ref HEAD` → код **128**. `git symbolic-ref --short HEAD` → ветка и код **0**. Тот же репозиторий, обе подряд.

## Speaker notes

Тот же файл, что вы сейчас спроектировали, — слева номера частей с предыдущей карты.

Событие и матчер — две верхние строки. Дальше четыре шага команды, это третья часть: достать команду из описания вызова, проверить, что это коммит, проверить, что репозиторий есть, узнать ветку. Каждая строка делает ровно одно.

Два ответа — четвёртая часть. Репозитория нет — спрашиваем человека. Ветка защищённая — запрещаем. Тексты причин сокращены, целиком они будут во втором кейсе.

Таймаут снизу: десять секунд вместо шестисот по умолчанию. Зачем урезали в шестьдесят раз — в третьем кейсе.

Адрес под кодом: склонируйте и запустите самотест, в свежем клоне барьер работает сам.

Сноска важнее, чем выглядит. Привычная команда определения ветки на репозитории без коммитов падает с кодом сто двадцать восемь, менее привычная отдаёт ветку и ноль. Упавшая проверка ничего не блокирует — она просто не срабатывает, и снаружи выглядит как пройденная.
