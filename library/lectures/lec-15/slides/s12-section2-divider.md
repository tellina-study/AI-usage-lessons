# Раздел 2

# Experiment: самый сильный успех AI в науке нобелевского уровня — и его трещины

## Что будет в разделе

AlphaFold 2 → 3 + Нобель 2024 + Recursion-Roche каскадный эффект.

AlphaFold DB 200M+ структур + open-source debate + Boltz-1.

## Главная мысль

AI в фазе Experiment работает потому, что задачи здесь часто принадлежат закрытому миру. Пространство возможных решений описано через физические уравнения — квантовая механика для катализа, гидродинамика для погоды, теория графов для математики. Проверка результата возможна в той же системе. Но успех нобелевского уровня не означает финальности нобелевского уровня — у каждого подраздела есть свои трещины.
