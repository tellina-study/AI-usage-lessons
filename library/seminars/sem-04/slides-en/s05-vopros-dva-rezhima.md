# Two modes — a self-diagnosis

## Assertion

When setting an agent up in a new repository, everyone works in one of two modes — put the baseline in place right away, or wait for a real problem.

## Visual

At the top — a short link line: "A quick read of the room before we go further."

The question verbatim, in a gold frame:

> "When you set a new agent up in a new repository — which of the two modes is usually closer to you?"

Two option cards:

| Card | Title | Examples under the card |
|---|---|---|
| A | "I put the baseline in place right away" | readiness gate ("what counts as done") · tracking of tasks and decisions |
| B | "I wait until it hurts" | repository overview · nested convention files · complex, multi-level memory |

There is no breakdown table on the slide and no highlighting of the "right" option — their place is on the next slide.

## Speaker notes

Two voices; the answers are stated aloud and left without comment: the breakdown comes with the next slide.

Fallback wording if the room stays silent: "Put another way: here is a list — a readiness gate, a decision log, a repository overview, nested files, complex memory. Which of these do you set up on the first day, and which do you defer until there is a real problem?"
