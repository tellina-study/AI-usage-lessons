## Speaker notes

"AI slop" and homogenization are a clear critique of the last two years. Nielsen Norman Group states it plainly: UI still matters, but it will become a less significant differentiator, because anyone will be able to produce a decent-looking interface. The mechanism of homogenization: generators are trained on one corpus of existing UI patterns, so many independent teams prompting "a modern dashboard" converge on a visually similar result.

Accessibility gaps — with a hard number. An academic study ran twenty-one thousand eight hundred eighty WCAG accessibility evaluations against interfaces generated by AI tools and found only twenty-nine point zero percent conformance. The worst scores were on the most basic criteria: color contrast and use of color. An important finding: the platform's own design influenced final accessibility more than user prompts did — asking to "make it accessible" was not guaranteed to fix it. This directly refutes the naive defense of "you just need to ask the AI correctly."

A key addition for this audience — designing for non-deterministic output. Classical UX assumes a deterministic system: the same input produces the same output. AI products break this assumption — the same input can produce different output across different runs, which requires new patterns: graceful failure, co-creation, accountable autonomy. What stays from the classic: "empathize first" design thinking, Nielsen's heuristics as a fast expert gate review, and real usability testing — the antidote to hallucinated "best practices," because testing measures real human confusion. When this isn't AI-first: a product aimed at the emotional attachment of vulnerable users, or one that automates a decision about people, requires an explicit safety review in the MVP, not polish after the fact.
