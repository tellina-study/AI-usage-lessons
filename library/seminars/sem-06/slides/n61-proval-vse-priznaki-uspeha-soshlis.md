## Speaker notes

Этот курс собирают так же — несколькими сессиями разом, в одной рабочей копии. Три случая из его журнала.

Первый. Шесть сессий правили одну деку в одном каталоге. Соседняя сборка переписала входной файл в тот момент, когда его читал конвертер. Код возврата ноль, построчно «отрисован слайд сорок четыре … пятьдесят», «PDF скопирован», число страниц верное — и все пятьдесят четыре страницы из пятидесяти четырёх пустые, файл похудел с шести с лишним до двух с половиной мегабайт. Поймали сравнением времён: вход оказался новее выхода.

Второй. Две сессии правили один файл сборки, и чтение попало в середину чужой записи. Сборка упала с жалобой на имя, которого «нет», — строка объявления в файле была. Через полминуты та же сборка прошла без правок.

Третий. Лекцию собирали параллельно с другой в одном каталоге, и ветку переключали из обеих сессий: больше семи переключений за сессию, около двух часов на восстановление. После перехода на отдельные копии — три, затем четыре параллельные сборки без единого столкновения.

Все привычные признаки успеха сошлись. Правду показал только сам результат.

**Справка.**

*Если спросят, чем это кончилось в правилах курса.* Отдельная копия на сессию стала обязательной, и это записано в инструкции репозитория вместе с причиной. Отсюда же взялся второй обход — не трогать общий файл вовсе: собирать свой набор страниц в своём каталоге, и тогда чужая сборка ваш вход переписать не может.

*Если спросят, почему пустой PDF не поймали раньше.* Потому что искали поломку в своих слайдах: страницы белые, значит сломал тот, кто правил последним. Признак, по которому это опознаётся, вообще не в содержимом — он во времени правки входного файла.

*Если спросят, при чём здесь роли, если во всех трёх случаях сессии.* Ломается общий каталог, и ему безразлично, кто в нём работает. Для ролей разница одна: своей копии у них по умолчанию нет вовсе, поэтому выбора между копией и зонами там не возникает.

*Если прозвучит «значит, параллельно работать нельзя».* Параллельно работали и продолжают: четыре сборки разом на отдельных копиях прошли без столкновений. Запретить пришлось общий каталог под ней.

*Если спросят, как вообще заметили второй случай.* Случайно: та же сборка через полминуты прошла без правок. Ошибка, исчезающая сама, — признак того, что читали состояние, которое кто-то в этот момент менял.
