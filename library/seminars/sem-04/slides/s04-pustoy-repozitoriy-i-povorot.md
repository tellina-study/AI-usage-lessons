# Пустая директория, задача через спеку, ни одного вопроса

## Assertion

Репозиторий буквально пуст, задача передана через спеку, а агент не задал ни одного уточняющего вопроса — и то, чего spec.md по определению не покрывает, структуру репозитория, решил за вас молча.

## Visual

Верхний ярус. Слева — реальный захваченный вывод:

```
$ ls -la signup-landing/
total 8
drwxr-xr-x 2 harness harness 4096 Sep 20 12:45 .
drwxr-xr-x 3 harness harness 4096 Sep 20 12:45 ..
```

Справа — постановка задачи дословно, по содержанию совпадающая с функциональной частью `spec.md`:

> «собери лендинг с формой заявки на демо-урок: статическая HTML-страница, сборка Vite (`npm run build` → `dist/`), поля формы — имя и email, тест на Playwright, который проверяет, что форма не отправляется с пустыми обязательными полями (`tests/form.spec.ts`)»

Средний ярус — дословная цитата из захваченного диалога, крупно, в gold-рамке, с явной конкретикой поворота вторым предложением:

> «Уточняющий вопрос не задавался. Все параметры задачи… были однозначно выводимы из текста задачи, поэтому работа была начата сразу, без уточнений.» Но о структуре — как назвать файлы, куда их положить, как разложить проект — агент не спросил тоже: spec.md по определению это не описывает, это устройство кода, а не требование к продукту.

Нижний ярус. Слева — что он создал:

```
index.html
src/main.js
package.json
tests/form.spec.ts
# + spec.md, README.md (раздел 0) — агент их не создавал
```

Пометка последней строкой (Fix 5, round-6 QA) — не строка реального захвата
`36-first-task-dialogue.md` (его не трогаем), а явное уточнение: `spec.md`/`README.md` уже
существуют в репозитории с раздела 0 (слайд 0.3), агент их не создавал, поэтому их нет в
списке «что создал» — но они никуда не делись.

Справа — блок команд из его же финального ответа:

```
npm install
npm run build          # → dist/
npm run test:e2e       # playwright test
```

## Speaker notes

«Вот тот же самый пустой каталог — реальный вывод команды, ничего не постановочно. И вот текст, который реально получил агент в этом демо-репозитории. По содержанию это ровно функциональная часть нашей spec.md — та же информация, что мы только что зафиксировали письменно.

Агент не задал ни одного уточняющего вопроса. Собрал index.html, src/main.js, package.json, тест — сам прописал скрипты сборки и теста, сам разложил файлы по папкам. Его собственные слова: "все параметры задачи были однозначно выводимы из текста, поэтому работа была начата сразу, без уточнений".

Заметьте, о чём он не спросил. Не о критерии приёмки — тот в нашей spec.md уже есть. О структуре: как назвать файлы, куда их положить, как разложить проект. Спека по определению не обязана это описывать — это не требование к продукту, это устройство кода. И агент решил это сам, молча, без единого вопроса.»

Мысль, которую надо оставить в зале: «Агент не спросил про структуру репозитория — а нужно ли было писать это заранее в файл инструкций? Это первый настоящий кейс сегодняшнего занятия.»
