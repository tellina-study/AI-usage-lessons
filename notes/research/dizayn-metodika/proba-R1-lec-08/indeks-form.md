# Индекс форм каталога (№ 1–33)

Механическая выжимка четырёх частей сведённого каталога форм. Числа бюджета — пересчитанные
под пол кегля 15 пт (столбец «Стало» в каждой форме каталога), если пересчёт дан; где форма
не несёт текстового слота с числом знаков (ограничение по счёту элементов, по обязательности
или геометрии) — отмечено явно.

формы: у каждой из 33 форм минимум один слот несёт число знаков в пересчёте под пол 15 пт.

## §0 первой части: правила, общие для всех форм

Из `02-KATALOG-FORM.md` §0 «Метод пересчёта бюджета знаков» (решение владельца 2026-10-29 о
подъёме пола кегля видимого слоя с 12,0 до 15,0 пт, рост на 25%; рабочая область кадра и сетка
не меняются — 864 × 492 пт, 12 колонок по 72 пт):

1. **Ширина знака — измерено, не взято на веру.** Отрисована проба кириллического текста
   (смешанный регистр, с пробелами, шесть строк по 28–36 знаков) на кегле 15 пт в гротеске,
   метрически совместимом с Arial/Helvetica. Фактическая ширина: **9,09 пт/знак** в среднем
   (разброс 8,69–9,13 пт). Для расчёта взято **9,0 пт/знак**. Отношение к кеглю — 0,60 (не
   0,48–0,55, названное постановкой задачи как оценка для гротеска вообще — разница объясняется
   тем, что измеренный cap-height кириллицы 0,733 кегля больше, чем у латиницы, 0,70).
2. **Ширина слота — по сетке, не по ощущению.** Восемь стандартных классов ширины, кратных
   колонке (72 пт): во всю ширину (12 кол., 864 пт, 96 знаков/строка), три четверти (9, 648, 72),
   две трети (8, 576, 64), половина (6, 432, 48), треть (4, 288, 32), четверть (3, 216, 24),
   шестая (2, 144, 16), двенадцатая (1, 72, 8). Слот «в ряд из N» получает ширину 864/N, и N
   берётся худшим (наибольшим) из диапазона, который форма сама разрешает, а не средним.
3. **Число строк — верхняя граница диапазона, который называет сама форма** («2–3 строки» →
   считать 3); если форма не называет число строк для однострочной подписи-ярлыка — считать 1
   строку. Без отдельной поправки на межстрочие (оно меняет высоту блока, не число знаков в
   строке).
4. **Формула:** `бюджет = (ширина_пт / 9,0) × строк`, округление вниз до целого знака.
5. **Чтение результата.** Уменьшение бюджета относительно прежнего числа — не само по себе
   дефект (рост кегля на 25% при почти неизменной ширине кадра сам по себе срезает ёмкость строки
   процентов на 20). Порог тревоги — **новый бюджет меньше прежнего больше чем вдвое** (помечается
   у формы «требует пересмотра состава»); отдельная, более острая проверка — **влезает ли в новый
   бюджет реальный образец**, который форма сама приводит для этого слота; несовпадение названо
   явно у каждой такой формы (№ 2, 9, 19, 21, 22, 24, 26, 28, 29, 32, 33 — где состав указывает на
   конкретный образец и сравнивает его длину с новым бюджетом).

## Разряды утверждений А–Д

Отдельной сводной таблицы-легенды «что означает каждая буква» в частях № 1–4 каталога нет — коды
вводятся в части 1 отсылкой «Вид содержания указан по кодам из `SVEDENIE-KATALOGOV.md` §3:
А/Б/В/Г/Д» (файл `SVEDENIE-KATALOGOV.md` не входит в читаемые четыре части этой задачи). Значение
каждой буквы ниже восстановлено из повторяющихся глосс в поле «Вид:» самих форм (дословные
формулировки каталога):

- **А** — «разбор случая» (развёрнутая форма у № 5: «разбор случая с ценой ошибки и сравнением
  режимов»).
- **Б** — «величина с базой».
- **В** — «порядок/процесс».
- **Г** — «противопоставление работает/не работает» (чистая форма — у № 13).
- **Д** — «одно число как результат».

Вне этой лестницы каталог называет два отдельных класса: **«универсальный»** (№ 24, плашка-вывод
— «накладывается на любую форму как завершающий слот кадра») и **«служебная»** (№ 30, обложка —
«не кодирует содержание, открывает кадр/лекцию»).
