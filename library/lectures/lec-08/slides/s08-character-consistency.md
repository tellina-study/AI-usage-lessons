# Сохранение персонажа: cameos и Omni Reference

## Assertion

Сохранение персонажа: Sora 2 cameos + Midjourney Omni Reference + Runway Director Mode — multi-scene narrative стал возможен.

## Visual

Сверху assertion 26pt. Слева — 3 Ocean rounded boxes столбиком: Sora 2 cameos (Disney 1B+ deal), Midjourney Omni Reference (v7 — 60% → 85%+ accuracy), Runway Director Mode (скриптинг между сценами). Справа — крупная backup-картинка сохранение персонажа между генерациями demo grid (4 кадра одного персонажа из Midjourney showcase). Внизу — gold-tint мини-провал блок: «Но drift между сценами после 5-10 сцен. Континьюити-супервайзер — новая профессия творческого pipeline».

## Speaker notes

Одна из самых заметных возможность-улучшений 2024-2026 — сохранение персонажа между генерациями, способность сохранять визуальные характеристики персонажа через множественные генерации. Это критическая возможность для нарратива: без неё AI-video нельзя использовать для multi-scene story. Sora 2 cameos: механизм — пользователь регистрирует «cameo» с определёнными визуальными атрибутами; в последующих video-промптах cameo вызывается по имени, и модель воспроизводит его консистентно. OpenAI заявило о партнёрстве с Disney на миллиард долларов и более для licensed character generation: Disney IP-character'ы могут официально появляться в AI-сгенерированных видео под лицензией Disney. Midjourney Omni Reference в v7: один reference-image персонажа используется в последующих промптах для сохранения пропорций лица, одежды, посадки. По заявлению Midjourney, character preservation accuracy выросла с примерно шестидесяти процентов в v6 до выше восьмидесяти пяти в v7. Runway Gen-4 Director Mode — полноценный скриптинг между сценами: пользователь определяет character'ов, locations, motion patterns как структурированные объекты. Anti-hype для этой возможность: сохранение персонажа между генерациями работает значительно лучше, чем в 2023 году, но multi-scene narrative всё ещё имеет drift. После пяти-десяти сцен мелкие детали — татуировка, шрам, оттенок волос — могут изменяться. Использование промышленного качества требует континьюити-супервайзера, человека, который проверяет каждую сцену на consistency. Это новая профессия — мы вернёмся к ней в разделе про новые роли.
