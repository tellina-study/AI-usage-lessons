## E1. `[схема] s49_1` закрыт переадресацией, а не отменой сторожа

`s49_1` — вторая половина разрезанного Этапом C разбора: на `s49` постановка опыта и схема
порядка чтения кардиограммы, здесь вскрытие. Схема у разреза одна по построению, и ставить её
дублем на вторую половину запрещено §5.12. Сторож `[схема]` при этом видел только своё поле и
требовал ровно того, что запрещено.

Заведено поле **`scheme_ref: <sid>`** (`build_lec07.check_scheme_refs`): кадр `type: case` без
своей `scheme` принимается, если названный кадр существует и несёт собственную схему. Проверка
не отменена, а **переадресована** — и проверяется целиком: битый ref даёт то же блокирующее
`[схема]` с уточнением, чем он битый (кадра нет · кадр есть, схемы на нём нет · ссылка на себя).
Ссылка, по которой ничего не лежит, хуже отсутствия поля: отсутствие видно, а мёртвая ссылка
читается как сделанная работа.

Ref проверяется ПОСЛЕ прогона по всем собранным кадрам, иначе кадр, стоящий раньше своей цели,
судился бы по непрочитанной половине. На частичной сборке (`--only s49_1`), где цель в пакет не
попала, ref резолвится по файлу на диске — своим чтением фронтматтера, не через
`slidefile.read_slide`, иначе кадр-цель получил бы свои `[ссылка]`/`[файл]` второй раз.

**Доказано поломкой** — проба `[отсылка схемы]` в `selftest_lec07.py`, четыре входа на один
механизм: живой ref обязан МОЛЧАТЬ (молчит), три битых обязаны сработать (срабатывают все три).
Ссылающийся кадр стоит в каталоге пробы ПЕРЕД целью нарочно — проба ловит именно отложенность
проверки.

## E2. Минутный счёт: честного −1 минуты нет, и вот чем это измерено

**Заказ был: найти −1 минуту пере-замером кадров, которые Этапы A–D облегчили. Такого запаса в
деке нет, и числа ниже это показывают. Тайминги не занижены ни на одном кадре.**

Собственный переводчик деки (`pereschet_minut.py`) считает минуту кадра как **слова видимого
слоя ÷ 122**, где 122 — медиана деки на момент, когда переводчик заводили. Пере-замер нынешней
деки по свежему PDF (прогон `zamer_minut_po_pdf.py`, заведён этим этапом) даёт:

| | значение |
|---|---:|
| объявлено по файлам кадров | **81,65 мин** |
| замер по собранному PDF при 122 словах в минуту | **103,00 мин** |
| медиана деки сейчас, слов на объявленную минуту | **154** |

То есть **дека объявлена на 21 минуту ЛЕГЧЕ**, чем её же переводчик считает по весу кадров.
Пересчёт при нынешней медиане (154) сумму не меняет по построению — он её перераспределяет;
пересчёт при 122 поднимает её до 103. Снять минуту «пере-замером» можно было бы только выбрав
те кадры, где замер ниже объявленного, и промолчав про те, где выше, — это и есть занижение ради
отчёта, прямо запрещённое нарядом.

**Кадры, которые Этапы A–D действительно облегчили, проверены поимённо** (Этап D снимал строки с
видимого слоя `s27a`, `s33`, `s31`, `s05`, `s49b`, `s105`, `s20b`, `s97` и тайминга не трогал).
Замер по свежему PDF: `s33` объявлен 0,75 при весе 1,55 · `s31` 1,65 при 1,65 · `s27a` 1,30 при
1,25 · `s05` 1,15 при 1,25 · `s97` 1,05 при 1,40 · `s20b` 0,80 при 0,90. Ниже объявленного
оказались двое — `s49b` (2,15 при 1,65) и `s105` (1,00 при 0,95), и оба несут длинные разборы,
которые лектор проговаривает дольше, чем весит их текст. Опускать их объявление значило бы
подогнать число под отчёт.

**Счёт сходится во всех трёх местах** (§9): сумма по фронтматтеру кадров = сумма по разделам
