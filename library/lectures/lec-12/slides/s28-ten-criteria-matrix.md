## Speaker notes

Десять структурных критериев — центральный результат лекции для LO7. Каждый критерий — это структурное ограничение, не «иногда AI не работает». Каждая альтернатива — это инструмент, который доказывает себя десятилетиями.

Один. Критичный по безопасности контур (аварийный останов, блокировки, аварийное отключение). Альтернатива: проводной PLC плюс IEC 61508 SIL 2/3 плюс формальная верификация. RL не сертифицируется.

Два. Процесс с известной физикой (контур регулирования температуры печи, расход реагентов). Альтернатива: модельное предиктивное управление (MPC). Доказуемые гарантии устойчивости.

Три. Редкое событие с MTBF больше года, выборка отказов меньше 30. Альтернатива: физическая симуляция плюс RCM — методология Nowlan-Heap 1978.

Четыре. Поиск дефектов нестабильного процесса. Каскад ложных срабатываний превышает экономию. Альтернатива: пересмотр процесса перед применением vision AI.

Пять. Жёсткие допуски ±0,001 мм. Альтернатива: метрология + GD&T + SPC.

Шесть. Универсальная генерация PLC-кода. Альтернатива: специализированный инструмент с инженером в петле или инженер + симулятор + IEC 61131-3.

Семь. Регулируемая среда без объяснимости (FDA 21 CFR Part 11, GAMP 5). Альтернатива: объяснимый ИИ (SHAP / LIME) + правила + журнал аудита. Чёрный ящик ML не принимается.

Восемь. ATEX Zone 0 — взрывоопасная среда. Альтернатива: ATEX-сертифицированные датчики + удалённая обработка. Физический регуляторный запрет.

Девять. Стоимость AI больше стоимости ошибки человека. Альтернатива: не внедрять; обучение оператора.

Десять. Отсутствие чёткого сценария применения (аудит слоя данных не пройден). Альтернатива: аудит слоя данных + устранение замечаний ДО любого пилота.

Бонус: Gartner — к 2027 году 40% агентных AI-проектов отменены. Задайте вендору пять вопросов из s31.
