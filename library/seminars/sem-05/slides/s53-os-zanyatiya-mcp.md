# Решаем по сигналу, предотвращаем с нуля

## Assertion

Подключение сервера — решаем, по сигналу; дисциплина минимальных прав — предотвращаем, день 0, и никакого сигнала сверх факта создания токена не ждёт.

## Visual

> Интуиция говорила: одобрил один раз, права выдал — вопрос решён; зелёный статус значит «работает».
> Проверка показала: права вычёркиваются, а не выдаются; зелёный статус — утверждение о транспорте, не о работе.
> Одобрение не окончательно — 8 из 8 сокрытий доставили инструкцию модели, 0 из 8 спросили заново.

| Что | Режим | Когда |
|---|---|---|
| подключение сервера | решаем | по сигналу: повторяющаяся боль конкретного проекта |
| дисциплина минимальных прав | предотвращаем | день 0, сверх факта создания токена ничего не ждёт |

## Speaker notes

Строка в ось смешанная. Подключение — решаем, по сигналу. Дисциплина минимальных прав — предотвращаем, день ноль: она не ждёт ничего, кроме факта создания токена.

Последний блок дал агенту руки — он дотягивается до внешней системы. Чем больше он может сам, тем острее вопрос: роль повторяется из сессии в сессию — или её объясняют заново?
