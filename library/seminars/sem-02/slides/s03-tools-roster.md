# Шесть инструментов

## Assertion

Шесть инструментов — один и тот же вопрос: модель, чат, агент или приложение?

## Visual

Верхний gold-обведённый бар: иконки `hand` (GOLD) + `camera` (DEEP), текст «4 раунда поднятия руки на инструмент — один вариант за раз», ниже мелким «где голоса разойдутся — объясняем выбор вслух до официального ответа».

Ниже — вертикальный список из 6 строк (Ocean rounded box каждая), пронумерованных 1–6, с иконкой и названием инструмента слева, коротким описанием контекста справа: 1) YOLO-детектор (демо Лекции 1), 2) AI-чат для разовой консультации, 3) GitHub Copilot inline Tab-completion, 4) GitHub Copilot Agent-режим, 5) YandexGPT во врезке поиска, 6) агент для 200 PDF-отчётов.

## Speaker notes

Механику голосования вы уже знаете с прошлого семинара — рука, камера считает, YOLO выводит число сразу. Сегодня та же механика, но материал — не калибровка интуиции, а классификация с правильным ответом.

Шесть инструментов на экране. Для каждого — четыре последовательных раунда поднятия руки: модель, чат, агент, приложение — по одному варианту за раз. После каждого раунда называю результат вслух. Там, где голоса заметно разойдутся — вызываю одного-двух человек объяснить выбор до того, как назову официальный ответ.

Обратите внимание на пункты 3 и 4 — один и тот же продукт, GitHub Copilot, но в разных режимах. Не торопите эту пару, когда до неё дойдём — это ключевой момент раздела.
