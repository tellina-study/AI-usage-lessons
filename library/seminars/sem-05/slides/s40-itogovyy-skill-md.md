# SKILL.md целиком

## Assertion

Процедура переезжает целиком: сорок строк вырезаются из файла инструкций в тот же момент, когда появляется скилл.

## Visual

Слева — файл целиком:

```markdown
---
name: deploy
description: Деплоит лендинг signup-landing на прод — сборка, smoke-тест формы, публикация,
  проверка прод-URL. Используй, когда пользователь просит задеплоить, выкатить или опубликовать
  сайт — не для обычных правок кода без деплоя.
---

# deploy

1. Собрать: `npm run build` (код выхода должен быть 0).
2. Прогнать smoke-тест формы: `npx playwright test` (должен быть зелёным).
3. Опубликовать: `wrangler pages deploy dist --project-name signup-landing`.
4. Открыть прод-URL, вручную отправить форму с валидными данными — заявка должна дойти.
5. Записать в `Tasks/<date>_<slug>/log.md`, что задеплоено, когда и какой командой.
```

Справа сверху — дерево ступени 4, `.claude/skills/deploy/SKILL.md` выделен gold.

Справа снизу — плашка со стрелкой «переехало, а не скопировалось»: **сорок строк вырезаются из файла инструкций.**

## Speaker notes

Главное, что нужно сказать на этом слайде, — не про содержимое файла, а про то, что происходит одновременно с его появлением.

Сорок строк процедуры вырезаются из файла инструкций. Это не опция: если процедура осталась в двух местах, налог никуда не делся, а к нему добавился риск расхождения копий. Через месяц одна из версий обновится, а вторая нет, и агент прочитает обе.

Обратить внимание на пятый шаг тела: запись в журнал. Он единственный из пяти, который ещё не обсуждался, и он вернётся в последнем разделе как один из трёх артефактов дисциплины.

Дерево справа — четыре блока конфигурации. И все четыре по-прежнему файлы внутри проекта: правила, решения, барьер, процедура. Это стоит отметить вслух — следующая ступень будет первой, которая смотрит наружу.

Отдельно — шаг три, публикация: команда конкретная, с именем проекта. Это тот случай, когда команда в тексте оправдана: она не дублирует `package.json`, её там нет.

И короткая проверка на понимание, если зал идёт с опережением: спросить, почему описание в этом файле длиннее, чем любой из пяти шагов тела. Ответ уже прозвучал на предыдущем кадре — описание работает в каждой сессии, тело только в одной из десяти, — но услышать его от зала полезнее, чем повторить самому.
