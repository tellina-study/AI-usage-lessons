# Угадай температуру

## Assertion

Три ответа на один промпт — какой температуре какой соответствует?

## Visual

Верхний тег (не gold, SLATE фон, обязательная пометка): «Три ответа ниже написаны автором методического комплекта для иллюстрации — это не реальный вызов модели». Ниже строка с промптом: «Промпт (один и тот же для всех трёх): "Напиши короткое приветствие для email-рассылки студентам о начале нового курса"».

Ниже 3 равные Ocean rounded box карточки с текстом ответов (без подписи T, порядок перемешан, не по возрастанию): карточка 1 — «Уважаемые студенты! Рады сообщить вам о начале нового курса. Занятия начинаются согласно расписанию. Желаем успехов в обучении!»; карточка 2 — естественно разнообразный, но связный текст с конкретными деталями и живой интонацией; карточка 3 — рваный текст с неожиданными оборотами и почти бессвязными переходами, на грани распада связности. Каждая карточка помечена только нейтральной буквой (А/Б/В), не числом температуры.

Внизу нейтральная подсказка-полоса: «3 раунда — для каждого ответа: низкая / средняя / высокая температура?».

## Speaker notes

Вводная фраза, обязательна дословно по смыслу: три ответа ниже написаны автором методического комплекта для иллюстрации — это не реальный вызов модели. Формат и стиль подобраны так, чтобы реалистично имитировать типичное поведение LLM при разных значениях температуры.

Промпт один и тот же для всех трёх ответов: напиши короткое приветствие для email-рассылки студентам о начале нового курса. Показываем три ответа на слайде без подписи температуры, зачитываем вслух каждый.

Три раунда голосования — для каждого ответа студенты поднимают руку за то, какой температуре он соответствует: низкая, средняя или высокая. Порядок показа на слайдах перемешан, не по возрастанию температуры, чтобы не подсказывать.
