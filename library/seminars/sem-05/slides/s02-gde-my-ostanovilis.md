# Где мы остановились

## Assertion

Репозиторий на входе в занятие — рабочий прототип с продуктовым, конфигурационным и документационным слоями, но каталога `.claude/` в нём нет вовсе: ни хука, ни скилла, ни настроенного MCP-сервера.

## Visual

> «Двадцать строк инструкций, три раздела — и ни одного механизма, который бы их исполнял.»

```
README.md          spec.md            DECISIONS.md       ← что строим и почему
CLAUDE.md          AGENTS.md (симлинк на CLAUDE.md)      ← 20 строк, 16 непустых, 3 раздела
doc/adr/           шаблон + 3 ADR + README.md            ← как принимались решения
.tasks/            README.md · active/ · done/README.md  ← задачная память
index.html         package.json       package-lock.json
vite.config.js     playwright.config.ts
src/main.js        src/style.css      src/validate.js    ← продукт
tests/form.spec.ts tests/delivery.spec.ts
tests/page-objects/form.page.ts
.gitignore

.claude/  — НЕТ ВОВСЕ: ни хука, ни скилла, ни настроенного сервера, ни субагента
```

> «Всё это — текст. Агент может его учесть. Может и не учесть.»

## Speaker notes

Слои назвать вслух по порядку, показывая: что строим (README, спека, лог решений) · чем настроен агент (файл инструкций и симлинк) · как принимались решения (каталог решений, задачная память) · продукт и тесты.

Масштаб файла инструкций держать в голове: двадцать строк, шестнадцать непустых, три раздела. Читается за минуту.

Главное на этом слайде — не дерево, а последняя строка каталога: `.claude/` нет вовсе. Механического слоя не заведено вообще.

Дерево снято с репозитория напрямую — его можно склонировать и пересчитать построчно.

Замыкающую строку произнести дословно, она и есть мостик: «Всё это — текст. Агент может его учесть. Может и не учесть.»
