# Что говорят четыре источника

## Assertion

Четыре источника сходятся на одном: курированное, узкое описание-триггер поднимает успех задачи и защищает от деградации выбора, — а прямой экономики для кейса «один скилл про одну процедуру» ни один не измеряет.

## Visual

| Источник | Тезис | Сила доказательства |
|---|---|---|
| Официальная спецификация Agent Skills | Три уровня раскрытия: метаданные (имя+описание) ≈100 токенов всегда; тело <5000 токенов — только при совпадении описания с запросом; вложения — 0 токенов, пока не открыты | Сильное: документированная архитектура механизма |
| SkillsBench (87 задач, 8 доменов, 18 конфигураций) | Курированные скиллы: 33,9%→50,5% успешных прохождений на тех же задачах (+16,6 п.п.); узкие скиллы (≤3 модуля) обгоняют широкие наборы | Сильное: парный контролируемый эксперимент, единственная переменная — наличие курированного скилла |
| Skill Shadowing | Деградация успешности при росте библиотеки скиллов (до −21% при 202 скиллах) объясняется неверным выбором скилла, а не ростом стоимости контекста | Сильное: контролируемая декомпозиция эффекта на одном наборе задач |
| Agent Skills Can Be Harmful | 307 подтверждённых случаев вреда от скилла на тех же задачах без него; 68,8% функциональных провалов — от скиллов, казавшихся релевантными | Сильное: дифференциальный анализ (тот же прогон со скиллом и без него) |

**Честный пробел.** Ни один из источников не измеряет экономику конкретно на масштабе «маленький репозиторий, один скилл про одну процедуру» — цифры относятся либо к крупным бенчмаркам, либо к сканам целых каталогов.

## Speaker notes

Прежде чем разбирать голоса — что говорят источники, по силе доказательства, а не по порядку появления. Официальная спецификация Agent Skills документирует сам механизм послойного раскрытия — не гипотеза, а описанная архитектура. SkillsBench — контролируемый эксперимент на восьмидесяти семи задачах: курированные скиллы поднимают долю успеха с 33,9 до 50,5 процента, и узкие скиллы обгоняют широкие наборы. Skill Shadowing раскладывает деградацию библиотеки скиллов на два компонента и показывает: виноват неверный выбор, не рост стоимости контекста. Работа про вредные скиллы — дифференциальный анализ, тот же прогон со скиллом и без него. Честный пробел: ни один источник не измеряет экономику именно на масштабе «маленький репозиторий, один скилл про одну процедуру» — перенос общего принципа на наш кейс, не отдельное измерение.
