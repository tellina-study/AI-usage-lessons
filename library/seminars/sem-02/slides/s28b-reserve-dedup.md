# Дедупликация новостей

## Assertion

Дешёвый детерминированный фильтр закрывает основную массу случаев дублирования; ИИ нужен только на остаток, который фильтр не берёт.

## Visual

Постановка сверху: «Поток новостей из многих источников — нужно склеивать сообщения об одном и том же событии в одну карточку». Ниже — двухколоночный разбор. Левая колонка «Fuzzy-matching / shingling — основная масса (~90%)»: сравнение текстов по перекрывающимся фрагментам без обращения к модели, дёшево и предсказуемо. Правая колонка «LLM — только остаток»: случаи, где два сообщения об одном событии написаны разными словами почти без общих фрагментов текста (перефраз без лексического пересечения). Внизу урок: «сначала дешёвый детерминированный фильтр — ИИ на то, что он не взял».

## Speaker notes

Резервный quickfire — используется только при остатке времени, после основной лестницы резерва. Постановка: поток новостей из многих источников, нужно склеивать сообщения об одном и том же событии в одну карточку.

Ожидаемая интуиция зала: «нужно понимание смысла текста → LLM». Дайте залу минуту среагировать на постановку, прежде чем переходить к разбору.

Разбор: shingling и fuzzy-matching — методы near-duplicate detection, сравнение текстов по перекрывающимся фрагментам (n-граммам) без обращения к модели — закрывают порядка 90% случаев дублирования дешевле и предсказуемее, чем вызов модели на каждую пару новостей. LLM нужен только на оставшуюся часть — случаи, где два сообщения об одном и том же событии написаны разными словами и почти не имеют общих фрагментов текста, то есть перефраз без лексического пересечения.

Урок для явного проговаривания: сначала дешёвый детерминированный фильтр закрывает основную массу случаев, а ИИ применяется только к остатку, который фильтр не берёт. Проговорите явную связь: это тот же вопрос, что уже разбирался в разделе 1 на кейсе «Персоналка в логах» — там же граница между regex и NER/LLM проходила внутри одной задачи; здесь тот же принцип на новом материале.
