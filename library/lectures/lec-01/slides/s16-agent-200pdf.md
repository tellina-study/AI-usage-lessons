## Visible content

**Заголовок (assertion):**
Агент = чат + инструменты + планирование. Уровень автономии — ваше дизайн-решение, не свойство модели.

**Кейс-карта (слева):**
- **Кейс:** прошерстить **200 PDF** отчётов и собрать таблицу
- **Решение:** агент (многошаговая задача + внешние инструменты)
- **Цикл:** plan → act → observe → iterate

**Формула (Weng 2023):**
**Agent = LLM + Memory + Planning + Tools**

**Примеры:** Claude Code · Devin · OpenAI Operator · AutoGPT · CrewAI · Manus

**5 уровней автономии (справа, лесенка, Feng et al. 2025):**

| # | Роль пользователя | Пример |
|---|---|---|
| 1 | **Operator** — одобряет каждый шаг | Claude Code «approve each command» |
| 2 | **Collaborator** — работают совместно | парное программирование с Cursor |
| 3 | **Consultant** — корректирует план | Devin предлагает декомпозицию, вы правите |
| 4 | **Approver** — утверждает узлы | агент собирает PR, вы делаете merge |
| 5 | **Observer** — только наблюдает итог | AutoGPT на ночь → отчёт утром |

**Gold callout:** Уровень автономии = **design choice**, а не врождённое свойство модели.

## Speaker notes

Агент — следующий слой. К чату добавляются (а) внешние инструменты — возможность вызывать API, читать файлы, выполнять код, искать в интернете; (б) планирование — способность разложить задачу на шаги; (в) цикл act/observe — после каждого действия агент наблюдает результат и решает, что делать дальше.

Каноническая формулировка из Лилианы Венг: **Agent = LLM + Memory + Planning + Tool Use** (Weng, 2023). Google Whitepaper 2024 определяет агента через 3 компонента: Model + Tools + Orchestration Layer (ReAct, CoT, ToT).

Базовая статья по архитектуре ReAct — Yao et al. 2022: чередование reasoning trace («что я хочу сделать») и действия («вызываю такой-то инструмент с такими-то параметрами»), за которым следует наблюдение и новое рассуждение.

**Кейс 200 PDF**: многошаговая задача с инструментами (открыть, прочитать, извлечь, сложить в таблицу). Плохо подходит ни для модели (нет специализированной «возьми 200 PDF и сделай таблицу»), ни для чата (некомфортно копировать 200 файлов в окно). Агент — естественный выбор.

**5 уровней автономии (Feng, McDonald & Zhang 2025, arXiv:2506.12469)** — характеризуются **ролью пользователя**, не сложностью модели. Один и тот же агент в режиме «operator» и в режиме «observer» — это разные продукты с разными требованиями к надёжности, объяснимости и интерфейсу. На семинарах будем возвращаться к этой шкале, обсуждая выбор уровня под конкретный риск.

Источники: Weng 2023 (lilianweng.github.io); Yao et al. 2022 ReAct (arXiv:2210.03629); Schick et al. 2023 Toolformer; Feng, McDonald & Zhang 2025 (arXiv:2506.12469).
