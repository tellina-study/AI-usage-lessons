# Where Inside the Prompt Each of the Four Actions Acts

## Assertion

Three actions only rearrange what's already inside the prompt. The fourth changes its structure.

## Visual

> The prompt is built from three parts: an instruction, the knowledge-base list, the client's question. Three actions work INSIDE this structure -- the fourth builds a different one.

## Speaker notes

Before comparing the actions on price and on what the research shows, look at where each one physically happens inside one and the same prompt. The prompt is built from three parts in a row: an instruction to the process, the knowledge-base list, the client's question. This structure doesn't change for any of the four actions -- what changes is what happens inside it, or around it.

The first two actions are about position inside the list. Appending a new item to the end is the simplest: open the list, add a line. Moving frequently asked or critical items to one of the edges is a decision of the same kind, except now order becomes a parameter someone chooses and revisits. Both actions touch nothing but the order of the lines inside the same block.

The third action works with the client's question -- it repeats its text next to the list: before it, after it, or on both sides. The prompt's structure stays the same, but the client's question now appears in it twice. The idea behind it is simple: whatever sits in the middle of the list, the model will read the wording of the question right next to it and can match the words directly, instead of holding the question in memory across the whole knowledge base's text.

The fourth action is the only one that changes the structure itself. The knowledge-base list stops being part of the prompt at all: instead, only the one item found for the specific question makes it into the request. This isn't a rearrangement inside the old structure -- it's a different structure, and it brings a piece of the process none of the first three actions had: a separate store and a separate retrieval step.

Next is the table: how each of the four actions works, what it gives you, what it costs, and what the research shows about that effect. But keep in mind the layout you just saw: it's exactly why the fourth action's price and limits are of a completely different kind than the first three's. The first three change the order inside the same text field -- whoever set that order can fix it. The fourth changes the process's architecture itself, and its price is no longer counted in words of the prompt but in nodes that have to be built and maintained.
