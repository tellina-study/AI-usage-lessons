# Кейс 3

## Assertion

Разовый отчёт о продажах — для одной встречи, один раз.

## Visual

Крупная Ocean rounded box карточка. Сверху — chip «КЕЙС 3» (MID fill). Иконка `trending-up` (96px, MID) слева. Текст курсивом справа: «Аналитику компании нужно один раз проанализировать выгрузку продаж за квартал — для встречи с руководством на следующей неделе. Результат в таком виде больше не понадобится: после встречи выгрузка и отчёт по ней теряют актуальность до следующего квартала, когда данные и вопросы руководства, скорее всего, будут другими» — слова «один раз» выделены bold TEAL внутри текста.

Снизу gold-подчёркнутая строка-вопрос: «Какую ступень лестницы вы выберете?»

## Speaker notes

Аналитику компании нужно один раз проанализировать выгрузку продаж за квартал — для встречи с руководством на следующей неделе. Результат в таком виде больше не понадобится: после встречи выгрузка и отчёт по ней теряют актуальность до следующего квартала, когда данные и вопросы руководства, скорее всего, будут другими.

Обратите внимание на слово «один раз» в постановке — оно важно для одного из четырёх критериев.
