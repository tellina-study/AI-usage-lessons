# Фотографии — Adidas Speedfactory (закрытая фабрика, закрыта 2019)

Кейс: автоматизированная фабрика обуви Adidas Speedfactory (Ansbach, Германия, партнёр-оператор
Oechsler Motion). Открыта 2015-2016, производство остановлено в 2019, закрытие завершено к апрелю
2020. Фабрика закрыта → часть источников живёт только в Wayback Machine; протокол 6-tier применён
без mock-fallback.

Нужны три категории: (а) здание снаружи, (б) роботизированное оборудование внутри, (в) готовая
обувь со Speedfactory.

## (а) Здание снаружи

**Источник:** `https://moezer.de/project/oechsler-ansbach-speedfactory/` — страница портфолио
строительной компании Moezer GmbH, которая вела стройку корпуса Oechsler в Ансбахе (2015-2016,
по их собственной подписи к проекту). Прямой доступ без блокировок, HTTP 200.

- Страница отдаёт превью `-510x382`, но у файлов нашлись полноразмерные оригиналы без суффикса
  thumbnail (сняли суффикс `-510x382` → `IMG_4751-1-webp.webp` 1920×1280 и
  `Oechsler_IMG_4746-1-webp.webp` 1921×697). Оба скачаны напрямую с moezer.de, не через Wayback.
- `adidas-speedfactory-building-exterior.jpg` (бывш. `IMG_4751-1-webp.webp`, 1920×1280): фасад
  трёхэтажного белого офисного блока, флаги (местный клуб · Бавария · Германия), фургон Muhr,
  стоянка. **На кадре виден логотип adidas над входной дверью** — прямое визуальное подтверждение,
  что это тот самый корпус (Oechsler Motion = производственный партнёр, вывеска «OECHSLER Motion»
  видна в правой части кадра на торце здания). Это совпадает с описанием из прессы 2016-2019 гг.
  («nondescript white building bearing Oechsler's name», подтверждено независимым WebSearch-сводом
  до загрузки фото).
- `adidas-speedfactory-building-exterior-wide.jpg` (бывш. `Oechsler_IMG_4746-1-webp.webp`,
  1921×697, панорама): тот же корпус целиком, с другого угла, вывеска «OECHSLER Motion» крупно
  читается. Запасной широкоформатный ракурс — на случай, если на слайде нужен full-bleed hero.
- Конвертация: WebP → JPEG через Pillow (`PIL.Image.save(quality=90-92)`), без потери содержимого,
  только контейнер.

**Gap, честно:** ни одна официальная adidas-фотография именно экстерьера здания 2016 года не
найдена в открытом доступе (адидас публиковал в основном интерьерные/продуктовые снимки для
прессы). Используемые фото — от стороннего подрядчика (Moezer), но здание визуально совпадает и
содержит логотип adidas на кадре — это не адидас-press-kit, а независимое, но прямое
фотографическое подтверждение того же объекта.

## (б) Роботизированное оборудование внутри

**Источник страницы:** `https://www.solereview.com/whats-inside-the-adidas-speedfactory/` —
развёрнутый тур 2017 года по Speedfactory с указанными моделями оборудования (Stoll CMS 530 HP
вязальная машина, лазерный раскрой Eurolaser, роботы-манипуляторы KUKA/Stäubli, литьё подошвы).
Сама HTML-страница отдаёт 403 (анти-бот), но:
1. Подтверждена доступность через Wayback Machine (`web.archive.org`, снэпшот 200 OK) — прочитана
   полностью, извлечены все `<img>` с alt-подписями.
2. Прямые URL картинок (`solereview.com/wp-content/uploads/2017/05/*.jpg`) отдают 200 **без**
   обхода через Wayback — бот-защита стоит только на HTML, не на медиа-CDN. Итоговые файлы
   скачаны напрямую с solereview.com (не wayback-прокси), что даёт чистый файл без водяного
   знака archive.org.

Отобраны:
- `adidas-speedfactory-robot-arm-shoe.jpg` (исходное имя `1_adidas_Speedfactory.jpg`, 800×450):
  промышленный робот-манипулятор держит готовую вязаную кроссовку в драматичном синем свете на
  фоне пара/дыма цеха. Подпись на кадре «image credit : adidas» — официальное фото adidas,
  перепечатанное изданием. Хорошо показывает именно «роботизированное оборудование» + продукт в
  одном кадре.
- `adidas-speedfactory-knitting-machine.jpg` (исходное имя `9_Stoll_knitting_machine.jpg`,
  800×448): компьютеризированная вязальная машина Stoll CMS 530 HP (та самая, что вяжет верх
  Primeknit) — реальный снимок в цеху, катушки нитей на виду, не стоковая иллюстрация.
- Отклонено: `6_Kuka_Fortec_600.jpg` — при визуальной проверке оказалось фото-каталога робота
  KUKA с подписью «image source: KUKA Aktiengesellschaft» на нейтральном сером фоне студии, а
  **не** фото из цеха Speedfactory — не используем, т.к. это стоковое фото модели робота, а не
  документальный снимок фабрики (протокол запрещает такие подмены под видом реального кейса).
  Аналогично не взяты картинки с the-spin-off.com — WebFetch-саммари ошибочно назвал их «вид
  снаружи», но визуальная проверка (Read на скачанный файл) показала, что обе — те же
  интерьерные кадры роботов/пресс-формы, что уже покрыты solereview-подборкой (дубликат той же
  adidas-пресс-фотографии). См. [[feedback_webfetch_unreliable_on_large_json]] — тот же класс
  ошибки: не доверять текстовому summary без визуальной сверки файла.

## (в) Готовая обувь со Speedfactory

- `adidas-speedfactory-futurecraft-mfg-shoe.jpg` (исходное имя
  `27_adidas_Futurecraft_MFG.jpg`, 800×533): студийный продуктовый снимок кроссовки adidas
  Futurecraft M.F.G. (Made for Germany) — модель, которая и производилась на пилотной
  Speedfactory. Подпись на кадре «image credit : adidas» — официальное фото, не мок.
- Доп. находка (не сохранена как отдельный файл, зафиксирована для возможного re-use):
  `https://images.nordbayern.de/image/contentid/policy:1.4731450:1504216388/OBJ3460145_1.JPG`
  (источник — Reuters, через статью nordbayern.de) — крупный план робота-манипулятора,
  держащего готовую бутсу adidas (красно-жёлтая, модель футбольных бутс, не беговая Primeknit).
  Не включена в итоговый набор, т.к. это, вероятно, бутса с другого мероприятия/презентации
  (конкретно не подтверждено, что снято в Ансбахе), в отличие от Futurecraft M.F.G., который
  явно и многократно упоминается как продукт пилотной Speedfactory 2017 года.

## Протокол 6-tier — как применялся

1. **og:image / прямой media CDN страницы** — сработал для картинок solereview.com (media отдаётся
   без защиты, даже когда HTML страницы блокирует бот) и для moezer.de (без блокировок вовсе).
2. **Wikipedia/Wikimedia Commons** — проверено, отдельной статьи/категории «Adidas Speedfactory» на
   Commons нет (404) — tier пропущен за отсутствием материала, не за недоступностью инструмента.
3. **Press release / официальный источник** — адидас не хранит собственный пресс-кит по закрытой
   фабрике в открытом доступе по прямому URL (проверено WebSearch) — tier закрыт отсутствием
   активной страницы (ожидаемо для производства, закрытого 6 лет назад).
4. **YouTube thumbnail** — не потребовался, достаточного материала с Tier 1.
5. **Wayback Machine** — обязательно использован для чтения заблокированной (403) HTML-страницы
   solereview.com, чтобы извлечь список и alt-подписи картинок; сами файлы итогово скачаны с
   живого CDN после того, как подтвердили их существование и релевантность через Wayback-копию
   страницы.
6. **Google Images / общий веб-поиск** — использован для поиска здания (building exterior),
   что и привело к moezer.de.

**Честный gap:** собственный официальный пресс-фотобанк adidas по Speedfactory (2016-2019) сейчас
недоступен по прямым URL (обычная судьба закрытых проектов) — все используемые фото «официальные
adidas photos» доступны только как репосты третьих лиц (solereview, nordbayern/Reuters). Это
отмечено, не скрыто: подписи на самих кадрах («image credit : adidas» / «© Foto: Reuters»)
подтверждают провенанс лучше, чем мы могли бы восстановить напрямую.
