# Скилл, который не может сработать сам

## Assertion

Скилл, у которого в перечне вместо описания стоит собственное имя, вызвать по имени можно, а сработать по смыслу запроса нельзя: описание — единственный канал выбора.

## Visual

> «По имени такой скилл вызвать можно — сработать сам, по смыслу запроса, нельзя. Описание здесь единственный канал выбора.»

> «Что вы допишете, чтобы он начал срабатывать? Назовите недостающие части, а не готовую формулировку.»

```
.claude/skills/deploy/SKILL.md   — фронтматтера нет, файл открывает заголовок
# deploy
1. Собрать: npm run build
2. Прогнать smoke-тест формы: npx playwright test
3. Опубликовать: wrangler pages deploy dist --project-name signup-landing

в перечне доступных скиллов он виден так:    deploy — deploy

официальный список антипаттернов описания, дословно:
description: Helps with documents      (помогает с документами)
description: Processes data            (обрабатывает данные)
description: Does stuff with files     (делает что-то с файлами)
```

## Speaker notes

Перед залом скилл, чьё описание в перечне — его собственное имя.

Что сказать, если спросят «он сломан»: нет. Явный вызов по имени команды отработает. Не может он другого — сработать сам, по смыслу запроса: описание единственный канал, по которому модель выбирает нужный скилл среди сотни установленных, и сопоставлять ей тут не с чем.

Три формулировки внизу — из официального списка антипаттернов, дословно. Это ровно то, что пишут, когда торопятся.

Вопрос залу: какие части нужно дописать. Не формулировку целиком — части. Два-три голоса, не комментировать; собираем на следующем слайде.
