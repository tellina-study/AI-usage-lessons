# Карта слайдов — Семинар 7

Таблица собрана из файлов слайдов, а не из плана: номер, блок, тип, заголовок экрана и минуты
взяты из фронтматтера и первой строки каждого файла. Границы блоков — из статической таблицы
сборщика деки (`build_sem07.SECTIONS`, см. её же комментарий — деку не дописывают параллельные
сессии, поэтому вывод по якорям здесь не заведён). Границы кейсов выведены по дивайдерам кейса
— все шесть дивайдеров кейсов этой деки несут один и тот же приём `case_divider_quote`
(асимметрия со `section_divider_macro`, которая была у трёх дивайдеров ступени 2 на
промежуточном круге сведения, снята — решение задокументировано в `build_sem07.py`), резка
карты всё равно смотрит на оба имени про запас.

Нумерация сквозная, `n01`…`n37`, без буквенных хвостов. Занятие открывает дугу из шести
семинаров про процессы на LLM поверх агентов (`SPLIT-PLAN-7-12.md`): сегодня закрываются три
нижние строки лестницы из девяти — хватит ли одного вызова, цепочка, маршрут с decision-моделью.

Кейсов на занятии шесть: три в ступени 1 (механика email-пайплайна, Zillow Offers, Octomind/
LangChain), три в ступени 2 (механика маршрутизации, Optum/UnitedHealth, IRS). Кейс A каждой
ступени — учебная механика, несущая приём через кейсы B и C той же ступени, а не документированный
публичный случай; это честно названо на самих дивайдерах (n04, n21) и в их заметках.
