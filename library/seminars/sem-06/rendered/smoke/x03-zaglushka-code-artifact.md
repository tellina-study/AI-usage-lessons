# ЗАГЛУШКА: проверка терминальной карточки

## Assertion

Проверка приёма `code_artifact` — тёмной моноширинной карточки, которая должна вырасти под листинг целиком и не потерять последнюю строку.

## Visual

```markdown
# ЗАГЛУШКА — не настоящий файл конфигурации
# Проверяет: `code_artifact` растёт под листинг, ограждение `markdown`
# превращает обратные кавычки в жирный прогон, а не печатает их буквально.

[servers.zaglushka]
command = "echo"
args = ["смоук-тест конвейера сборки Семинара 6"]
# строка ниже — самая длинная в листинге, проверяет перенос и ширину карточки
# она не должна вылезать за рамку и не должна резаться по середине слова
env = { ZAGLUSHKA = "true", NAZNACHENIE = "proverka-konveiera-sborki" }
```

## Speaker notes

Это техническая заметка смоук-слайда, а не речь лектора. Слайд проверяет приём `code_artifact` — тёмную моноширинную карточку, в которую на настоящей деке попадают реальные артефакты занятия (например, файл `.mcp.json` или файл роли субагента `diff-reviewer.md`). Листинг заглушки набран с нарочно длинными строками и с обратными кавычками внутри, чтобы проверить два механизма одновременно: во-первых, что карточка вырастает по высоте под весь листинг и не теряет последнюю строку (известная ловушка верстки — недомерка межстрочного интервала на моноширинных карточках, зафиксированная в примечаниях к рендереру Семинара 5); во-вторых, что ограждение, помеченное языком `markdown`, превращает обратные кавычки внутри листинга в разметку (жирный прогон), а не печатает их на слайде буквально — в отличие от ограждения без языка или с `bash`/`json`, где обратные кавычки являются частью дословного содержимого и не должны вырезаться.
