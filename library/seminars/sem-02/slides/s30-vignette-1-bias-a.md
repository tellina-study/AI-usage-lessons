# Виньетка 1 — скрининг резюме, ответ

## Assertion

Скрининг резюме DevOps-инженеров занижает кандидатов без диплома.

## Visual

Широкая Ocean rounded box карточка сверху (иконка `scale`) с курсивным текстом сценария. Снизу — слева цветной блок-badge «Bias» (MID, белый текст), справа Ocean rounded box с объяснением.

## Speaker notes

Тип — bias. Модель воспроизводит исторический перекос обучающих данных, структурное предпочтение дипломированных кандидатов на прошлых этапах отбора, статистически предсказывая «такие профили обычно отказывали» — не оценивая кандидата по существу.
