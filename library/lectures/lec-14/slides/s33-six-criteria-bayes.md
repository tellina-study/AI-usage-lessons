# Шесть критериев «AI не нужен» — карманная карта

## Visible content

6 карточек в ряд (числа в gold-кругах):
1. Forensic / юридический аудит-трейл — Каждое решение для суда
2. Нормативные требования (PCI-DSS / SOX / HIPAA) — Compliance hardline
3. Детерминированная задержка — URLLC / ядро / E911
4. Редкие события + Байес — PPV падает на низкой базовой ставке
5. Аппаратные / криптографические примитивы — TPM, secure boot, hash
6. Малый масштаб (<50 эндпойнтов) — Стоимость лицензии > выгода

Внизу — teal-tint «ОСВЕЖЕНИЕ — пункт 4 "редкие события", напоминание о математике Байеса»:
• На редких событиях даже супер-точный детектор даёт в основном ложные срабатывания.
• Пример: 10 000 событий, базовая ставка 1%, точность 99,9%:
  - Истинно-положительные: 99,9 · Ложно-положительные: 9,9 · PPV = 91%
  - Каждый одиннадцатый алерт — шум. Аналитики игнорируют 71% после такой реальности.
• Это и есть усталость от алертов. Это и есть «Tenable 3% CVE». Это математика, не вкус.

## Speaker notes

Шесть критериев — это карманная карта лекции. Распечатайте её, носите в кармане.

Первый — forensic / legal audit trail. Любое решение, которое потенциально может оказаться в суде, не может быть probabilistic.

Второй — compliance hardline. PCI-DSS, SOX, HIPAA, FDA Part 11 для фармы. ML probability не проходит audit. Это закон.

Третий — deterministic latency. URLLC, kernel hot path, E911, lawful interception. ML вносит хвост по латентности — иногда быстро, иногда медленно. Для critical path нужна детерминированность.

Четвёртый — rare-event detection. Это Bayes из s21. На редких событиях positive predictive value падает. Не «может упасть» — математически падает. Чем меньше базовая ставка, тем больше false positives относительно true positives. Это математика, не вкус.

Refresh Bayes. Пример s21: десять тысяч событий, базовая ставка один процент, точность 99,9%. True positives — 99,9. False positives — 9,9. PPV — 91%. Каждый одиннадцатый алерт шум. Аналитики игнорируют семьдесят один процент алертов после такой реальности. Это и есть alert-fatigue. Это и есть Tenable «только три процента CVE».

Пятый — hardware и crypto primitives. TPM, secure boot, cryptographic verification. Никогда ML. Это математика.

Шестой — малый scope. Меньше пятидесяти endpoints, меньше десяти серверов — стоимость лицензии AIOps выше, чем value. Базовые правила, конфиг, monitoring.

Если хотя бы один — auto-mode AI выключаем. Это рамка решения.
