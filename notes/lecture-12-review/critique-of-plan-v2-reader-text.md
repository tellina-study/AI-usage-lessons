# Что я понял (5 takeaways)

1. **Шкала автономии — это шкала доверия, а не мощности AI.** A0 (наблюдает) → A1 (советует) → A2 (замыкает петлю) → A3 (действует автономно). Каждая ступень — это **уровень делегирования решений**, а не «более умный AI». Цифровой двойник — единственный известный архитектурный механизм, позволяющий подниматься выше A1 без слепой веры.
2. **Цифровой двойник — это двусторонняя петля с возможностью симулировать действие назад** (Kritzinger 2018: Model → Shadow → Twin), а не 3D-картинка для маркетинга. ГОСТ Р 57700.37-2021 даёт российскую формальную базу. 75% проектов проваливаются на слое данных — отсюда обязательный 5-вопросный data-layer audit ПЕРЕД любым AI-проектом.
3. **A0 безопасен, но не «без оговорок»**: vision FP cascade (1% × 10K = 100 годных отвергнуто за смену) — это структурный риск; для tight tolerances (±0,001 мм) → metrology + GD&T + SPC, не AI; для редких отказов (MTBF > 1 года) → physics-based simulation + RCM, не ML на 30 точках данных.
4. **A1 generic ChatGPT для PLC = disaster** (`MOV %M99999` в S7-1500 — illegal address). Решение: purpose-built tools (PLC Copilot / PLCAutoPilot / Wipro PARI) с engineer-in-loop. **A2 RL на химической колонне без twin = слепая вера**: sim-to-real gap концентрированно показан на T-drift + surface fouling + 10% excursion. Yokogawa FKDPP в JSR 35 дней получился ТОЛЬКО потому, что внутренний twin колонны был safe sandbox для RL обучения ДО deploy.
5. **10 структурных критериев «не применяй AI»** — самая ценная декомпозируемая часть плана. Каждый критерий имеет inline-якорь альтернативы (MPC / formal verification / RCM / IEC 61508 / GD&T / SPC / explainable AI с SHAP-LIME / process redesign / ATEX-сертифицированные датчики / data-layer audit). Worked example фарма+FDA (AI ±0,5% vs required ±0,1%) показывает, как применять критерий в конкретной ситуации. Плюс 5 вопросов вендору (carry-forward lec-11 §5.2 pattern).
