| **Материал** | FUNSD, 100 отсканированных бланков (36 из `testing_data`, 64 из `training_data`), 364 целевых поля по 4–6 на форму |
| **Что сравнивается** | мультимодальная модель · распознавание текста с правилами по якорным подписям · гибрид «распознавание → модель» |

| **Поворот второго порядка** | Проигрыш гибрида — свойство среднего по корпусу, не приговор методу. На телефонах и факсах он **впереди** модели, и был впереди уже на тридцати формах. Внутри среднего живут обратные случаи, и выбирают не метод, а категорию поля |

| **Граница** | Распознавание с правилами остаётся рабочим инструментом там, где подпись поля печатная и якорь стабилен. Передавать модели право действовать по полю без сверки нельзя ни в одном из трёх вариантов |

## Кейс C — Вердикт «запрещено»

| | |
|---|---|
| **Дивайдер** | Перед публикацией кадры должен кто-то досмотреть — а что именно мы ищем? |
| **Материал** | Open Images V7, пометки на снимок (`val`+`test`, `Confidence=1`), курация глазами: курение 134 (41/93) · еда и напитки 129 (38/91) · экран в кадре 117 (48/69) |
| **Что сравнивается** | мультимодальная модель · локальный детектор · словесный классификатор без обучения, по порогу |
| **Разворот** | Интуиция зала: у метода есть доля ошибок, по ней и выбирают. Измерено: **главное число — не доля, а где ошибки стоят.** Модель на курении не пропускает ничего (0%) и платит 25 ложными тревогами из 93 — но **24 из них (96,0%) приходятся на жёсткий негатив** (предмет курения без человека), и **1 из 68 (1,5%)** на обычный. Числа стоят только парой: одно без другого лжёт в свою сторону |
| **Поворот второго порядка** | Словесный классификатор на импортированных порогах (0,3/0,5/0,7) выглядит неработающим — и это свойство порогов, а не метода: на своём 0,01 он даёт пропуск 41,5% и ложную тревогу 1,1%. **Чужой порог переносит ошибку, а не убирает её** |
| **Чего нельзя делать с числами** | Два вида ошибки **не складываются**: у пропуска запрещённого и у задержания невиновного разная цена и разный адресат. Сумма 13,4% скрывает ровно то, что кейс показывает |
| **Словарь против зрения** | Детектор на курении не «плохо находит» — в COCO-80 нет такого понятия вовсе. Замер здесь классификация, не детекция, и это сказано до чисел |
| **Граница** | Право решать «это можно публиковать» не передаётся модели ни в одном варианте: процесс помечает подозрение и останавливается. Документированная цена обратного — заблокированный навсегда аккаунт человека, снимок которого был сделан для врача |
| **Замер** | `stend/zamery-C/README.md` — три класса, два вырожденных режима для масштаба, полоса скоров приведена |

## Что идёт поперёк кейсов

Четыре нити закрытия (`ZAKRYTIE-BRIEF.md` §2–§5) не раскладываются по одному на
кейс — они собираются из всех четырёх:

1. **Дешёвый метод — опора, а не замена:** у каждого кейса есть категория, где
   дешёвое впереди дорогого, и выбирают категорию, а не метод.
2. **Истина грязная:** человеческая разметка, которой мерят, сама с ошибками, и
   это измерено на своей выборке в каждом кейсе, где она есть.
3. **Чужой архив смертен:** модель ушла из каталога через 17 дней после отбора,
   бесплатный ярус отдал 12 векторов из 30. Запасная модель и журнал отказов — часть
   проекта, а не аварийная мера.
4. **Определение решает:** там, где спросили словом вместо определения, число
   получилось про другое — у кейса C это целый разворот, у A и B по одному месту.
