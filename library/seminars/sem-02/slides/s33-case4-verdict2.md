# Звонки продаж — разбор 2

## Assertion

Сложно для человека — не значит сложно для модели

## Visual

Схема: «свободный разговор» → «извлечение полей по фиксированному
шаблону» → «локальная модель 7–8 млрд параметров» → «данные не покидают
периметр компании». Внизу — две строки-урока.

## Speaker notes

Задача на самом деле сузилась: нужна не свободная беседа, а
структурированная выжимка по фиксированному шаблону из нескольких полей.
И вот в чём дело — небольшая локальная модель порядка 7-8 миллиардов
параметров, после настройки формулировки промпта под конкретный формат
вывода, без дообучения весов, вполне справляется с извлечением полей по
шаблону, и данные при этом не покидают периметр компании, GPU-ферма не
нужна. Два урока проговорим явно. Первый — «сложно для человека» не
значит «сложно для модели»: свободный разговор кажется сложным входом, но
извлечение структурированных полей по шаблону — задача умеренной
сложности, которую малая модель решает надёжно. Второй — чувствительность
данных не видна в исходной постановке задачи, её нужно выяснять вопросами
о содержимом входных данных, а не предполагать по формулировке.
