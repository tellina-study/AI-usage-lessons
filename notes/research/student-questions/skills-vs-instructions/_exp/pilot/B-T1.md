# Slash-команда vs хук: инициирование и время выполнения

**Date:** 2026-10-02 · **Issue:** #217-EXP

## Основное отличие

Slash-команда (skill, `/build-deck`) — это **явное действие, запущенное пользователем на момент поступления его сообщения**. Пользователь печатает `/command`, хук срабатывает и выполняется синхронно как часть текущего цикла обработки сообщения.

Хук (hook в `.claude/settings.json`) — это **декларативное правило, которое срабатывает автоматически при выполнении условия**, вне зависимости от явного запроса. Примеры: «whenever I edit a Python file, run linter», «before I commit, check for secrets», «after my session compacts, re-read the plan».

Основное различие в сроках: slash-команда исполняется **прямо сейчас**, хук — **когда условие выполнится** (может быть минуты или часы спустя).

| утверждение | источник | тип |
|---|---|---|
| Slash-команда исполняется синхронно при запросе пользователя | CLAUDE.md § Orchestration Rule + практика `tools/lecture-production/` | документация |
| Хук исполняется асинхронно при выполнении условия в settings.json | CLAUDE.md § Subagent Rules, update-config skill | документация |
| Хуки для автоматизации («whenever X»), slash-команды для явных действий | CLAUDE.md § update-config skill definition | документация |

— Как slash-команды и хуки взаимодействуют при вложенных вызовах (может ли хук запустить slash-команду).

— Типовые performance-характеристики (latency хука vs прямого вызова).
