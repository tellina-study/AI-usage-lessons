## Speaker notes

Code A is a real function from the `requests` library, one of the most-used Python libraries, open source on GitHub, MIT licensed. Code B was generated by AI on a similar prompt — write a small function of similar scope.

An honest comparison, without putting down either side: `requests` is code that's been running in thousands and millions of real projects for over ten years — every hidden bug has most likely been found and fixed by the community by now, the result of years of testing under complex, high-load infrastructure. You get the AI version in 10–20 seconds — a great option precisely for typical helper functions like this, boilerplate code, one-off scripts.

This round's lesson isn't "AI is worse" — it's a split by task type: typical, helper tasks — AI, it's faster and reliable enough. Complex and unique solutions, architectural, high-stakes ones that a system's stability depends on — a human, with their experience and accountability for the decision.
