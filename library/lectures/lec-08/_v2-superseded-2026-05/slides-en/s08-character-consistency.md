# Character preservation: cameos and Omni Reference

## Assertion

Character preservation: Sora 2 cameos + Midjourney Omni Reference + Runway Director Mode — multi-scene narrative became possible.

## Speaker notes

One of the most noticeable capability improvements of 2024-2026 is character preservation across generations, the ability to keep a character's visual characteristics across multiple generations. This is a critical capability for narrative: without it, AI video cannot be used for a multi-scene story. Sora 2 cameos: the mechanism — a user registers a "cameo" with defined visual attributes; in subsequent video prompts the cameo is invoked by name, and the model reproduces it consistently. OpenAI announced a partnership with Disney for a billion dollars and more for licensed character generation: Disney IP characters can officially appear in AI-generated videos under a Disney license. Midjourney Omni Reference in v7: one reference image of a character is used in subsequent prompts to preserve facial proportions, clothing, posture. Per Midjourney's statement, character-preservation accuracy grew from about sixty percent in v6 to above eighty-five in v7. Runway Gen-4 Director Mode — full scripting across scenes: the user defines characters, locations, motion patterns as structured objects. Anti-hype for this capability: character preservation across generations works significantly better than in 2023, but multi-scene narrative still has drift. After five-to-ten scenes, small details — a tattoo, a scar, a hair shade — may change. Industrial-quality use requires a continuity supervisor, a person who checks each scene for consistency. This is a new profession — we will return to it in the section on new roles.
