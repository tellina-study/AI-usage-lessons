# Ключ из окружения — и куда положить файл

## Assertion

Ключ хранится в переменной окружения, а не в файле, — с честной оговоркой, что это не гарантирует полной защищённости; а область видимости конфигурации решает, коммитится ли файл в репозиторий вообще.

## Visual

**Вопрос 3.** «Где хранить ключ?» → в переменной окружения, не в файле.

Оговорка: даже переменная окружения не гарантирует, что ключ нигде не всплывёт текстом — диагностическая команда статуса подключения сама может стать ещё одним каналом утечки, если подстановка отображается буквально.

**Вопрос 4.** «Куда положим сам файл?»

- `local` (по умолчанию) — только у меня на этой машине
- `project` — в репозиторий, для всех
- `user` — глобально во всех моих проектах

Проверенный сервер → `project`: конфигурация становится кодом, ревьюится. Эксперимент → `local`.

Факт про дефолт: команда подключения по умолчанию кладёт сервер в `local`, не в `project` — чтобы файл закоммитить, область нужно указать явно.

## Speaker notes

Третий шаг — про ключ, и зал отвечает правильно почти сразу: переменная окружения, не значение в файле. Стоит добавить честную оговорку: даже вынесение секрета в переменную окружения не гарантирует, что он нигде не всплывёт текстом — диагностическая команда, которой проверяют статус подключения, сама может оказаться ещё одним каналом утечки того же секрета, если подстановка отображается буквально там, где должна быть маскирована.

Четвёртый шаг — область видимости, и разбор здесь двусторонний, а не «правильный вариант один». Проверенный сервер — в репозиторий: конфигурация становится кодом, изменение подключения видно в ревью. Непроверенный эксперимент — только у себя: «попробовал у себя, потом принёс команде» — нормальная последовательность.

И факт, который стоит проговорить прямо: по умолчанию команда подключения кладёт сервер в личную конфигурацию, а не в проект. Дефолт правильный — он соответствует эксперименту, — но если про него не знать, получится разговор «я подключил, всё работает» — «а у меня нет», и оба правы. Чтобы файл стал кодом репозитория, область нужно указать явно.
