# Один продукт — два режима

## Assertion

Один и тот же продукт, два режима использования — что это?

## Visual

Общий баннер сверху: «GitHub Copilot — один и тот же продукт, два режима
использования». Ниже — две строки-карточки друг под другом, идентичного формата, без
badge и без цветового ответа. Верхняя: иконка `mouse-pointer-click`,
«Inline-автодополнение (Tab-completion)», описание «Нажал Tab — получил предложение
по текущей строке». Нижняя: иконка `bot`, «Agent-режим (Workspace)», описание
«Получает текстовую задачу, самостоятельно открывает несколько файлов проекта,
правит код, коммитит». Между строками — нейтральный разделитель (не gold-стрелка,
она появится только на слайде-ответе).

## Speaker notes

Третий и четвёртый инструменты — снова GitHub Copilot, но два разных режима использования. Сначала inline-автодополнение: нажал Tab — получил предложение по текущей строке кода, без диалога и без многошагового планирования.

Затем Copilot Workspace, он же Agent-режим: получает текстовую задачу, самостоятельно открывает несколько файлов проекта, правит код, коммитит.

Для каждого — четыре раунда голосования: модель, чат, агент или приложение. Здесь ожидайте расхождение голосов на первом пункте — часть аудитории скажет «агент», потому что «Copilot понимает код». Обязательно вызовите двух-трёх студентов с обеих сторон объяснить рассуждение до официального ответа — не торопите этот момент.
