# Visible content

## Title bar
Запуск — это не «включить», а передача контроля по ступеням

## Body
[Лестница из 3 ступеней: v1 высокий контроль → v2 утверждение → v3 fallback]

**CC/CD** (Continuous Calibration/Development) — против привычного CI/CD

- v1: маршрутизирует, высокий контроль/низкая агентность
- v2: предлагает решения на утверждение человека
- v3: автоматически разрешает с fallback на человека

[Gold callout]
«Если не тестировали при высоком контроле — не готовы давать высокую агентность»

## Speaker notes

Заметный переформат понятия «запуск» для AI-эры принадлежит Айшварье Реганти и Кирити Бадаму: framework CC/CD — непрерывная калибровка и непрерывная разработка, противопоставляемый привычному CI/CD, потому что CI/CD предполагает детерминированный код, который либо проходит тесты, либо нет, а AI-системы этим свойством не обладают.

Механика: фаза до запуска — версионировать релизы по уровню агентности, а не по набору функций. Пример: бот поддержки выходит как версия один — маршрутизирует тикеты, высокий контроль, низкая агентность, версия два — предлагает решения на утверждение человека, версия три — автоматически разрешает с fallback на человека. Построить reference dataset и спроектировать evals — прикладные метрики против эталонного набора перед развёртыванием. Фаза после запуска — прогонять оценки на живых данных, анализировать паттерны ошибок.

Именованный провал, дословно: если вы не тестировали, как система ведёт себя при высоком контроле, вы не готовы давать ей высокую агентность. Бот, сразу прыгающий к полной автономии, рискует цепочкой сбоев, которую трудно распутать постфактум. Реальный пример: agency-ladder GitHub Copilot и Cursor — от завершений к блокам кода к целым pull request'ам, каждая ступень разблокируется только после того, как предыдущая доказала надёжность на практике. Крупные консалтинги независимо описывают тот же сдвиг, но каждый честно называет свои режимы сбоя: смещение узкого места, распространение пилотов, пробелы измерения. Урок для launch-фазы: консенсус — не «отгружай быстрее», а «перестрой процесс вокруг агента, сохранив человеческое ревью в критических точках».
