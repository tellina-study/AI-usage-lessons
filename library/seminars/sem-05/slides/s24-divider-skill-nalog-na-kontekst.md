# Ступень 4 · скилл

## Assertion

Ступень 4 — скилл: файл инструкций уже платит налог за процедуру деплоя, которая нужна не в каждой сессии, — второе усиление разбирается по сигналу перегрузки, а не по порядку голосования.

## Visual

Крупный заголовок «Ступень 4 · скилл» на Ocean-фоне, с gold-номерным значком «2» слева. Под ним — узкий tag: «1 кейс · 2 провала», без минут и без деталей содержимого.

Вверху — широкий 5-сегментный gold progress-bar пяти ступеней занятия (хук · скилл · MCP · субагент · процесс), сегмент 2 подсвечен.

В углу — небольшая иллюстрация: переполненный чемодан у стойки регистрации рядом с крохотным рюкзаком.

## Speaker notes

Хук закрыл прямой путь нарушения правила синтаксисом. Второе усиление — не про принуждение, про экономику: файл инструкций, который вы только что видели сорока строками, вот-вот вырастет вдвое из-за процедуры, нужной в одной сессии из десяти. Один кейс, два слоя провала — сначала вредит содержание сработавшего скилла, потом — сам факт, что это чужой исполняемый код.
