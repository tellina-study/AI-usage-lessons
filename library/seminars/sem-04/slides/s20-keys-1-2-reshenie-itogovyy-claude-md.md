# Итоговый CLAUDE.md — пятнадцать строк

## Assertion

Итоговый файл — пятнадцать строк: критерий готово, гейт-предупреждение, честная оговорка предела и один разовый шаг, без которого тесты падают не по делу; `AGENTS.md` — симлинк на тот же файл.

## Visual

```markdown
# CLAUDE.md

signup-landing: статический лендинг с формой заявки на демо-урок.
Готово = `npm run build` код 0, `npx playwright test` зелёный, форма
отправлена руками из собранного `dist/` — и заполненная, и пустая.

## Safety / scope boundaries
- Никогда не запускать деплой на прод без явного запроса.

## Build, test, verify
- To verify: открыть `dist/index.html` после сборки и отправить форму
  руками — с заполненными и с пустыми полями.
- Один раз на машину, до первого `npx playwright test`: `npm ci`, затем
  `npx playwright install chromium`. Без второй команды падают все тесты
  сразу и не по делу.
```

Справа — три механические детали:

1. Файл грузится в начало каждой сессии целиком (официальный ориентир — до 200 строк, наш итог — 15).
2. `@`-импорты организуют файл, но не экономят контекст — импортированное всё равно грузится целиком.
3. `AGENTS.md` — симлинк на тот же файл (`ln -s CLAUDE.md AGENTS.md`). Острый край: поведение `cp -R` на симлинке **стандартом не задано** (POSIX.1-2024: при `-R` без `-H`/`-L`/`-P` дефолт не определён); `-P` фиксирует намерение, `-L` ломает симлинк гарантированно.

## Speaker notes

«Вот итог кейса 1.2: пятнадцать строк — критерий готовности, гейт-предупреждение вручную проверить доставку, честная граница на деплой и один разовый шаг после клонирования, без которого тесты падают мгновенно и не по делу. Файл грузится в начало каждой сессии целиком, официальный ориентир — до двухсот строк, у нас — пятнадцать. `@`-импорты организуют файл, но контекст не экономят — импортированное всё равно грузится целиком.

Про последнюю строку отдельно. `npx playwright install chromium` — это ровно тот разовый шаг, ради которого в файле вообще есть раздел «Build, test, verify»: без него из чистого клона падают все тесты сразу, и падают не по делу — не потому, что код сломан, а потому, что браузера на машине нет. Агент, который это прочитал, не начнёт чинить исправный код.

`AGENTS.md` у нас с первого дня — симлинк на этот же файл, один источник правды для разных движков. Обратите внимание: заводится он сразу, а содержимого в нём ровно столько же, сколько в `CLAUDE.md`, потому что это один и тот же файл. Острый край здесь не в том, что какая-то система ведёт себя неправильно, а в том, что поведение `cp -R` на симлинке стандартом просто не задано: POSIX прямо пишет, что при `-R` без `-H`, `-L` или `-P` дефолт не определён. На GNU coreutils симлинк переживает копирование, но полагаться на это нельзя — `-P` фиксирует намерение явно. А вот что ломает симлинк гарантированно, так это `-L`: `cp -RL` даст вам вторую настоящую копию, и дальше два файла тихо разойдутся. Надёжнее всего переносить проект через `git clone` или `git archive`.»
