# Семинар 5 — сборка кодинг-агента: когда просьбы недостаточно

## Assertion

Пять усилений превращают текстовую просьбу в барьер, который агент не обходит, даже если захочет — у каждого своя цена и своё место, где интуиция предсказывает не то, что показывает проверка. Сегодня разбираем три из них.

## Visual

> «Правило было записано в файле инструкций. Агент его прочитал. Правило всё равно нарушили.»
> «Пять усилений превращают просьбу в барьер, который агент не обходит. У каждого своя цена — и своё место, где интуиция предсказывает не то, что показывает проверка.»
> «Сегодня разбираем три из них.»

## Speaker notes

Вход — с последней фразы прошлого занятия, без разгона: правило записано, прочитано, нарушено.

Три сегодняшних назвать именами: исполняемый барьер, загрузка по требованию, доступ наружу. Две оставшиеся — только назвать, содержание не трогать.

Дальше сразу к дереву репозитория, паузы нет.
