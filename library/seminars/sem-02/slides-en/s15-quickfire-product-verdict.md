# Product descriptions — debrief

## Assertion

A "generate description" button right inside the catalog admin panel

## Visual

A card with a mockup of the existing product-catalog admin panel, where a single
new button appears next to the description field. At the bottom — a line: "A
second login and a separate tab — the cost nobody thought about."

## Speaker notes

This should be a "generate description" button right inside the existing
product-catalog admin panel that marketing already uses every day, entering
new products and editing product cards. A separate product means a second
login, a separate tab, a habit that has to be built from scratch, and an extra
step in the workflow. In practice, separate tools like this often die from
disuse, even when the technology inside them works perfectly well — simply
because people never quite get around to using them when it's easier to just
write by hand what they've always written for years. A separate service is
still justified in one case — if there's no admin panel of your own at all,
meaning marketing has no single place where they already work with product
cards. Then there's nowhere to build the feature in, and a separate tool isn't
a compromise — it's the only option available.
