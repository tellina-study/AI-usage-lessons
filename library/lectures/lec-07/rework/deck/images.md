# Реестр иллюстраций деки Лекции 7

Строка на каждый кадр, которому по послайдовому плану нужна иллюстрация. Три графы: **что за
иллюстрация · где брать · статус**.

**Ничего не выдумано и не заменено стилизованной карточкой.** Нарисованная в палитре карточка с
дословным заголовком новости — это макет, а не изображение, и курс это прямо запрещает
([[no-mock-fallbacks]], `tools/presentation-build/trebovaniya-k-soderzhaniyu.md` §5.7). Где
изображения нет — стоит статус **не добыта**, и поле `media` в файле кадра пустое. Пустое поле
`media` сборщик отрабатывает молча: кадр отдаёт тексту ширину, которую освободил отсутствующий
снимок, и места под снимок на экране не обозначает ничем.

**Источники фотографий на слайде не подписываются** (решение владельца). Подпись источника живёт в
подвале через поле `source` только тогда, когда это ссылка на работу, а не на картинку.

## Как добывать — шесть ярусов по порядку

1. `og:image` из страницы пресс-релиза или публикации;
2. Wikipedia / Wikimedia Commons через `prop=imageinfo&iiurlwidth=960`;
3. страница пресс-релиза или официальная страница изделия — первый `<img>` / `<figure>`;
4. кадр видео: `https://img.youtube.com/vi/<id>/maxresdefault.jpg`;
5. Wayback Machine для страниц, которые уже отдают 404;
6. поиск по картинкам — последний ярус, лицензия проверяется руками.

Уход в примитив допустим **только** при документированном провале всех шести ярусов по этому
конкретному кадру, и провал обязан быть выписан попыточно: шесть адресов, а не «всё было закрыто».

Складывать: `library/lectures/lec-07/assets/screenshots/sNN-<имя>.<ext>` плюс рядом файл
`sNN-<имя>.url` с адресом источника — чтобы происхождение кадра можно было проверить, а не принять
на слово.
