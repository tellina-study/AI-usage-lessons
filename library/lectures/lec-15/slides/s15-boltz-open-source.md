# Boltz-1. Открытая модель MIT. Обогнала AlphaFold 3 по внедрению.

## Boltz-1 / Boltz-2

В декабре 2024 года команда MIT (Corso, Wohlwend et al.) опубликовала **Boltz-1** — полностью открытый конкурент AlphaFold-3. **MIT license**, разрешает коммерческое использование, полный код плюс веса. **Boltz-2** (2025) расширил архитектуру до молекулярного докинга.

К концу 2025 года Boltz стал самой широко используемой открытой моделью своего класса, **обогнав AlphaFold 3 по академическому внедрению**.

## Сравнение точности

| Задача | Boltz-1 | AlphaFold 3 |
|---|---|---|
| Протеин-только GDT_TS | сопоставим (±1-3) | эталон |
| Docking аффинности | в пределах 8-12% | эталон |
| Академическое внедрение | **>50%** к концу 2025 | <40% |
| Коммерческое использование | **разрешено** | требует лицензии |
| Стоимость на 1 GPU потребительского уровня | да (квантование) | нет |

## Закономерность «обгон открытым»

**Stable Diffusion 1.5** (открытая) обогнал DALL-E 2 (закрытый) по внедрению через 6 месяцев.

**LLaMA-2** (Meta) обогнал шаблоны развёртывания GPT-4 для академических исследований.

**Mistral 7B** стал основой для нескольких академически дообученных моделей.

**AlphaFold 2** сам был открытым с начала — накопил критическую массу за 3 года.

## Урок

(а) Открытый против закрытого — это **бизнес-стратегия**, не философия. (б) Открытая альтернатива зрелого класса часто **обгоняет** по внедрению закрытую, более точную модель. (в) В академической работе по умолчанию выбирайте открытый исходный код, если есть достаточно близкая альтернатива.

## Speaker notes

В декабре 2024 года команда MIT под руководством Corso и Wohlwend опубликовала Boltz-1 — полностью открытый конкурент AlphaFold 3. MIT лицензия разрешает коммерческое использование, полный код плюс веса. Boltz-2 в 2025 году расширил архитектуру до молекулярного докинга. К концу 2025 года Boltz стал самой широко используемой открытой моделью своего класса, обогнав AlphaFold 3 DeepMind по академическому внедрению.

Технически: на эталонных тестах предсказания только белков Boltz-1 и AlphaFold 3 показывают сравнимые результаты — средний GDT_TS в пределах нескольких единиц. На предсказании взаимодействий белок-лиганд AlphaFold 3 показывает несколько более высокую точность, но разница по большинству независимых тестов не критическая для дальнейшего использования. Для большинства академических применений — проверка гомологии, предварительный скрининг лекарств, проектирование антител — Boltz «достаточно хорош».

Boltz-2 расширил оригинальный Boltz-1 в нескольких направлениях. Первое — поддержка более широкого класса лигандов: не только малые молекулы, но и пептиды, нуклеиновые кислоты, ковалентно связанные модификаторы. Второе — улучшенная функция оценки докинга: обучен на дополнительных данных, повысил точность предсказания энергии связывания в среднем на 8-12 процентов. Третье — оптимизация для вычислений: квантование и эффективное выполнение на стандартных GPU потребительского уровня.

Эта история повторяется в нескольких других областях AI-в-науке. Stable Diffusion 1.5 обогнал DALL-E 2 по внедрению сообществом через шесть месяцев. LLaMA-2 от Meta обогнал шаблоны развёртывания GPT-4 для академических исследований. Mistral 7B стал основой для нескольких академически дообученных моделей. AlphaFold 2 сам был открытым с самого начала и поэтому накопил критическую массу внедрения за три года.

Урок для академического исследователя. Когда выбираете AI-инструмент: по умолчанию выбирайте открытый исходный код, если нет сильной причины для закрытого. Проверьте, активно ли открытое сообщество. Планируйте, что вы будете делать через 3-5 лет — если закрытая модель умрёт, что произойдёт с воспроизводимостью? Выбирайте открытые веса даже когда закрытый API удобнее.
