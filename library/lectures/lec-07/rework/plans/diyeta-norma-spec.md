# Диета деки Лекции 7 до замеренной нормы: общая часть наряда

Читается ПЕРВЫМ, до своего персонального наряда. Персональный наряд называет только
твои разделы, твою базу числами и то, что в твоих разделах трогать нельзя.

## 0. Откуда взялся круг

Владелец, посмотрев деку: «очень много текста, надо сократить в пользу структуры и
читаемости. Сейчас везде полотна. Так же сократи в 1,5 раза количество примеров».
Полотна сделали мы сами в предыдущем круге, добавляя в каждый раздел описание стадии.

Затем владелец потребовал норму не из головы: «что-то не то с нормой, как будто 95
много… посмотри по лучшим образцам учебных лекций, сколько там?» Замер сделан и лежит в
`library/lectures/lec-07/rework/research/08-norma-teksta-na-kadre.md` — 26 публичных дек
университетских курсов, 1171 страница, тем же скриптом, которым меряется наша дека.

## 1. Норма круга — замеренная, не догадка

| | Число | Откуда |
|---|---|---|
| **Медиана слов на страницу собранного PDF** | **≤ 75** (полоса 60–75) | медиана эталонов 52 (англ.) / 57 (все); медиана медиан 57–58; наша Лекция 6 — 71, публичная Лекция 2 — 68 |
| **Предел на кадр** | **140** | 95-й процентиль эталонных страниц: 129 (англ.) / 139 (все) |
| **Кадров тяжелее предела** | **≤ 5% деки**, ни одного тяжелее **200** | у эталонов 3,0–4,7% страниц тяжелее 140, 99-й процентиль 165–170 |

Прежняя норма «медиана ≤90–95, предел 160» **отменена** — она была догадкой и оказалась
мягче замера. Если твой прошлый круг отчитался по 95/160 — это не зачёт, порог сменился.

**Мерить только по собранному PDF** (`render_sec.py N [N N]` из `deck/`), не по телу
`## Видимый текст слайда`: плашки, столбцы, подписи схем и подвал живут во фронтматтере,
и счёт по телу занижает — на этом в этом производстве ошиблись дважды (112 против 183).

## 2. Структурный пол кадра разбора — и как с ним живёт медиана ≤75

Две сессии независимо посчитали: кадр подробного разбора обязан нести по §5.13
цену обеих ошибок ≈18 слов · оба классических режима ≈15 · «как это устроено» с именем
изделия ≈30 · полосу плашек с базой у каждого числа ≈25 · заголовок с именем кейса ≈6 ·
подвал-рукоятку источника ≈10. **Итого ≈105 — ниже только снимая обязательное.**

Медиана ≤75 при этом **достижима и не требует резать обязательное**, вот арифметика:
разборных кадров в деке 18 из 106, они живут в полосе **105–140**; остальные 88 кадров —
описания стадий, своды, дивайдеры, карты, Вход, Сборка, Закрытие — обязаны уйти в
**45–70**. Тогда медиана деки садится на 65–75, а доля тяжелее 140 остаётся нулевой.

**Отсюда твои два числа, а не одно:**
- кадр **подробного разбора**: **≤140**, цель 105–125;
- любой другой кадр: **≤75**, цель 45–70.

**Кто такой «кадр разбора» — по работе, а не по метке** (уточнено 2026-10-14 по останову
сессии раздела 2, её чтение принято). Полоса 105–140 выведена из состава обязательного:
цена обеих ошибок + оба классических режима + «как это устроено» с именем изделия + полоса
плашек с базой у каждого числа + заголовок с именем кейса + подвал-рукоятка. Кадр, который
этого состава **не несёт**, полосу не заслуживает — он просто тяжёлый: описание стадии,
один классический режим отдельным кадром, свод, дивайдер, карта, словарь — всё это цель
**45–70**, сколько бы меток ни стояло в их `method_steps`.

Признак `②классические режимы` при `заземлении` ставился как «здесь названы режимы», а не
«здесь разбор», и замер по нему считает разборами кадры заземления. Поэтому: **увидел
такую метку на кадре, который разбором не работает — поправь саму метку** и скажи
оркестратору, что поправил. Иначе следующий замер посчитает их разборами снова, уже без
тебя, и это расхождение переедет в свод «Сборки».

**ПОПРАВКА 2026-10-15 — предел 140 для кадра разбора ОТМЕНЁН (решение О20).** Владелец после
этого наряда потребовал третьего: «обязательно слайд должен читаться и без голоса, и ключевая
информация должна быть понятна» — то есть описание работы («что делали») на каждом кадре-примере,
подписи единиц и перевороты частоты со знаменателем. Это ещё 30–45 обязательных слов на разбор, и
полоса 105–140 их не вмещает. Замер после исполнения: разделы 6–10 — медиана 125,5, шесть кадров
из 34 за 140, максимум 170.

**Предел кадру подробного разбора ставит теперь состав обязательного и физическая раскладка, а не
число 140.** Жёсткого осталось два: (1) текст не наезжает — предупреждения `[высота]` / `[кегль]`
блокирующие, кегль тела не ниже 12,0 пт (**минимум по кадру об этом НЕ говорит**: 12,0 — это
фиксированный кегль подписей и оговорок плашек, ужимается же тело, и под ним обычно пять ступеней
запаса — я записал обратное по недосмотру и отозвал, см. О20); (2) вес выше 140 допустим только **объявленный** —
`pol_slov` с причиной, называющей, **чем заняты слова** (не каким был вес во вторник: измеренное
число, записанное прозой, расходится с инструментом уже через две правки — на этом в круге
попались четыре объявления из шести).

Полоса **45–75 для всех прочих кадров остаётся в силе** — именно она держит медиану, и именно её
нарушение, а не шесть тяжёлых разборов, делает деку полотном. Норма 75/140 замерена по 26
публичным декам, которые **никогда** не предполагались читаемыми без докладчика (это реквизит
выступления); на самодостаточный кадр она не переносится. Подробно — О20 в
`decisions-orkestratora.md`.

**Обязательное не снимать ни на одном кадре:** цена обеих ошибок · оба классических
режима в одной единице либо названный отказ с причиной · имя изделия · база у каждого
числа · источник живой гиперссылкой. Диета, съевшая базу числа, — это та правка, за
которую деку возвращают.

## 3. Чем режется текст — по убыванию отдачи

1. **Перечень шагов стадии уходит в заметки целиком.** На кадре — одна картина работы
   (CLAUDE.md § «Строение раздела отраслевой лекции», уточнение 2026-10-10: «сидели
   обложены методичками», а не список действий). Это самая большая экономия в разделах,
   где описание стадии добавлял прошлый круг: 40–60 слов с кадра.
2. **Числа — плашками**, пара «было → стало» **одной** плашкой (§5.12). Два числа в
   прозе — это 15 слов, та же пара плашкой — 6.
3. **Порядок работы — схемой** (`scheme.rows`), до четырёх шагов в ряду.
4. **Сплошной текст — в буллиты**; лирика, оговорки, разряд свидетельства, слабая
   сторона замера — **в заметки**.
5. **Подвал источника — рукоятка** (решение О8, `decisions-orkestratora.md`): «авторы, журнал,
   год» + настоящая гиперссылка (`run.hyperlink.address`). DOI, PMID, том, страницы —
   в заметки, в их раздел «Источники». Медиана подвала по деке 26 слов, в разделах 7–8 —
   33, максимум 48; это −25 слов с кадра разбора. **Разделы 4–6 это уже сделали, образец
   там.** Делаешь у себя в своих разделах.
6. **Свёртка парных кадров «Пример N» / «Пример N, цена» в один** — решение О6, то самое
   «в 1,5 раза меньше примеров», исполняемое кадрами, а не снятием разборов. В твоих
   разделах такие пары назовёт персональный наряд. **Условие свёртки:** пара «дало →
   потребовало» обязана читаться с одного взгляда, и собранный кадр не перевалить 140 по
   PDF. Не складывается — не складывай и скажи числом, почему.

**Содержание в воздух не выбрасывается.** Что не влезло в структуру — в заметки, их норма
**500–800 слов** на кадр, место есть. Заметки — связный произносимый текст, не описание
вёрстки.

## 4. Разборы по правилу отбора — снимать только по моему слову

Правило отбора (разбор ОСТАЁТСЯ, если оба классических режима посчитаны в одной единице
либо назван отказ с причиной · названо изделие · назван адрес оси — внимание, навык,
подпись, арбитраж · он делает работу, которой не делает другой разбор раздела) уже
прогнан по всем 18 разборам деки и дал **одного** кандидата на снятие. Поэтому
**квоты на снятие у тебя нет**: коэффициент исполняется свёрткой кадров (п. 3.6).

Увидел разбор, который по правилу уходит — **напиши мне, не снимай**. Снятый кадр
кладётся в `deck/slides/_snyato/` с записью в её `README.md`: что было, сколько минут,
по какому пункту правила снято, как вернуть.

## 5. Сверка счётчиков — отдельным проходом на один вопрос

Прошлые круги давали 12–15 расхождений этого класса на круг, и ни критика, ни просмотр
глазами их не находили (`tools/seminar-production/README.md` §8.10). После правок —
отдельный проход по своим разделам ТОЛЬКО на этот вопрос: «четыре способа», «три режима»,
«два кадра до него», «шесть действий стадии», номера примеров, перечни разборов на
дивайдерах, итоговые плашки сводов. Числа в прозе не пересобирает ни один генератор.

Кириллица: `grep -P` даёт **ложный ноль** на русских шаблонах — искать Python `re` либо
`grep` без `-P`, якорить с двух сторон, смотреть контекст совпадений, а не счёт.

## 6. Что держать и не трогать по всей деке

- сквозной пример с письмом женщины, проведённый через все разделы;
- тройку keystone 92 · 74 · 76 и обвал 71 → 39;
- пятый механизм на `s70` (измеренный стимул соглашаться, 248 немецких врачей);
- разбор хирургов на септическом шоке (0,712 против 0,816 и 0,820);
- кадр единицы у доли копирования (`s60bb`: доля **текста**, не доля заметок);
- единственное рандомизированное испытание деки (автоматическая запись приёма);
- кегль: **не ронять.** Не влезает — значит текста всё ещё много, режь текст. Знаков
  ниже 12 пт по собранному PDF — ноль.

## 7. Минуты

Дека сейчас **83,95 минуты при бюджете 80,00**. Диета обязана вернуть минуты, а не
только слова: после правки пересчитай `timing_min` своих кадров честно по тому, что на
кадре осталось, и назови сумму раздела до и после. Свёртка пар (п. 3.6) даёт минуты
прямо.

## 9. Git и среда

- База: `git fetch origin && git checkout -b issue-229-<твоя-ветка> origin/issue-229-diyeta-svodka`. **Не ребейз.** Эта ветка уже содержит слияние трёх прошлых ветвей диеты и замер нормы.
- Коммит **поимённо и по разделу**: `git commit -m "…" -- <файлы>` (`git add X && git commit` коммитит весь индекс — ловушка этого производства).
- Бинарники сборки (`*.pdf`, `*.pptx`, `parts/`, `parts-sec/`) **не коммитить**.
- Манифесты `deck*.yaml` **не править руками и не коммитить** — их пересобирает оркестратор генератором `make_deck_yaml.py` после слияния.
- Сообщения на русском, с `#229`, последняя строка `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`.
- Пушить свою ветку. После каждого раздела — коммит, пуш, одна строка мне через
  `mcp__harness-control-mcp-server__send_message` без `receiver_id`.
- `timeout` на тяжёлые вызовы; в `/tmp` не писать (уборка съедает, мерить потом нечего).
- Противоречие в наряде или правило, которое мешает правилу, — **останови пункт и спроси
  меня числом цены**, не решай молча. В этом производстве два таких останова оказались
  правильными.
