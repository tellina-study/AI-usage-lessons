# Сервер обновился сам. Никто не заметил

## Assertion

Три недели назад команда подключила сервер уведомлений и одобрила инструмент один раз, при первом вызове. С тех пор сервер обновился сам — пакет подключён через `npx -y`, без зафиксированной версии, — и никто этого не заметил: всё продолжало работать.

## Visual

> Сервер уведомлений: отправляет сообщение в рабочий канал при каждом успешном прогоне тестов перед показом. Инструмент одобрили один раз, при первом вызове.

- Пакет подключён через `npx -y`, без зафиксированной версии.
- Сервер обновился сам — это свойство самого способа подключения, не наблюдение задним числом.
- Уведомления приходили, как и раньше. Никто не заметил.

## Speaker notes

Три недели назад команда подключила сервер уведомлений: он отправляет сообщение в рабочий канал при каждом успешном прогоне тестов перед показом. Инструмент одобрили один раз, при первом вызове. С тех пор сервер обновился сам — пакет подключён без зафиксированной версии, — и никто этого не заметил, потому что всё продолжало работать: уведомления приходили, как и раньше.

Если спросят, что именно изменилось: сцена заканчивается подозрением, не фактом — мы пока не знаем, что произошло внутри обновления, только то, что оно случилось незаметно.

Если спросят, откуда вообще известно, что сервер обновился: команда подключения без зафиксированной версии забирает последнюю доступную версию пакета при каждом старте — это свойство самого способа подключения, не наблюдение задним числом.

Если спросят, нормально ли, что это прошло незаметно: да. Незаметность здесь — нормальное следствие того, как подключён сервер; внимание команды к этому не имеет отношения.
