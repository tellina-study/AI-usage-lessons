> **Where does the process get its facts, and why does it consider them true?**

> Four rows — the session's four cases. The right column is filled in with measurement: a run of our own rig on real data.

## Speaker notes

Here's the axis the whole of today's session stands on. Four rows, and each one holds a claim that looks like a reasonable continuation of what either the previous seminar or the previous case of this same session just taught. Read the left column in full.

If the base has grown — just list it all in the prompt, like last session: if ten items fit in the prompt, a hundred will fit too. You can cut a document into pieces any way you like, as long as the chunk ends up in storage — where the cut falls looks like a technical detail, even though in practice it's a decision. Semantic search, through a vector, finds the same thing as keyword search anyway, just smarter — since it understands the meaning of the question, it's obviously better than matching on word overlap. And if we already know how to search text, we'll find an image the same way, just by captioning it in words.

The right column is empty, and it's empty by design. None of the four left-hand rows was invented for contrast — each continues exactly what either the previous seminar or the previous case of this same session just taught. We'll come back to this table after each case and fill in one row — with a number from the run you'll have just seen on screen.

The question below the table is today's main question. Notice its second half — "why the process considers them true": it carries more weight than the first half, "where the facts come from." That's the difference between "something was found" and "what was found can be used as grounds for an answer" — and that difference will keep coming back all day, right up to a dedicated breakdown in the middle of the session that will show directly: "found" and "correct" are different things.

Four cases in a row will give four answers to this table. None of the four runs will stop at the first intuition — each will check it with a number.
