# Корпуса кейсов A/B/C — Веха 1, круг 2

Каждый корпус **проверен загрузкой, а не рассуждением**: скачан, файлы посчитаны,
несколько открыто глазами, лицензия прочитана. Журнал проверки, включая отказы и грязные
пометки, — `zhurnal-A-B-C.md`. Бинарники в гит не кладутся (решение оркестратора):
воспроизводимость даёт `korpus/fetch_korpus.py` + `korpus/manifest-foto-BC.json` с
`sha256` каждого скачанного файла, лицензией и автором. Исключение — снимки, попавшие на
кадры деки: те и так живут в `rendered/figures/`.

## 1. Корпус A — документы: FUNSD (принят на гейте круга 1, без изменений)

| | |
|---|---|
| Откуда | `https://guillaumejaume.github.io/FUNSD/dataset.zip` (EPFL, LTS5) |
| Что это | 199 отсканированных **форм** (анкеты, факс-обложки, бланки): 149 train + 50 test, PNG + JSON |
| Сколько | 398 пар PNG+JSON; 31 485 слов, 9 707 сущностей, 5 304 связи |
| Ground truth | текст каждого слова + разметка `question`/`answer` со связями «поле → значение»: адресат, телефон, дата, число страниц — значения, которыми процесс ручается |
| Лицензия | прочитана на странице License: «non-commercial, research and **educational** purposes» — учебное использование разрешено явно; картинки из RVL-CDIP (публичные документы табачных процессов) |
| Трудные негативы | кейсу A не нужны (не поиск); для контроля D — близкие значения полей (формы одного отправителя, соседние даты), ≥10 запросов, единственность по GT |
| Размер / путь | zip 16,8 МБ, распаковано 29 МБ; `/tmp/s12-corpora/funsd/`; восстановление — `fetch_korpus.py` |
| Глазами | 3 формы открыты: поля заполнены, сканы шумные, перекос настоящий |

Почему формы, а не счета: счёт-фактура визуально тот же чек (сняты владельцем целиком);
форма = **входящая заявка в учебный центр**, бизнес-кейс дуги. Подвыборка кейса A: 25–30
форм из `testing_data` с богатыми полями — критерии в `kejs-A-dokumenty.md`.

## 2. Единый фотокорпус B+C — Open Images V7, два среза

Ответы владельца: готовых фотографий центра нет — «найди готовые размеченные датасеты с
людьми»; запрещённое — «слайды учебных материалов (боимся что утащат конкуренты) и сцены
курения или употребления еды/напитков». Решение оркестратора: один корпус на B и C,
нарезанный срезами; машинные пометки истиной не считаются.

### 2.1 Источник и проверка

| | |
|---|---|
| Откуда | Open Images V7 (Google): метаданные `storage.googleapis.com/openimages/…`, картинки пофайлово `open-images-dataset.s3.amazonaws.com/<split>/<id>.jpg` (проверено скачиванием из validation, test и train) |
| Пометки | берутся ТОЛЬКО человеческие (`Source=verification`), машинные отфильтрованы. В val+test: Person 32 573 позитива; Classroom 120, Lecture 162, Seminar 93, Conference hall 69, Public speaking 86, Meeting 89, Whiteboard 98, Coffee cup 629; Projection screen 139, Presentation 124; Eating 136, Drinking 58, Food 14 197, Drink 1 899; **Cigarette 29**. Train (потоковый греп 1 раз): Cigarette **558**, Smoking **394** позитивов и **1 301/1 336 проверенных человеком негативов** |
| Лицензии | у каждой картинки в метаданных; все 18 713 кандидатов наших классов — **CC BY 2.0** (проверено объединением с `*-images-with-rotation.csv`); автор и ссылка — в манифесте, на кадре деки — подпись |
| Скачано и посчитано | 131 снимок, 43 МБ, 11 срезов (см. 2.2–2.3) + 1 train-проба; `sha256` каждого в `manifest-foto-BC.json` |
| Глазами | открыто 8 снимков по срезам: курящий мужчина; доклад со сцены; мастер-класс за столом; конференц-зал со слайдом «Web 2.0 roadmap»; уличная еда. **Две грязные пометки найдены и записаны** (журнал): теннисный стол в срезе Whiteboard; ведро окурков без людей в срезе Cigarette — человеческая пометка OI тоже бывает кривой, и «сигарета в кадре» ≠ «сцена курения» |

### 2.2 Срез B — группы «похожие, но не те», с людьми (требования D §1–§5)

8 групп × 6–8 кандидатов скачано; финальная курация глазами до 4–6 на группу, целевой
объём **36–48** (внутри 30–60 по D):

аудитория/класс · лекция · семинар · конференц-зал · выступление с микрофоном ·
совещание за столом · у доски (пересобрать после находки с теннисным столом) ·
кофе-брейк (кружки/напитки).

Поверх — **моя разметка** «что видно» 5–10 строк на снимок, пишется **после гейта круга 2
и до единого модельного описания** (истина не делается той же моделью, чьи описания
проверяем). Запросы: 3 класса × 12–15 (слово из описания / то же другими словами /
деталь, которую описание не упомянет), RU + EN-перевод, единственность — проверкой по
разметке до прогона. Выход B для D: `stend/zamery-B/opisaniya.json` (id → описания, имя
модели, дословный промт) — замер D не стартует до этого файла.

### 2.3 Срез C — три класса запрещённого (рамка: премодерация архива мероприятий)

| Класс | Позитивы | Негативы | Тип истины |
|---|---|---|---|
| Слайды учебных материалов в кадре | Projection screen 139 + Presentation 124 (val+test); скачано 22 | сцены мероприятий без экрана (срез B) | пометка на снимок; рамок на «наш материал» нет и быть не может — сличение с библиотекой слайдов, ступень 3 кейса |
| Курение | 29 val/test + добор из train (558 Cigarette / 394 Smoking); скачано 29 + 1 train-проба | **1 301/1 336 train-негативов, проверенных человеком** + сцены B | пометка на снимок целиком, рамок нет → замер — **классификация, не детекция** (сказать на кадре) |
| Еда и напитки | Eating 136 + Drinking 58 (+Food/Drink/Beer/Wine/Coffee cup с рамками); скачано 20; алкоголь из круга 1 — частный случай напитков | verified-negatives Food/Drink (5 566/1 629) + сцены B | рамки есть у Food/Drink → детекция возможна |

Три класса ложатся в три разных места относительно общего детектора — проверено запуском
yolov8n на этих самых снимках (журнал): еду находит (sandwich 0,43 / hot dog 0,41),
сигарету структурно не может (класса нет в словаре; на сцене курения — только person),
на слайдовой сцене видит человека, а не экран с нашим материалом.

**Определение каждого класса — до замера, письменно** (урок К1 «спросили словом, а не
определением», подтверждён здесь же: ведро окурков — «курение»? по пометке да, по рамке
владельца нет). Проекты определений — `kejs-C-zapreshchennoe.md` §2, финальное слово —
владельца.

### 2.4 Люди на кадрах деки

Замер идёт по всему корпусу; на кадры деки берутся снимки, где лицо не узнаётся, либо
лицо замыливается на самом кадре (решение оркестратора; курс публикуется открыто).
Снимки с детьми (есть в срезе «класс») в деку не идут вовсе — помечаю в разметке.

## 4. Что НЕ выбрано и почему

- **COCO val2017** (круг 1) — снят гейтом: группы без людей против ответа владельца;
  классов курения/слайдов в COCO нет вовсе. Нож и MIDV-500 сняты вместе с прежней рамкой C.
- **SROIE/счета** — визуально чек; **DocVQA/XFUND** — регистрация, NC-оговорки;
  **Flickr30k/Visual Genome** — research only; **Unsplash Lite** — нет истины и групп;
  **Roboflow/Kaggle-наборы** — скачивание через аккаунт, лицензии пёстрые по датасету.

## 5. Риски, названные прямо

1. **Cigarette в val+test — всего 29**; добор из train обязателен (проверено: train-картинка
   скачивается тем же S3-путём, train-метаданные с лицензиями стримятся грепом). Если после
   курации глазами чистых «сцен курения» останется <20 — скажу числом, и класс меряется на
   том, что есть, с названной шириной шага метрики.
2. **Пометка ≠ определение.** Обе найденные грязные пометки лечатся одним и тем же: моя
   разметка глазами на финальный состав, определения классов письменно до замера.
3. **Отсутствие пометки ≠ проверенное отсутствие** (у Cigarette в val/test нет verified-
   негативов). Негативы берутся из train-verified-негативов и из размеченных мной сцен B.
4. **Язык нулевого выстрела:** английские подсказки, русские рядом как измеренная цена
   (параллельная сессия уже измерила деградацию RU-башни SigLIP — её числа наследуются,
   не перемеряются).
