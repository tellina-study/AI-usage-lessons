# Как это решают без модели — классические режимы Раздела 1

## Assertion

Шесть классических режимов Раздела 1 работают прямо сейчас. Главный — сплошное опрыскивание по регламенту: ≈$65-67/акр на кукурузе, ≈$94/акр на сое. Каждый рабочий случай ниже сравнивается с одним из них, а не с нулём.

## Visual

Верхняя крупная плашка (Ocean rounded box, gold accent на цене) — режим №1: «**Сплошное опрыскивание по регламенту** (blanket spray) — препарат на всю площадь по календарному плану защиты, независимо от фактического распределения сорняка. Основная база сравнения для всего раздела». Рядом — два ценовых бейджа: «**$65-67/акр** — кукуруза (препарат $56 + custom-проход $8,50-11)» и «**$94/акр** — соя (2 прохода, препарат $75 + custom $9,35×2)».

Ниже — компактный список оставшихся пяти режимов (по одной строке каждый, Ocean rounded box, без фотографий):
2. **Осмотр агронома с выборочной обработкой** — человек проходит контур, находит очаги; точность высокая, масштабируемость низкая.
3. **Механическая прополка** — культиваторы (Lemken Steketee, Kverneland Onyx); без химии, без модели; **$21,23/акр** (разброс $12-35/акр).
4. **Агротехнические приёмы** — севооборот, покровные культуры, сроки сева; подавляют сорняк без обработки вообще.
5. **Внесение по карте урожайности прошлых лет** — переменная норма по заранее нарезанным зонам, без обучения на новых данных; это уже точное земледелие, но ещё не ИИ.
6. **Консультация extension service** / районного агронома — внешняя экспертиза вместо собственного решения.

## Speaker notes

Прежде чем смотреть на See & Spray, нужно назвать по именам то, с чем мы его будем сравнивать, — потому что модель почти никогда не приходит на пустое место, она приходит рядом с уже работающим режимом.

Главный режим — сплошное опрыскивание по регламенту. Препарат вносится на всю площадь по календарному плану защиты, независимо от того, где сорняк на самом деле стоит. Это самый простой, самый предсказуемый и самый расходный по химии режим, и это основная база сравнения для всего раздела. Полная цена этого режима — не только химия. На кукурузе препарат стоит пятьдесят шесть долларов с акра, а найм техники и оператора на проход — восемь с половиной — одиннадцать долларов за проход, то есть полная цена режима — примерно шестьдесят пять-шестьдесят семь долларов с акра. На сое, где регламент устойчивых сортов требует два прохода, препарат стоит семьдесят пять долларов с акра, а два прохода добавляют почти девятнадцать долларов — полная цена режима примерно девяносто четыре доллара с акра. Источник обеих цифр — Iowa State University Extension, Ag Decision Maker, бюджеты культур 2026 года.

Второй режим — осмотр агронома с выборочной обработкой: человек проходит контур, находит очаги, назначает точечную обработку. Точность высокая, но масштабируемость низкая — ограничена тем, сколько контуров один агроном успевает обойти за сезон.

Третий — механическая прополка: междурядные культиваторы вроде Lemken Steketee или Kverneland Onyx, физическое уничтожение сорняка без химии и без обучаемой модели. Детерминирован, устойчив к пыли и освещению, ограничен геометрией посадки. Цена — в среднем двадцать один доллар двадцать три цента с акра, с разбросом двенадцать-тридцать пять долларов с акра, по данным Ohio Farm Custom Rates 2026 — это цифра для полевых культур вообще, не точный аналог сои или кукурузы под selective spray, но для сравнения порядка величины годится.

Четвёртый — агротехнические приёмы: севооборот, покровные культуры, сроки сева, которые подавляют сорняк без всякой обработки. Пятый — внесение по карте урожайности прошлых лет: переменная норма по заранее нарезанным зонам, без обучения на новых данных. Это важно не перепутать: это уже точное земледелие, но ещё не ИИ — смешивать эти два режима — самая частая ошибка чтения отраслевой рекламы. Шестой — консультация службы распространения знаний или районного агронома: внешняя экспертиза вместо собственного решения.

Каждый рабочий случай этого раздела, который мы разберём дальше, сравнивается именно с одним из этих шести режимов — и почти всегда именно со сплошным опрыскиванием, потому что это самый распространённый режим в товарном земледелии США.
