# Сценарий 3 — inline-подсказка кода

## Assertion

AI-ассистент в IDE: inline-подсказка следующей строки кода.

## Visual

Левая карточка (SURFACE-фон, TEAL обводка вместо обычной ocean_box, чтобы визуально перекликаться со следующим слайдом): иконка `mouse-pointer-click`, курсивный текст сценария («Вы пишете код в IDE. AI-ассистент на лету достраивает следующую строку — вы видите подсказку серым текстом и нажимаете Tab, чтобы принять её»), внизу компактно Q1/Q2.

Справа квадрант 2×2, ячейка «Приложение» выделена gold, gold callout снизу «Понимание контекста кода само по себе не означает планирование».

## Speaker notes

Прогоняем через чек-лист. Q1 — нет: нет диалога, нет уточнений — принял или отклонил подсказку. Q2 — нет: один проход «текущий контекст кода → предложение строки», без самостоятельного вызова внешних инструментов. Правильный ответ — приложение, тот же паттерн, что Copilot inline из раздела 2.

Ожидаемая путаница: часть аудитории могла проголосовать «агент», потому что ассистент «понимает код» — это и есть точка обсуждения: понимание контекста, даже сложного, само по себе не означает наличие планирования, памяти за пределами сессии и самостоятельного вызова инструментов. Обязательно вызовите студента, который проголосовал «агент», и попросите аргументировать — затем мягко покажите, чего именно не хватает для агента.
