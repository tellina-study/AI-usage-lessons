# Пять вариантов — и один плательщик налога

## Assertion

Из пяти вариантов только скилл с описанием-триггером отдаёт решение о релевантности модели, не человеку и не среде; файл инструкций уже платит за процедуру в девяти сессиях из десяти.

## Visual

| Вариант | Где это работает | Почему здесь рано — и что вместо |
|---|---|---|
| оставить как есть | нигде: это и есть тот антипаттерн, который ступень называет | налог платится в каждой сессии независимо от запроса |
| отдельный файл + импорт | файл станет читаемее | импортированный файл всё равно грузится целиком при старте: налог переехал, а не исчез |
| отдельный файл, напоминать вручную | пока деплоев мало и память не подводит | человек нужен в каждом цикле, а способность модели решить самой не используется |
| хук | там, где правило нельзя нарушить ни разу | деплой нельзя исполнить за агента: на каждом шаге решение. Хук — для правил, скилл — для процедур |
| ✔ скилл с описанием-триггером | здесь — именно то, что нужно | не рано: файл уже платит в девяти сессиях из десяти. Ломается, если описание написано для человека |

## Speaker notes

«Оставить как есть — ровно тот случай, который ступень и называет: налог платится в каждой сессии, независимо от того, о чём вы спрашиваете.

Отдельный файл плюс импорт: импорт не экономит контекст, импортированный файл грузится целиком при старте. Файл стал читаемее — счёт остался прежним.

Напоминать вручную работает, пока деплоев немного. Но человек нужен в каждом цикле, а способность модели решить самой не используется.

Хук — продуктивная путаница, разведём. Хук это механика: среда исполняет его сама. Скилл это знание: агент может учесть, а может нет. Исполнить деплой за агента нельзя — там на каждом шаге решение: что показал адрес на проде, дошла ли заявка.

И целевой. Единственный способ его испортить — написать описание для человека, а не как триггер.»
