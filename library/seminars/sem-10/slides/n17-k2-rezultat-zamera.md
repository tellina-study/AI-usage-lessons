# Что показал прогон на пяти размерах куска

## Assertion

Версия 1 никогда не опускается до нуля разорванных ответов; версия 2 — почти всегда в границах 0–1,4%.

## Visual

| Размер куска, символов | V1 — резать по счёту символов | V2 — резать по предложениям |
|---|---|---|
| 120 | 9,7% (7 из 72) | 1,4% (1 из 72) |
| 180 (заголовочное) | 12,5% (9 из 72) | 1,4% (1 из 72) |
| 220 | 4,2% (3 из 72) | 1,4% (1 из 72) |
| 300 | 6,9% (5 из 72) | 0,0% (0 из 72) |
| 450 | 2,8% (2 из 72) | 1,4% (1 из 72) |

> **Версия 1 не монотонна по размеру куска: 9,7% → 12,5% → 4,2% → 6,9% → 2,8%. «Удобный» на вид размер не гарантирует качества без проверки.**

## Speaker notes

Шестьдесят документов из SberQuAD длиной не короче пятисот символов — иначе резать на части просто нечего — и семьдесят два вопроса с разметкой ответа, которую мы проверили напрямую, а не приняли на веру: двадцать два процента строк исходного датасета оказались с битой разметкой позиции ответа, и такие строки исключены из замера, не подогнаны под удобный результат.

Таблица читает одно и то же измерение пятью разными глазами — на пяти разных размерах куска, от ста двадцати до четырёхсот пятидесяти символов. И на каждом из пяти версия, которая режет по границам предложений, даёт заметно меньшую долю разорванных ответов, чем версия, которая режет по голому счёту символов. Версия 1 ни разу не опускается до нуля — минимум, которого она достигает, это 2,8% на самом крупном из проверенных размеров. Версия 2 почти всегда держится в границах от нуля до 1,4%, и на одном размере, трёхсот символах, достигает честного нуля.

Отдельно обратите внимание на заголовочную плашку: версия 1 ведёт себя не монотонно по размеру куска. Интуитивно кажется, что чем крупнее кусок, тем меньше шанс разрыва, — но на практике доля разорванных ответов версии 1 прыгает: 9,7%, затем 12,5% на размере чуть больше, затем падает до 4,2%, снова растёт до 6,9% и только потом падает до 2,8%. Это значит, что выбор «удобного на вид» размера куска сам по себе ничего не гарантирует — проверять нужно на своих данных, а не переносить чужое эмпирическое правило без проверки.

Версия 2 ведёт себя иначе: её кривая почти плоская — 1,4%, 1,4%, 1,4%, 0,0%, 1,4%. Она не просто даёт меньшую долю разорванных ответов в среднем, она ещё и устойчива к выбору конкретного размера куска, в то время как версия 1 заметно зависит от того, какое именно число выбрано. Это второй, отдельный довод в пользу резки по смыслу — не только меньше ошибок, но и предсказуемость результата при изменении настройки.
