# Границы CV-QC + альтернативы до ML

## Где CV ломается

**Low-contrast defects.** Микротрещина на алюминиевой поверхности при обычном освещении — невидима для CV. Размытые границы дефекта, маленькая контрастность.

**Сдвиг распределения при смене продукта.** Завод выпускает 5+ моделей. Модель CV-инспекции, обученная на модели A, плохо работает на модели B без дообучения.

**Scarce defect labels.** Defect rate 1% + редкие типы дефектов = модель не видит rare defects. Callback на s16: стоимость разметки.

## Альтернативы (применять ДО ML)

**Physical signal amplification:**
- **Структурированный свет** — проектор + камера + триангуляция → 3D-микрорельеф. Trick: усиливаем сам сигнал, а не алгоритм.
- **Поляризованный свет** — стресс в стекле, scratches в покрытии.
- **Рентген (X-ray)** — внутренние дефекты литья, сварных швов.
- **Тепловидение** — горячие точки в электронике.

**Rules-based vision** — простые правила (площадь, контур, цвет) → ловят 60–70% inspection workloads в controlled environments. Дёшево, объяснимо, валидируется.

## Hybrid

Сначала физика амплифицирует сигнал. Потом rules ловят простые случаи. ML — только на остатке (10–20%).

## Speaker notes

Где компьютерное зрение для контроля качества не работает, и что использовать вместо.

Первое ограничение — low-contrast defects. Микротрещина на алюминиевой поверхности при обычном освещении — практически невидима для CV. Размытые границы дефекта, маленькая контрастность с фоном, шум сенсора. Модель может натренироваться отличать с точностью 60-70 процентов, но это недостаточно для production-уровня. Здесь нужна физическая амплификация сигнала, не больше данных.

Второе — сдвиг распределения при смене продукта. Завод обычно производит не одну модель, а 5-10. Модель CV-инспекции, обученная на модели A, работает плохо на модели B. Нужно дообучать. На переоборудование линии под новую модель — дни. На сбор размеченных данных + дообучение CV — недели или месяцы. Это операционный risk.

Третье — scarce defect labels. Defect rate 1 процент, и среди этого процента ещё есть rare типы дефектов, которые встречаются раз в 10000 деталей. Класс imbalance возводится в куб. Модель не видит rare defects, потому что у неё мало примеров. Callback к s16 — стоимость разметки.

И вот альтернативы, которые надо использовать ДО того, как добавлять ML.

Physical signal amplification. Это самая важная категория. Структурированный свет — проектор + камера + триангуляция → получаешь 3D-микрорельеф поверхности. Микротрещина, которая невидима при обычном освещении, видна как изменение высоты на десятки микрон. Trick: ты усиливаешь сам сигнал, а не алгоритм. Поляризованный свет — отлично для стресса в стекле, для scratches в покрытии. Рентген — внутренние дефекты литья, сварных швов. Тепловидение — горячие точки в электронике.

Rules-based vision. Простые правила: площадь, контур, цвет, geometric primitives. Это ловит 60-70 процентов inspection workloads в controlled environments. Дёшево, объяснимо, валидируется регулятором за неделю. Когда мы дойдём до §4 и категории «регуляторика» — black-box ML не проходит FDA Part 11. Rules-based проходит без вопросов.

Hybrid-подход — самый рациональный. Сначала физика амплифицирует сигнал — получаем чистый input. Потом rules ловят простые случаи — 60-70 процентов inspection workloads. ML добавляется только на остаток — 10-20 процентов сложных случаев. В этой архитектуре ML делает то, в чём он реально хорош, а не пытается заменить всю pipeline.

Это рамка для категории «данные» в §4: если у вас нет эталонной разметки в достаточном объёме — попробуйте сначала physical signal amplification, потом rules, и только если осталась 10-20% сложности — ML.
