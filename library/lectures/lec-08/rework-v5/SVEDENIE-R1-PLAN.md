## 2. Один перенос порядка, и он важнее всех слияний

**`s31` (1,84 байта) встаёт ПЕРЕД `s30` (Getty).**

Запись выводит права из устройства одной причинной цепочкой: модель не конструирует
объект → значит не копирует → значит остаётся только товарный знак. Счёт «4,27 ГБ на 2,32
млрд картинок — 1,84 байта на изображение» предъявлен **до суда, как доказательство
невиновности**, и решение суда читается второй опорой, а не первой.

У нас порядок обратный, и стрелка «не конструирует → не копия → только товарный знак» не
произнесена вовсе — её собирает из двух карточек сам слушатель. Это и есть «повествование
как в звуковых дорожках»: не другая форма, а другой порядок.

## 3. Чем мерить сохранность — и одна ловушка счёта

| Что | Сейчас в разделе | Чем мерить |
|---|---|---|
| Минуты | 21,0 | `deck/sverka_s_kartoy.py` |
| Доля провалов и границ | **7,1 мин из 21,0 — 34 %** | по минутам, не по кадрам |
| Кадров с иллюстрацией | 10 из 33 | поле `media`; при слиянии двух кадров с картинками решить, какая остаётся |
| Накопительная карта | `s32a` | не трогать |

**Ловушка: долю провалов считать по минутам, а не по кадрам.** Сейчас 12 кадров из 33 —
36 % по штукам и 34 % по минутам. После слияния кадров станет меньше, и **доля по штукам
подскочит до сорока с лишним процентов, ничего не означая**. По минутам доля при честном
слиянии не меняется вовсе: содержание то же, время то же. Поэтому мера — минуты, и
расхождение минут после сведения есть признак, что содержание всё-таки потеряли.
