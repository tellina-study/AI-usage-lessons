# Журнал и вердикт

## Assertion

Закрыть задачу — только по проверяемой ссылке: SHA, PR или файл плюс таймстампированная запись, не по фразе «готово» в чате.

## Speaker notes

Слева — реальная запись из `Tasks/2026-09-20_form-endpoint-fix/log.md`: три записи с настоящими таймстампами, и каждая называет конкретную выполненную команду, а не общую фразу вроде «поработал над формой». Первая запись — создание ветки от `main`. Вторая — сама правка `src/validate.js` с точным regex и с номером коммита `cf58408`, который можно открыть и проверить прямо сейчас. Третья — слияние обратно в `main` fast-forward, без отдельного merge-коммита, потому что `main` не уходил вперёд параллельно. Это и есть журнал, который пишется по ходу работы, а не восстанавливается по памяти в конце дня — единственный артефакт дисциплины этого проекта, чья частота использования не менялась ни при какой нарезке данных.

Справа должен быть заполненный `review.md`, собранный из `review.md.template`: вердикт `PASS` или `BLOCK`, раздел «что проверено» с конкретными файлами и командами, раздел «находки». Правило простое — `BLOCK` означает починку и узкую перепроверку того же ревьюера, максимум два круга; третий круг на одном и том же артефакте — сигнал чинить саму конструкцию, а не продолжать ревью.

Стоит явно проговорить, чем это отличается от отдельного режима планирования: `Shift+Tab` дважды перед началом задачи включает баннер `plan mode on`, в котором запись и выполнение физически отключены, а одобрение плана — явное действие, а не автоматический шаг. Закрывать задачу можно только по проверяемой ссылке — SHA коммита, номеру PR или самим готовым файлам плюс записи в `log.md`; фраза «я сделал X» в переписке этому не равна.

Три артефакта работают вместе, а не по отдельности: план до кода задаёт согласованный чертёж, журнал фиксирует факт по ходу выполнения, а `review.md` — это и есть проверяемая ссылка, на которую можно указать вместо фразы «готово» в чате. Без любого одного из трёх остальные два теряют часть смысла: журнал без вердикта — просто хроника, вердикт без журнала — непроверяемое утверждение того же типа, что и «готово».
