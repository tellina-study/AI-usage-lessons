## Speaker notes

Карьерный мост — четыре роли инженера в индустрии AI-автоматизации производства.

Первая роль — AI/ML engineer industrial. Что делает день за днём: дизайнит и тренирует модели (vision QC, прогностическое обслуживание, alarm prediction) на исторических данных завода. Интегрирует модели в edge runtime. Мониторит drift. Общается с цеховыми инженерами. Ключевые навыки: Python + PyTorch/TensorFlow, MLOps, OPC UA basics, статистика, временные ряды, знание физики процесса. Учиться: профильные технические магистратуры по AI в промышленности.

Вторая — digital twin engineer. Что делает: строит и поддерживает twin для конкретной линии или цеха. Подключает датчики через OPC UA, строит модель оборудования (физика + ML), валидирует точность, разворачивает на edge. Ключевые навыки: Siemens Composer / NVIDIA Omniverse / PTC ThingWorx, CAD, численное моделирование, OPC UA, data pipelines. Учиться: магистратуры по цифровому моделированию плюс Coursera/edX курсы.

Третья — MES integration specialist. Что делает: внедряет advisory-AI в существующий MES (Opcenter, FactoryTalk, SAP MII). Конфигурирует workflow «AI рекомендация → оператор апрув → исполнение». Ключевые навыки: SQL, REST/OPC UA, конкретный MES-стек вендора, бизнес-процессы цеха. Учиться: vendor-сертификации Siemens / Rockwell / SAP.

Четвёртая — edge AI engineer. Что делает: деплоит inference на edge-устройства (NVIDIA Jetson, Modicon edge), оптимизирует latency и throughput, разрабатывает fail-safe handover. Ключевые навыки: C++/Rust, embedded Linux, ONNX/TensorRT, real-time scheduling, безопасность сети для КИИ-объектов. Учиться: embedded плюс ML — стык. Сертификации NVIDIA Jetson плюс cybersecurity для КИИ.
