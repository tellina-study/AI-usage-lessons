# The task file must not mislead

## Assertion

The task file existed from the very start and still misled — a choice of five options for what to do differently.

## Visual

The question verbatim, in a gold frame:

> "The task file existed from the very start, and the plan in it looks current — the first steps are marked done. And the second session still does step 3 differently from what was agreed in the first. Choose what needs to be done differently — from the cards below — so that the task file does not mislead but actually reflects the progress of the work. Justify your choice."

Below — five option cards:

`rely on the context window — never compact and never close the session` · `write the plan into DECISIONS.md` · `a rule in CLAUDE.md: append an agreement to the task file the moment it is made` · `set up a folder per task with a separate file for each step` · `ask the agent to "continue from where we left off"`

The slide has not a single figure, no breakdown table and no target answer — they are on the next slide.

## Speaker notes

One reaction is worth preparing for in advance, but it is acknowledged aloud without any comment on the substance: "Append it to DECISIONS.md" sounds like the right answer from the previous case — the facilitator simply notes the option and moves on, the comment comes on the next slide.
