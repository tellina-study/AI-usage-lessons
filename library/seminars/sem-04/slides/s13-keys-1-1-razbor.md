# Разбор: файл остаётся пустым

## Assertion

Правильный ответ на этом шаге — не какой текст написать, а пока никакой: файл остаётся пустым, потому что триггер ещё не сработал.

## Visual

| Вариант | Где это работает | Почему здесь ещё рано — и что вместо |
|---|---|---|
| «Подробное описание структуры репозитория» | Почти нигде для агента — разве что как документация для новых людей в команде | Агент выведет структуру сам за секунды; описание устареет при первом рефакторинге (анекдот коллеги). Контролируемый эксперимент: +20–23% cost, без прироста success. Вместо: не писать вообще |
| «Список технологий и зависимостей» | Когда версии критичны и не видны из `package.json` (редко) | В большинстве случаев тоже выводимо за секунды. Вместо: не писать, если версии видны в манифесте |
| «Инструкция, где лежит форма и как её найти» | Почти нигде на таком маленьком репозитории | Четыре файла, вся структура на одном экране — находимость не проблема. На большом монорепо разговор другой |
| «Неочевидная конвенция, которую агент не угадает сам» | Когда конвенция реально есть и реально невыводима (Lulla et al.) | На этом шаге такой конвенции ещё нет — проект только начался. Появится — записать её, и только её |
| **«Пока ничего — до первого реального сигнала»** | **Здесь и сейчас** | **Целевой ответ.** Перестаёт быть верным, когда появится конкретная невыводимая вещь — не раньше |

Нижняя плашка — критерий «здесь ещё рано»:

> «Всё, что агент выведет из кода за секунды (структура, технологии, список файлов), в файл не идёт никогда — не "пока рано", а вообще. Общее описание роли/архитектуры оправданно только там, где нет вообще другой документации; у `signup-landing` она будет — значит, оснований нет.»

## Speaker notes

«Смотрите на строку "cost плюс двадцать-двадцать три процента" — она значима во всех плечах эксперимента, а вот прирост успеха — нет, ни в одном. Единственное подтверждённое исключение — репозитории без другой документации вообще. У нас будет README, значит, для общего overview оснований нет. Правильный ответ на этом шаге — не "какой текст написать", а "пока никакой". Файл остаётся пустым. Это не значит, что он не понадобится — это значит, что триггер ещё не сработал.»

Критерий «ещё рано» — голосом, по нижней плашке: всё, что агент выведет из кода за секунды, в файл не идёт никогда, не «пока рано»; общее описание роли и архитектуры оправданно только там, где вообще нет другой документации — у нашего репозитория она будет, значит оснований нет.
