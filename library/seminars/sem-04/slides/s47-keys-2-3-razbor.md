# Разбор: один файл на задачу

## Assertion

Один файл на задачу — план, лог хода, результаты — целевой ответ для линейной задачи с одним агентом и одним разработчиком.

## Visual

Мелким шрифтом вверху — вопрос для контекста: «Куда записывать ход многошаговой задачи?»

Таблица разбора пяти позиций:

| Вариант | Где это работает | Почему здесь ещё рано — и что вместо |
|---|---|---|
| «Не сжимать, не закрывать сессию» | Для задачи, целиком укладывающейся в одну короткую сессию | Контекстное окно конечно; на многошаговой задаче рано или поздно случится сжатие или разрыв сессии — это не стратегия, а отсутствие стратегии |
| «Записать план в `DECISIONS.md`» | Никогда — не тот слой памяти | `DECISIONS.md` — про «почему» для решений, которые остаются в силе навсегда; статус одной задачи туда не относится. Смешение испортит оба журнала |
| «Один файл на задачу: план + лог хода + результаты» | Ровно наш случай — одна линейная задача, участники — разработчик и агент | Целевой ответ для этого масштаба |
| «Папка на задачу с файлом под каждый шаг» | На задачах с параллельными подзадачами, несколькими агентами/субагентами, или когда лог одного файла сам разрастается до неудобного объёма | Оверинжиниринг для одной линейной задачи здесь и сейчас. Паттерн реально масштабируется до папки, но не в рамках сегодняшнего упрощения |
| «Попросить "продолжи с того места"» | Внутри одной непрерывной сессии, до сжатия контекста | После сжатия или в новой сессии буквально нечего продолжать — просьба адресована памяти, которой не существует |

Нижняя плашка, gold: **целевой ответ — один файл на задачу, с явным уточнением, что это упрощённая версия паттерна, масштабируемого до папки.**

## Speaker notes

«Не сжимать, не закрывать сессию» — контекстное окно конечно, это не стратегия, а её отсутствие. «Записать план в DECISIONS.md» — никогда не тот слой: журнал решений про то, что остаётся в силе навсегда, статус одной задачи туда не относится, смешение испортит оба журнала — ровно та ошибка, которую разбирала карточка про упавший тест в первом кейсе раздела. «Один файл на задачу» — ровно наш случай, целевой ответ. «Папка на задачу» — оверинжиниринг для одной линейной задачи здесь и сейчас, но паттерн реально масштабируется до папки. «Продолжи с того места» — тот же механический факт, что «агент сам запомнит»: после сжатия или в новой сессии буквально нечего продолжать.

Целевой ответ — один файл на задачу, с явным уточнением про упрощение.
