# Quickfire А

## Assertion

НДС по чеку — какая архитектура?

## Visual

Одна широкая Ocean rounded box карточка (иконка `dollar-sign`, chip «QUICKFIRE А» TEAL fill). Текст курсивом крупным шрифтом по центру: «Нужно посчитать НДС по чеку: сумма × фиксированная ставка налога. Какая архитектура?»

Внизу — 2 равные нейтральные chip-плашки бок о бок (SURFACE fill, LIGHT stroke, НЕ gold): «ИИ не нужен вовсе / обычный код» и «Нужен какой-то ИИ» — упрощённое голосование, не полная 6-ступенчатая лестница.

## Speaker notes

Зачитайте вслух: нужно посчитать НДС по чеку — сумма умножить на фиксированную ставку налога. Какая архитектура?

Механика: примерно 45 секунд молчаливого решения, один быстрый раунд голосования — руки за «ИИ не нужен вовсе, обычный код» против «нужен какой-то ИИ» — мгновенный разбор, без вызова студентов на дискуссию.
