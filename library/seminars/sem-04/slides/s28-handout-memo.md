# Раздаточный лист

## Assertion

Лестница + 4 критерия — рабочая карточка на вынос.

## Visual

4 равных Ocean rounded box блока в сетке 2×2. Блок 1 «Лестница» (иконка `workflow`, MID): «Код (без ИИ) → промпт (один вызов) → RAG → workflow → агент → мульти-агент. Подниматься на следующую ступень — только при явном требовании задачи, которого текущая ступень не закрывает». Блок 2 «4 критерия» (иконка `list-checks`, TEAL): «Контроль (аудируемость результата) · Стоимость (за запрос + инфраструктура) · Шаги (риск накопления ошибок: 0.99ⁿ падает с ростом n) · Инструменты (нужен ли retrieval/function calling и на каких правах)». Блок 3 «Три кейса — три ступени» (иконка `file-search`, LIGHT): «Поиск в 200 PDF → RAG. Бот техподдержки с чтением и записью → workflow или агент, в зависимости от предсказуемости. Разовый отчёт → низ лестницы, без RAG и без агента». Блок 4 «Главная ловушка» (иконка `alert-triangle`, GOLD_DARK): «Задача "звучит важно" → тянет выбрать ступень выше, чем нужно. Считайте по критериям, а не по ощущению важности».

Внизу — курсив (SLATE, по центру): «Всё, что здесь написано, вы уже проходили сегодня своими руками».

## Speaker notes

Заранее подготовленная печатная карточка «Лестница сложности + 4 критерия» — компиляция того, что уже прозвучало на занятии, без нового материала.

Лестница: код без ИИ, промпт, RAG, workflow, агент, мульти-агент. Подниматься на следующую ступень — только при явном требовании задачи, которого текущая ступень не закрывает.

Четыре критерия: контроль — аудируемость результата; стоимость — за запрос плюс инфраструктура; шаги — риск накопления ошибок, 0.99 в степени n падает с ростом n; инструменты — нужен ли retrieval или function calling и на каких правах.

Три кейса сегодня — три ступени: поиск в 200 PDF привёл к RAG; бот техподдержки с чтением и записью — к workflow или агенту, в зависимости от предсказуемости маршрута; разовый отчёт — к низу лестницы, без RAG и без агента.

Главная ловушка: задача «звучит важно» тянет выбрать ступень выше, чем нужно. Считайте по критериям, а не по ощущению важности.

Раздайте карточку, коротко проговорив: всё, что здесь написано, вы уже проходили сегодня своими руками — в буквальном смысле. Это рабочая карточка, а не новый материал для запоминания.
