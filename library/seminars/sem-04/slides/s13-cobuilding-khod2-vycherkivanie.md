# Проверим эту строку на прочность

## Assertion

Имена скриптов придумал сам агент и сам записал их в `package.json` — строка про команды в файле инструкций почти ничего не добавляет, но платит контекстом в каждом запросе.

## Visual

Слева — строка из предыдущего кадра, **перечёркнутая** (зачёркивание видимое, строка не исчезает).

Справа — блок команд из финального ответа самого агента:

```
npm install
npm run build          # → dist/
npm run test:e2e       # playwright test
```

Подпись под блоком: «имена скриптов придумал он сам, когда собирал проект».

Под перечёркнутой строкой — то, что остаётся вместо неё, узкой плашкой: «как проверить, что правка реально работает, а не только компилируется».

Внизу — вопрос: «Вычёркиваем? Оставляем?»

## Speaker notes

Это тот момент, ради которого упражнение существует. Рядом с только что записанной строкой появляется блок команд из настоящего финального ответа агента — тех самых скриптов, которые он сам придумал и сам прописал.

«Смотрите: эти скрипты уже лежат в `package.json` — и имена им придумал сам агент, когда собирал проект. В следующей сессии он их оттуда прочитает. Мы это проверили на живом прогоне: на полностью сформулированную задачу он не задал ни одного вопроса про команды. Значит наша строка почти ничего не добавляет — но платит контекстом в каждом запросе. Вычёркиваем? Оставляем?»

Строка вычёркивается на экране, и на её месте остаётся заметно более узкая: как проверить, что правка реально работает, а не только компилируется. Вот это уже невыводимо — последовательность ручной проверки формы на собранной странице из кода не следует.

Если зал возражает («пусть будет, вдруг пригодится») — это отличное возражение, его надо поблагодарить и ответить числом: файл грузится в каждую сессию целиком, а измеренная надбавка к стоимости и числу шагов от присутствия файла — двадцать-двадцать три процента относительно работы вовсе без файла. «Вдруг пригодится» здесь имеет конкретный ценник.

И одна мысль, которую стоит оставить: строка в файле инструкций — не бесплатная заметка. У неё есть цена, и за неё надо уметь заплатить.
