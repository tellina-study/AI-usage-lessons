# Что показал прогон на пяти размерах куска

## Assertion

Версия 1 никогда не опускается до нуля разорванных ответов; версия 2 — почти всегда в границах 0–1,4%.

## Visual

> **72 вопроса, заголовочный размер куска — 180 символов.** Версия 1 — 9 разорвано (12,5%), 63 целиком (87,5%). Версия 2 — 1 разорван (1,4%), 71 целиком (98,6%).

| Размер куска, символов | V1 — резать по счёту символов | V2 — резать по предложениям |
|---|---|---|
| 120 | 9,7% (7 из 72) | 1,4% (1 из 72) |
| 180 (заголовочное) | 12,5% (9 из 72) | 1,4% (1 из 72) |
| 220 | 4,2% (3 из 72) | 1,4% (1 из 72) |
| 300 | 6,9% (5 из 72) | 0,0% (0 из 72) |
| 450 | 2,8% (2 из 72) | 1,4% (1 из 72) |

## Speaker notes

Структура теста уже известна — шестьдесят документов, семьдесят два вопроса, пять размеров куска, без единой модели на шаге резки. Вот что этот прогон показал.

На заголовочном размере, сто восемьдесят символов, разница видна сразу: версия, которая режет по счёту символов, разрывает ответ на девяти вопросах из семидесяти двух — это двенадцать с половиной процентов. Версия, которая режет по границам предложений, разрывает ответ только на одном вопросе из семидесяти двух — один и четыре десятых процента. Шестьдесят три ответа из семидесяти двух у версии один доходят целыми, у версии два целыми доходят семьдесят один из семидесяти двух. Разница не на проценты, а в разы, и это на одном и том же корпусе, одних и тех же вопросах, одном и том же размере куска — отличается только правило, по которому проходит разрез.

Таблица читает одно и то же измерение пятью разными глазами — на пяти разных размерах куска, от ста двадцати до четырёхсот пятидесяти символов, в том же порядке, что и в структуре теста. И на каждом из пяти версия, которая режет по границам предложений, даёт заметно меньшую долю разорванных ответов, чем версия, которая режет по голому счёту символов. Версия 1 ни разу не опускается до нуля — минимум, которого она достигает, это 2,8% на самом крупном из проверенных размеров. Версия 2 почти всегда держится в границах от нуля до 1,4%, и на одном размере, трёхсот символах, достигает честного нуля.

Обратите внимание, что это пять независимых прогонов одного и того же набора вопросов, а не один прогон, пересчитанный пятью способами: на каждом размере куска документы режутся заново, обеими версиями, и заново проверяется, уцелел ли каждый из семидесяти двух ответов. Устойчивость результата на всех пяти размерах — это не один удачный замер, а воспроизведённая разница.

Разберём, что стоит за этими процентами, на одном настоящем документе — дальше.
