## Разборы по форме (§4) — по одной строке на разбор

| Разбор | Цена обеих ошибок (плашками) | Классические режимы + графа (а)/(б)/(в) | Модель против них | Как устроено (вход · выход · на чём обучено · имя изделия) | Что переехало (форма словаря) | Адрес оси |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

- Выигрыш, посчитанный **от нуля** вместо классического режима, не принимается.
- Три условия отбора примера — все три разом: изменение вызвано именно ИИ (убери модель — остальное работает? тогда мимо) · предмет отраслевой · дихотомия измерена.
- Альтернативу ИИ **объяснить**, а не назвать жаргоном («замкнутый цикл» без расшифровки — дефект).
- При числе разборов больше десятка — отдельный реестр с правилом счёта (§5).
