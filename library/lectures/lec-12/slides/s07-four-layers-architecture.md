## Visible content

4-слойная архитектура: physical → sensors (OPC UA+MQTT) → model → AI-consumers.

## Speaker notes

Четыре слоя цифрового двойника — это операционное определение, а не презентационная картинка. Слой первый — физический актив: реактор, конвейер, линия, насос. Слой второй — датчики и протоколы передачи: OPC UA для семантики данных, MQTT для транспорта, sampling rate не менее десятикратного частоты управления (по теореме Найквиста). Слой третий — модель оборудования: физическая (Навье-Стокса для потоков, теплоперенос для теплообменников, кинетика для реакторов) плюс ML-надстройка для коррекции дрейфа. Слой четвёртый — AI-потребители: vision QC, оптимизатор, RL-агент, operator UI.

Между слоями — двусторонние стрелки. Это и есть Kritzinger Digital Twin: данные текут вверх, управляющее действие — вниз через симуляцию.

Без любого слоя это не twin. Без датчиков — модель. Без модели — поток без понимания. Без AI-потребителей — данные без действия. Когда вендор предлагает «twin», нарисуйте на салфетке эти четыре слоя и спросите, какой из них реализован у вас в проекте. Если хотя бы один отсутствует — проект придётся достраивать ещё на 12-18 месяцев, и Southeast Asian Port — каноническая иллюстрация что бывает без полного стека.
