## Speaker notes

Структура теста уже известна — шестьдесят документов, семьдесят два вопроса, пять размеров куска, без единой модели на шаге резки. Вот что этот прогон показал.

На основном размере, сто восемьдесят символов, разница видна сразу: версия, которая режет по счёту символов, разрывает ответ на девяти вопросах из семидесяти двух — это двенадцать с половиной процентов. Версия, которая режет по границам предложений, разрывает ответ только на одном вопросе из семидесяти двух — один и четыре десятых процента. Шестьдесят три ответа из семидесяти двух у версии один доходят целыми, у версии два целыми доходят семьдесят один из семидесяти двух. Разница — почти на порядок, и такую не спутать со случайным разбросом в доли процента: один и тот же корпус, одни и те же вопросы, один и тот же размер куска — отличается только правило, по которому проходит разрез.

На том же размере версия, которая режет по границам слов, разрывает ответ на шести вопросах из семидесяти двух — восемь и три десятых процента; версия, которая режет по счёту символов с перекрытием, — на четырёх вопросах, пять и шесть десятых процента. Обе лучше первой версии, обе заметно хуже второй.

Таблица читает одно и то же измерение пятью разными глазами — на пяти разных размерах куска, от ста двадцати до четырёхсот пятидесяти символов, в том же порядке, что и в структуре теста. И на каждом из пяти версия, которая режет по границам предложений, даёт заметно меньшую долю разорванных ответов, чем любая из трёх остальных версий. Версия 1 ни разу не опускается до нуля — минимум, которого она достигает, это 2,8% на самом крупном из проверенных размеров. Версия 2 почти всегда держится в границах от нуля до 1,4%, и на одном размере, трёхсот символах, достигает честного нуля. Версии 3 и 4 ведут себя похоже друг на друга — где-то ближе к версии 1, где-то опускаются до нуля на крупных размерах, но ни на одном из пяти размеров не обгоняют версию 2.

Это пять независимых прогонов одного и того же набора вопросов. Один прогон, пересчитанный пятью способами, здесь ни при чём: на каждом размере куска документы режутся заново, всеми четырьмя версиями, и заново проверяется, уцелел ли каждый из семидесяти двух ответов. Устойчивость результата на всех пяти размерах — это воспроизведённая разница; один удачный замер такого не даёт.

Это измерение — про разрез куска: уцелел ли эталонный ответ внутри одного куска. Отвечает ли сама модель правильно, когда цепочка ищет нужный кусок без подсказки, — отдельный, более честный замер, дальше.
