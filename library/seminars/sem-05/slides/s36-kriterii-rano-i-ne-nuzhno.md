# Ещё рано — и не нужно вообще

## Assertion

Скилл рано ставить там, где процедура нужна каждой сессии, одноразовая, или правило нельзя нарушить ни разу; а набор скиллов из чужого списка «про запас» — не рано, а измеримо вредно: −21% успешности при 202 скиллах.

## Visual

**«Здесь ещё рано»:**

- Нужно каждой сессии → строка в файле инструкций, скилл ничего не экономит
- Процедура одноразовая → дешевле один раз подробно попросить; официальная рекомендация — сначала пройти без скилла, оформить по факту повторения
- Правило нельзя нарушить ни разу → хук, не скилл: скилл остаётся знанием, которое можно проигнорировать
- Нужен отдельный изолированный бюджет контекста → субагент (ступень 6), не скилл

**«Здесь не нужно вообще»:**

- Скилл из непроверенного публичного каталога без аудита — установка стороннего кода с постоянными правами
- Скилл, пытающийся заменить хук — остаётся текстом, который можно не выполнить
- Скилл, пытающийся заменить `README.md` — выводимо агентом за секунды или должно жить в описании репозитория
- «Наберу про запас» — измеримо вредно: **−21%** успешности при 202 скиллах, доминирует неверный выбор, не рост стоимости контекста

## Speaker notes

Формула та же, что и с хуком, только применительно к скиллу. Если процедура нужна каждой сессии, скилл ничего не экономит — он сработает всё равно каждый раз, дешевле строка в файле инструкций. Если процедура одноразовая — дешевле один раз подробно попросить: официальная рекомендация прямая — сначала пройти задачу без скилла, и только по факту повторения решать, что оформлять. Если правило нельзя нарушить ни разу — нужен хук, не скилл: скилл остаётся знанием, которое агент может учесть или проигнорировать. Если нужен отдельный изолированный бюджет контекста — нужен субагент, не скилл.

А вот набор скиллов из чужого списка про запас — не «пока рано», а «не нужно вообще»: формальное измерение говорит, что при росте библиотеки до двухсот скиллов падение успешности достигает двадцати одного процента, и не потому, что скиллов дороже держать в контексте — контекстная составляющая остаётся маленькой. Падает точность выбора: чем больше похожих кандидатов рядом, тем чаще модель берёт не тот. Количество установленных скиллов — не сигнал качества, это сигнал будущей проблемы выбора.
