# Сценарий 2 — ночной скрипт багов

## Assertion

Ночной скрипт: баг-репорты → критичность → очереди Jira — куда его отнести?

## Visual

Верхняя широкая Ocean rounded box карточка: иконка `git-branch`, курсивный текст сценария («Скрипт запускается каждую ночь по расписанию. Сам скачивает новые баг-репорты, классифицирует каждый по критичности через AI и автоматически раскладывает по очередям в Jira. Никто не наблюдает за процессом»).

Ниже — две маленькие карточки бок о бок с Q1 и Q2 текстом. Ниже — квадрант 2×2 слева, все 4 ячейки нейтрального серого (ни одна не выделена) + нейтральная подпись справа «30–60 сек размышления → голосуем по всем 4 углам».

## Speaker notes

Скрипт запускается каждую ночь по расписанию. Он сам скачивает новые баг-репорты, классифицирует каждый по критичности через AI и автоматически раскладывает по очередям в Jira. Никто не сидит и не наблюдает за процессом.

30–60 секунд индивидуального размышления, затем четыре раунда голосования по квадранту. Это менее очевидный угол, чем сценарий 1 — не торопите размышление, дайте полные 60 секунд.
