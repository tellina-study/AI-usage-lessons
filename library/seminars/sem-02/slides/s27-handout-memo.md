# Памятка «Воронка решений + красные флаги»

## Assertion

Всё, что здесь написано, вы уже видели сегодня в разборах — это компиляция для того, чтобы унести с собой рабочую версию воронки.

## Visual

Двухколоночная памятка. Левая колонка «Четыре вопроса воронки»: 1) Нужен ли здесь ИИ вообще, или задачу лучше решает обычный код? 2) Встраиваем в существующее приложение или делаем своё? 3) Если своё — разовый вызов модели, RAG или агент? 4) Внешний API или локальный инференс? Правая колонка «Красный флаг на каждый вопрос»: выбор сделан по двум-трём показанным примерам без запроса на весь реальный объём данных; vendor-KPI без знаменателя — впечатляющая цифра без базы расчёта; отдельный продукт там, где нужна кнопка в существующем интерфейсе; RAG или агент выбраны потому что модно, а не по конкретному новому требованию; чувствительность данных никто не проверил до архитектурного выбора; «сложно для человека» принято за «сложно для модели» без проверки на суженной версии задачи.

## Speaker notes

Раздаточный лист — компиляция того, что уже прозвучало на занятии, без нового материала. Четыре вопроса воронки: нужен ли здесь ИИ вообще, или задачу лучше решает обычный код; встраиваем в существующее приложение или делаем своё; если своё — разовый вызов модели, RAG или агент; внешний API или локальный инференс.

Шесть красных флагов, всё — из того, что прозвучало на занятии. Выбор сделан по двум-трём показанным примерам, без запроса на весь реальный объём данных, с которым решение столкнётся — это был кейс «Документы поставщиков». Vendor-KPI без знаменателя — впечатляющая цифра эффекта без указания, от какой базы она посчитана. Отдельный продукт там, где нужна кнопка в существующем интерфейсе — игнорирование того, где пользователь уже проводит рабочее время — это Kite против Copilot и «Описания товаров». RAG или агент выбраны потому что модно, а не потому что появилось конкретное новое требование — рост базы знаний или необходимость действия во внешней системе — это «Протоколы встреч» и «Еженедельный дайджест». Чувствительность данных никто не проверил до архитектурного выбора, пока кто-то не прослушал или не прочитал реальные входные данные внимательно — это «Саммаризация звонков» и Samsung. «Сложно для человека» принято за «сложно для модели» без проверки на суженной, структурированной версии задачи — это ход три трёхходовки.

Всё, что здесь написано, вы уже видели сегодня в разборах — это компиляция для того, чтобы унести с собой рабочую версию воронки, применимую уже на следующем практическом задании курса.
