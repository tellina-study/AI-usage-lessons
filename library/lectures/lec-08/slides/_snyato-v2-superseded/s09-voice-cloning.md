# Клонирование голоса + дубляж на несколько языков

## Assertion

ElevenLabs: клон голоса из 1 мин аудио → 32+ языков. Dubbing $50-500/мин → <$1/мин. Production: Deutsche Telekom, Klarna.

## Visual

Сверху assertion 26pt. Слева — Ocean rounded box: ElevenLabs voice library screenshot (мокап с 4 voice samples). Под скриншотом — QR на elevenlabs.io/voice-library. Справа сверху — крупная обвал стоимости стрелка: «$50-500/мин → <$1/мин» (gold-выделена «<$1»). Под стрелкой — 3 chips productionrs: Deutsche Telekom, Klarna, multi-language корпоративный agents. Снизу — gold-tint мини-провал блок: «Scarlett Johansson против OpenAI "Sky" (май 2024) — de-facto win для права на образ. Клон голоса обязывает к явное согласие».

## Speaker notes

ElevenLabs к 2026 году стал де-факто стандартом для клонирования голоса и AI-дубляжа. Возможность: клон голоса из одной минуты оригинального аудио, говорит на тридцати двух языках и более, сохраняя характеристики голоса — тембр, темп, эмоциональную окраску. Dubbing Studio — готовый к продакшену инструмент для локализации видео длинного формата между двадцатью девятью языками. До этого продукта традиционная студия дубляжа требовала актёра озвучки для начитки на целевом языке, sound-инженера для микширования, опционально post-sync редактора для синхронизации с губами. Стоимость — пятьдесят-пятьсот долларов за минуту дубляжа на один язык. ElevenLabs Dubbing Studio — меньше одного доллара за минуту на язык, минуты вместо недель. Production в корпоративном секторе: Deutsche Telekom использует ElevenLabs для многоязычных customer-service агентов — один заранее записанный образец голоса CEO, склонированный на тридцать языков и более для регионального общения. Klarna — для автономных AI-агентов работы с клиентами. Блок мини-провала: возможность клонирования голоса одновременно открывает новый класс юридических рисков. Scarlett Johansson против OpenAI «Sky» в мае 2024 года: OpenAI продемонстрировал голос «Sky» в ChatGPT, чрезвычайно похожий на голос Johansson. Johansson ранее отказалась озвучивать ChatGPT, когда Sam Altman лично обратился к ней. OpenAI убрал голос «Sky» в течение недели; формально иска подано не было. Это де-факто победа для прав на образ: возможность клонирования голоса обязывает к явному согласию, даже если технологически голос «всего лишь похож». Этот кейс готовит мост к третьему разделу, где мы разберём другие кейсы голоса и образа под отдельным углом.
