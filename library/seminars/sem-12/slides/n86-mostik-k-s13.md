# Что дальше

## Assertion

Сегодня, когда архив ошибался, цена падала на процесс: не нашёл, нашёл не то, склеил разное. Следующий шаг ставит картинку на выход — и там та же по характеру ошибка падает уже наружу, на человека.

## Visual

> **На входе цена ошибки падала на процесс (архив не нашёл, нашёл не то, склеил разное). На выходе цена ошибки падает наружу: документ с опечаткой в фамилии человека, снятый через сутки пост, персональные данные в открытом доступе.**

> Сегодня это уже было видно изнутри: семь запросов из двенадцати не совпали со словами описаний — архив бы не нашёл. Отобранная модель эмбеддинга пропала из каталога через три недели — выбор, сделанный один раз, прожил меньше месяца. В обоих случаях цена осталась внутри работы: потерянное время, повторный замер, не потерянный человек снаружи.

> Куда именно процесс пойдёт с архивом изображений дальше по циклу — решается отдельно, не этим занятием.

## Speaker notes

Сегодняшнее занятие с начала до конца держалось на одной особенности: когда архив изображений ошибался, цену платил сам процесс. Запрос не совпадал с лексикой описания — поиск не находил нужное, и это было видно только тому, кто сверял результат с ожиданием. Эталон, на который равнялись, сам нёс ошибку — и это стало видно только потому, что проверка прошла по строкам, а не по итоговой цифре отчёта. Выбранная модель исчезла из каталога поставщика через три недели — работа, построенная на ней, осталась жить, просто с другим риском на будущее. Во всех случаях нужное либо нашлось, либо не нашлось, и в обоих случаях неудача оставалась на территории самого процесса: архив ошибался, путался, недооценивал собственную опору — и последствия этого несла команда, которая с архивом работает, не кто-то за её пределами.

Следующий шаг дуги курса разворачивает эту же картинку в обратную сторону: процесс больше не ищет изображение — он производит и выпускает его сам. Механика при этом не меняется. Меняется то, куда падает цена ошибки. Сегодняшние примеры — несовпавший запрос, прожившая три недели модель — остались внутри работы ровно потому, что архив на входе ещё не публикует то, что нашёл или не нашёл, наружу без человека между собой и результатом. На выходе такого зазора не будет: документ с опечаткой в фамилии уходит человеку, снятый через сутки пост уже увидели, персональные данные в открытом доступе уже открыты. Тот же тип ошибки — не найти нужное, спутать одно с другим, недооценить то, на что опираешься, — выходит за пределы процесса вместе с самой картинкой.

Куда именно процесс пойдёт с архивом изображений дальше по циклу — решается отдельно, не сегодняшним занятием. Один вывод можно унести уже сейчас: проверка, которая сегодня спасала процесс от собственной ошибки, не защищает автоматически того, кто получит результат его работы снаружи.
