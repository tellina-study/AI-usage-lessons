# Что грузится сразу, и что — по требованию

## Assertion

При старте сессии в контекст попадают только имена инструментов и общая инструкция сервера; полная схема конкретного инструмента подгружается отдельно, только когда модель сама решает, что он может понадобиться.

## Visual

После подъёма транспорта Claude Code сам, не по запросу модели, отправляет серверу запросы обнаружения (`tools/list`, `prompts/list`, `resources/list`).

Каждый инструмент виден модели под полным именем: `mcp__<имя-сервера>__<имя-инструмента>` — именно эту форму требуют правило прав, `allowed-tools` скилла и matcher хука.

| Момент | Что грузится |
|---|---|
| Старт сессии | только **имена** инструментов и **инструкции** сервера |
| По требованию модели | полная схема конкретного инструмента, отдельным вызовом |

Управляет одна переменная — `ENABLE_TOOL_SEARCH`: не задана / `true` — всё откладывается (дефолт); `auto:N` — грузится, пока определения занимают меньше N% окна; `false` — всё сразу.

> Цифра «подключение стоит X токенов» на следующем слайде — про режим **без** отсрочки. По умолчанию набирается не X, а только имена и инструкции.

## Speaker notes

После того как транспорт поднялся, происходит ещё один шаг, который зал обычно не замечает: Claude Code сам, без участия модели, спрашивает сервер, что тот умеет, — список инструментов, список подсказок, список ресурсов. Если сервер потом объявит, что список изменился, Claude Code обновит его без переподключения.

Каждый инструмент модель видит под полным именем: имя сервера, два подчёркивания, имя инструмента. Это не косметика — именно эту форму, а не короткое имя, требует правило прав в хуке, список инструментов в скилле или в субагенте: механизмы, заведённые на предыдущих ступенях этого же занятия, ссылаются именно на неё.

А теперь — то, ради чего этот слайд здесь. При старте сессии в контекст попадают не полные схемы всех инструментов. Попадают только имена и общая инструкция сервера. Полное описание конкретного инструмента подгружается отдельно, только когда модель сама решает, что оно может понадобиться. Управляет этим одна настройка: по умолчанию на актуальных моделях откладывается всё; можно явно откладывать всё; можно грузить сразу, пока определения занимают меньше десяти процентов окна, а дальше откладывать; можно вовсе отключить отсрочку и грузить всё при старте.

Вот что это значит для цифры, которую вы увидите на следующем слайде. Утверждение «подключение стоит столько-то токенов» — это утверждение про режим без отсрочки. По умолчанию сегодня вы его не платите при каждом подключении — вы платите только за имена и инструкции. Цифра остаётся верной как верхняя граница: для площадок, где отложенной загрузки нет, и для сессии, где модель реально дотянула почти до всех определений. Проверить у себя — посмотреть, не выключена ли отсрочка явно, и что по факту показывает панель конкретного сервера.
