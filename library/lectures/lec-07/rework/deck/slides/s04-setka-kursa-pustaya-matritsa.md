## Видимый текст слайда

**Про каждый инструмент спрашиваем две вещи: какую задачу он решает и с какими данными работает.** Шесть типов на семь видов данных — сорок две клетки; на экране окно из двенадцати.

| | текст | изображение | структурированные данные |
|---|---|---|---|
| классификация | null | null | null |
| распознавание | null | null | null |
| поиск с генерацией | null | null | null |
| прогноз | null | null | null |

**Клетки заполняются по ходу лекции, разделом за разделом. К концу видно, какие остались пустыми: куда за восемь разделов не зашёл никто.**

## Заметки лектора

Два имени — весь рабочий инструмент, которым курс называет каждый встреченный инструмент. Первое отвечает на вопрос, что система выдаёт на выходе: классификация ставит метку из списка, распознавание находит и опознаёт во входе, поиск с генерацией сначала находит и ранжирует, а потом создаёт содержимое по найденному, прогноз предсказывает число, планирование строит последовательность действий. Названия эти курсу знакомы, и определений со сцены они не требуют: на экране рядом с каждым стоит то, что система по нему выдаёт, одной строкой. Второе имя — с какими данными система работает: текст, изображение, звук, видео, структурированные данные, код, комбинации нескольких видов сразу. Пара бывает составной, и это не оговорка: чат, который ищет в документах и пишет по ним ответ, решает две задачи подряд.

Зачем это нужно. Два имени задают поставщику два вопроса, на которые тот обязан ответить коротко. Если ответа нет или он звучит как «у нас комплексное решение на основе искусственного интеллекта», разговор о пригодности инструмента ещё не начался. По паре имён сразу видно, где искать опыт: распознавание на изображении — обкатанная область с готовыми мерами качества, а планирование на структурированных данных в медицинской практике встречается редко, и каждый случай придётся разбирать с нуля. И пара показывает подмену, которая стоит дорого: успех показывают в одной клетке, а продают инструмент для другой.

Заполняется карта по ходу, и обещать стоит ровно это. В конце каждого раздела на экран возвращается та же сетка, и в неё вписываются короткие имена случаев, которые раздел разобрал: по строкам типы задач, по столбцам виды данных. К последнему разделу карта собрана целиком, и с этого момента читать на ней надо прочерки. Занятых клеток за всю лекцию наберётся четыре, то есть восемь из двенадцати показанных так и останутся пустыми. Эти восемь — такое же содержание карты, как четыре занятых: пустая клетка говорит, что инструмент такого класса на этой стадии искать незачем, и время, которое ушло бы на поиск, карта экономит заранее. Заполнение само по себе результат, и восемь неподвижных прочерков — результат тоже.

Общую картину стоит держать в голове с первой минуты. Медицина занимает здесь четыре клетки, и все четыре — те же, которыми заканчивалась инженерная лекция: распознавание и классификация на изображении, прогноз на структурированных данных, поиск с генерацией на тексте. Совпадение клеток и есть результат: отрасли различают цена ошибки и процедура вокруг человека, класс модели их не различает. Чисел в этой раскладке нет ни одного — ни долей рынка, ни числа допущенных изделий, ни «лидеров».
