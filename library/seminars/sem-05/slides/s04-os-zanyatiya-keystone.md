# Ось занятия: предотвращаем или решаем — и где именно не срабатывает интуиция

## Assertion

Каждое из пяти усилений сегодня либо стоит завести заранее, либо стоит завести только по сигналу — и у обоих режимов есть ровно одна точка, где интуиция предсказывает неверно.

## Visual

Таблица — пустая, кроме имён строк:

| Ступень | Предотвращаем / решаем | Интуиция говорила | Проверка показала |
|---|---|---|---|
| Хук | | | |
| Скилл | | | |
| MCP | | | |
| Субагент | | | |
| Процесс | | | |

Под таблицей, в gold-рамке — единственная подпись слайда:

> «Пять строк, общих на два занятия. Сегодня закрываются три — одна на ступень. Оставшиеся две ждут следующего занятия.»

## Speaker notes

Ось занятия — та же, что была на прошлом, с одним добавлением. Каждое из пяти сегодняшних усилений либо стоит завести заранее, на день 0, потому что цена завести мала, а цена отсутствия непредсказуема, — либо стоит завести только по сигналу, потому что понадобится оно или нет, зависит от конкретного проекта и заранее не угадывается.

Добавление — третья пара столбцов: что подсказывала интуиция, и что показала проверка. У каждого из пяти усилений есть ровно одна точка, где эти два ответа расходятся.

Вот таблица на пять строк, общая на два занятия. Сейчас в ней заполнены только имена: хук, скилл, MCP, субагент, процесс — в том порядке, в котором мы будем их проходить, три сегодня и два на следующей встрече. Сейчас в ней заполнены только имена. Три строки закроются сегодня — одна на ступень, сразу после того, как эта ступень разобрана. Оставшиеся две дождутся следующего занятия.

Держите эту таблицу в голове весь сегодняшний разбор — каждая ступень будет возвращаться сюда и закрывать свою строку.
