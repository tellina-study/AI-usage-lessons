# Research — реально новые ИИ-изделия против упрощёнки, по странам (issue #241)

## Задача и опора

Владелец курса посчитал по первичной таблице FDA: за всю историю (1995–2025) США допустили
**1 614** ИИ-изделия, из них **96,2% (1 553)** — по упрощённому 510(k) (воспроизведение
предшественника), и только **61** (**3,8%**) — реально новые (De Novo + PMA). Это число —
**опора, не пересчитывается заново**.

Задача этого файла: найти по каждой стране **свой** механизм деления «воспроизведение
предшественника против реально нового» и проверить гипотезу владельца — что при сравнении
именно по реально новым изделиям разрыв между странами окажется куда меньше, чем по полным
счётам (США 4,82 на млн населения кумулятивно против России 0,39, Японии 0,41, Китая 0,11).

## 1. Национальный механизм «упрощёнка против реально нового» — по странам

| Год | Реально новые (De Novo + PMA) | По упрощёнке 510(k) |
|---|---|---|
| 2015 | 0 | 6 |
| 2017 | 4 | 23 |

Итого с 1995 г.: **61** реально новых, **1 553** по упрощёнке — **3,8%**. На млн населения
кумулятивно: всего **4,82**, реально новых — **0,18**.

### 1.2 Китай (NMPA) — упрощёнки для диагностического ИИ Класса III фактически нет

**Классовая структура.** Кумулятивно к середине 2025 г. — **154** ИИ-изделия, из них
**123 (79,9%)** класс III (максимальный риск), **31 (20,1%)** класс II
([JMIR Medical Informatics, 2026](https://medinform.jmir.org/2026/1/e85538)). Более узкий
снимок на середину 2026 г. по категории решающего ПО (21-04, «вспомогательная диагностика»):
**127** регистрационных удостоверений, из них **126 (99,2%)** класс III, только
**1 (0,8%)** класс II ([zhonglun.com, обзор соответствия ИИ-медизделий](https://www.zhonglun.com/research/articles/9287.html)).
Два снимка, разная методология счёта (все ИИ-изделия против узкой категории decision-support),
но направление совпадает: класс III — почти всё.

**Ключевой структурный факт, отличающий Китай от США: предшественник не освобождает от своих
клинических испытаний.** В отличие от 510(k), где показанная похожесть на уже допущенное
устройство заменяет новое клиническое испытание, китайский регулятор для диагностического и
решающего ПО класса III требует **собственное многоцентровое клиническое испытание почти для
всех таких изделий независимо от наличия предшественника** — правило закреплено отдельным
техническим руководством ЦОМИ (Центр оценки медизделий) именно для софта на глубоком обучении,
а не общим правилом для медизделий ([zhonglun.com](https://www.zhonglun.com/research/articles/9287.html)).
То есть упрощённого пути «похож на предшественника — клинику не повторяем» для этой категории
**структурно не существует**, а не просто редко используется.

**«Инновационный» канал — это не то же самое, что «без эквивалентности».** В 2025 г. NMPA
одобрила **76** инновационных медизделий во всех областях (+17% г/г) — ИИ там один из многих
профилей ([cisema.com](https://cisema.com/news/nmpa-2025-innovative-devices),
[flcube.com](https://flcube.com/?p=58023)). Кумулятивно с 2014 по конец 2025 г. — **391**
инновационное изделие всего; по ИИ отдельно — **свыше 700** изделий всех профилей вошли в
особый ускоренный канал рассмотрения с начала программы, из них **свыше 500** вышли на рынок,
**класс III — ≈85%** инновационных одобрений, и **свыше 100 именно ИИ-продуктов** прошли этим
каналом ([zhonglun.com](https://www.zhonglun.com/research/articles/9287.html)). Но «инновационный
канал» в Китае — это **ускоренная сопровождаемая процедура рассмотрения**, а не освобождение от
клинического испытания: изделие всё равно проходит клинику, только быстрее и с консультационным
сопровождением ЦОМИ. Поэтому деление «по инновационному каналу против по стандартному» в Китае
**не равно** американскому делению «De Novo/PMA против 510(k)» — почти все китайские ИИ-изделия
класса III реально новые в смысле «прошли свою клинику», независимо от канала подачи.

**Итог для Китая:** реально новых (= прошли собственное клиническое испытание, не сослались на
предшественника без испытания) — **≈123–126 из 154–160**, то есть **80–99%**, а не 3,8%, как в
США. На млн населения (1 409 млн): реально новых **≈0,087–0,089**, против полного счёта
**≈0,109–0,113**.

### 1.3 Япония (PMDA) — 承認 (сёнин) против 認証 (нинсё)

Японский аналог деления — не класс риска, а **путь рассмотрения**: **сёнин** (承認, полная
проверка самой PMDA, типично для первого изделия в своём роде, нового клинического применения)
против **нинсё** (認証, сертификация зарегистрированным органом по уже утверждённому стандарту
признания — применяется, когда для данного типа устройства такой стандарт уже существует, то
есть похожий тип уже был допущен раньше и под него написан стандарт).

**Числа по всем программным медизделиям (не только ИИ), по состоянию на сентябрь 2025 г.:**
**承認 160 (27,5%)** против **認証 421 (72,5%)**, итого **581**
([jfmda.gr.jp, итоговый отчёт по ИИ-ПО](https://www.jfmda.gr.jp/wp/wp-content/uploads/2026/01/Final-Study-Report-for-Review-of-SaMD-utilizing-AI_English.pdf)).
Отдельный срез PMDA/METI на январь 2025 г. даёт кумулятивно **285** изделий именно по пути
сёнин с распределением по назначению: диагностика по изображению (включая сертификацию) — 371,
прочая диагностика — 106, планирование лечения — 67, прочее — менее 20 на категорию
([meti.go.jp, презентация PMDA](https://www.meti.go.jp/shingikai/mono_info_service/medical_equipment_healthcare/pdf/007_03_02.pdf)).

**ИИ-подсчёт отдельно:** **40** ИИ-SaMD на 31.12.2024 (из них 20 — радиология) и **51** на
сентябрь 2025 г. ([10a-ii-izdeliya-skolko-i-gde.md](10a-ii-izdeliya-skolko-i-gde.md) §2.1,
первоисточник — отчёт PMDA об ИИ-SaMD). **PMDA не публикует отдельно долю сёнин/нинсё именно
для ИИ-подмножества** — это подтверждённый пробел, не недосмотр поиска.

**[≈ оценка]** Применяя общую долю всех программных медизделий (27,5%/72,5%) к 51 ИИ-SaMD:
**≈14 через сёнин** (аналог «реально новое»), **≈37 через нинсё** (аналог «упрощёнка по уже
утверждённому стандарту»). Это экстраполяция общей пропорции, не прямой подсчёт — для ИИ она
может быть смещена в любую сторону (радиологическое ИИ-ПО чаще подпадает под уже существующие
стандарты признания, то есть доля нинсё для ИИ может быть выше общей).

**Итог для Японии:** реально новых (сёнин) **≈14 из 51**, то есть **≈27%**. На млн населения
(123,8 млн): реально новых **≈0,11**, против полного счёта **0,41**.

### 1.4 Евросоюз (CE/MDR) — класс I самосертификация — лёгче любой упрощёнки

Официального агрегата по ИИ-изделиям ЕС не публикует (подтверждённый пробел, см.
[10a-ii-izdeliya-skolko-i-gde.md](10a-ii-izdeliya-skolko-i-gde.md) §2.1). Единственный
сопоставимый по методологии массив — Muehlematter et al., *Lancet Digital Health*, 2021: **240**
CE-маркированных ИИ-изделия в Европе за 2015–2020 гг. с разбивкой по классу риска:

| Класс | Изделий | Доля |
|---|---|---|
| I (самосертификация, без участия notified body) | 85 | **35%** |
| IIa (notified body, обычно путь эквивалентности без нового испытания) | 95 | **40%** |
| IIb (notified body) | 28 | **12%** |
| III | 2 | **1%** |
| IVD | 11 | **5%** |

([исследование целиком цитировано по researchgate.net/publication/348599977](https://www.researchgate.net/publication/348599977_Approval_of_artificial_intelligence_and_machine_learning-based_medical_devices_in_the_USA_and_Europe_2015-20_a_comparative_analysis),
оригинал — [thelancet.com PIIS2589-7500(20)30292-2](https://www.thelancet.com/journals/landig/article/PIIS2589-7500(20)30292-2/fulltext))

**Класс I в ЕС — это упрощёнка жёстче американской: вообще без независимой проверки.**
Производитель сам декларирует соответствие, никакого notified body, никакого сравнения с
предшественником не требуется вовсе — это не «похож на уже допущенное», это «никто со стороны
не смотрел». **35% европейских ИИ-изделий 2015–2020 гг. прошли именно так.** Для класса IIa/IIb
(53% вместе) путь эквивалентности (equivalence route, MDCG 2023-7) — основной способ не делать
новое клиническое испытание, но точной доли именно для ИИ-изделий после введения MDR (с 2021 г.)
в рецензируемой литературе не найдено — **прямой, подтверждённый пробел**, отдельно от общего
пробела «нет агрегата по числу изделий».

**Итог для ЕС (только по старым, пре-MDR данным, с явной оговоркой о дате):** реально новых в
строгом смысле «класс III, прошли полный клинический путь без эквивалентности» —
**2 из 240 (1%)**, на порядок меньше американской доли 3,8%. Если считать «реально новым» всё,
что не класс I (то есть IIa+IIb+III+IVD) — **65%**, на порядок больше. Диапазон настолько широк
именно потому, что у ЕС нет единого аналога понятия «De Novo» — есть непрерывная шкала классов
риска, а не бинарное «новый класс против похожего на старый».

### 1.5 Корея (MFDS) — 혁신의료기기 (инновационное изделие) как узкий, не основной, канал

**Общий счёт ИИ-изделий (허가·인증·신고 — допуск + сертификация + уведомление вместе, без
раздельной методологии):** **62** (2023) → **108** (2024) → **157** (2025), рост
**в 2,53 раза за три года**
([ajunews.com](https://www.ajunews.com/view/20260412110801896),
[v.daum.net](https://v.daum.net/v/20260412193636880)). Более раннее окно: **4** (2018),
**13** (2019), **50** (2020) — та же серия, другой источник.

**혁신의료기기 (инновационное медизделие) — отдельная добровольная программа статуса** (ускоренный
допуск, льготы по возмещению), не параллельная классификация по риску. По ИИ в её рамках:
**15 из 29** всех инновационных назначений — ИИ в 2024 г.; **25 из 45** — ИИ в 2025 г.
([koreabiomed.com, 45 innovative medical devices 2025](https://www.koreabiomed.com/news/articleView.html?idxno=30473),
[ezyeconomy.com](https://www.ezyeconomy.com/news/articleView.html?idxno=231567)).

**Это даёт прямую, хотя и приблизительную, долю «реально новое по собственному признанию
регулятора» внутри всего потока ИИ-допусков:** **25 из 157 (≈16%)** в 2025 г.,
**15 из 108 (≈14%)** в 2024 г. Остальные **≈84–86%** — стандартный путь, который для
большинства Class II/III устройств в Корее означает сравнение с уже одобренным аналогичным
изделием (동등성, аналог 510(k)/равнозначности), без нового клинического испытания.

**Итог для Кореи:** реально новых (инновационный статус) **≈25 из 157** в 2025 г. — **≈16%**,
ближе к японской доле (27%), чем к американской (3,8%) или китайской (80–99%). На млн населения
(51,7 млн) за 2025 год: всего **3,04**, реально новых **0,48**.

### 1.6 Россия — гипотеза владельца проверена и структурно НЕ подтверждается

**Утверждение владельца:** любое ИИ-ПО автоматически получает класс риска 3 (приказ Минздрава
№ 4н), значит упрощённого пути по эквивалентности для ИИ в России нет, и все 57 зарегистрированных
изделий по построению ближе к «реально новым», чем 1 614 американских.

**Что на самом деле определяет путь — не класс, а наличие зарегистрированного аналога.** Правило
регистрации медизделий в России: **для классов риска 2б и 3 клинические испытания проводятся в
форме оценки и анализа уже существующих клинических данных — КРОМЕ изделий, не имеющих
зарегистрированных аналогов, и имплантируемых изделий, для которых требуется испытание с
участием пациентов** (сводка правил по
[reg.ecosafety.ru](https://reg.ecosafety.ru/tpost/bpb92p99z1-kak-opredelitsya-s-protseduroi-registrat)
и [centrattek.ru](https://www.medalis.ru/arcticles/klassy-riska-medizdelij)). Это — **свой
аналог 510(k)**, только ворота не класс риска, а наличие предшественника в реестре, а не класс
сам по себе: класс 3 не блокирует лёгкий путь, если аналог уже есть.

**Проверка на первых изделиях.** Первые два российских ИИ-медизделия — **Webiomed** (К-Скай) и
**Botkin.AI** (Интеллоджик), оба зарегистрированы в 2020 г. — у обоих **не было
зарегистрированного аналога**, и оба прошли **полноценные клинические испытания с участием
пациентов**: Webiomed — независимые клинические испытания
([webiomed.ru](https://webiomed.ru/novosti/sistema-webiomed-stala-pervoi-rossiiskoi-razrabotkoi-v-oblasti-iskusstvennogo-intellekta/)),
Botkin.AI — на базе ЦКБ РАН ([zdrav.expert](https://zdrav.expert/index.php/%D0%9F%D1%80%D0%BE%D0%B4%D1%83%D0%BA%D1%82:Botkin.AI)).
Это подтверждает правило — **для первых в своём роде изделий лёгкого пути действительно не было**.

**Но к 2026 году аналоги накопились.** Отечественный реестр содержит уже 10+ именованных
продуктов анализа медицинских изображений, зарегистрированных начиная с 2020–2021 гг. (Botkin.AI,
Care Mentor AI, Гамма Мультивокс, ЦЕЛЬС, Third Opinion, RADLogics, JEMYS и др. — полный список в
[10a-ii-izdeliya-skolko-i-gde.md](10a-ii-izdeliya-skolko-i-gde.md) §4.3). Для любого нового
изделия той же товарной категории (анализ рентгена, анализ КТ) **аналог теперь, как правило,
есть** — значит для большинства регистраций 2022–2026 гг. формально доступен лёгкий путь «оценка
и анализ клинических данных» без нового испытания на пациентах.

**Точного агрегата «сколько из 57 прошли испытания с пациентами, сколько — оценку по аналогу»
Росздравнадзор не публикует** — подтверждённый пробел, не недосмотр поиска (проверены отчёт
К-Скай, блог webiomed.ru, профильные СМИ — ни один не даёт этой разбивки). Честная оценка
по структуре правила: **испытания с пациентами были практически гарантированы только для первых
1–2 изделий без аналога (2020 г.); с ростом реестра доля изделий, у которых уже есть
отечественный аналог, выросла, и лёгкий путь стал доступен большинству более поздних
регистраций.** Это значит, что **реально новых (в строгом смысле «испытание на пациентах,
потому что аналога не было») среди 57 — вероятно, единицы, а не большинство.**

**Вывод: гипотеза владельца о механизме НЕ подтверждается.** Автоматический класс 3 сам по себе
не закрывает лёгкий путь — лёгкий путь закрыт отсутствием аналога, а не классом, и к 2026 году
аналог есть почти всегда. 57 российских изделий **не равны** 57 «реально новым» в американском
смысле De Novo/PMA — это смешанный массив, где подлинно новых (без аналога на момент подачи),
скорее всего, заметно меньше 57, возможно, порядка первых нескольких регистраций 2020–2021 гг.

**Ответ на вопрос владельца числом.** Раскладка по полным счётам даёт разрыв США/Китай
**≈44×** на млн населения (4,82 против 0,11), США/Япония **≈12×** (4,82 против 0,41), США/Россия
**≈12×** (4,82 против 0,39). После фильтра «только реально новое»:

- **Китай: разрыв сжимается до ≈2×** (0,18 против 0,087–0,089) — гипотеза владельца
  **подтверждается** сильно: Китай почти догоняет США именно потому, что для диагностического
  ИИ класса III там структурно нет пути без своей клиники.
- **Япония: разрыв сжимается до ≈1,6×** (0,18 против ≈0,11, оценочно) — гипотеза
  **подтверждается умеренно**, с оговоркой, что доля сёнин для ИИ — экстраполяция, не прямой
  подсчёт.
- **Корея: доля реально нового (≈16%) ближе к японской, чем к американской** — умеренное
  подтверждение на уровне структуры, прямое сравнение на душу населения кумулятивно невозможно
  (нет полного ряда с начала программы).
- **Россия: гипотеза владельца НЕ подтверждается.** Причина разрыва в России — не отсутствие
  упрощённого пути (он есть, просто завязан на наличие аналога, а не на класс риска), а то, что
  аналоги уже накопились к 2022–2026 гг. Прямое приравнивание «57 российских = 57 реально новых»
  **неверно**: подлинно новых, прошедших испытание на пациентах из-за отсутствия аналога,
  вероятно, единицы (достоверно — первые два, 2020 г.), а не весь массив.

**Итог одной строкой:** гипотеза «при счёте по реально новому страны окажутся примерно так же»
**верна для Китая и Японии** (разрыв с США падает с 12–44× до 1,6–2×) и **неверна для России**
конкретно по заявленному механизму (автоматический класс 3 не блокирует упрощённый путь — его
блокирует только отсутствие аналога, и аналог почти всегда уже есть).

## Чего в открытых источниках нет (честно, отдельно от «≈ оценка»)

1. **Точная доля ИИ-изделий, прошедших сёнин против нинсё, именно в японском ИИ-подмножестве**
   (есть только общий показатель по всем программным медизделиям, 27,5%/72,5%).
2. **Точный агрегат «сколько из 57 российских ИИ-изделий прошли испытания с пациентами против
   оценки по аналогу»** — Росздравнадзор не публикует такую разбивку по регистрационным делам.
3. **Доля equivalence route (эквивалентности) именно для ИИ-изделий ЕС после введения MDR**
   (данные есть только по классу риска, 2015–2020 гг., устарели на пять лет).
4. **Официальные годовые агрегаты по ИИ-медизделиям Великобритании, Индии и Бразилии** —
   ни один регулятор этих трёх стран не ведёт публичный счётчик именно ИИ-подмножества.
5. **Полный кумулятивный ряд Кореи с начала программы (до 2018 г.) и за 2021–2022 гг.** —
   найдены только крайние точки и последние три года.
6. **Точная годовая цифра Китая за полный 2025 год** — опубликован только снимок за первое
   полугодие (20).
