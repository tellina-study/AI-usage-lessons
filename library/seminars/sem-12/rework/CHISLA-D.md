## 8. Чего на кадрах НЕТ намеренно

- **Цены за тысячу запросов и задержки.** В README замера их нет: есть только
  суммарная цена прогона ветки 2 ($0,000155, `raw/branch2_results.json`) и
  настенное время двух батч-вызовов. Пересчитывать их в «за тысячу» значило бы
  считать самому — не сделано, на кадрах этих чисел нет. В заметке n58 цена
  названа структурно: индексация платится один раз, запрос — каждый раз.
- **Длины текстового вектора** (`text-embedding-3-small`). Прогоном не проверена,
  в README её нет. На кадрах и в главе не стоит; вместо неё — свойство
  «вектор фиксированной длины, одинаковой для описания и запроса».
- **Суммы `38 + 14 = 52`.** Снята сознательно: при расширении корпуса сумма
  поедет молча. На n69 два числа стоят порознь.
