# Тридцать три события, одно в работе

## Assertion

Хук использует одно из тридцати трёх событий жизненного цикла агента — и срабатывает не тогда, когда модель решила вызвать инструмент, а после того, как она уже сформировала его аргументы.

## Visual

| Группа | События |
|---|---|
| Сессия целиком | SessionStart, SessionEnd, Setup |
| Каждый ход | UserPromptSubmit, UserPromptExpansion, Stop, StopFailure |
| **Вызовы инструментов** | **PreToolUse**, PostToolUse, PostToolUseFailure, PermissionRequest, PermissionDenied, PostToolBatch |
| Уведомления/интерфейс | Notification, MessageDisplay |
| Команда агентов | SubagentStart, SubagentStop, TaskCreated, TaskCompleted, TeammateIdle |
| Файлы/окружение/worktree | FileChanged, CwdChanged, DirectoryAdded, WorktreeCreate, WorktreeRemove |
| Конфигурация | ConfigChange, InstructionsLoaded, PreCompact, PostCompact |
| Модель | PreModelSwitch, PostModelSwitch |
| MCP-элиситация | Elicitation, ElicitationResult |

Ядро для агента-кодера: `PreToolUse` (до вызова) · `PostToolUse` (после) · `Stop` (перед завершением) · `SessionStart` (начало сессии).

`PreToolUse` срабатывает после того, как модель уже сформировала аргументы вызова, и до того, как харнесс начал сам вызов обрабатывать.

Три факта: хуки разных уровней настроек складываются, а не перекрываются; явный `deny` в правах побеждает всё, включая хук, вернувший `allow`; `PreToolUse` срабатывает в любом режиме разрешений, включая `bypassPermissions`.

## Speaker notes

Барьер уже стоит — прежде чем разбирать, где он не срабатывает, важно понять, что вообще значит «сработать». В Claude Code тридцать три события жизненного цикла — число перепроверено дважды по документации: первый проход дал ошибочные тридцать четыре, сумма по группам не сошлась, второй, построчный, дал тридцать три. Хук использует одно. Ядро для агента-кодера — четыре события, остальные двадцать девять — под задачи, которых у этого проекта пока нет: элиситация MCP, автоматизация worktree, мультимодельные пайплайны, командный режим с несколькими агентами.

Ключевая деталь про `PreToolUse`: он срабатывает не тогда, когда модель решила вызвать инструмент, а после того, как она уже сформировала аргументы — команда уже написана. Хук видит один вызов в изоляции: не видит, что будет после, и не видит другие вызовы той же параллельной пачки. Острая кромка составной команды — прямое следствие этой же точки: состояние ветки читается в момент запуска хука, до того как вся строка реально выполнится.

И последнее: хуки разных уровней настроек складываются, а не перекрываются — если есть и личный хук, и проектный на то же событие, сработают оба; явный запрет в правах побеждает всё, включая хук, вернувший «allow»; а сам хук срабатывает в любом режиме разрешений без исключения, включая режим без запросов подтверждения, — это пригодится в разборе провалов.
