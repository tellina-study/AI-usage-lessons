# Slash-команда vs Хук в агентном харнесе

**Date:** 2026-10-02 · **Issue:** #217-EXP

Slash-команды и хуки — два разных способа управления автоматизацией в harness-control и Claude Code, различающиеся триггером и частотой.

| утверждение | источник | тип |
|---|---|---|
| Slash-команда — явный вызов пользователя, выполняется один раз по запросу (e.g., `/config`, `/loop`, `/schedule`) | CLAUDE.md § Working Conventions; Update Config skill description | определение |
| Хук — конфигурируемая автоматизация в settings.json, срабатывает многократно по условию (e.g., «when X do Y», «before/after Z») | CLAUDE.md § Orchestration Rule; update-config skill; settings.json config | определение |
| Slash-команда выполняет действие немедленно, без необходимости сохранять состояние между запусками | по памяти, не проверено | механика |
| Хук работает на уровне harness-control (не Claude), поэтому не зависит от памяти агента между сессиями | CLAUDE.md § Orchestration Rule, update-config skill | механика |
| Пример хука: «when claude stops show X» — конфигурируется в settings.json один раз, срабатывает при каждой остановке Claude | по памяти, не проверено | пример |
| Slash-команда может вызваться вручную или через prompt; хук срабатывает автоматически без явного промпта | по памяти, не проверено | особенность |

## Что НЕ доказано

- Полный список всех доступных хуков в текущей версии harness-control (требуется просмотр settings.json схемы)
- Точная реализация срабатывания хуков (timing, порядок, error recovery)
- Существование встроенного slash-команды `/hook-list` для просмотра активных хуков
