## Часть 2. Предлагаемая арка повествования

Одна непрерывная производственная нить; одобренная структура (6 кейсов, вопрос до исследования,
ось день-0/жди-сигнала, честная сила доказательств) сохраняется целиком, меняется только рамка.

**День 0 — получили задачу и подняли проект.**
Заказчик формулирует задачу (s02) → раскладываем в `spec.md` + `README.md` первым коммитом (s03) →
первый прогон: пустая директория → рабочий прототип, без единого уточняющего вопроса, структура
выбрана агентом молча (s04). Срез по залу: два режима настройки (s05) → два типа решений с разной
ценой ошибки (s06) → карта слотов и что в работе сегодня, одной строкой (s07).

**Дальше — обычная работа над этим же репозиторием, и развилки встречаются в её естественном
порядке:**

| Когда | Что происходит в работе | Развилка |
|---|---|---|
| сразу после прототипа | впереди дни задач, каждая — новая сессия; заводим `CLAUDE.md` | 1.1 чем заполнять пустой файл |
| первая неделя | с первого дня в файле стоит гейт «готово»; заказчик пишет, что заявка не дошла | 1.2 гейт есть, поведения нет |
| ~месяц | в `tests/` накопилась своя конвенция | 1.3 дробить файл или нет |
| та же неделя, что и 1.2 | `DECISIONS.md` заведён на дне 0; отклонённое решение всплывает снова | 2.1 куда пишется решение |
| ~четыре месяца | журнал вырос, связи между записями потерялись | 2.2 структура вместо плоского лога |
| многошаговая задача (визард) | файл задачи есть, мелкая договорённость в него не попала | 2.3 дисциплина синхронной записи |

**Правила подачи, из которых следует всё остальное:**

1. **Каждый кейс открывается одной строкой «где мы в работе»**, а не «прошло N недель» с новым
   персонажем. Персонаж один: мы и агент в `signup-landing`.
2. **Единый календарь** — зафиксировать шкалу (день 0 → неделя 1 → месяц 1 → месяц 4) и привести к
   ней все даты в артефактах на слайдах.
3. **Проблемный слайд = состояние проекта + развилка.** Без оценочных слов, без уже показанного
   исхода, без афоризма-морали. Неизмеренные режимы отказа переезжают в блок «честно про пробел» на
   слайде исследования, где стоят рядом с пометкой «правдоподобно, но не измерено».
4. **Классификация «день-0 / по сигналу» снимается с кейс-дивайдеров** и собирается сводной
   таблицей s50 — там она становится выводом, а не спойлером, повторённым шесть раз.
5. **Регистр:** факт → механизм → следствие. Ни «кто угадал», ни «вас удивит», ни «запомните».
6. **Охват называется один раз, одной строкой, без защиты.** Честный охват «два из пяти» остаётся
   в разделе 3 (s51), где он к месту.
7. **Ноль следов производства в студенческом тексте.** Провенанс капчуров — в `visual.backup`.
