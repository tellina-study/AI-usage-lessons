# Структура: тематические файлы со ссылками

## Assertion

Запись явно ссылается на связанную запись — то, чего в плоском append-only логе не было в принципе.

## Visual

```
memory/decisions/
  index.md        ← оглавление тем + ссылки
  validation.md   ← решения по валидации формы
  backend.md      ← решения о том, чего мы НЕ делаем
  deploy.md
```

Пример записи в `validation.md`:

```markdown
## 2026-09-20 — не подключаем библиотеку валидации форм
Форма — два поля, хватает нативных required/pattern.
См. также: 2026-11-30 (антиспам) — это решение НЕ
распространяется на защиту от спама, другой механизм.

## 2026-11-30 — антиспам через honeypot-поле, без капчи
Отменяет часть решения от 2026-09-20 для случая антиспама.
```

Подпись: «иллюстративный пример, не захваченный вживую — ждёт реальной сессии».

## Speaker notes

«Это не снятый кадр из нашего репозитория — ждём живой сессии, чтобы захватить настоящий. Но устройство ровно такое: тематические файлы плюс оглавление, и в самой записи — явная ссылка на связанную запись. То, чего в плоском логе просто не было места сделать.»
