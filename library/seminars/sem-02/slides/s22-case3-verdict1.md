# Протоколы встреч — разбор

## Assertion

Один вызов, ни хранилища, ни цикла

## Visual

Схема из трёх блоков: «письмо с транскриптом» → «вызов модели с шаблоном» →
«протокол». Никакой полосы вариантов под схемой — просто финальная схема
решения.

## Speaker notes

Весь транскрипт одной встречи целиком помещается в контекст модели —
значит, нужен один разовый вызов модели, ни RAG, ни агент не требуются и
были бы избыточным усложнением. Схема простая: письмо с транскриптом
приходит на вход → один вызов модели с заранее заданным шаблоном
(«выдели решения, поручения, сроки») → на выходе готовый протокол. Никакого
хранилища, никакого цикла с проверкой промежуточных результатов — потому
что задача этого не требует. Всё, что нужно модели для ответа, помещается
в один запрос целиком, и результат приходит сразу же, без промежуточных
шагов и без обращения к каким-либо внешним системам. Это самый простой
вариант из всех возможных, и он здесь полностью оправдан текущей
формулировкой задачи — усложнять его сейчас означало бы решать проблему,
которой пока попросту не существует.
