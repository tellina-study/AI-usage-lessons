## 3. Красота и вёрстка — нормы для всякого изменённого слайда (требование владельца)

1. **Один предмет на экран.** У слайда один главный визуальный объект (скрин, схема, полоса
   плашек или таблица); всё остальное — подчинённые строки. Шесть разнотипных блоков на
   экране (нынешний n51) — запрещённое состояние.
2. **Числа — плашками** (А11/§5.12): несущее число набирается крупно отдельным блоком с
   подписью-пояснением; пара «было → стало» — одна плашка. Число внутри абзаца жирным —
   не плашка.
3. **Пустота — осознанная.** Нижняя треть экрана не остаётся случайно пустой (нынешние n07,
   n12): либо контент перераспределяется по вертикали с равными просветами, либо слайд
   честно минималистичен (дивайдер). «Половина экрана воздуха + текст прижат кверху» — дефект.
4. **Выравнивание по сетке:** один левый край для всех блоков контента; просветы между
   блоками равные; плашки одного ряда — одной высоты (сторож пар знает это для колонок —
   для плашек проверять глазами).
5. **Контраст:** на тёмных фонах не использовать серый курсив для несущих строк — белый или
   голубой из палитры, WCAG AA ≥4.5:1. Курсив — только для настоящих цитат, не длиннее
   трёх строк подряд.
6. **Кегль:** пол 7,5 pt на схемах/скринах после уменьшения — проверять замером по PDF, не
   на глаз; подписи плашек не ниже 10 pt; никакой научной записи (§5.14).
7. **Дубли запрещены:** текст, пересказывающий стоящий на том же экране скрин/схему, — в
   заметки (§8 требований к форме). На экране остаются только выноски.
8. **Ocean-палитра:** фоновые панели `#F4F7FA`, рамки `#1C7293`, золото `#F0AB00` — только
   для одного акцента на слайде (вопрос, выплата, текущий кейс в дорожке). Два золотых
   акцента на экране — дефект.
9. **Визуальный цикл обязателен:** Generate → PDF → PNG → смотреть глазами → Fix, минимум
   3 итерации на каждый изменённый слайд, лог в `rendered/iteration-log.md` (если файла
   нет — завести). Первый рендер без замечаний = недостаточно критики.
10. **После правок:** `check_text_overlap_pdf.py` = 0, `check_tracks_pdf.py` по эталону —
    блокирующие; «влезло» и «читается» проверяются по отдельности (журнал 2026-09-30).
