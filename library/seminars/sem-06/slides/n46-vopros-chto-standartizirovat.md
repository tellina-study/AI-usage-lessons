# Что из этого стоит взять в привычку

## Assertion

Три проверки вместо одной по очереди сработали. Решаем, что из этого стоит взять в привычку.

## Visual

> «Три проверки вместо одной по очереди — что из этого стоит взять в привычку? Выберите карточку.»

`ничего не менять — проверять по одной, это надёжнее` · `объединить все три правки в одно задание для одной роли` · `сначала проверить, зависят ли правки друг от друга, и только потом запускать по отдельному вызову роли на каждую` · `параллелить всегда, по умолчанию`

## Speaker notes

Три проверки вместо одной по очереди — что из этого стоит взять в привычку? Выберите карточку и обоснуйте, чем параллельный запуск отличается от простого «быстрее».

Если прозвучит «параллелить всегда»: сильный, но слишком широкий ответ — разбор покажет, когда именно он подводит.
