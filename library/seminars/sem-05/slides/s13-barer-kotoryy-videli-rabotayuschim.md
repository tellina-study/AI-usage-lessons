# Обе половины проверки — на одной ветке

## Assertion

Собранный хук — реальный файл, который исполнялся: четыре захваченных срабатывания закрывают обе половины проверки — запрет, пропуск, состоявшийся коммит и вопрос вне репозитория.

## Visual

| Ситуация | Что вернул хук — дословно, все четыре сняты с ветки `seminar-5-hook` |
|---|---|
| Ветка `main`, попытка коммита | `deny` — «BLOCKED: direct commit to main/master. Create a feature branch first.» |
| После `git switch -c fix-form-field`, тот же коммит | пустой вывод, код возврата 0 — не блокирует |
| **Тот же коммит реально выполнен** | **[fix-form-field a666b27] fix: second form field — 1 файл изменён, 8 строк** |
| Каталог, где `git init` не выполнялся | `ask` — «branch-protection gate inactive — this is not a git repository yet…» |

```jsonc
{ "hooks": { "PreToolUse": [ {
  "matcher": "Bash",
  "hooks": [ {
    "type": "command",
    "command": "jq -r '.tool_input.command' | { read -r cmd;
       if echo \"$cmd\" | grep -qE '(^|[;&|]\\s*)git\\s+commit\\b'; then
         if ! git rev-parse --is-inside-work-tree >/dev/null 2>&1; then
           echo '{…\"permissionDecision\":\"ask\"…}'; exit 0; fi
         branch=$(git symbolic-ref --short HEAD 2>/dev/null);
         if [ \"$branch\" = \"main\" ] || [ \"$branch\" = \"master\" ]; then
           echo '{…\"permissionDecision\":\"deny\"…}'; exit 0; fi
       fi; }",
    "timeout": 10 } ] } ] } }
```

## Speaker notes

Вот он целиком. Читаем сверху вниз: вытащить строку команды из описания вызова, проверить, есть ли в ней коммит, выяснить, репозиторий ли это вообще, взять ветку через `symbolic-ref`, сравнить с двумя защищёнными именами. Два выхода: «спросить» и «запретить». Во всех остальных случаях хук молчит — и молчание здесь означает «разрешаю».

Четыре срабатывания сверху настоящие, все сняты с опубликованной ветки: репозиторий клонируется и повторяется.

Первое и второе — то, что назвал зал: отказ на главной ветке с дословным текстом причины, и пустой вывод после создания ветки.

Третья строка — та самая, которую почти никто не назвал. Коммит действительно лёг: вот ветка, вот хеш, вот изменённый файл. Без неё пустой вывод во второй строке ничего не доказывает — ровно так же выглядит хук, который вообще не запустился.

Четвёртое — вопрос вне репозитория, решение с предыдущего шага.

И деталь, которая выглядит косметической: таймаут выставлен в десять секунд при стандартных шестистах, автор урезал его в шестьдесят раз сознательно. Почему это важно — сразу дальше.
