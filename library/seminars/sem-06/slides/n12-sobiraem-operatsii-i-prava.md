# Решаем: какие операции разрешить, потом — какие права

## Assertion

Первый ход — список операций, которые агент должен уметь. Второй — по каждой строке широкого токена вычёркиваем то, что список не требует.

## Visual

**Ход 1 — что конкретно агент должен делать?**

`читать открытые issue` · `писать комментарий` · `создавать черновик правки`

**Ход 2 — что даёт широкий персональный токен по умолчанию, и что из этого нужно?**

| Право по умолчанию | Нужно для нашего списка операций? |
|---|---|
| все репозитории пользователя, включая приватные | нет — вычеркнуть |
| чтение и запись | частично — чтение нужно, запись (комментарий, черновик) нужна |
| управление настройками | нет — вычеркнуть |
| удаление | нет — вычеркнуть |

> Остаётся: один репозиторий, чтение issue, создание черновика правки.

## Speaker notes

Файл пишется в конце разговора, не в начале: начни с синтаксиса — минуешь два решения, которые важнее синтаксиса.

Первый шаг быстрый: что конкретно агент должен уметь? Зал перечисляет, фиксирую: читать открытые задачи, писать комментарий, готовить черновик правки. Три операции, ничего больше.

Второй шаг несёт основной вес. На экране — список того, что даёт широкий персональный токен по умолчанию: все репозитории пользователя, включая приватные; чтение и запись; управление настройками; удаление. Идём по строкам и спрашиваем про каждую: наш список из трёх операций этого требует? Вычёркивание происходит на экране, строка за строкой. Остаётся один репозиторий и две операции.

Запомните, как выглядит этот экран сейчас. Через несколько минут покажу инцидент, который воспроизводится ровно тогда, когда верхняя строка не вычеркнута.

Если спросят, почему нельзя создать токен с правами «по умолчанию» и просто не пользоваться лишним: токен может быть использован тем, кто завладеет им, — вопрос здесь не в вашем намерении: решает то, что физически позволяет сделанный ключ.

Если спросят, насколько это типично — выдавать больше, чем нужно: та же системная выборка показывает, что подобная избыточность — норма, не исключение, и это касается не только отдельных серверов, но и самого транспортного слоя официального SDK протокола.

Если спросят, сколько времени занимает эта проверка: прямых замеров нет ни в одном источнике — честный пробел; но разговор, который мы сейчас ведём, и так происходит в момент создания токена, отдельного времени он не требует.
