Три шага RAG + три границы (chunking / порог близости / жёсткость grounding) — чёткая карта. «Вернул что-то ≠ вернул правильное» + observability + «скрытая бомба» — врезалось. **Часть 2, §3 Fine-tuning.** «Fine-tuning не умер — сузился» — снимает миф, который я реально слышал. Лестница Prompt→RAG→Fine-tune→Distill. PEFT/LoRA/QLoRA — понятно. Хорошо.

**Часть 3, §4.1–4.6 Агенты.** structured output / function calling / prompt caching / MCP — механика ясная. «Модель не исполняет ничего сама, только формулирует намерение» — это несущая граница безопасности, повторена к месту. Экономика (кэш ≈ 1/10, агент ×50 токенов, мульти-агент ×15) с явной базой сравнения — то, чего часто не хватает, здесь есть. **Часть 4, §4.7–4.10 — ВТОРОЙ КЛЮЧЕВОЙ ТЕСТ (injection, мульти-агент p^n, перегруз именами/цифрами).**
