# Контраргумент: сам фьюжен может быть вреден независимо от веса

## Assertion

Разрыв между поиском по словам (0,74) и поиском по смыслу (0,86) на этом корпусе — 12 процентных пунктов, заметно больше порога, после которого сам фьюжен становится подозрительным.

## Visual

> **Разрыв между поиском по словам и поиском по смыслу: 12 процентных пунктов** (0,74 против 0,86 по recall@1).
>
> «Fusion Tax» (arXiv:2610.30612): при разрыве nDCG между сигналами больше 0,04 сам фьюжен рискует оказаться вреднее одного чистого сигнала — независимо от того, какой вес ему ни поставь.

> **На этих данных это уже видно без единого вызова классификатора:** фиксированный равный вес даёт recall@1 = 0,84 — хуже, чем один чистый поиск по смыслу (0,86). Объединение сигналов не гарантирует выигрыша по каждой метрике.

## Speaker notes

Весь этот кейс до сих пор задавал один вопрос: какой вес поставить гибриду на каждый конкретный вопрос. Этот нюанс идёт глубже простого ответа: он ставит под сомнение саму постановку вопроса.

Разрыв между поиском по словам и поиском по смыслу на этом корпусе — двенадцать процентных пунктов по recall@1: семьдесят четыре процента против восьмидесяти шести. Исследование, которое ввело термин «Fusion Tax», показывает: когда разрыв в качестве между двумя объединяемыми сигналами превышает определённый порог, сам факт их объединения начинает рисковать оказаться хуже, чем просто использование одного, более сильного сигнала в одиночку — независимо от того, какой вес этому объединению ни назначь.

И на собственных данных этого занятия это уже видно, причём без единого вызова классификатора. Фиксированный равный вес — тот самый рецепт прошлого занятия, который этот кейс использовал как базовую линию для сравнения, — даёт recall@1 равный восьмидесяти четырём процентам. Это ХУЖЕ, чем один-единственный чистый поиск по смыслу, который даёт восемьдесят шесть. Объединение двух сигналов не гарантирует выигрыша по каждой метрике сразу: оно выигрывает по recall@3 и по среднему рангу, но проигрывает по recall@1 самому сильному из двух отдельных участников.

Это переставляет вопрос, с которого кейс начался. «Какой вес выбрать между поиском по словам и поиском по смыслу» иногда поставлен неверно с самого начала — правильный вопрос ближе к «а нужно ли вообще объединять эти два сигнала на этом конкретном потоке вопросов», и он должен задаваться раньше вопроса о весе, в дополнение к нему. Там, где один сигнал заметно и стабильно сильнее другого, усложнение в виде классификатора решает не ту задачу: оно подбирает вес для объединения, которое само по себе могло оказаться лишним шагом.
