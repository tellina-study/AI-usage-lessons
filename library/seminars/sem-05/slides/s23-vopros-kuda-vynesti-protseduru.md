# Куда вынести процедуру, чтобы агент открыл её сам?

## Assertion

Выбор из пяти карточек: куда вынести процедуру деплоя так, чтобы агент сам понял, когда её открыть.

## Visual

> В файле инструкций живёт процедура деплоя. Она нужна не каждую сессию, а грузится в каждую — даже когда вы правите отступ в вёрстке. Выберите, куда её вынести, — так, чтобы агент сам понял, когда её открыть.

`оставить как есть` · `отдельный файл + импорт` · `отдельный файл, напоминать вручную` · `скилл с описанием-триггером` · `хук`

## Speaker notes

Пауза, три-четыре голоса. Любой выбор фиксирую одинаково, без оценки.

Что слушать в ответах: назовут ли вторую половину вопроса — «чтобы агент понял сам». Без неё задача сводится к «вынести в отдельный файл», и самое интересное остаётся за кадром.

За первую карточку голосуют не по невнимательности: по мерке из сцены запас ещё есть. Если её выберут — спросить, по какой мерке.
