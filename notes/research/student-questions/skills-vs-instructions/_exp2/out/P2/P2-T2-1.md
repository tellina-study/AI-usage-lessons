# Модальное окно подтверждения удаления

## Структура и компоненты

### Заголовок (Header)
Заголовок располагается в верхней части модального окна чёрным текстом на белом фоне. Текст заголовка должен быть ясным и лаконичным, например: «Удалить элемент?» или «Подтвердить удаление». Размер шрифта — 18–20px, вес — bold (600–700). Левое выравнивание текста стандартно для модальных окон.

### Пояснительный текст (Body)
Под заголовком располагается пояснительный текст с чёрным цветом основного контраста (или светло-серый для деактивированных состояний). Текст выполняет функцию уточнения: почему нужно удалить этот объект, какие последствия это повлечёт, если данные восстановить нельзя. Рекомендуемый размер — 14px, высота строки — 1.5. Текст выравнен по левому краю, имеет внутренние отступы.

Пример: «Это действие нельзя отменить. Все данные будут удалены без возможности восстановления.»

### Две кнопки (Footer)
В нижней части окна находятся две кнопки, расположенные горизонтально с равномерным распределением пространства.

**Кнопка «Отменить» (Cancel):**
- Фон: светло-серый (`#F0F0F0`)
- Текст: чёрный (`#333333`)
- Размер: высота 40px, ширина ~100px
- При наведении (hover): фон светлеет на 5–10%
- При нажатии (active): глубина нажатия (shadow), фон темнеет на 5%
- Состояние отключено (disabled): 50% непрозрачности, курсор `not-allowed`

**Кнопка «Удалить» (Delete):**
- Фон: красный (`#EF4444` или `#DC2626`)
- Текст: белый (`#FFFFFF`)
- Размер: высота 40px, ширина ~100px
- При наведении (hover): фон темнеет (на 10–15%)
- При нажатии (active): усиленная тень, фон переходит на `#991B1B`
- Состояние отключено (disabled): 50% непрозрачности, курсор `not-allowed`

### Дополнительные состояния
- **Loading**: при нажатии кнопки «Удалить» появляется спиннер внутри кнопки, текст исчезает
- **Error**: если операция не удалась, модальное окно остаётся открытым с красным баннером ошибки
- **Accessibility**: обе кнопки должны быть фокусируемы (tab-order), иметь aria-labels
