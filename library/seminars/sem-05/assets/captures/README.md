## `git symbolic-ref` vs `git rev-parse` на repo без коммитов

`03-symbolic-ref-vs-rev-parse-unborn-head.txt` — свежий `git init -b main`, ни одного коммита
(«unborn HEAD»): `git symbolic-ref --short HEAD` возвращает `main` (код 0), `git rev-parse
--abbrev-ref HEAD` падает с `fatal: ambiguous argument 'HEAD': unknown revision...` (код 128).
Объясняет живьём, почему хук в `settings.json` использует именно `symbolic-ref`. Слайд: Раздел 3,
«Нюанс» / разбор построчно хука.

## Как пересобрать демо-репозиторий (для досъёмки TODO-части)

Демо-репозиторий живёт только в `/tmp/signup-landing-demo` (не в этом проекте, не закоммичен).
Последовательность коммитов на ветке `main` (плюс вспомогательные ветки `fix-form-field` и
`form-endpoint-fix`, слитые обратно) воспроизводит все семь ступеней ровно в порядке `plan.md` +
`plan-part2.md`. Кто будет доснимать TODO-часть (живые диалоги, `/memory`, `/context`, `/skills`,
`/mcp`, режим планирования, вердикт `diff-reviewer`) — тому нужно поднять реальную сессию Claude
Code в этом же (или заново собранном по тем же командам) репозитории. См. `TODO-capture.md` для
точных команд и того, что должно быть видно в кадре.
