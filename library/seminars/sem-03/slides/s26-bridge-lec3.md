# Мостик к Лекции 3

## Assertion

Сегодня — три механизма поодиночке. Дальше — модель выходит за пределы цикла.

## Visual

Одна широкая Ocean rounded box карточка с текстом-крючком (не более 3-4 предложений по смыслу, включая явную связку с упражнением «клубника»). Ниже — 4 равные плитки (SURFACE/TEAL) с иконками (`search`/`puzzle`/`network`/`rotate-ccw`) и короткими подписями «RAG», «Function calling», «MCP», «Agent loop» — без определений, чисто визуальный анонс терминов следующей лекции.

## Speaker notes

Сегодня мы натренировали три механизма внутри модели поодиночке: эмбеддинги — для поиска смысла, внимание — для фокуса, сэмплинг — для выбора токена. На Лекции 3 мы увидим, как модель выходит за пределы этого замкнутого цикла: ищет во внешней базе знаний через RAG, построенный, кстати, именно на эмбеддингах, которые вы тренировали сегодня в упражнении «клубника», вызывает внешние инструменты через function calling, работает по открытому протоколу MCP, и действует в цикле агента — действие, наблюдение, корректировка. Подробности — на Лекции 3.

Не объясняем механику — это намеренно короткий крючок. Если студенты начнут задавать уточняющие вопросы про RAG или агентов — хвалим интерес и явно говорим, что разберём подробно на следующей лекции.
