# Шесть источников — и один честный пробел

## Assertion

Шесть источников независимо сходятся на одном: доступ снаружи расширяет площадь ошибки быстрее, чем растёт доверие к серверу, — а сколько времени в среднем занимает сама проверка перед подключением, не измерил ни один из них.

## Visual

| Источник | Тезис | Сила доказательства |
|---|---|---|
| Zhou et al., arXiv:2605.22333 | 40,55% из 7973 живых удалённых MCP-серверов отдают инструменты вообще без аутентификации | Сильное: весь отсканированный набор, не подвыборка; 9 CVE через ответственное раскрытие |
| DBHub, CVE-2026-61788 / CVE-2026-61742 | Флаг `readonly` не гарантирует реальный режим только для чтения; HTTP-эндпойнт уязвим к DNS rebinding | Сильное для механизма: официальные CVE с патчем; эксплуатация «в дикой природе» не подтверждена |
| Rashidi, arXiv:2607.05744 | Юникод-сокрытие инструкции доставляет её модели, минуя повторное одобрение | Сильное: 3 независимые реализации, 32/32 согласованных результата, 0 ложных срабатываний |
| OX Security | STDIO-транспорт исполняет команду процесса независимо от того, поднялся ли сервер | Умеренное: механизм и 6 продакшен-систем подтверждены; масштаб — от вендора |
| Pillar Security, кампания | Сервер безобиден первые 3 вызова, затем подменяет описания на поиск секретов | Умеренное: живая кампания с реальным кодом; задокументированной жертвы не приведено |
| Scalekit, mcp-vs-cli-benchmark | CLI дешевле MCP в 4–32× по токенам, 17× по деньгам | Умеренно-сильное: открытый воспроизводимый бенчмарк, узкий домен задач |

Честный пробел:

> Сколько времени в среднем занимает сама проверка нового сервера перед подключением — не измерено ни в одном источнике. Критерий «здесь ещё рано» дальше по разделу построен на структурных признаках, а не на измеренной стоимости самой процедуры.

## Speaker notes

По силе доказательства, не по порядку появления. Сканирование Zhou с соавторами — системное: почти восемь тысяч живых удалённых MCP-серверов, и сорок процентов с половиной из них отдают инструменты вообще без проверки, кто обращается, — это не подвыборка, это весь отсканированный набор.

Два свежих CVE у сервера баз данных для работы с базами — сильные для самого механизма: официально раскрытые уязвимости с техническим разбором и патчем, хотя эксплуатация «в дикой природе» не подтверждена. Контролируемый эксперимент Rashidi показывает то же самое с другой стороны — сокрытая в описании инструмента инструкция доставляется модели в восьми случаях из восьми, и ни разу не вызывает повторного одобрения.

Разбор от OX Security и живая кампания Pillar Security — умеренная сила: механизм подтверждён и растиражирован независимо, но точные цифры масштаба — от вендора-исследователя, методология не всегда раскрыта. Бенчмарк Scalekit — открытый и воспроизводимый, но на одном домене задач.

Честный пробел — прямо, без цифры взаймы: сколько именно времени уходит на саму проверку сервера перед подключением, не нашлось ни у кого.
