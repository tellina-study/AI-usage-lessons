# Протоколы встреч

## Assertion

«После каждой встречи кто-то полчаса пишет протокол руками. Транскрипты есть — сделаем автоматом?»

## Visual

Карточка: значок транскрипта встречи целиком (один документ, разумный
объём) → стрелка → значок структурированного протокола (решения,
поручения, сроки). Справа — вопрос: «Какая архитектура?» Внизу — полоса
«Разовый вызов → RAG → Агент» с подписью-осью «ступени архитектуры».

## Speaker notes

Постановка: «После каждой встречи кто-то полчаса пишет протокол руками.
Транскрипты есть — сделаем автоматом?» То есть у нас на входе — полный
транскрипт одной встречи целиком, разумного объёма, буквально запись
одного созвона, а на выходе нужны структурированные решения, поручения и
сроки, разложенные по пунктам. Ничего больше пока не просили — только эту
одну функцию, никакого поиска по прошлым встречам, никаких интеграций с
другими системами. Вопрос в зал: какая архитектура здесь нужна? Разовый
вызов модели, RAG или агент? Аргументируйте, почему именно так — что
конкретно в этой постановке подсказывает вам этот выбор, а не другой?
Не просто называйте технологию — объясните ход рассуждения целиком, от
формулировки задачи до вывода. Кто готов ответить первым?
