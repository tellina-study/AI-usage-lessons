# Visible content

## Title
«Гибридный поиск: две ступени, слитые по рангам.»

## Speaker notes

Ранее мы вывели: лучший RAG — возврат классики поверх семантического слоя. Здесь этот вывод разворачивается в конкретную конструкцию — гибридный поиск, ставший дефолтом продакшена. Начнём с «зачем комбинировать», потому что комбинация не бесплатна. BM25 находит по точному совпадению слов: коды, идентификаторы, имена, номера ошибок, — но бессилен перед синонимом: «сломанный вход» не совпадёт с «authentication failure». Плотный поиск наоборот ловит смысл, но размывается на редких точных токенах и дрейфует, когда две команды называют одно понятие по-разному. Гибрид берёт оба источника recall'а сразу.

Сначала снимем два вопроса. Первый — «гибрид чего с чем». Зафиксируем два вида векторов: разреженный (BM25 и обучаемый SPLADE) — во весь словарь, почти все нули, интерпретируем, ищется инвертированным индексом; плотный (эмбеддинги) — низкой размерности, все значения float, кодирует смысл, ищется приближённо, не интерпретируем. Одной фразой: BM25 — sparse, эмбеддинги — dense, SPLADE — тоже sparse, но «умный». Второй вопрос: слово «гибрид» несёт три смысла, их путают. Смысл (а) — лексика плюс плотные, слитые по рангам, — базовое значение. Смысл (б) — семантика плюс фильтр по метаданным (юрисдикция, дата): ортогональный рычаг, не слияние ретриверов. Смысл (в) — BM25 плюс SPLADE/ELSER: обе ветки разреженные. Дальше разбираем механику смысла (а).

Теперь механика по шагам. Оба ретривера запускаются параллельно: BM25 отдаёт свой топ-N по инвертированному индексу, плотный поиск — свой топ-N по ANN. Дальше их надо слить, и здесь ловушка: оценки BM25 не ограничены сверху и зависят от корпуса, а косинусная близость лежит в диапазоне ноль–один — шкалы несопоставимы, нормировать сырые оценки хрупко. Reciprocal Rank Fusion обходит это, сливая не по оценкам, а по рангам: итоговый вес документа — сумма по ретриверам от единицы, делённой на «k плюс ранг». Документ, первый у BM25 и третий у плотного поиска, получает одна шестьдесят первая плюс одна шестьдесят третья — важен только порядок, поэтому несопоставимость шкал перестаёт мешать. Параметр k по умолчанию около шестидесяти: больший уплощает вклад верхних рангов, меньший заостряет упор на топ каждого; это конвенция, её стоит подбирать.

Реранкер — вторая ступень, и разница между двумя энкодерами несущая. Bi-encoder (первичный retrieval) кодирует запрос и документ по отдельности, заранее: векторы документов посчитаны при индексации, на запросе — быстрое сравнение, дёшево, но грубо по порядку. Cross-encoder прогоняет пару «запрос плюс документ» вместе, одним проходом трансформера: оценивает релевантность заметно точнее, но его нельзя предвычислить — считать приходится на запросе для каждого кандидата. Отсюда правило: он дорог, поэтому применяется только к переупорядочиванию верхних пятидесяти–ста кандидатов, отобранных гибридом.

Приросты читаем с базой и скептически. На WANDS гибрид даёт NDCG 0,7497 против 0,6983 у BM25 — около семи процентов над уже настроенной базой, скромно. Крупные приросты там, где лексика или смысл ломается по отдельности: у Anthropic доля промахов упала с 5,7 до 1,9 процента. Выигрыш зависит от корпуса: сначала измерьте разрыв на своих запросах, потом усложняйте.
