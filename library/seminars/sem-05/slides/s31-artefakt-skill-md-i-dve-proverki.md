# Файл, который открывается сам — и файл, который похудел

## Assertion

Собранный SKILL.md — реальный файл в репозитории; файл инструкций одновременно худеет обратно до сорока строк, а скилл проверяется в обе стороны — срабатывает, когда нужно, и молчит, когда не нужно.

## Visual

```markdown
---
name: deploy
description: Деплоит лендинг signup-landing на прод — сборка, smoke-тест формы, публикация,
  проверка прод-URL. Используй, когда пользователь просит задеплоить, выкатить или опубликовать
  сайт — не для обычных правок кода без деплоя.
---

# deploy

1. Собрать: `npm run build` (код выхода должен быть 0).
2. Прогнать smoke-тест формы: `npx playwright test` (должен быть зелёным).
3. Опубликовать: `wrangler pages deploy dist --project-name signup-landing`.
4. Открыть прод-URL, вручную отправить форму с валидными данными — заявка должна дойти.
5. Записать в текущий файл `.tasks/active/YYYY-MM-DD-описание.md`, что задеплоено, когда и
   какой командой.
```

Дерево — добавилась строка: `.claude/skills/deploy/SKILL.md`. Одновременно `CLAUDE.md` — восемьдесят строк возвращаются к сорока, тем же, с которыми ступень начиналась, но без процедуры деплоя.

| Уровень | Когда грузится | Стоимость |
|---|---|---|
| 1. Метаданные | всегда | ≈100 токенов |
| 2. Тело | только при срабатывании | <5000 токенов |
| 3. Вложения и код | по обращению | 0, пока не открыт |

**Две проверки.** Позитивная: «задеплой сайт» → скилл открывается сам. Негативная: мелкий баг в вёрстке → скилл **не должен** открыться.

## Speaker notes

Вот файл целиком, живёт по пути `.claude/skills/deploy/SKILL.md`. И одновременно — вот что происходит с файлом инструкций: восемьдесят строк уходят обратно до сорока, тех же, с которыми начиналась эта ступень, но без процедуры деплоя — она вырезана целиком. Это не опция: если процедура осталась в двух местах, налог никуда не делся, а к нему добавился риск, что копии разойдутся.

Три уровня раскрытия — коротко, подробно через два слайда: метаданные всегда в контексте, тело — только при срабатывании, вложения и код — по обращению, ноль, пока не открыто.

Как проверить, что реально сработало, а не просто выглядит правильно? Первая проверка очевидная: просим «задеплой сайт» — скилл должен открыться сам. Вторая — та, которую почти всегда пропускают: просим починить мелкий баг в вёрстке. Скилл открываться не должен. Если открылся — описание слишком широкое, и вы купили лишнее срабатывание в каждой второй сессии.
