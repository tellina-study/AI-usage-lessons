# Не длина файла решает

## Assertion

Мерка длины файла не может ответить на вопрос «пора ли»: при двухстах строках та же процедура стоила бы ровно столько же; считать надо загрузки, которые ничего не вернули, и по этому счёту скилл с описанием-триггером — единственный вариант, отдающий решение о релевантности модели.

## Visual

| Вариант | Где это работает | Почему здесь не подходит — и что вместо |
|---|---|---|
| оставить как есть | пока каждая строка файла нужна в каждой сессии | мерка длины на этот вопрос не отвечает: при 200 строках те же 40 стоили бы столько же. Считать надо загрузки, а не строки |
| отдельный файл + импорт | файл станет читаемее | импортированный файл всё равно грузится целиком при старте: налог переехал, а не исчез |
| отдельный файл, напоминать вручную | пока деплоев мало и память не подводит | человек нужен в каждом цикле, а способность модели решить самой не используется |
| хук | там, где правило нельзя нарушить ни разу | деплой нельзя исполнить за агента: на каждом шаге решение. Хук — для правил, скилл — для процедур |
| **скилл с описанием-триггером** | **здесь — именно то, что нужно** | **решение о релевантности отдаётся модели: процедура грузится в той сессии, где нужна, и молчит в остальных девяти. Ломается, если описание написано для человека** |

> Мерка — не длина файла, а доля загрузок, которые ничего не вернули. За десять сессий процедура грузится десять раз и пригождается один: девять загрузок из десяти — чистый убыток, и при двухстах строках их было бы ровно столько же.

## Speaker notes

**Первая строка — та, ради которой этот разбор и нужен.** «Оставить как есть» не глупость: мерка проекта названа на сцене, и по ней запас есть. Ответ не в том, что человек невнимателен, а в том, что мерка не та.

Двести строк — это мерка читаемости файла: сколько текста человек готов держать в одном документе. Вопрос ступени другой: сколько из прочитанного вернулось пользой. Эти две мерки не связаны. Доведите до крайности: файл на сто девяносто строк, из них сорок — та же процедура. Убыток ровно тот же самый, а мерка длины по-прежнему говорит «норма». Мерка, которая при любом ответе говорит одно и то же, решения не принимает.

Рабочая мерка в рамке под таблицей: считаем не строки, а загрузки. Десять сессий — десять загрузок, одна пригодилась. Девять впустую.

Дальше по строкам. Импорт: файл стал читаемее, счёт прежний — импортированный файл грузится целиком при старте. Напоминать вручную работает, пока деплоев мало, но требует человека в каждом цикле. Хук — продуктивная путаница: хук исполняет среда без согласия агента, а деплой за агента исполнить нельзя, там на каждом шаге решение — что показал адрес на проде, дошла ли заявка.

Целевой вариант — жирная строка. Единственный способ его испортить: написать описание для человека, а не как триггер. Этим и займёмся.
