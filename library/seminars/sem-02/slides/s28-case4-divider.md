# Кейс 4. Звонки продаж

## Assertion

Выбор: внешний API или локально?

## Visual

Крупный номер кейса и заголовок на нейтральном фоне. Мелкий тег снизу:
«внешний API или локально».

## Speaker notes

Последний, четвёртый кейс сегодня. Про звонки отдела продаж — и здесь
ответ у нас поменяется дважды по ходу разбора, так что не держитесь
крепко за первое мнение, оно наверняка изменится не один раз, и это
нормально. Тег внизу — «внешний API или локально» — про то, где
физически считать данные, а не про то, какая модель лучше по качеству
ответа. Слушайте постановку внимательно, и особенно обращайте внимание
на то, что именно менеджер по продажам говорит клиенту и что клиент
говорит в ответ — там будет важная деталь, которая всплывёт не сразу,
а чуть позже в разборе. Как и раньше, начнём с постановки задачи одной
фразой от заказчика.
