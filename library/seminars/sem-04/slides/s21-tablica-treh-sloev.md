# Три слоя записи

## Assertion

Разница между слоями не в формате — оба markdown, — а в том, кто инициирует запись и кто её потом увидит.

## Visual

Таблица на весь слайд:

| | Файл инструкций (ступень 1) | Авто-память | `DECISIONS.md` |
|---|---|---|---|
| **Кто автор** | вы, заранее | агент, по ходу | вы, в момент решения |
| Где живёт | в репозитории, git | вне репозитория, на этой машине | в репозитории, git |
| Что грузится | целиком, каждую сессию | индекс: первые 200 строк / 25 КБ | ничего автоматически |
| Проходит код-ревью | да | нет | да |
| Переживает смену машины | да | нет | да |
| Что туда идёт | стабильные правила и границы | предпочтения, подтверждённые подходы | решения и их «почему» |

Под таблицей — три строки: индекс памяти — только индекс · агент сам пропускает выводимое из кода · сжатие контекста переживают только файлы на диске.

## Speaker notes

Зал должен унести отсюда не список свойств, а один критерий различения. Сформулировать его стоит одной фразой:

«Разница не в формате — оба markdown. Разница в том, кто инициирует запись и кто её потом увидит. Авто-память пишет агент, для себя, на этой машине, без ревью. Журнал решений пишете вы, для команды, в репозиторий, через ревью. Первое — быстрый непрерывный слой, который вы почти не поддерживаете. Второе — маленький курируемый слой, который переживёт вашу машину, ваш ноутбук и вас на этом проекте.»

Дальше — три механические детали. Индекс памяти — только индекс: одна строка на запись со ссылкой на тематический файл, и это не вкус, а следствие жёсткого лимита — за двести строк содержимое физически не попадает в сессию. Агент сам пропускает то, что выводимо из кода: архитектуру, пути файлов, найденные исправления; если он всё-таки это пишет, это сигнал раздутия, а не полезности. И третье: сжатие контекста переживают только файлы на диске — то, что было сказано лишь в разговоре, при сжатии может исчезнуть.

Последняя деталь полезна как возврат к первой ступени: «объясню в чате ещё раз» не работает даже внутри одной длинной сессии, потому что при сжатии контекста разговор превращается в сводку, а файл с диска перечитывается заново.

Авто-память здесь описывается словами. Живого кадра с выводом команды памяти на этом слайде нет, и рисовать его имитацией нельзя — таблица и реальный файл держат раздел сами.
