# Разбор: куда девать отклонённое решение

## Assertion

Командное решение с обоснованием идёт в `DECISIONS.md`, личное предпочтение — в авто-память, выводимое из кода — никуда.

## Visual

Мелким шрифтом вверху — вопрос для контекста: «Куда записать отклонённое решение?»

Таблица разбора:

| Вариант | Где это работает | Почему здесь ещё рано — и что вместо |
|---|---|---|
| «Допишу в `CLAUDE.md`» | Механически сработает: файл читается каждую сессию | Смешивает два разных по природе слоя. На десятке решений файл выйдет за ориентир в 200 строк. Вместо: развести слои по авторству |
| «Ничего, агент сам запомнит» | Нигде: это не настройка, которую забыли включить | Модель не имеет состояния между вызовами по конструкции: без записи на диск ничего не переживает конец сессии |
| «Скажу агенту "запомни это"» | Для личного предпочтения — идеально | **Половина ответа.** Уходит в авто-память: машинно-локальный слой без синхронизации и без ревью. Для командного решения этого мало |
| «Заведу `DECISIONS.md`» | Для командного решения с обоснованием — именно то, что нужно | **Вторая половина ответа.** Требует дисциплины: писать «почему», а не «что» |
| «Поставлю систему памяти (векторную/графовую)» | На десятках-сотнях записей, при потребности в поиске по смыслу | Рано на порядок: живые замеры показывают, что на малых корпусах простой файл регулярно конкурентен со сложными системами |

Нижняя плашка, gold: **целевой ответ — оба механизма разом, с разделением ролей.**

## Speaker notes

Разбор. «Допишу в `CLAUDE.md`» — механически сработает, спорить не о чем; но представьте тридцать таких решений за полгода: файл читается целиком каждую сессию, ориентир — двести строк. «Агент сам запомнит» — отвечать не «нет», а механикой: между двумя вызовами модель не хранит ни одного бита. «Скажу "запомни это"» — половина ответа: это уходит в авто-память, машинно-локальный слой без синхронизации и без ревью. «Заведу `DECISIONS.md`» — вторая половина, с дисциплиной писать «почему», а не «что». «Поставлю систему памяти» — признать разумность и отложить: «через пять минут я покажу замеры, после которых это будет звучать менее очевидно. Пока запомните вопрос: относительно чего мы измеряем, что система памяти лучше?»

Целевой ответ — оба механизма разом, с разделением ролей. Этот разбор собирается на следующем шаге совместного формирования: три корзины.
