# Круг правок владельца — кейс 1 блока субагента + базовый слайд ступени

## По каждому замечанию

**4. Одностраничник «Роль целиком, одним экраном».**

Образец — `sem-05/slides/n11` + `rendered/figures/khuki-n12-ustroystvo.png` — посмотрен как
настоящий PNG, не по описанию. Прежний `n41` (`mechanics_map`) нёс только три из шести фактов
образца (вход / выход / три состояния `tools:`), на холсте 1600×580. Пересобран в полный
одностраничник из шести пронумерованных блоков:

1. где объявляется — файл `.claude/agents/<имя>.md` построчно по полям (`name`/`description`/
   `tools`/тело файла);
2. как позвать и как увидеть, кого позвали на самом деле — явно (`@agent-<имя>`) vs по описанию
   (решает модель), строка транскрипта `<имя>(<задача>)`, «`general-purpose` вместо ожидаемого
   имени — не долетело»;
3. что приходит на вход — системный промпт роли, задача, иерархия файлов инструкций, снимок
   репозитория, и отдельно — чего физически нет (переписка сессии, которая роль позвала);
4. что уходит обратно — только итог, канал в одну сторону;
5. права — три состояния записи `tools:` (не указано → всё; явно пусто → ничего, но жива; не
   резолвится → не запускается вовсе) — тот же факт, что нёс прежний слайд, без изменений;
6. чем оплачивается — короткая сводка числа с `n38` (15×/3–10×), не новый факт, явная отсылка
   «подробности — на предыдущем слайде».

Блоки 1, 2 и 6 — новые факты, которых раньше не было ни на одном слайде кейса целиком. Источники:
`section-2-subagent.md` §A.1 («Артефакт», «Механика») + `sem-05/research/mechanics-6-subagent.md`
§1.2–1.3 и §4.1 (явный вызов vs автовыбор, строка транскрипта, дословная цитата quickstart) и
§2.1–§2.4 (вход/выход/права — без изменений содержания). Ничего не выдумано.

Рисовалку написала сама — функция-секция `n41` в `rendered/make_figures_subagent.py` (та же
`fig_toolkit.py`, те же `mtext`/`mpanel`, локальный `bhead` для кружков-номеров). Настоящий PNG
(`figures/subagent-n41-vhod-vyhod-roli.png`, 1600×566) посмотрен и дважды пересчитан по пиксельной
сетке до того, как запускать скрипт, — собрался с первой попытки без предупреждений сборки
(`python3 make_figures_subagent.py` → «предупреждений нет»). Палитра Ocean, красного нет (три
состояния блока 5 и «чего нет» блока 3 держатся на `DEEP`/`MID`/`TEAL`/`DEEP`, не на красном);
золото — кружки-номера всех шести блоков и рамка блока 6, больше одного раза.

**3 и 5 — читаемость.**

- `n42` (провал) — было три абзаца прозы подряд до самой цитаты отказа харнесса, дальше ещё два
  абзаца разбора и только потом вывод. Переведено в: строка-сцена → таблица в одну строку
  (записано · харнесс видит · итог, несёт саму механику разбора `All`/`tools` на два имени) →
  цитата отказа целиком → одна строка контекста → вывод золотом → команда `grep`. Пятисекундная
  проверка по собранному PNG (`rendered/preview/n42.png`) — главное сообщение считывается с
  таблицы и заголовка, не требуя читать абзацы.
- Самоизобличающий пример курса (14 файлов ролей, 13 без поля `tools:`, 1 с нерабочим значением)
  — было: абзац на шесть строк внутри `n43`, не читавшийся с экрана за пять секунд («таблица
  отказа» прозой, не формой). Стало: короткая строка-статистика тремя числами жирным через точку,
  сборка рендерит её тремя отдельными плашками (видно на `rendered/preview/n43.png`) — числа не
  тронуты.
- `n33`–`n37`, `n40` — прошли отдельный проход на читаемость (замечание сформулировано как общее,
  не только про `n42`/`n43`): каждый собран и просмотрен настоящим PNG
  (`rendered/preview/n3{3,4,5,6,7}.png`, `n40.png`). Все уже читаются за пять секунд на момент
  старта круга — не трогала, чтобы не вносить правку без причины.

**6. Больше границ применимости.**

У кейса уже был один слайд границы (`n43`, «роли ещё нет» / «роль не нужна вовсе»). Добавлена
третья, которой не было: где урезание прав начинает мешать работе, а не защищать её. Материал —
`sem-05/research/mechanics-6-subagent.md` §3.2, официальный пример документации харнесса
(дословная цитата, не перефразировано): `code-reviewer` (`Read, Grep, Glob, Bash`, без
`Edit`/`Write`) — верно, ревью не чинит код; `debugger` (тот же набор плюс `Edit` возвращён
обратно) — «потому что починка бага требует правки кода». Мост к собственному артефакту кейса:
тот же узкий список `Read, Grep, Glob`, который на `n39`/`n40` был верным выбором для
диф-ревьюера, не хватило бы роли, чья работа — чинить, а не только находить.

Первая попытка — добавить третью границу прямо на `n43` вторым столом — провалила полную сборку
(`ЗА КРАЕМ ПОЛОТНА [n43]: композиция кончается на 8,40″ при высоте полотна 7,50″`). Это и есть
живое подтверждение замечания 3/5: слишком много на одном экране не читается, даже если каждый
факт сам по себе верный. Решение — новый слайд `n43a` отдельно, не довесок.
