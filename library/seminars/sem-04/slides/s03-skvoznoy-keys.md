# Сайт, который мы собираем весь семинар

## Assertion

Один и тот же репозиторий одного и того же сайта проходит все семь ступеней — не абстрактный демо-проект.

## Visual

Ocean rounded box карточка на всю ширину слайда, четыре строки фактов: «Задача» — лендинг с формой заявки на демо-урок, поля «имя» и «email», без собственного бэкенда; «Стек» — сборка Vite (`npm run build` → `dist/`), тест `tests/form.spec.ts` на Playwright, статический хостинг, деплой `wrangler pages deploy dist`, задачи и баги — только GitHub Issues; «Кто работает» — один разработчик с агентом Claude Code, без команды; «Готово» — `npm run build` код 0, `npx playwright test` зелёный, сайт открыт по продакшен-URL, форма реально отправляет заявку на проде. Под карточкой отдельная gold-обведённая строка: «У заказчика назначен показ сайта — фиксированная дата».

## Speaker notes

Весь сегодняшний разговор держится на одном репозитории — `signup-landing`. Задача простая и конкретная: статическая HTML-страница с формой заявки на демо-урок, два поля — имя и email, кнопка отправки. Собственного бэкенда нет, заявка уходит на внешний сервис приёма форм. Сборка через Vite, `npm run build` кладёт результат в `dist/`. Проверка — тест на Playwright, `tests/form.spec.ts`, он должен убедиться, что форма не отправляется с пустыми обязательными полями. Хостинг статический, например Cloudflare Pages, деплой командой `wrangler pages deploy dist`. Задачи и баги живут только в GitHub Issues этого же репозитория, больше нигде.

Над сайтом работает один разработчик вместе с агентом — соло-сценарий, без команды. Это важное условие: курс отдельно проверяет применимость каждой ступени лестницы для случая, когда второго человека для ревью и обсуждения физически нет, и вы увидите это явно в критериях «здесь не нужно» дальше по занятию.

«Готово» здесь имеет точное, проверяемое определение: сборка завершается без ошибок, тест зелёный, сайт реально открыт по продакшен-адресу, и форма реально отправляет заявку — проверено на проде, не только на локальной машине. Это не то же самое, что «агент написал в чате, что готово» — к разнице между этими двумя вещами занятие вернётся в разделе про процесс, ближе к концу.

И последний факт, который держит напряжение всего сценария: у заказчика уже назначен показ сайта, конкретная дата. Именно это давление порождает боль в двух местах занятия — накануне показа и прямо перед ним, когда работу начинают принимать на слово. Сейчас, впрочем, до показа ещё далеко — репозиторий, который вы увидите на следующем слайде, совершенно пуст.
