# Сценарий 4 — coding-agent

## Assertion

Coding-агент: находит баг, правит код, коммитит — куда его отнести?

## Visual

Слева квадрант 2×2, все 4 ячейки нейтрального серого (ни одна не выделена). Справа
карточка (зеркально к предыдущему слайду, где похожая карточка была слева —
визуальная парность): иконка `bot`, курсивный текст сценария («Вы даёте текстовую
задачу coding-агенту: "почини баг в обработке заказов". Агент сам открывает
несколько файлов проекта, находит проблему, правит код, запускает тесты и, если всё
прошло, делает коммит»), компактно Q1/Q2 внизу. Без связующего текста снизу — он
появится только на слайде-ответе.

## Speaker notes

Вы даёте текстовую задачу coding-агенту: «почини баг в обработке заказов». Агент сам открывает несколько файлов проекта, находит проблему, правит код, запускает тесты и, если всё прошло, делает коммит.

30–60 секунд индивидуального размышления, затем четыре раунда голосования по квадранту — этот сценарий ставим сразу после сценария 3, посмотрим, увидит ли аудитория параллель с парой Copilot inline / Copilot Workspace из раздела 2.
