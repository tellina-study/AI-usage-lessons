# Три варианта фронтматтера подряд

## Assertion

Два наивных фронтматтера ломаются каждый по своей причине; третий зал собирает сам — по одному предложению на каждый из трёх вопросов.

## Visual

| Вариант | Что при этом происходит |
|---|---|
| фронтматтера нет | описанием становится заголовок `# deploy` — дубль имени. По смыслу скилл не откроется никогда, а прямой `/deploy` работает, поэтому автор ничего не замечает |
| `description: Помогает с деплоем` | поле не пустое, фронтматтер годный — но не сказано **когда** звать и **когда не**. Это запрещённая документацией формулировка, переведённая дословно |
| третий — собираем сейчас | чем он обязан отличаться от второго, называет зал: вопросы ниже |

| Спрашиваем у зала | Куда ложится ответ |
|---|---|
| Что этот скилл делает? | первое предложение, третьим лицом |
| По каким словам его будут звать? | второе, после «используй, когда» |
| Где он сработать **не** должен? | явное «не для…» в конце |

```
.claude/skills/deploy/SKILL.md — из трёх ответов зала

---
name: deploy
description: Деплоит лендинг signup-landing на прод — сборка, smoke-тест
  формы, публикация, проверка прод-URL. Используй, когда пользователь
  просит задеплоить, выкатить или опубликовать сайт — не для обычных
  правок кода без деплоя.
---
```

## Speaker notes

Три варианта подряд, и ломаются они по-разному — в этом весь смысл показывать все три.

Первый: фронтматтера нет. Описанием становится первая непустая строка, а это заголовок. Ровно то, что мы видели на экране двенадцать раз. Коварство здесь в том, что прямой вызов через слэш продолжает работать — автор пробует, всё хорошо, и не узнаёт, что автоматически скилл не откроется никогда.

Второй: описание есть, но общее. «Помогает с деплоем» — это буквальный перевод формулировки, которая прямо приведена в документации примером «как не надо». Смотрите на карточку: три запрещённых примера, все три одинаково устроены — глагол плюс расплывчатое существительное. Поле не пустое, файл годный, а триггера нет: не сказано, когда звать, и не сказано, когда не звать.

Рядом — одобренный официальный пример для сравнения. Обратите внимание на его устройство: сначала конкретные действия, потом «используй, когда…» с настоящими словами запроса.

**Третью строку таблицы вслух не закрывайте.** Спросите прямо: чем третий вариант обязан отличаться от второго? Ответ «сказать, когда звать» приходит почти всегда; «сказать, когда НЕ звать» — почти никогда, и вот его ждите.

**Дальше три вопроса, по одному ответу на каждый, записываем словами зала.** Что делает — третьим лицом, без «я» и «вы». По каким словам звать — тут нужны настоящие слова запроса: задеплоить, выкатить, опубликовать. Где не должен — «не для обычных правок кода без деплоя».

**Берите формулировки зала, а не мои.** Порядок частей важнее слов; нижняя карточка — один из возможных ответов, а не эталон. Пометку «рабочий» ставьте после того, как зал назвал третью часть сам.

**Три запрещённые формулировки, дословно** — если зал предложит что-то похожее, назовите их: `Helps with documents`, `Processes data`, `Does stuff with files`. Все три устроены одинаково: глагол плюс расплывчатое существительное. «Помогает с деплоем» — их точный перевод.

**Одобренный пример для сравнения**, оттуда же: «Extract text and tables from PDF files, fill forms, merge documents. Use when working with PDF files or when the user mentions PDFs, forms, or document extraction». Сначала конкретные действия, потом «используй, когда» настоящими словами запроса.

**Проверять потом надо в обе стороны:** просим выкатить сайт — должен открыться; просим поправить опечатку в вёрстке — открываться не должен.
