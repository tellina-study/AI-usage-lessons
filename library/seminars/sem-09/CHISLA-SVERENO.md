## Пояснения к расхождениям

**№1. PEAR (arXiv:2510.07505) — withdrawn.** Запрос страницы `arxiv.org/abs/2510.07505` показывает:
«This submission has been withdrawn by arXiv administrators due to incorrect authorship. Author
list truncated» (версии v3–v4). Скачанная мной версия PDF (прямой URL без версии — отдал более
раннюю редакцию) содержит реальный текст с теми же числами (Michigan State University, Purdue,
University of Texas at Dallas, секция 4.3 с «about 30%»/«below 60%»), и эти числа я прочитал
дословно. Проблема не в содержании измерения, а в статусе публикации: на сегодня первоисточник
официально отозван администрацией arXiv по вопросу авторства (не по качеству данных). Это не
повод говорить «цифры выдуманы» — но это повод не ставить «EACL 2026 Findings» на слайд как
подтверждённый факт (венюе на странице arXiv не указано вовсе) и explicitly предупредить
орхестратора/владельца перед финальной сборкой деки, т.к. ссылка может не открыться студенту
так же, как не открылась мне с первого запроса.

**№2. RefusalBench — атрибуция моделей.** Список реально оценённых моделей в статье: «GPT-4
series (GPT-4o, GPT-4.1, o4-mini)» — GPT-3.5 в списке моделей бенчмарка не найден ни разу по
всему тексту. Находка А1 файла 05 говорит «GPT-3.5/GPT-4o минимизирует...» — число (4,3%
пропущенных, >60% ложных отказов) принадлежит только GPT-4o; «GPT-3,5/» нужно убрать.

**№3. InjecAgent Table 3 — перепутанная строка.** Таблица содержит для раздела «Fine-tuned»: GPT-3.5
(база 3,8% → усиленная 8,4%), GPT-4 (база 6,6% → усиленная 7,1%). Находка приводит «GPT-3,5:
3,8%→6,6%» — это значение 6,6% на самом деле является БАЗОВЫМ ASR для fine-tuned GPT-4, не
усиленным ASR для fine-tuned GPT-3.5. Реальное усиленное значение для GPT-3.5 — 8,4%.

**№4. LLMail-Inject — потерянная ссылка.** Числа 839 участников / 208 095 атак / 58%/47%/32%
реальны и дословно подтверждены — но они взяты из отдельной, отличной от «Attacker Moves
Second» работы: Abdelnabi et al. (или соавторы конкурса), *«LLMail-Inject: A Dataset from a
Realistic Adaptive Prompt Injection Challenge»*, arXiv:2506.09956. Текст находки Н2 вставляет этот
абзац сразу после ссылки на `arXiv:2510.09023` без отдельной сноски, что читается как «то же
исследование описывает и это» — нужно явно назвать вторую работу.

**№5. Jia et al. — диапазон ASV против GCG занижен по нижней границе.** Table 2 статьи даёт для
колонки «GCG» значения 0,24 / 0,46 / 0,72 / 0,88 / 0,80 / 1,00 / 0,88 / 1,00 (SecAlign и StruQ,
два бенчмарка, existing/adaptive). Нижняя граница диапазона — 0,24 (SecAlign на
OpenPromptInjection, существующая атака), а не 0,72, как в находке. Для «типовой» атаки
(не GCG) диапазон 0,03–0,14 подтверждён точно.

1. **Air Canada (2024 BCCRT 149)** — число и цитата проверены и точны, но владелец явно отклонил

   от качества фактчека — это решение о содержании, не о достоверности.

   найдены; источник числа 0,790 («другая независимая работа») не назван по имени в самой находке.
   Не ставить на слайд без указания точного источника каждого числа.
3. **PEAR (Б1, направление «план→исполнение», файл 01)** — показывать с осторожностью: первоисточник
   отозван администрацией arXiv по вопросу авторства (см. пояснение №1). Если кейс идёт на слайд —
   либо снять явную ссылку на «EACL 2026 Findings», либо заменить источник на иной (Б2/Б3 файла 01
   не затронуты этой проблемой и методологически не слабее).

   непроверенный блог-эксперимент; подтверждаю эту оценку, отдельно не перепроверял. Статус находки
   честно названа «не кейс» — это верно, не менять.
5. **Qualiteg/clawrouters — токены GPT-4o-mini (файл 07, А2)** — оба источника вторичные
   (не официальная страница OpenAI), сам исследователь это обозначил. Подтверждаю: ставить на
   слайд только с явной пометкой «по независимому пересчёту, не из документации OpenAI»,
   не как официальную цифру.
