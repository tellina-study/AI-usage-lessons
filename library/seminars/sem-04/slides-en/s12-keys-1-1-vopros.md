# What goes into the file now

## Assertion

A choice among five options: which of the listed items goes into the file now, before the next session.

## Visual

At the top, in a gold-outlined block — the question, verbatim:

> "In front of you is the empty `CLAUDE.md` of the `signup-landing` repository. Pick from the cards what goes into the file now, before the agent's next session."

Below — five option cards in this order:

`a detailed description of the repository structure` · `a list of technologies and dependencies` · `an instruction on where the form lives and how to find it` · `a non-obvious convention the agent will not guess on its own` · `nothing yet — until the first real signal`

There is not a single number and not a single source reference on the slide. There is no breakdown table and no target answer here either — those are on the next slide, together with the evidence.

## Speaker notes

The question is asked with the set of options already on the screen. Two or three voices. Answers are recorded neutrally and without judgment: "repository structure — noted", "list of technologies — noted".

Any option that comes up is recorded the same way, including "I'd describe the architecture": "Got it, we'll come back to that in a minute."

The vote happens with not a single number on the screen — the evidence and the breakdown come on the next slide, in one pass.
