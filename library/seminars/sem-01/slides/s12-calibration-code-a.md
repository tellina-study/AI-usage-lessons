# Код A — библиотека requests, 10+ лет в проде. Код B — AI, 10-20 секунд

## Assertion

Код A — библиотека requests, 10+ лет в проде. Код B — AI, 10-20 секунд.

## Visual

Те же 2 code-карточки, подписаны: Код A — «requests, github.com/psf/requests, MIT
license» (иконка `git-branch`), Код B — «AI, по запросу написать похожую функцию»
(иконка `sparkles`). Снизу — tradeoff-блок (2 колонки), round-2 переписан в
позитивной рамке (убрано «без истории эксплуатации и без гарантии, что учтены все

вспомогательных функций за секунды. Gold-callout снизу — «Урок: типовые задачи —
AI, сложные и уникальные решения, от которых зависит стабильность системы, —
человеку».

## Speaker notes

Код А — реальная функция из библиотеки `requests`, одной из самых используемых библиотек Python, с открытым исходным кодом на GitHub, лицензия MIT. Код Б сгенерирован AI по аналогичному запросу — написать небольшую функцию похожего масштаба.

Честное сравнение, без принижения любой из сторон: `requests` — код, который уже больше десяти лет работает в тысячах и миллионах реальных проектов, каждый скрытый баг за это время скорее всего найден и исправлен сообществом — это результат многолетней проверки на сложной нагруженной инфраструктуре. AI-версию вы получаете за 10–20 секунд — отличный вариант именно для таких типовых вспомогательных функций, boilerplate-кода, одноразовых скриптов.

Урок этого раунда — не «AI хуже», а разделение по типу задачи: типовые, вспомогательные задачи — AI, это быстрее и достаточно надёжно. Сложные и уникальные решения, архитектурные, высокоставочные, от которых зависит стабильность системы, — человеку, с его опытом и ответственностью за решение.
