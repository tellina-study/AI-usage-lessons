# Звонки продаж — разбор

## Assertion

Сложно для человека — не значит сложно для модели

## Visual

Схема: «свободный разговор» → «извлечение полей по фиксированному
шаблону» → «локальная модель 7-8 млрд параметров, 4-bit квантование» →
«данные не покидают периметр компании». Рядом — список открытых моделей
класса 7-8B: Qwen3, Llama, Gemma, Mistral, T-lite, T-pro. Внизу — две
строки-урока. Никакой полосы ходов под схемой.

## Speaker notes

Задача на самом деле сузилась: нужна не свободная беседа, а
структурированная выжимка по фиксированному шаблону из нескольких полей —
это извлечение фиксированных полей по шаблону, а не свободная беседа с
пониманием контекста. Что именно раскопал инженер, разбираясь с этим:
класс задачи хорошо закрывают актуальные открытые модели размером 7-8
миллиардов параметров — Qwen3, Llama, Gemma, Mistral, а также российские
T-lite и T-pro, разработка Т-Банка на лицензии Apache 2.0, построенные на
базе Qwen. 4-bit квантование — сжатие весов модели до 4 бит на параметр —
позволяет уместить такую модель в 4-6 гигабайт памяти и запустить на
обычном сервере без GPU-фермы, через инструменты вроде Ollama или
llama.cpp. Если понадобится точнее подстроить модель под формат вывода —
можно дообучить методом LoRA, экономным способом дообучения без изменения
всех весов модели, и сделать это на одной GPU. Два урока проговорим явно.
Первый — «сложно для человека» не значит «сложно для модели»: свободный
разговор кажется сложным входом, но извлечение структурированных полей по
шаблону — задача умеренной сложности, которую малая модель решает
надёжно. Второй — чувствительность данных не видна в исходной постановке
задачи, её нужно выяснять вопросами о содержимом входных данных, а не
предполагать по формулировке.
