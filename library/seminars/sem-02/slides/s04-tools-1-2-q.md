# Модель, чат, агент или приложение?

## Assertion

Модель, чат, агент или приложение — инструменты 1 и 2.

## Visual

Две равные Ocean rounded box карточки, идентичного формата (без ответа, без цветного
badge). Левая: иконка `scan`, заголовок «YOLO-детектор людей в кадре», описание
«Детекция людей в кадре в реальном времени — прямая перекличка с демо Лекции 1».
Правая: иконка `message-square`, заголовок «AI-чат для разовой консультации по
тексту», описание «Например, ChatGPT — уточняющий диалог по тексту». Внизу общая
подсказка-подзаголовок: «4 раунда поднятия руки на инструмент — модель? чат? агент?
приложение?».

## Speaker notes

Первый инструмент — YOLO-детектор из демо сегодняшнего утра: детекция людей в кадре в реальном времени. Второй — AI-чат для разовой консультации по тексту, например ChatGPT.

Для каждого — четыре раунда поднятия руки: модель, чат, агент или приложение. Голосуем по очереди на каждый вариант, камера считает поднятые руки. Если голоса заметно разойдутся — один-два студента объясняют выбор вслух до официального ответа.

Прогоняем оба через Q1 (нужно ли взаимодействие с пользователем?) и Q2 (нужна ли самостоятельная работа с инструментами?) про себя, прежде чем поднять руку.
