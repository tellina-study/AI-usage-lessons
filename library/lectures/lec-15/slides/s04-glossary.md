# Пятнадцать терминов. Без них следующий час не сложится.

## Словарь

| Термин | Определение | Первый пример |
|---|---|---|
| Фундаментальная модель (foundation model) | Большая модель машинного обучения общего назначения, обученная на огромном корпусе и применимая к множеству задач | AlphaFold, Aurora, GNoME |
| RAG (поиск с генерацией) | Архитектура, в которой LLM генерирует ответ с опорой на найденные в индексе документы | NotebookLM, Elicit, Consensus |
| Галлюцинация | Правдоподобный, но фактически неверный или несуществующий вывод модели; нормальное поведение LLM | Galactica «цитирует» несуществующие статьи |
| Рецензирование (peer review) | Независимая оценка коллегами по специальности перед публикацией | NeurIPS 2025: 24,52% принятых |
| Кризис воспроизводимости | Значительная доля опубликованных результатов не воспроизводится | Психология — 39 из 100 |
| Закрытый / открытый мир | Закрытая задача: пространство решений описано, проверка возможна. Открытая: проверка требует выхода за пределы системы | Закрытая: катализ через DFT. Открытая: организменная биология |
| IDP (внутренне разупорядоченный белок) | Белок без стабильной 3D-структуры; существует как ансамбль конформаций | AlphaFold даёт ~22% галлюцинаций в IDP-регионах |
| Эталонная разметка (ground truth) | Независимо проверенная истина, с которой сравниваются предсказания модели | PDB-структуры, реанализ ECMWF, синтез в катализе |
| CASP | Двухгодичная слепая международная олимпиада по предсказанию структуры белков | CASP14 (2020) — AlphaFold 2 «решил» задачу |
| DFT / MD | Density functional theory (>50 лет) / Molecular dynamics (>60 лет) — методы первого принципа | Альтернатива ML в катализе и материалах |
| BO / GP | Байесовская оптимизация (40+ лет) / Гауссовский процесс (60+ лет) | Альтернатива «AI» в планировании экспериментов |
| ECMWF | Европейский центр среднесрочных прогнозов погоды; разрабатывает собственную модель AIFS | AIFS оперативно с 25 февраля 2025 |
| FrontierMath | Закрытый эталонный тест по продвинутой математике (Epoch AI, 2024+) | <2% при запуске → 52,4% (GPT-5.5 Pro, май 2026) |
| ICMJE | Международный комитет редакторов медицинских журналов | AI не может быть автором; раскрытие обязательно |
| IMO | Международная математическая олимпиада | AlphaProof + AG2 — 28 из 42 баллов в 2024 (серебро) |

## Дополнительно

**Фабрика статей (paper mill).** Индустриализированное производство фальшивых публикаций для накрутки метрик.

**HITL (человек в петле).** Человек в петле принятия решения.

**Обратное проектирование (inverse design).** Задача нахождения параметров системы по желаемым свойствам.

## Speaker notes

Прежде чем мы двинемся по разделам, договоримся об общем словаре. Эти пятнадцать терминов встречаются в каждом разделе лекции, и непонимание любого из них блокирует следующие.

Фундаментальная модель — большая модель машинного обучения общего назначения, обученная на огромном корпусе и применимая ко многим задачам. AlphaFold для белков, Aurora для атмосферы, GNoME для материалов. RAG — это поиск с генерацией: LLM генерирует ответ с опорой на найденные документы. NotebookLM, Elicit, Consensus — все построены на RAG поверх научной литературы.

Галлюцинация — это не сбой модели, это нормальное поведение LLM, генерирующего правдоподобную последовательность токенов. Запомните: галлюцинация — не баг, она встроена в архитектуру. Galactica цитировала несуществующие статьи именно потому.

Рецензирование, репликация, кризис воспроизводимости — фундаментальные институциональные термины. Воспроизводимость психологии — 39 из 100, экономика — 61 процент, AI и машинное обучение — от 24 до 50 процентов. AI не лечит эту проблему и может её усугубить.

Закрытый против открытого мира — это диагностический критерий лекции. Закрытая задача: пространство решений описано через физические уравнения, проверка возможна. Открытая: пространство не описано, проверка требует выхода за систему. Катализ — закрытый; гипотеза о роли социальных сетей — открытый.

IDP — внутренне разупорядоченный белок без стабильной 3D-структуры. AlphaFold там галлюцинирует, и это критично для разработки лекарств. Эталонная разметка — это независимо проверенная истина: PDB-структуры в биологии, реанализ ECMWF в погоде, синтез в катализе.

CASP, DFT, MD, BO, GP, ECMWF, FrontierMath, ICMJE, IMO — институциональные имена и аббревиатуры. Каждое расписано подробнее по ходу лекции. Запомните: DFT и MD — методы первого принципа, BO и GP — байесовская оптимизация и гауссовский процесс — это зрелые альтернативы AI, работающие десятилетиями.
