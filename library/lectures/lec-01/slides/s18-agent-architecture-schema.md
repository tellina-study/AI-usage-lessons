# Агент = чат + оркестратор + внешняя память + инструменты

## Assertion

Агент = чат + оркестратор + внешняя память + инструменты.

## Visual

Архитектурная схема в Ocean rounded box. Слева — иконка «USER» (пользователь). По центру — блок «LLM / Chat». Сверху — «Оркестратор» (планирование, decision loop, gold-fill). Внизу слева — «Внешняя память» (vector DB, файлы, логи). Внизу справа — «Инструменты» (API, файлы, code, search). USER связан с Chat двумя стрелками: верхняя (USER → Chat — запрос, синяя), нижняя (Chat → USER — ответ, teal). Соединительные линии между Chat и компонентами вертикальные. Снизу подпись цикла ReAct: «plan → act → observe → reflect → continue / stop» + ссылка Yao 2022.

## Speaker notes

Агент — следующий слой после чата. По сравнению с чатом у агента появляется три дополнительных компонента, которых у чата не было.

Первый компонент — оркестратор. Логика управления: план, decision loop, критика. Оркестратор смотрит на цель пользователя, разбивает её на шаги, выбирает, какой инструмент применить на каждом шаге, и решает, когда остановиться.

Второй — внешняя память. В отличие от чата, у агента есть память за пределами одной сессии: vector database (база данных, оптимизированная для поиска по сходству эмбеддингов; подробнее на лекции 3), файловая система с промежуточными результатами, лог собственных предыдущих действий.

Третий — инструменты. Возможность вызывать внешние API, читать и писать файлы, выполнять код, делать веб-поиск. Каждый инструмент — это функция с описанием: что делает, какие параметры принимает, что возвращает. Оркестратор выбирает, какой инструмент применить на каждом шаге.

Цикл работы агента, базовая модель ReAct — Reasoning plus Acting. Шаг план: оркестратор и LLM формулируют план действий. Шаг act: выбирается и вызывается инструмент с конкретными параметрами. Шаг observe: результат инструмента наблюдается, записывается в память, передаётся обратно в LLM. Шаг reflect: LLM обдумывает результат — цель достигнута или нет, нужен ли следующий шаг. Если цель достигнута или итераций было слишком много — остановка. Иначе — следующий шаг.

Каноническая формулировка из работы Лилианы Венг: Agent равен LLM плюс Memory плюс Planning плюс Tool Use. Канонические продукты-агенты: Claude Code от Anthropic — агент в терминале для разработки. Devin от Cognition Labs — облачный коддинг-агент. OpenAI Operator — агент для веб-задач. AutoGPT — open-source автономный агент.
