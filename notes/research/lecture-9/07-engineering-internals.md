# 07 — Инженерные внутренности кейсов (на 2026-10-31)

## 1. ECMWF AIFS

Архитектура: encoder–processor–decoder, attention-based graph-трансформеры на входе/выходе,
процессор — 16-слойный трансформер со sliding-window attention по широтным полосам. Сетка N320
(~0.25°) снаружи, ~1° внутри процессора. AIFS ENS/CRPS — 229 млн параметров (точное число для
AIFS Single не раскрыто публично). **AIFS не делает свою ассимиляцию данных** — потребляет готовый
анализ атмосферы из классической системы 4D-Var (та же, что у физической модели IFS): радиозонды,
спутниковые радиометры, SYNOP, буи и т.д. обрабатывает классический вариационный алгоритм, AIFS
получает результат как готовое начальное условие. Обучение — 38 лет ERA5 (1979–2017) + 8 лет
операционных анализов IFS, минимизация CRPS, AdamW, 64×A100. Прогноз генерируется авторегрессивно,
шаг 6 часов. 10-дневный прогноз — ~2.5 минуты на одном A100 против часов на суперкомпьютере для
IFS; AIFS-SUBS (46-дневный) — ~920× быстрее и ~200× меньше энергии аналогичного прогона IFS.
Источники: arXiv 2406.01465, GMD Copernicus 2026, ECMWF Newsletter 181/185, arXiv 2412.15832.

## 2. NOAA AIGEFS (на основе DeepMind GraphCast)

Message-passing GNN, encoder–processor–decoder между lat-lon сеткой и icosahedral-мультисеткой
(7 икосаэдрических сеток), 16-слойный message-passing процессор, ~36.7 млн параметров (исходный
GraphCast). Вход — две аналитические карты GDAS (t₀ и t₋₆ч), шаг 6 часов, сетка 0.25°. **Тоже не
делает свою ассимиляцию** — потребляет готовый анализ GDAS. Предобучение на ERA5, дообучение на
GFS/HRES NOAA. Ансамбль AIGEFS — 31 член; гибрид HGEFS = 31 AIGEFS + 31 классический GEFSv12 = 62.
16-дневный прогноз на 0.25° — <4 минуты на одном узле A100, полный операционный цикл ~40 минут,
NOAA называет это ~0.3% вычислений от операционной GFS. Точное число GPU в операционном инференсе
не названо явно (обучающий кластер — узлы 8×H100/80GB). Операционно с 17.12.2025.
Источники: noaa.gov релиз, NWS SCN 25-89, graphcastgfs.readthedocs.io.

## 3. ICON Project Olympus (печать лунного реголита)

Два параллельных трека внутри NASA MMPACT: (1) лазерное спекание/плавление реголита слоями —
главный заявленный метод ICON (принтер Vulcan); (2) микроволновое спекание (MSCC) — альтернатива,
энергоэффективнее (~2-3% энергии лазерного по одной из оценок). Vulcan управляется через мобильное
приложение с «автоматизированной системой управления» — по формулировкам ICON это автоматика по
программе, не явный ML. NASA MMPACT заявляет разработку «ИИ-инструментов, превращающих простые
инструкции в траектории работы» + landmark tracking для навигации машин + «интегрированные сенсоры
и мониторинг процесса для автономного строительства» — но **конкретная архитектура (какая модель,
что в контуре качества слоя) публично не раскрыта** — уровень программных анонсов, не инженерная
спецификация. Испытания в вакууме пройдены, лунная гравитация и доставка на Луну — план 2026-27.
Источники: NASA MMPACT NTRS PDF, Singularity Hub, CNN, NTRS Microwave Sintering PDF.

## 4. NASA IPEx (экскаватор)

Рабочий орган — bucket drums (вращающиеся барабаны-ковши с внутренними баффлами), а не классический
отвал — позволяет работать и как бульдозер, и как самосвал при малой массе (важно при лунной
гравитации). Алгоритмы копания — «Auto-dig» (эвристика/классическая алгоритмика, не заявлена как
нейросеть). Навигация — камеры + пылеподавление, явного LIDAR/SLAM-стека уровня марсоходов в
открытых источниках не описано. **Автономия — supervised campaign-level, не покомандная**: три
режима — телеоперируемое картографирование, супервизируемый автономный цикл экскавации, докинг для
подзарядки. Задержка связи с Луной делает покомандную телеоперацию непрактичной на уровне отдельных
циклов копания, но человек верифицирует задачи на уровне кампании.
Источники: NASA NTRS SRR-Autodig-2022 PDF, NASA IPEx TRL5 Design Overview PDF, space-robotics.org.

## 5. Марсоходная автономия: AutoNav, AEGIS, Claude/Anthropic (дек. 2025)

**AutoNav/GESTALT — классический стек, без обучаемой модели.** Стереопара (hazard/nav камеры) →
облако точек → подгонка плоскостей (уклон/шероховатость) → карта проходимости → эвристический
планировщик дуг движения. Mars 2020 — улучшенная параллельная версия ENav, та же архитектурная
схема, быстрее за счёт параллелизма этапов, не за счёт ML.

**AEGIS — гибрид классики и лёгкого ML.** Алгоритм Rockster: находит объекты по перепаду яркости/
границам на NavCam-стерео, извлекает геометрические/визуальные признаки, отфильтровывает
неподходящие кандидаты, ранжирует по профилю цели; для классификации объектов используется **random
forest classifier** (не deep learning). Без AEGIS — 24% попаданий в научно интересную цель
(Curiosity целится по команде Земли с ограниченной информацией); с AEGIS — 93%. Впервые применён на
Opportunity (2010, Pancam), рутинно на Curiosity с 2016 (ChemCam).

**Claude/Anthropic, 8 и 10 декабря 2025 (Jezero Crater) — верхний слой планирования, не замена
AutoNav/AEGIS.** Claude Code анализировал орбитальные снимки HiRISE (Mars Reconnaissance Orbiter) +
цифровые модели рельефа (DEM, уклон/рельеф), «сшивал» маршрут из сегментов ~10 м, расставлял
waypoints, сам проверял/редактировал их по безопасности, конвертировал план в Rover Markup Language
(RML) — тот же формат, которым пользуются люди-операторы. Итог — ~400-456 м маршрута за два сола.
**Проверка плана — классическая инженерная симуляция, не ИИ-валидация:** цифровой двойник JPL
проверял >500 000 телеметрических переменных на совместимость с полётным ПО перед отправкой команд
(проверка ограничений/совместимости, не физическое моделирование рельефа заново). Ожидаемый эффект
— вдвое быстрее планирование маршрута.
Источники: Anthropic — Claude on Mars, NASA Perseverance release, JPL AEGIS project page, Science
Robotics scirobotics.adi3099, Tech Briefs NPO-44504.

## 6. Лавовые тоннели: SherpaTT/Coyote III/LUVMI-X и NeBula/CoSTAR

**COROB-X (DFKI + Space Applications Services, Лансароте, февраль 2023) — демонстратор-концепт, не
летящая миссия.** SherpaTT — гибридный колёсно-ногий робот, разведка поверхности + якорь для
троса; Coyote III — лёгкий ровер, спускается в скайлайт (вход лавовой трубы) для автономной
3D-разведки внутри; LUVMI-X — картографирование совместно с SherpaTT. 4 фазы: картографирование →
развёртывание сенсорного куба → спуск на тросе → автономная 3D-разведка.

**NeBula/CoSTAR (JPL+Caltech+MIT+KAIST+Luleå, победитель DARPA SubT) — технически:**
- **SLAM — LAMP** (Large-scale Autonomous Mapping and Positioning), 3 уровня: локальный
  single-robot frontend (мультисенсорная одометрия — LIDAR, визуально-инерциальная, колёсно-
  инерциальная, IMU) → multi-robot frontend на базовой станции (межроботные loop closures) →
  multi-robot backend (совместная оптимизация графа поз, сливающая локальные карты в глобальную).
  LAMP 2.0 — масштабируется на 8+ гетерогенных агентов на дистанциях в километры.
- **Детекция объектов — явный ML-компонент**: CNN (включая YOLOv4) в видимом+тепловом спектре на
  нескольких камерах (почти 360°), геометрическая локализация находки — классическая проективная
  геометрия (не ML). EaRLaP-пайплайн для борьбы с ложными/пропущенными находками.

**Честная оговорка:** связь SherpaTT/Coyote/LUVMI-X с NeBula/LAMP — по духу подхода (та же задача,
то же семейство решений: мультисенсорная одометрия + loop closure + CNN-детекция), прямого
подтверждения заимствования кода/архитектуры JPL в открытых источниках нет.
Источники: DFKI corobx-feldtests, ResearchGate COROB-X, Universe Today, JPL NeBula capability page,
arXiv 2103.11470, DTIC LAMP PDF, arXiv 2003.01744, GitHub NeBula-Autonomy/LAMP, arXiv 2504.13461.

## Честные пробелы (не раскрыто публично — не придумывать на фазе главы)

- AIFS Single: точное число параметров.
- ICON: конкретная архитектура AI quality-control слоя печати.
- NOAA AIGEFS: число GPU в операционном инференс-кластере.

- SherpaTT/Coyote/LUVMI-X ↔ NeBula: содержательная, не буквальная связь архитектур.
