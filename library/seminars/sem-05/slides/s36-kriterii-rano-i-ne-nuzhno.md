# Ещё рано — и не нужно вообще

## Assertion

Скилл рано ставить там, где процедура нужна каждой сессии, одноразова или где правило нельзя нарушить ни разу; а набор скиллов «про запас» — не рано, а измеримо вредно.

## Visual

| Здесь ещё рано | Почему не скилл | Что вместо |
|---|---|---|
| нужно каждой сессии | тело грузится почти всегда, а сверху добавлен шаг угадывания | строка в файле инструкций |
| процедура одноразовая | дешевле один раз попросить обычным запросом | запрос; оформлять по факту повторения |
| правило нельзя нарушить ни разу | скилл остаётся знанием, которое агент может не учесть | хук |
| нужен отдельный бюджет контекста | скилл делит то же окно, он решает другую задачу | субагент, ступень 6 |

| Здесь не нужно вообще | Почему | Что вместо |
|---|---|---|
| скилл из непроверенного реестра | установка чужого кода с постоянными правами | обойтись своим файлом |
| скилл вместо описания проекта | знание о структуре выводимо или живёт в описании репозитория | README |
| набор скиллов «про запас» | падает точность выбора, а не цена контекста | ставить по факту нужды |

- −21% успеха при 202 скиллах — те же задачи, тот же агент; падает точность выбора, не цена контекста.

## Speaker notes

«Четыре ситуации, где скилл — правильная вещь, но ещё рано.

Нужно каждой сессии — тело всё равно грузится почти всегда, выигрыша нет, а шаг угадывания «совпадёт описание или нет» добавился. Честнее строка в файле инструкций.

Процедура одноразовая — дешевле один раз подробно попросить. Рекомендация прямая: сначала пройти задачу без скилла и только по факту повторения решать, что оформлять.

Правило нельзя нарушить ни разу — это хук. Скилл остаётся знанием, которое агент может и проигнорировать.

Нужен изолированный бюджет контекста — это субагент. Скилл делит то же окно: он решает «не грузить, пока не нужно», а не «слишком много в одном окне».

И три ситуации, где скилл не нужен вообще. Скилл из непроверенного реестра — мы только что видели, что это такое. Скилл вместо описания проекта — знание о структуре выводимо за секунды.

И последнее. Желание поставить набор заранее, про запас, — не нейтральная привычка. При двухстах скиллах падение успешности доходит до двадцати одного процента, на тех же задачах и том же агенте. Падает не цена контекста, она остаётся маленькой, — падает точность выбора. Количество установленных скиллов не сигнал качества, это сигнал будущей проблемы выбора.»
