# Первая запись в уже заведённом файле

## Assertion

Новое — не файл (он с нами с первого дня), а первая содержательная запись в нём.

## Visual

Слева — файл целиком, реальный:

```markdown
# Decisions

Append-only log of why, in date order.

## 2026-09-20 — не подключаем библиотеку валидации форм
Форма — два поля (имя, email), хватает нативных `required`/`pattern` в `index.html`.
Сторонняя библиотека — лишняя зависимость и лишние килобайты в сборке ради этого объёма.
```

Справа — дерево кейса 2.1, строка `DECISIONS.md` выделена gold:

```
AGENTS.md
CLAUDE.md
DECISIONS.md
index.html
package.json
src/main.js
tests/form.spec.ts
# + spec.md, README.md (раздел 0) — не в этом git-дереве
```

Последняя строка — пометка (Fix 5, round-6 QA), не часть реального капчура (`22-tree-stage2.txt`):
`spec.md`/`README.md` существуют в репозитории с раздела 0, но не входят в этот конкретный
git-снимок.

## Speaker notes

Два механизма, не один. Авто-память рантайма живёт вне репозитория, в каталоге памяти на машине разработчика: индекс из первых 200 строк или 25 КБ плюс тематические файлы, которые агент создаёт сам. Команда «запомни: не подключаем стороннюю библиотеку валидации» создаёт тематический файл именно там — в дерево справа он не попадает.

`DECISIONS.md` — второй механизм, git-трекнутый append-only лог, заведённый ещё на дне 0. Новое здесь — не файл, а первая содержательная запись в нём. Это реальный файл реального демо-репозитория, не пример, сочинённый для слайда, — и это стоит произнести вслух.
