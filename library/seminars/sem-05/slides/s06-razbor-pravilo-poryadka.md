# Своя боль у каждого — правило порядка вместо ответа

## Assertion

У вопроса нет единственно верного ответа: есть правило порядка, а не рейтинг предпочтений — заводится то усиление, для которого сигнал уже прозвучал.

## Visual

Пять карточек — одна строка боли на каждую:

| Усиление | Боль, которая его вызывает |
|---|---|
| Хук | Правило файла инструкций уже прочитано — и уже нарушено: коммит в `main` состоялся вопреки записанной строке |
| Скилл | Процедура в файле инструкций разрослась и грузится в каждую сессию, хотя нужна не в каждой |
| MCP | Агенту нужно то, чего в репозитории физически нет, — данные или система за его пределами |
| Субагент | Одна и та же роль повторяется из сессии в сессию |
| Процесс | Утверждение агента «готово» — самоотчёт, который можно обойти, а не только не выполнить |

Ниже, в gold-рамке — разрешение вопроса, дословно:

> «У этого вопроса нет единственно верного ответа — потому что за каждой карточкой стоит своя боль, и предпочтение здесь ничего не решает. Есть правило порядка, а не рейтинг: заводится то усиление, для которого сигнал уже прозвучал. К хуку сигнал уже пришёл — на прошлом занятии, правило было нарушено буквально в последней сцене. Для скилла сигнал придёт по ходу сегодняшнего занятия, на своей ступени. Для субагента — на следующем занятии, тоже на своей ступени. А для процесса и для половины MCP — дисциплины минимальных прав — сигнал вообще не нужен: они заводятся на день 0, независимо от того, что происходит в конкретном проекте.»

## Speaker notes

За каждой из пяти карточек — своя боль, и они разной природы.

Хук — потому что правило файла инструкций уже прочитано и уже нарушено: коммит в `main` состоялся, несмотря на записанную строку. Скилл — потому что процедура в файле инструкций разрослась и грузится в каждую сессию, хотя нужна не в каждой. MCP — потому что агенту нужно то, чего в репозитории физически нет, данные или система за его пределами. Субагент — потому что одна и та же роль повторяется из сессии в сессию. Процесс — потому что утверждение агента «готово» — это самоотчёт, который можно обойти, а не только не выполнить.

Единственно верного ответа на вопрос «что завести первым» нет — потому что у вопроса нет одного измерения. Есть правило порядка, а не рейтинг предпочтений: заводится то усиление, для которого сигнал уже прозвучал. К хуку сигнал уже пришёл — на прошлом занятии, правило было нарушено буквально в последней сцене, это не гипотеза. Для скилла сигнал придёт по ходу сегодняшнего занятия, на своей ступени. Для субагента — на следующем занятии, тоже на своей ступени. А для процесса и для половины MCP — дисциплины минимальных прав — сигнал вообще не требуется: они заводятся на день 0, независимо от конкретики проекта.

Вернёмся к этому вопросу в конце занятия — и проверим, изменился ли ответ по трём усилениям, разобранным сегодня. Полный ответ по всем пяти — в конце следующего занятия.
