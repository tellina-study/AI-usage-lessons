# Slash-команды vs хуки в харнесе

**Date:** 2026-10-02 · **Issue:** #217-EXP

Slash-команда и хук — два разных способа запуска действий в агентном харнесе, различающихся по инициатору и моменту выполнения.

**Slash-команда** (`/skill-name`) — это явный, синхронный вызов, инициируемый пользователем или агентом в данный момент. Когда пользователь типирует `/sync-library`, харнес сразу же выполняет зарегистрированное действие и возвращает результат в той же сессии. Это как нажать кнопку — действие выполняется по требованию.

**Хук** — это декларативное правило автоматического выполнения при наступлении события. Хук настраивается в `settings.json` или `settings.local.json` с фразой типа "from now on when X, do Y" или "before/after X, execute Y". Например: `before_each_commit run pre-commit` или `when_compile_fails show_debug_log`. Хук срабатывает автоматически, без явного вызова, в ответ на определённое событие.

| утверждение | источник | тип |
|---|---|---|
| Slash-команда срабатывает явно по инициативе пользователя/агента | CLAUDE.md § update-config | документированное поведение |
| Хуки настраиваются в settings.json для автоматизации событий | CLAUDE.md § Orchestration Rule | документированное поведение |
| Slash-команда выполняется синхронно в текущей сессии | по памяти, не проверено | предположение |
| Хук срабатывает асинхронно при наступлении триггера | по памяти, не проверено | предположение |

## Что НЕ доказано

- Как именно обрабатываются параллельные хуки (если несколько триггеров срабатывают одновременно)
- Порядок выполнения хуков при наличии зависимостей между ними
- Механика fallback'а и error-handling'а для неудачных хуков
