# Решаем — не день 0

## Assertion

Решаем, не день 0: план и запись по ходу уже действуют с прошлого занятия, полный цикл вердикта резервируется для решений, не для каждой строки. Интуиция говорила — честность или ложь; проверка показала — самоотчёт структурно упускает большую часть действий, а незаполненный гейт молча обходят.

## Visual

**Ось занятия:**

> **Процесс — предотвращаем (день 0):** план и запись по ходу дописываются сразу, без отдельного цикла ревью — это уже действует в нашем репозитории с прошлого занятия. Полный цикл вердикта — не день-0-гигиена: он резервируется для решений, а не для каждой строки. **Интуиция говорила:** агент, написавший «готово, тесты прошли», либо честно закончил, либо соврал. **Проверка показала:** дело не в честности — самоотчёт структурно упускает большую часть реальных действий, а гейт, который никто не обязан заполнять, не проваливают — его молча обходят, оставляя пустым.

В углу — та же иллюстрация, что на разделителе ступени: шлагбаум и гроссбух, теперь закрытый.
