## 2. Жёсткая граница: чего переборка не трогает

- **41 кадр с иллюстрацией сохраняет иллюстрацию.** Доля кадров с иллюстрацией

- **Файлы вне своего раздела.** Общие файлы (`DECK-KARTA*.md`, `deck.yaml`,

## 3. Разнарядка — предложение, а не приказ

Кадры, помеченные в `RAZNARYADKA-FORM.md` знаком `?`, назначены **только по
сводке**, без чтения кадра. **Открой такой кадр и реши сам**: форма подходит —
ставь; не подходит — **верни с возражением и причиной**. Разнарядка, принятая
не глядя, — ровно та ошибка, которую мы ловим.

Кадры без `?` прочитаны при составлении разнарядки, но и их решение не
священно: нашёл причину — назови.

**Сторож разнарядки, общий для всех форм:** форма берётся, когда она
**утверждает то, что кадр и так говорит**. Каждая форма в своём докстринге
называет, ЧТО она утверждает (порядок · независимость · сравнение · величину
со знаменателем · распределение · направление · критерий). Поставить форму,
чьё утверждение кадру не принадлежит, — хуже, чем оставить плашки: стрелка
есть утверждение «сначала одно, потом другое», и в прошлом круге она пришла
умолчанием на шесть кадров, где порядка не было.

## 4. Нижняя плашка-вывод `itog` — считать, а не раздавать

Разнарядка §10 говорит «берут все кадры с телом тяжелее нормы — их 56».
**Это число не воспроизводится** нынешним замером: по плашкам и столбцам при
пороге 75 слов выходит 40 кадров, с таблицей и прозой — 89. Прежний счёт
снят с другой редакции деки и устарел.

Поэтому **квоты нет**. Критерий содержательный:

> `itog` ставится туда, где у кадра есть вывод, который лектор сейчас
> проговаривает с экрана, и этот вывод называется **разрядом** формы разбора.

Разряды (ярлык плашки):

| Ярлык | Когда |
|---|---|
| `Цена ошибки` | кадр открывает разбор |
| `Классический режим` | кадр считает, как делали без модели |
| `С моделью` | кадр ставит модель рядом |
| `Что переехало` | кадр называет, куда ушла работа |
| `Адрес платежа` | закрытие раздела |
| `Итог` | всё прочее |

Свой список кандидатов по разделу считай сам:

```
python3 - <<'EOF'
import glob,yaml
def w(o,skip=('key','label')):
    if isinstance(o,str): return len(o.split())
    if isinstance(o,list): return sum(w(x) for x in o)
    if isinstance(o,dict): return sum(w(v) for k,v in o.items() if k not in skip)
    return 0
for f in sorted(glob.glob('library/lectures/lec-08/rework-v5/slides/s*.md')):
    t=open(f).read(); fm=yaml.safe_load(t.split('---')[1])
    if not isinstance(fm,dict): continue
    vis=len(t.split('---',2)[2].split('## Заметки')[0].split())
    n=sum(w(fm.get(k)) for k in ('blocks','columns','matrix'))+vis
    if n>75: print(fm['id'], n, fm.get('section'))
EOF
```

Проза, снятая с кадра плашкой-выводом, **уезжает в заметки, а не пропадает**.
Заметки — связный текст для студента, не конспект: 500–800 слов на кадр
лекции. Снял с кадра три фразы — убедись, что в заметках они читаются как
речь, а не как осколок.

разнарядки) добавят ~4,5–5,5 минуты; источник этих минут — проза, снятая

**Это обязано быть посчитано, а не обещано.** Ведёшь по каждому тронутому

только отдельный сплошной проход на один вопрос.

## 6. Правила кадра, которые переборка обязана держать

Из `tools/presentation-build/trebovaniya-k-soderzhaniyu-forma.md` и CLAUDE.md:

- **Золото `#F0AB00` — заливка, а не текст.** На белом золотой текст даёт
  1,99 : 1 при пороге 3,0. Формы ядра это правило держат сами; не обходи его
  руками.
- **Предел «четыре шага в ряду»** не отменяется. Длинный конвейер — это
  `fazy` (скобки фаз), а не лента из девяти клеток и не кегль мельче.
- **Два столбца — только под противопоставление** «что получается / что не
  получается». Перечень случаев — буллитами друг за другом.
- **Единица у классического режима и у режима модели одна.** Разные
  знаменатели на одну шкалу не кладутся — `polosy` и ось откажут, и правильно.
- **Знаменатель печатается на кадре.** Доля без базы нарушает правило курса.
- **Ни минут, ни методических комментариев** в видимом теле и в заметках.
- **Научная запись в видимом теле запрещена:** «169 тысяч часов», не
  «1,687·10⁵».
- **Заголовок называет предмет, а не достоинство.**
- **Англицизм и рабочее слово переписки** («рычаг», «разряд», «в кучу») на
  кадр не попадают. Проверяй оба слоя — видимое тело и заметки.

## 7. Как доказать, что сделано

Самоотчёт не принимается ни в какой части.

1. **Сборка зелёная.** Двадцать сторожевых тегов блокирующие; ноль
   блокирующих предупреждений.

   ```
   source tools/presentation-build/render-env.sh
   cd library/lectures/lec-08/rework-v5/deck && python3 build_lec08_v5.py
   ```

   (`soffice` и `pdftoppm` стоят в `/home/harness/.local`, не в `PATH` по
   умолчанию — отсюда `render-env.sh`.)

2. **Просмотр глазами каждого тронутого кадра.** Открой PNG через Read.
   Форма, не проверенная просмотром, считается непоставленной: на этой деке
   форма, прошедшая все двадцать своих проб, развалилась на первом настоящем
   кадре, и поймано это было снимком, а не прогоном.

3. **Сверка с картой** по минутам — `deck/sverka_s_kartoy.py`.

4. **Отчёт**: тронутые кадры списком (кадр · была форма · стала · минуты
   было→стало · что увидел на снимке), возражения по кадрам с `?`, и
   отдельным разделом — **находки**: содержательные проблемы, замеченные по
   дороге и НЕ исправленные.

## 8. Чего НЕ делать

- Не коммитить. Правки остаются в рабочем дереве.
- Не трогать чужой раздел, даже если видно, что там то же самое.
- Не ставить форму «чтобы было разнообразнее». Разнообразие — следствие, а не
  цель: цель — чтобы кадр утверждал глазом то, что говорит словами.
