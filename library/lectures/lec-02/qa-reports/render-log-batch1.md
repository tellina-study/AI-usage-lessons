## Toolchain окружения

- Нет системных libreoffice/pdftoppm/rsvg-convert/ImageMagick; sudo недоступен.
- Convert-этап в этой сессии: LibreOffice 26.2 AppImage (libreitalia mirror) →
  `--appimage-extract` (без FUSE) + user-space `apt-get download`+`dpkg -x`
  для 9 недостающих .so + `LD_LIBRARY_PATH`; PDF → PNG через PyMuPDF.
  **Post-factum:** на хосте уже был канонический no-root wrapper
  `source /home/harness/.local/lo-portable-env.sh` (mcp-limitations
  [#172-2]) — батчу 2 использовать его, AppImage-дубликат не нужен
  (мой лежит в ephemeral scratchpad и в репо не попадает).
- SVG → PNG: PyMuPDF (rsvg-convert отсутствует). Найдено ограничение: PyMuPDF
  игнорирует SVG linearGradient → заливка рендерится ЧЁРНОЙ (добавлено в
  mcp-limitations [#183-1]).
- Charts: QuickChart POST `/chart` (v4) — работает; GET с фигурными скобками
  без URL-encoding падает (известное).
