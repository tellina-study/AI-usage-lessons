# Внешний API или локальный инференс?

## Assertion

Четвёртый выбор: где физически считать данные, а не какая модель лучше

## Visual

Крупный заголовок темы выбора на нейтральном фоне + фоновая иллюстрация
(дизайнер подберёт) + одна строка-комментарий без спойлера.

## Speaker notes

Последний, четвёртый вопрос сегодня: считать данные через внешний облачный
API или на своей инфраструктуре. Это про то, где физически обрабатываются
данные, а не про то, какая модель лучше по качеству ответа — обе модели
могут выдавать похожий результат, а разница окажется в том, куда именно
уходит запрос и что происходит с содержимым на другом конце. У внешнего
API — максимальная мощность без вложений в железо; у локального инференса —
контроль над тем, что покидает периметр компании, и независимость от
чужого сервиса. Взвешивать эти стороны приходится не абстрактно, а на
конкретных данных конкретной задачи — одинаковых ответов для разных
компаний здесь не бывает. Как и раньше, начнём с постановки задачи одной
фразой от заказчика.
