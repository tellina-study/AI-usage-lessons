# Два принципиальных способа: по символам и по предложениям

## Assertion

Два способа режут документ без перекрытия: по счёту символов — вслепую, по границам предложений — по смысловой границе. Какой из них ломает ответы чаще — дальше.

## Visual

| Действие | Как делает | Преимущество | Недостатки |
|---|---|---|---|
| Резать строго по счёту символов, без оглядки на текст | Документ рубится на части заданной длины без оглядки на текст внутри | Проще всего реализовать — один параметр, один механический проход по тексту | Разрез может прийтись ровно на середину фразы с ответом, независимо от выбранного размера куска; неочевидно заранее, какой размер «удобнее» без проверки |
| Резать по границам предложений | Разрез проходит только там, где заканчивается одно предложение и начинается следующее | Куски не рвут фразу посередине: разрез идёт по смысловой границе текста — счёт символов тут роли не играет | Чуть сложнее в реализации: нужен отдельный шаг, который понимает, где заканчивается предложение в конкретном языке — простого счёта символов здесь недостаточно; качество этого шага зависит от текста |

## Speaker notes

Четыре действия, и все реальны как инженерный выбор — этот такт объясняет, как устроены два принципиально разных способа резать без перекрытия: оба решают одну и ту же задачу, но исходят из разной логики разреза. Какое из них лучше на числах, увидим дальше.

Резать строго по счёту символов, не глядя на текст, — самое простое и самое дешёвое в реализации: один параметр, задающий длину куска, один механический проход по тексту. Плата за эту простоту — разрез не знает, где в тексте заканчивается мысль, и может пройти ровно посередине фразы с ответом на будущий вопрос, независимо от того, какой размер куска выбран. И заранее, не проверив, не скажешь, какой размер здесь удобнее: на глаз любой вариант выглядит разумно, потому что сам кусок при любом размере читается нормально.

Резать по границам предложений чуть сложнее: нужен отдельный шаг, который сначала понимает, где заканчивается одно предложение и начинается следующее, и только потом проводит разрез. Это зависимость, которую первое действие не несёт вовсе — качество разбивки на предложения зависит от конкретного языка и текста. Но плата возвращается тем, что разрез держится смысловой границы текста — счёт символов тут ни при чём, — и поэтому куски реже рвут фразу посередине. Два действия, два разных компромисса: один платит точностью ради простоты, другой — простотой ради точности.

Разорванная фраза выливается ниже по цепочке в конкретный сбой. Если разрез прошёл посередине фразы с ответом, поиск потом честно находит нужный кусок — и в этом куске лежит половина ответа. Модель получает обрывок и отвечает по обрывку: поиск формально сработал, ответ при этом неполный. Третье и четвёртое действия пробуют справиться с этим иначе, оставаясь в рамках того же принципа резки по счёту символов, — следующий кадр.
