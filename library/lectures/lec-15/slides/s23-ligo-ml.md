# LIGO: ML быстрее, физика финальнее. Конформное предсказание калибрует.

## LIGO ML-конвейер

**LIGO** (Laser Interferometer Gravitational-Wave Observatory) — массив детекторов гравитационных волн, запущен в 2015 году. К 2026 году обнаружено ~150 подтверждённых событий.

**Классический конвейер:** matched filtering (Wiener 1949, 80+ лет физической обоснованности). Сопоставление наблюдаемого сигнала с библиотекой предварительно рассчитанных форм волн. Провабельно оптимальный линейный метод в гауссовом шуме.

**Что добавляет ML.** CNN на сырых временных рядах деформации; **конформное предсказание** для количественного определения неопределённости. Не заменяет matched filtering — **дополняет**.

## Конкретная работа: Ashton, Malz, Colombo 2025

**arxiv:2504.17587.** Независимый анализ методологов. Показал, что ML-методы:
- сопоставимая точность с matched filtering для типичных слияний чёрных дыр (масса 5-50 солнечных)
- **уступают на редких событиях** — нейтронные звёзды, экстремальные отношения масс

## Конформное предсказание

Статистический метод количественного определения неопределённости. Для каждого ML-предсказания — **калиброванный доверительный интервал**: «95% уверенность» = действительно ~95% правильных на длинной серии, **независимо от формы распределения ошибок**.

В отличие от классических доверительных интервалов: не требует предположения о нормальности; даёт гарантии покрытия для конечной выборки.

## Когда ML, когда классика

| Режим | Где доминирует ML | Где доминирует matched filter |
|---|---|---|
| Реальное время (онлайн) | **Низкая задержка** для последующих оптических наблюдений | — |
| Пакетный (офлайн) | — | **Абсолютная уверенность** через месяцы анализа |

## Speaker notes

LIGO — Laser Interferometer Gravitational-Wave Observatory — массив детекторов гравитационных волн, запущенный в 2015 году. К 2026 году обнаружено около 150 подтверждённых событий гравитационных волн — слияния чёрных дыр, нейтронных звёзд.

Конвейер обнаружения включает три компонента. Первый — сопоставление с шаблонами: сравнение наблюдаемого сигнала с библиотекой предварительно рассчитанных форм волн. Классический метод, 60+ лет в обработке сигналов. Второй — фильтрация шума: удаление артефактов инструмента. Третий — оценка статистической значимости: расчёт частоты ложных тревог.

Где AI помогает. В 2024 году и позже методы на основе ML — CNN на сырых временных рядах деформации, конформное предсказание для количественного определения неопределённости — добавляются к классическому сопоставлению с шаблонами. Не заменяют — добавляют. Обнаружение через ML используется для быстрого первичного просмотра — идентификация кандидатных событий в реальном времени для последующих наблюдений оптическими телескопами. Сопоставление с шаблонами используется для финального определения уверенности.

Конкретная статья 2025 года — Эштон, Малц и Коломбо опубликовали детальный анализ применения ML-конвейеров с конформным предсказанием в LIGO, arxiv 2504.17587. Это не коллективная публикация LIGO-VIRGO, а независимый анализ группы методологов. Их анализ показал: ML-методы дают сопоставимую точность с сопоставлением с шаблонами для типичных событий слияния чёрных дыр массой 5-50 солнечных, но уступают на редких событиях — масса нейтронной звезды, экстремальные отношения масс компонентов.

Конформное предсказание — ключевой инструмент. Статистический метод для количественного определения неопределённости в ML-предсказаниях. Для каждого предсказанного события конформное предсказание даёт калиброванный доверительный интервал. Это в отличие от классических доверительных интервалов, которые требуют предположения о нормальности — часто нарушаемого — и дают только асимптотические гарантии. Без количественного определения неопределённости сырой выход CNN — просто число; с конформным предсказанием — это статистически интерпретируемое утверждение.

Обработка в реальном времени против пакетной. Реальное время — нужна низкая задержка идентификации для оптических наблюдений; ML здесь полезен. Пакетная — предварительно построенные конвейеры анализа за месяцы; классические методы доминируют, где абсолютная уверенность важнее скорости.

Это разделение — ещё один пример расширения AI, а не замены.
