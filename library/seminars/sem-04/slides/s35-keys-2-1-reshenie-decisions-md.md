# Первая запись в уже заведённом файле

## Assertion

Новое — не файл (он заведён на дне 0), а первая содержательная запись в нём, датированная днём, когда решение записали.

## Visual

Слева — файл целиком, реальный:

```markdown
# Decisions

Append-only log of why, in date order.

## 2026-09-24 — сторонние виджеты в форму не добавляем
Форма — два поля (имя, email), хватает нативных `required`/`pattern` в `index.html`.
Сторонний виджет — лишняя зависимость и лишние килобайты в сборке ради этого объёма.
```

Справа — состояние репозитория на конец первой недели, строка `DECISIONS.md` выделена gold:

```
README.md
spec.md
DECISIONS.md
CLAUDE.md
AGENTS.md
index.html
package.json
src/main.js
tests/form.spec.ts
tests/delivery.spec.ts
tests/page-objects/form.page.ts
```

## Speaker notes

Два механизма, не один. Авто-память рантайма живёт вне репозитория, в каталоге памяти на машине разработчика: индекс из первых 200 строк или 25 КБ плюс тематические файлы, которые агент создаёт сам. Команда «запомни: сторонние виджеты в форму не добавляем» создаёт тематический файл именно там — в дерево справа он не попадает.

`DECISIONS.md` — второй механизм, git-трекнутый append-only лог, заведённый на дне 0. Новое здесь — не файл, а первая содержательная запись в нём, и дата у неё сегодняшняя: решение принято несколько дней назад, а записано только сейчас. Это реальный файл реального демо-репозитория, не пример, сочинённый для слайда, — и дата в нём стоит настоящая, та, которой коммит реально помечен в git. Календарь занятия («конец первой недели») мы с датами git намеренно не сводим: репозиторий собран за два дня, а занятие идёт по своему счёту времени.
