## По слайдам

### Slide s45a — «Пять шагов поиска»
**Severity:** P1
**Issue:** Hero-иллюстрация (50% площади кадра, см. `media_hero_target: 0.50`) — это
официальный скриншот слайда 10 презентации NASA Goddard (`ntrs-slide10-how-it-works-process-
diagram.jpg`), причём **целиком на английском**: заголовок «How it works», пять подписанных
блоков («User inputs», «Create voxel mesh of design space», «Run Topology Optimization»,
«Output results for user review», «Reconstruct CAD model of selected outputs»), вложенные
буллиты внутри каждого блока и отдельная зелёная строка «CAD ready for fabrication» — ни одно
слово не переведено на кадре. При этом видимое тело слайда (два буллита слева) описывает идею
только ОБЩО («пять шагов, не один скачок», «инженер задаёт цель») и ни разу не называет ни один
из пяти шагов по-русски — расшифровка пяти шагов есть только в заметках лектора (устный канал).
Студент, читающий материал самостоятельно (reader-simulator-режим, self-study, что явно
предусмотрено курсом) без лектора не сможет связать заголовок «Пять шагов поиска» с пятью
реально названными шагами, не читая английский скриншот. Отдельно — часть подписей на самом
скриншоте физически нечитаема даже в hero-масштабе: цитата источника под вторым блоком
(«Image source: https://www.researchgate.net/figure/illustration-of-the-two-meshing-approaches
…») и зелёная строка под пятым блоком набраны настолько мелко в исходном скриншоте NASA, что
укрупнение всего изображения до 50% кадра их не вытягивает — проверено прямым кропом PNG
(`k-49.png`, координаты ~590×630–920×680) с 3-кратным увеличением: текст URL читается с трудом
даже «в упор», с проектора нечитаем гарантированно. Это не декоративная мелочь — это именно та
же проблема, которую предыдущий прогон уже называл P2 для маленьких инсертов (s30/s31/s32/s40/
s42/s44), но здесь она применена к НОВОМУ hero-формату, то есть к кадру, явно задуманному как
крупная, читаемая, доказательная иллюстрация — и это ожидание не оправдывается в части мелких
подписей исходника.
**Recommendation:** Два независимых фикса, любой из них снимает P1:
(а) добавить в видимое тело слайда явную русскую нумерацию пяти шагов (хотя бы короткую,
  1–5 словами на шаг — «1. Входные данные → 2. Сетка → 3. Оптимизация → 4. Проверка →
  5. CAD-модель»), чтобы кадр был самодостаточен без знания английского и без лектора;
(б) для совсем мелких/нечитаемых фрагментов самого скриншота (URL-цитата, зелёная строка) —
  либо обрезать их из кадрируемой области изображения (если `media_hero_wcap`/кроп это
  позволяет без потери остальных пяти блоков), либо явно принять как «источник виден, детали
  источника не обязаны читаться» — но тогда не акцентировать на них внимание кадрированием.
**Visual evidence:** k-49.png (общий план — пять английских блоков без русских подписей);
`/tmp/crop_s45a.png` (кроп 590,630–920,680 ×3 — нечитаемая URL-подпись под вторым блоком).
