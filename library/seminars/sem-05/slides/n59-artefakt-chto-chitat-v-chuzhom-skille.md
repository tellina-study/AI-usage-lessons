# Что читать в чужом скилле и в каком порядке

## Assertion

Вычитка чужого скилла — четыре места в определённом порядке, и одно средство проверяет фронтматтер без запуска сессии.

## Visual

```
чужой-скилл/
├── scripts/*.sh, *.py      ← 1. ЧИТАТЬ ПЕРВЫМ: исполнится обязательно,
│                                с правами вашей сессии
├── вложения (*.md, *.json) ← 2. на что ссылается тело; обновятся без
│                                повторного согласия
├── SKILL.md — фронтматтер  ← 3. описание: не шире, чем надо, иначе
│                                скилл начнёт срабатывать не там
└── SKILL.md — тело         ← 4. ЧИТАТЬ ПОСЛЕДНИМ: это текст, модель
                                 ещё может ему не последовать
```

| Где | Что ищут |
|---|---|
| скрипты | обращения наружу: сеть, переменные окружения, ключи, запись за пределы каталога проекта |
| вложения | то же самое, плюс ссылки на файлы вне каталога скилла |
| фронтматтер | слишком широкое описание — оно решает, когда скилл сработает; и нет ли выключенного явного вызова |
| тело | шаги, которые делают необратимое, — и нет ли среди них запуска чего-то ещё |

> `claude plugin validate <каталог>` находит скиллы, чей фронтматтер не читается, **без запуска сессии** — то есть до установки. Это единственная проверка из перечисленных, которую делает машина; остальные четыре делает человек глазами.

## Speaker notes

Порядок здесь обратный тому, который просится, и в этом вся польза слайда.

Просится начать с тела: там же написано, что скилл делает. Начинать надо со скриптов. Тело — это текст, и модель может ему не последовать. Скрипт выполнится обязательно, и с вашими правами. Плюс измерение из свидетельств: со скриптом внутри уязвимость вдвое вероятнее.

Что искать в скриптах — вторая таблица, первая строка. Обращения наружу: сеть, переменные окружения, ключи, запись за пределы каталога проекта. Не нужно понимать код целиком, нужно найти эти четыре вещи.

Вложения — то же самое плюс ссылки за пределы каталога скилла.

Фронтматтер третьим, и здесь смотрят не на безопасность, а на ширину: слишком общее описание заставит скилл срабатывать там, где вы его не звали. Мы это уже разбирали с другой стороны, когда писали своё.

Тело — последним.

И внизу единственная машинная проверка из всех: команда находит скиллы с нечитаемым фронтматтером, причём без запуска сессии, то есть до установки. Живого снимка её вывода у меня нет — поэтому на слайде только назначение, а не картинка.
