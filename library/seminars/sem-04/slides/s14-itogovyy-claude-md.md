# CLAUDE.md целиком: восемнадцать строк

## Assertion

Итоговый файл инструкций — восемнадцать строк и ровно три содержательных пункта, ни одного выводимого из кода.

## Visual

Слева — файл целиком:

```markdown
# CLAUDE.md

signup-landing: статический лендинг с формой заявки на демо-урок.

## Safety / scope boundaries

- Никогда не запускать деплой на прод без явного запроса — это касается и критерия «готово»
  ниже: сам критерий не повод инициировать деплой.

## Definition of done

- `npm run build` код 0, `npx playwright test` зелёный, форма реально доставляет заявку —
  последнее проверяется на уже задеплоенной (с явного запроса) версии.

## Build, test, verify

- Открыть `dist/index.html` после сборки, вручную отправить форму с заполненными и с пустыми
  полями.
```

Справа сверху — дерево ступени 1 (реальный вывод):

```
AGENTS.md
CLAUDE.md
index.html
package.json
src/main.js
tests/form.spec.ts
```

Справа снизу — плашка: `ln -s CLAUDE.md AGENTS.md` — один источник правды для разных движков.

Внизу узкой полосой — четыре факта: грузится целиком в начало каждой сессии · уровни конкатенируются, а не перекрываются · `@`-импорты не экономят контекст · ориентир — до 200 строк.

## Speaker notes

Три пункта в файле — ровно те три требования, которые в первом разделе попали в группу «нигде не будет видно». Арифметика шесть → три плюс три сходится здесь буквально.

Если кто-то из зала заметит, что команды всё-таки остались в первом абзаце, — это хороший вопрос, и ответ на него точный: там они часть критерия приёмки («готово = собралось кодом 0 и тест зелёный»), а не справочник команд. Справочник дублирует `package.json`, критерий не дублирует ничего.

Дальше — короткий блок механики, потому что без него файл инструкций остаётся магией. Он загружается движком в начало каждой сессии целиком, до первого сообщения пользователя: это не документ «на почитать», а контекст, который тратит токены каждый раз, нужен он сегодня или нет. Загрузка иерархическая — политика организации, пользовательский, проектный, локальный, вложенные, — и все найденные файлы конкатенируются, а не перекрывают друг друга; отсюда неочевидное следствие: при противоречии между уровнями агент может выбрать любую сторону. `@`-импорты организуют файл, но контекст не экономят: импортированный всё равно грузится целиком при старте. Официальный ориентир объёма — до двухсот строк; у нас восемнадцать.

И одна строка про `AGENTS.md`: симлинк на тот же файл, чтобы не держать по копии на каждый движок. С честным острым краем: копирование шаблона обычным `cp -R` без флага `-P` на macOS разыменовывает симлинк во вторую реальную копию — молча, и дублирование, против которого паттерн придуман, возвращается. Копировать через `cp -a`, `git clone` или `git archive`.
