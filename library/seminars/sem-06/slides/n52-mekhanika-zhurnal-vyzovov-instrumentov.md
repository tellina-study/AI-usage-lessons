# Журнал вызовов — где смотреть и когда это нужно

## Assertion

У каждого запуска роли есть журнал реальных вызовов инструментов, независимо от текста финального ответа. Для правок с высокой ценой ошибки сверка журнала надёжнее одного только чтения вердикта.

## Visual

| Когда смотреть | Где смотреть |
|---|---|
| во время работы роли | панель запущенных ролей — видно происходящее в реальном времени |
| после того, как роль закончила | файл журнала конкретного запуска — каждый вызов инструмента по порядку, независимо от текста финального ответа |

> Для правок с высокой ценой ошибки сверка с журналом надёжнее одного только чтения вердикта: совпадает ли список файлов, которые роль назвала проверенными, со списком файлов, которые она действительно открыла.

## Speaker notes

Журнал реальных вызовов инструментов роли — не абстракция. У каждого запуска есть журнал, в который попадает каждый её вызов инструмента по порядку, независимо от того, что написано в финальном тексте ответа. Посмотреть, что родитель вообще получил от роли помимо текста, можно через панель запущенных ролей во время работы либо через файл журнала конкретного запуска.

Для правок с высокой ценой ошибки сверка с журналом надёжнее одного только чтения вердикта: совпадает ли список файлов, которые роль назвала проверенными, со списком файлов, которые она действительно открыла.

Если спросят, нужно ли сверять журнал каждый раз: нет — это проверка для случаев с высокой ценой ошибки, не рутинная практика на каждый вызов; для разовой мелкой правки чтение «что проверено» обычно достаточно.

Если спросят, где искать журнал технически: панель запущенных ролей показывает происходящее во время работы роли; файл записи конкретного запуска — после того, как роль закончила. Подробности зависят от версии харнесса, здесь — принцип, не точный путь к файлу.
