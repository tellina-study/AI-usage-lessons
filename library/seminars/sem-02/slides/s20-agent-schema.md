# Два слова про агента

## Assertion

Модель работает циклом с внешними инструментами, а не одним вызовом

## Visual

Круговая схема из четырёх шагов: «строит план» → «вызывает инструмент
(API, поиск, код)» → «проверяет результат» → «решает, что дальше» → назад
к «строит план». Подпись внизу: «подробно — Лекция 3».

## Speaker notes

И второе — агент. Здесь модель работает не одним вызовом, а циклом:
строит план, вызывает внешний инструмент — это может быть API, поиск,
запуск кода, — проверяет результат этого вызова, решает, что делать
дальше, и так несколько раз подряд, пока задача не будет выполнена или не
потребуется вмешательство человека. Ключевое отличие от RAG — здесь
модель не просто отвечает на вопрос по найденным фрагментам, она реально
что-то делает во внешнем мире и проверяет, получилось ли. Детали того,
как агент планирует внутри, — снова Лекция 3. Сегодня нам важно только
одно: узнавать, когда задача требует именно такого цикла с инструментами,
а не разового ответа модели. Держите эти две схемы в голове — RAG и
агент — они понадобятся буквально через минуту, в следующем кейсе.
