# Что уносим с занятия

## Assertion

Пять узлов, две ветки, один файл.

## Visual

| | |
|---|---|
| **файл** | `sem-07-vyhod.json` |
| **как поставить** | меню сценария → Import from File → выбрать файл |
| **что нужно** | свой n8n и ключ провайдера модели ([инструкция](PODNYAT-N8N.md)) |
| **что делать** | прогнать на своих трёх заявках и посмотреть, где развалится |
| **что завести своё** | учётные данные модели и свою таблицу: в файле они пустые намеренно |

## Speaker notes

Соберём, что получилось за полтора часа.

Процесс из пяти узлов. Форма принимает заявку. Узел извлечения достаёт три поля по описаниям. Успешные идут строкой в таблицу, неудачные — в ту же таблицу с пометкой. На узле модели стоит повтор, три попытки. Версия опубликована, то есть работает та же, что на холсте.

Это не учебная заготовка. Это рабочий минимум: такой процесс можно поставить в небольшом центре и он будет приносить пользу, пока поток не вырастет.

Файл называется так, как на экране. Ставится одним импортом через меню сценария. Что нужно с вашей стороны — свой n8n и ключ провайдера; инструкция по подъёму идёт вместе с файлом, там оба способа, с контейнером и без.

Задание на дом не письменное, и его никто не проверяет. Просьба такая: поставьте, прогоните на трёх своих заявках — не на моих, на тех, что похожи на вашу работу, — и посмотрите, где развалится. Оно развалится, у меня нет на этот счёт иллюзий. Интересно, где именно и первым.

Потому что с этого мы начнём следующее занятие.
