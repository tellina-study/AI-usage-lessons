# Оформление карточки товара

## Структура и компоненты

Карточка товара представляет собой основной элемент интерфейса покупателя и должна содержать следующие компоненты:

### Визуальная часть
- **Изображение товара** — основное фото в верхней части карточки, размер 280×280 пикселей. Поддерживает hover-эффект с увеличением (zoom 1.05x) и переходом на галерею товара. Фон изображения контрастный, без отвлекающих элементов.

### Текстовая информация
- **Название товара** — шрифт заголовка 16px, чёрный цвет (#1a1a1a), максимум 2 строки с обрезкой многоточием. Каждое слово начинается с заглавной буквы.
- **Категория** — вспомогательный текст 12px серого цвета (#666), над названием или сбоку.
- **Рейтинг и отзывы** — звёзды (1–5 звёзд) жёлтого цвета + число отзывов в скобках мелким шрифтом.

### Ценовой блок
- **Цена** — выделенная красным или жирным шрифтом (20px, вес 700). Если есть скидка, то старая цена зачёркивается, а процент скидки показывается красным бейджем в углу карточки.
- **Предыдущая цена** — если применимо, отображается серым с зачёркиванием для сравнения.

### Кнопка действия

**Основное состояние** — кнопка «В корзину» размером 200×40px, фон синий (#0066cc), текст белый, скруглённые углы (border-radius: 6px).

**Состояния кнопки:**
- **Наведение (hover)** — фон темнеет (#0052a3), тень появляется для глубины.
- **Активное нажатие (active)** — фон ещё темнее, текст сдвигается на 1px вниз.
- **Загруженное состояние** — спиннер внутри кнопки, текст скрывается, кнопка неактивна.
- **Успешное добавление** — кнопка становится зелёной (#28a745) с галочкой на 1 секунду, затем возвращается к синему.
- **Недоступно** — кнопка серая (#ccc), курсор disabled, текст «Нет в наличии».

## Дополнительные элементы
- **Сердечко избранного** — в правом углу, пустое по умолчанию, заполняется красным при клике.
- **Бейдж скидки** — красный прямоугольник в левом верхнем углу изображения, текст белый.
- **Тень карточки** — лёгкая тень (box-shadow: 0 2px 8px rgba(0,0,0,0.1)) с усилением при hover.

Карточка адаптивна для мобильных экранов с переносом кнопки под изображение.
