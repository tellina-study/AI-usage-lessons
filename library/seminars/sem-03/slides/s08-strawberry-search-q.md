# Упражнение «клубника»

## Assertion

Пять документов, запрос «клубника» — кто их найдёт?

## Visual

Заголовок-вводная строка сверху: «Запрос "клубника" в корпоративном wiki — тот же пример, что на Лекции 2, теперь на пяти документах». Ниже широкая Ocean rounded box таблица из 5 строк (документы) × 2 колонки-вопроса «Полнотекстовый найдёт?» / «Семантический найдёт?» (заголовки колонок нейтральные, не gold). Каждая строка — номер + название документа, ячейки ответа пустые (нейтральная иконка `help-circle` вместо галочки/крестика):

1. «Инструкция по выращиванию клубники на даче»
2. «Strawberry fields: a guide to growing your own»
3. «Сезонные ягоды средней полосы: сроки созревания»
4. «Клубный вечер для сотрудников: программа мероприятия»
5. «Рецепт варенья из лесной земляники»

Внизу нейтральная подсказка-полоса: «4 раунда на документ — полнотекстовый? семантический? оба? ни один?».

## Speaker notes

На Лекции 2 вы видели пример: запрос «клубника» в корпоративном wiki. Полнотекстовый поиск ищет буквальное совпадение строки; семантический — по смыслу. Сейчас у нас пять документов-кандидатов. Для каждого предскажите: найдёт его полнотекстовый поиск, семантический, оба или ни один?

Зачитываем название документа, для каждого — четыре раунда голосования поднятием руки: полнотекстовый найдёт, семантический найдёт, оба, ни один. Документы специально подобраны так, чтобы протестировать разные грани разницы полнотекстового и семантического поиска — от буквального совпадения до ложного срабатывания на общем корне слова.

Особое внимание — документу 4, «Клубный вечер для сотрудников»: у слова «Клубный» и слова «клубника» общий корень «клуб-». Здесь легко ошибиться интуитивно. Голосуем честно, даже если не уверены — обсуждение будет после четвёртого раунда каждого документа.
