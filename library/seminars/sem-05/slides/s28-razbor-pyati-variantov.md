# Пять вариантов — и один налогоплательщик

## Assertion

Из пяти вариантов только скилл с описанием-триггером отдаёт решение о релевантности модели, не человеку и не хуку; файл инструкций уже платит за процедуру в девяти сессиях из десяти.

## Visual

| Вариант | Где работает | Почему рано — и что вместо |
|---|---|---|
| Оставить как есть | Нигде: это ровно антипаттерн, который ступень называет по имени | Постоянный налог на контекст независимо от релевантности запроса |
| Отдельный файл + импорт | Организационно: файл станет читаемее | Импорт не экономит контекст — импортированный файл всё равно грузится целиком при старте сессии |
| Отдельный файл, напоминать вручную | Пока хватает памяти и деплоев немного | Требует человека в каждом цикле, не использует способность модели самой решить релевантность |
| Хук | Там, где правило нельзя нарушить ни разу | Хук — механика без согласия агента; деплой надо знать, там решения на каждом шаге |
| **Скилл с описанием-триггером** | **Целевой ответ** | Файл инструкций уже платит за процедуру в девяти сессиях из десяти |

## Speaker notes

«Оставлю как есть» — ровно тот антипаттерн, который ступень называет по имени: постоянный налог на контекст независимо от релевантности запроса. «Отдельный файл плюс импорт» — отсылка к прошлому занятию: импорт не экономит контекст, импортированный файл всё равно грузится целиком при старте. Файл стал читаемее, счёт за контекст — тот же. «Буду сам напоминать агенту» — работает, пока деплоев немного, но не даёт модели самой решить, что процедура сейчас релевантна. «Сделаю это хуком» — путаница, которую стоит развернуть: хук — механика, которую исполняет среда без согласия агента, скилл — знание, которое агент может учесть. Деплой нельзя исполнить за агента, его надо знать, там решения на каждом шаге. Целевой ответ — скилл с описанием-триггером: файл инструкций уже платит за эту процедуру в девяти сессиях из десяти.
