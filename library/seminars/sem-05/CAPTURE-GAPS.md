# Артефакты Семинара 5: что есть в демо-репозитории, а чего нет

Проверено 2026-09-27 напрямую: `gh api repos/tellina-study/signup-landing-demo` — ветки, деревья,
содержимое файлов, история коммитов. Не пересказ отчёта субагента.

## 1. Ступень 3 (хук) — материал есть, и он сильнее, чем предполагал каркас

В публичном репозитории есть ветка **`seminar-5-hook`** (коммит `9803643`, «Семинар 5, задел:
механический слой — хук защиты ветки и его самотест»), ответвлённая от конца дуги Семинара 4.
В ней два файла, которых нет ни в одном захвате:

| Файл | Что это | Почему важно для занятия |
|---|---|---|
| `.claude/settings.json` | Рабочий хук защиты ветки. В `$comment` — разобранные оба краевых случая (unborn HEAD; каталог без `git init`) и **задокументированная острая кромка**: хук читает ветку ДО выполнения всей команды, поэтому `git switch feature-x && git commit` отклоняется против старой ветки | Артефакт ступени, который студент может склонировать, а не перерисованный блок кода |
| `.claude/hooks/selftest-branch-guard.sh` | Исполняемый самотест ворот: 9 проверок + **5 явно перечисленных `LIMIT`-случаев**, где ворота молчат по построению | Это и есть контринтуитивный поворот ступени 3 в виде работающего кода, а не утверждения |

**Пять `LIMIT`-случаев самотеста** (дословно из файла — материал для слайда провалов):

| Случай | Почему проходит | Корневая причина |
|---|---|---|
| ветка по умолчанию названа `trunk` | не `deny` (хук сравнивает только `main`/`master`) и не `ask` (репозиторий существует) — первый коммит разрешён молча | сравнение только двух имён |
| `git -C . commit` | регулярное выражение требует `commit` сразу после `git` | форма команды, не намерение |
| `/usr/bin/git commit` | абсолютный путь — не литеральное слово `git` | то же |
| `env git commit` | любой префикс скрывает `commit` от регулярного выражения | то же |
| `git commit` на ВТОРОЙ строке многострочной команды | `read -r cmd` читает только первую строку | чтение stdin |

Плюс зафиксированный самим файлом режим отказа с ссылкой на официальную документацию: **хук,
превысивший тайм-аут, не блокирует вызов** — и отсутствующий `jq` даёт тот же тихий отказ.
Формулировка из файла, которая стоит того, чтобы прозвучать на занятии дословно: «ворота, чей
режим отказа — тишина, не доказаны, пока их не заставили отказать громко».

Ни один из этих пяти случаев не требует злого умысла: `git -C` используется в самом этом
самотесте, многострочные вызовы — рутина.

## 2. Ступени 4–7 — артефактов в опубликованном репозитории НЕТ

Дерево ветки `seminar-5-hook` не содержит ничего из ступеней 4–7: нет
`.claude/skills/deploy/SKILL.md`, нет `.mcp.json`, нет `.claude/agents/diff-reviewer.md`, нет
`Tasks/` с журналом и шаблоном ревью.

Захваты этих файлов (`30-code-deploy-SKILL.md.txt`, `32-code-mcp.json.txt`,
`31-code-diff-reviewer.md.txt`, `17-log-md-form-endpoint-fix.txt`, `34-diff-reviewer-verdict.md`)
сняты с репозитория `/tmp/signup-landing-demo`, который, по собственному признанию
`assets/captures/README.md`, **не закоммичен никуда за пределы `/tmp`** — то есть больше не
существует и не воспроизводим иначе, как пересборкой по процедуре.

Отдельно: деревья `24-tree-stage4.txt` … `27-tree-stage7.txt` сняты с той же исчезнувшей
версии — в них нет `spec.md`, `doc/adr/`, `.tasks/`, `src/validate.js`, `src/style.css`,
`playwright.config.ts`, которые есть в финальном состоянии Семинара 4. **Показывать их как
полное дерево нельзя** (это уже зафиксировано в `ARCHITECTURE.md` §2).

снимка — мок, а не материал.

## 4. Решение владельца, которое нужно на гейте A

Три варианта, честные издержки каждого:

| # | Вариант | Цена | Что получает занятие |
|---|---|---|---|
| **A** | Задание разработчику: достроить демо-репозиторий ступенями 4–7 поверх `seminar-5-hook` (как было сделано для дуги Семинара 4) + досъёмка 6 позиций в живой сессии | несколько дней ожидания, внешний исполнитель | все пять ступеней — с клонируемыми артефактами и реальными снимками; уровень ступени 3 распространяется на всё занятие |
| **B** | Ступень 3 — на опубликованных артефактах; ступени 4–7 — на захватах исчезнувшей версии, с явной подписью происхождения на каждом слайде | ноль ожидания | занятие идёт, но четыре ступени из пяти слабее третьей: код показан без возможности склонировать, шесть снимков отсутствуют |
| **C** | Гибрид: ступень 3 полностью, ступени 4–7 на захватах — и параллельно задание разработчику, артефакты подключаются к деке по мере готовности | ноль ожидания на старте, два круга правки деки | занятие не блокировано, но дека переделывается дважды |

Моя рекомендация — **C**, с одной оговоркой: задание разработчику нужно выдать до гейта B, иначе
второй круг правки деки придётся делать уже после того, как владелец её принял.

Чего я НЕ делаю сама: не выдаю задание разработчику и не пересобираю демо-репозиторий — это
решение владельца о внешнем исполнителе и сроках, а не производственный шаг.
