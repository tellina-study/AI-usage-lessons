# Скилл, который не может сработать сам

## Assertion

Скилл, у которого в перечне вместо описания стоит собственное имя, не может сработать по смыслу запроса — описание единственный канал выбора, и зал называет недостающие части, а не готовую формулировку.

## Visual

> «По имени такой скилл вызвать можно — сработать сам, по смыслу запроса, нельзя.»
> «Описание — единственный канал выбора. Что вы допишете, чтобы он начал срабатывать?»
> «Назовите недостающие части, а не готовую формулировку.»

```
.claude/skills/deploy/SKILL.md   — фронтматтера нет, файл открывает заголовок
# deploy
1. Собрать: npm run build
2. Прогнать smoke-тест формы: npx playwright test
3. Опубликовать: wrangler pages deploy dist --project-name signup-landing

в перечне доступных скиллов он виден так:    deploy — deploy

официальный список антипаттернов описания, дословно:
description: Helps with documents      (помогает с документами)
description: Processes data            (обрабатывает данные)
description: Does stuff with files     (делает что-то с файлами)
```

## Speaker notes

«Перед вами скилл, чьё описание в перечне — его собственное имя. Такой скилл не сломан: вызвать его явно, по имени команды, — он отработает. А сработать сам, по смыслу запроса, не может: описание единственный канал, по которому модель выбирает нужный скилл среди сотни установленных, и сопоставлять ей тут не с чем.

Рядом — три формулировки из официального списка антипаттернов. Узнаёте жанр? Это буквально то, что пишут, когда торопятся.

Что вы допишете, чтобы он начал срабатывать? Не формулировку целиком — назовите части.»
