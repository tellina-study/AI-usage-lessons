# Продвинутые практики RAG

## Assertion

Прошлое занятие дало один рабочий рецепт — один способ резать документ, один способ искать, один вес смешивания. Сегодня у этого рецепта появляется пять мест, где он ломается.

## Visual

> Пять приёмов, которые чинят по одному конкретному дефекту рецепта прошлого занятия — и у каждого приёма есть цена.

## Speaker notes

Прошлое занятие оставило процесс учебного центра Ольги с рабочим рецептом: одна векторная база, одна схема резки документа — по предложениям, один гибридный поиск словами и смыслом с равным весом. Рецепт был измерен и работал — на той базе, на которой его измеряли.

Сегодняшнее занятие берёт этот рецепт и подвергает его пяти разным испытаниям: нечёткому вопросу, длинному документу со сложной структурой, вопросу, для которого равный вес смешивания не подходит, базе, которая выросла не в объёме, а в разнообразии тем, и, наконец, случаю, когда поиск нашёл что-то тематически похожее, но не отвечающее по сути. В каждом из пяти случаев есть естественное усложнение рецепта, которое выглядит чистым улучшением. И в каждом из пяти случаев это усложнение имеет цену — иногда небольшую, иногда больше самого дефекта, который оно должно было починить.

Все пять кейсов сегодняшнего занятия измерены на живом стенде, не предсказаны по интуиции. Это полноценные технические разборы подряд, без облегчённой вставки между ними.
