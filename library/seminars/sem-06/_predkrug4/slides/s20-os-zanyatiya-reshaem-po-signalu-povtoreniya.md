# Решаем — по сигналу повторения

## Assertion

Кастомная роль — решаем, по сигналу повторения: делегировать можно бесплатно без единой строки конфигурации; заводить стоило не сам факт делегирования, а конкретную роль с урезанным набором инструментов.

## Visual

**Ось занятия:**

> Кастомная роль — решаем, по сигналу повторения (одноразовая проверка целиком закрывается бесплатным встроенным делегированием). Интуиция говорила: чтобы поручить проверку отдельному агенту, нужно завести файл и настроить его — иначе делегирования не получится. Проверка показала: делегировать можно и без единой строки конфигурации, это уже бесплатно; заводить стоило не сам факт делегирования, а конкретную роль с урезанным набором инструментов — и её оправдывает повторение роли, не разовая необходимость проверить что-то одно.

Мостик: у роли с урезанными правами есть один изъян — её собственный отчёт о готовности остаётся утверждением, а не фактом.

## Speaker notes

Ось произносится дословно: решаем — по сигналу повторения, а не по самому факту делегирования, который уже бесплатен.

Мостик к следующей ступени: роль с урезанными правами нашла бы в правке то, что автор не заметил. Но любой отчёт о готовности, включая отчёт собственного ревьюера, остаётся утверждением, а не фактом — что с этим делать, дальше.
