# Три несуществующих SHA — и что после них добавили

## Assertion

Активный файл задачи демо-репозитория прошёл через реальный независимый ROAST — находка: три SHA, которых для читателя не существует; ответом стала не более слабая проверка существования объекта, а проверка достижимости предка.

## Visual

| Что проверяем | Механически? |
|---|---|
| Файл задачи существует | Да |
| Обе строки «Сверено» на месте, дата не устарела | Да |
| Названные SHA — реальные объекты | Да, но недостаточно — проходит и на объектах, осиротевших после перебазирования |
| SHA достижимы с указанной ветки | Да — `git merge-base --is-ancestor` |
| «Что проверено» — дословный вывод, не пересказ | Частично — эвристика по форме текста |
| Вердикт отражает настоящее независимое суждение | Нет — не проверяется механически вообще |

> Активный файл задачи демо-репозитория прошёл через реальный независимый ROAST — находка была не гипотетической: три SHA, которых для читателя не существует, коммиты, оставшиеся от более ранней версии, переписанной перебазированием. Ответ — не «поверить на слово», а команда, которая проверяет не существование, а достижимость предка с нужной ветки.

## Speaker notes

И последний вопрос механики — не «что можно заставить», а «что реально проверяется, когда вы открываете файл задачи через месяц».

Существование файла — проверяется командой. Обе строки сверки на месте, и дата не устарела — проверяется. Названные коммиты — реальные объекты — проверяется, но недостаточно: эта проверка проходит и на коммитах, которых для остальной истории репозитория уже не существует. Достижимы ли они с нужной ветки — отдельная, более строгая проверка, и именно она ловит разницу. Дословность вывода команды — проверяется частично, эвристикой по форме текста. Отражает ли вердикт настоящее независимое суждение — не проверяется механически вообще.

Это не абстрактная таблица. Активный файл задачи нашего демо-репозитория прошёл через реальный независимый ROAST, и находка была не гипотетической: в файле нашлись три коммита, которых для читателя не существует — остались от более ранней версии истории, переписанной перебазированием. Ответ был не «поверить на слово», а команда, которая проверяет не существование коммита, а его достижимость с нужной ветки. Более слабая проверка — просто «существует ли объект» — прошла бы и на недостижимом коммите.
