# Quickfire А — ответ

## Assertion

Фиксированная формула — обычный код, ИИ не нужен вовсе.

## Visual

Та же широкая Ocean rounded box карточка. Левая chip-плашка «ИИ не нужен вовсе / обычный код» теперь GOLD fill (ответ), правая приглушена SOFT_GREY. Под chips — короткая строка разбора (DEEP): «Фиксированная детерминированная формула — нижняя ступень лестницы. ИИ добавил бы только недетерминизм и стоимость без всякого выигрыша».

## Speaker notes

Разбор: фиксированная детерминированная формула — это нижняя ступень лестницы, обычный код, ИИ здесь не нужен вообще. Это прямое повторение нижней плашки матрицы из главы Лекции 3: детерминированная, верифицируемая задача — ИИ добавил бы только недетерминизм и стоимость без всякого выигрыша.
