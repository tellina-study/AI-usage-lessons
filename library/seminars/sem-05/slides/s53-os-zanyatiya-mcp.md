# Решаем по сигналу, предотвращаем с нуля

## Assertion

Подключение сервера — решаем, по сигналу; дисциплина минимальных прав — предотвращаем, день 0, не ждёт сигнала сверх факта создания токена.

## Visual

**Ось занятия:**

> Подключение сервера — решаем, по сигналу (повторяющаяся боль конкретного проекта). Дисциплина минимальных прав — предотвращаем, день 0. Интуиция говорила: одобрил один раз, права выдал — вопрос решён; зелёный статус означает «работает». Проверка показала: права вычёркиваются, а не выдаются, и это не отменяется даже официальностью сервера; одобрение инструмента не окончательно; а зелёный статус — утверждение о транспорте, не о работе.

## Speaker notes

Строка в ось: подключение — решаем, по сигналу; дисциплина минимальных прав — предотвращаем, день 0. Интуиция говорила: одобрил один раз — вопрос решён. Проверка показала: права вычёркиваются, а не выдаются, и одобрение не окончательно.

Пять блоков в конфигурации, последний дал агенту руки — он дотягивается до внешней системы. Чем больше он может сам, тем острее вопрос: роль повторяется из сессии в сессию, или каждый раз объясняется заново?
