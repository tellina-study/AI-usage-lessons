# Своя боль у каждого — правило порядка вместо ответа

## Assertion

У вопроса нет единственно верного ответа: есть правило порядка, а не рейтинг предпочтений — заводится то усиление, для которого сигнал уже прозвучал.

> «Вернёмся к этому вопросу в конце занятия — по трём разобранным сегодня. Полный ответ по всем пяти — в конце следующего.»

| Усиление | Боль, которая его вызывает | Когда прозвучал сигнал |
|---|---|---|
| Хук | Правило файла инструкций прочитано — и нарушено: коммит в `main` состоялся вопреки записанной строке | Уже прозвучал — на прошлом занятии |
| Скилл | Процедура в файле инструкций разрослась и грузится в каждую сессию, хотя нужна не в каждой | Прозвучит сегодня, на своей ступени |
| MCP (Model Context Protocol) | Агенту нужно то, чего в репозитории физически нет, — данные или система за его пределами | Подключение — сегодня; минимальные права — без сигнала, день 0 |
| Субагент | Одна и та же роль повторяется из сессии в сессию | На следующем занятии, на своей ступени |

## Speaker notes

За каждой из пяти карточек — своя боль, и они разной природы.

Хук — потому что правило файла инструкций уже прочитано и уже нарушено: коммит в `main` состоялся, несмотря на записанную строку. Скилл — потому что процедура в файле инструкций разрослась и грузится в каждую сессию, хотя нужна не в каждой. MCP — потому что агенту нужно то, чего в репозитории физически нет: данные или система за его пределами. Субагент — потому что одна и та же роль повторяется из сессии в сессию. Процесс — потому что «готово» от агента это самоотчёт, который можно обойти, а не только не выполнить.

Единственно верного ответа нет — у вопроса нет одного измерения. Есть правило порядка, а не рейтинг предпочтений: заводится то усиление, для которого сигнал уже прозвучал. К хуку сигнал пришёл на прошлом занятии, правило нарушили буквально в последней сцене — это не гипотеза. Для скилла сигнал придёт сегодня, на своей ступени. Для субагента — на следующем занятии, тоже на своей. А для процесса и для половины MCP, для дисциплины минимальных прав, сигнал не требуется вообще: они заводятся на день ноль, независимо от конкретики проекта.

Вернёмся к этому вопросу в конце занятия — и проверим, изменился ли ответ по трём разобранным сегодня. Полный ответ по всем пяти — в конце следующего.
