## Решения планировщика, которые стоит знать производству

1. Третий метод кейса B — поля по схеме (а не второй zero-shot): продолжает линию С7/К1
   и даёт D вторую форму описания.
2. Нулевой выстрел — EN-подсказки, RU одной парой подсказок для цены языка (деградация
   RU-башни уже измерена сессией D — наследуем, не перемеряем).
3. Числа проб этого журнала на кадры не идут — только числа замеров производственных
   сессий на полном корпусе.
