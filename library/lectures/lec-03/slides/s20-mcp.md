# Visible content

## Title bar
«MCP: стандарт подключения — не гарантия доверия»

## Body
[Слева — что решает MCP]
**MCP (Model Context Protocol)** — «USB-C для инструментов LLM»
N моделей × M инструментов = N×M интеграций → MCP: **N+M**
Открыт Anthropic 11/2024, принят OpenAI и Google в 2025

[Справа — масштаб критически]
Каталоги — «до **90 000** серверов», но реально запускаемых — лишь **≈10 000 ≈ 11%**
Остальное — дубли, битые, заглушки; и даже рабочие **не проверены на безопасность**

[Плашка — поворот доверия]
30+ CVE за 60 дней (**≈43%** — command injection); path traversal у **82%** из 2 614 просканированных реализаций

[Gold callout, низ]
**Стандартизация подключения не означает безопасность подключаемого — и усугубляет проблему доверия.** Удобство подключения — не аргумент за подключение.

## Speaker notes

Function calling решает, как модель формулирует вызов. MCP решает, как инструмент физически подключается. До 2024 года каждый вендор решал по-своему, порождая комбинаторный взрыв. MCP — открытый стандарт: N моделей × M инструментов = N×M интеграций → N+M. Метафора: USB-C для инструментов. Anthropic открыла его в ноябре 2024, OpenAI и Google приняли в 2025 — де-факто отраслевой стандарт.

Масштаб читай критически. Каталоги называют до 90 000 серверов, но реально запускаемых около 10 000 — 11%. Остальное дубли, сломанные, заглушки. Даже работающие не проверены на безопасность.

Критический поворот: стандартизация подключения не означает безопасность подключаемого — усугубляет проблему. Каждый инструмент — код, запускаемый в твоём окружении, канал для недоверенного текста. За 60 дней: 30+ CVE на MCP-серверы, 43% — внедрение команд (command injection), 82% реализаций уязвимы к обходу пути (path traversal). «Подключить за минуту» и «доверять подключённому» — разные вопросы. MCP решил первый, сделал второй острее. Удобство не аргумент за подключение.
