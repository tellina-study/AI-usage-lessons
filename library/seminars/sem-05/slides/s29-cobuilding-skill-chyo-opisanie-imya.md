# Скилл, чьё описание — это его имя

## Assertion

Скилл `deploy: deploy` не может сработать по смыслу запроса — описание совпадает с именем каталога, и зал называет три недостающие части, а не готовую формулировку.

## Visual

Карточка скилла в списке доступных:

```
deploy: deploy
```

Рядом — три формулировки из официального списка антипаттернов:

`Helps with documents` · `Processes data` · `Does stuff with files`

> «Перед вами скилл, чьё описание — это его собственное имя. Что именно вы допишете, чтобы он начал срабатывать? Назовите недостающие части, не формулировку целиком.»

Три части проявляются по мере называния: **что делает** · **когда использовать** · **когда НЕ использовать**.

## Speaker notes

Перед вами скилл, чьё описание — его собственное имя: `deploy: deploy`. Автор вообще не написал фронтматтер, система подставила имя файла вместо описания. Вызвать скилл по имени явно — сработает. Сработать самому, по смыслу запроса, — не может: описание — единственный канал, по которому модель выбирает нужный скилл среди потенциально сотни установленных, сопоставлять ей тут не с чем. Рядом — три формулировки из официального списка антипаттернов. Узнаёте жанр? Это то, что пишут, когда торопятся. Ваша задача: не формулировку целиком — назовите недостающие части.
