# Тело, которое продиктовал зал

## Assertion

Пять шагов, у каждого названо действие целиком: три литеральные команды и два шага, которые исполняются руками.

## Visual

```
1. Собрать: npm run build — код выхода должен быть 0.
2. Проверить форму: npx playwright test — должно быть зелёным.
3. Опубликовать: wrangler pages deploy dist --project-name signup-landing.
4. Открыть адрес на проде, вручную отправить форму с верными данными —
   заявка должна дойти.
5. Записать в .tasks/active/ГГГГ-ММ-ДД-описание.md: что выложено,
   когда и какой командой.
```

> Официальное правило с другой стороны: не предлагать несколько способов без необходимости. Не «можно этим, а можно тем», а ровно один — тот, что в этом репозитории действительно работает. **Шагов пять, литеральных команд три: четвёртый и пятый исполняются руками, и выдуманной команды у них нет.**

## Speaker notes

Сверяем с тем, что назвал зал.

**Каждый шаг называет действие целиком, а не намерение.** Сборка — команда и ожидаемый код выхода. Проверка формы — команда и критерий «зелёное».

**Публикация — ловушка, и её стоит поймать голосом:** почти всегда забывают имя проекта, а без него команда публикует не туда.

**Честная арифметика, её надо сказать.** Шагов пять, литеральных команд три. Четвёртый и пятый исполняются руками, и придумывать им команду незачем — на слайде её нет.

**Правило с другой стороны** — про соблазн быть полным: не предлагать несколько способов без необходимости. Один способ, тот, что в этом репозитории работает.
