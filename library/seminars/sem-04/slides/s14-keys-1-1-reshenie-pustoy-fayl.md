# Файл остаётся пустым

## Assertion

Описания структуры репозитория в `CLAUDE.md` не появляется: сигнала для него нет — а первое содержимое у файла появится уже в следующем кейсе, и по другой причине.

## Visual

Состояние репозитория:

```
README.md
spec.md
DECISIONS.md
index.html
package.json
src/main.js
tests/form.spec.ts
CLAUDE.md        ← заведён, по-прежнему пуст
```

Крупная строка-итог:

> «Описания структуры репозитория в файле нет: сигнала для него нет.»

Строка-мостик к кейсу 1.2:

> «Пусто — не навсегда. Часть содержимого `CLAUDE.md` появится в нём уже на этой неделе, и по другой причине: не по сигналу, а как базовая практика.»

## Speaker notes

«Итог первой развилки: описания структуры в файле нет — сигнала для него нет, а стоимость присутствия есть.

Но пустой файл — не позиция на весь проект. Часть содержимого `CLAUDE.md` появится в нём уже на этой неделе, и по другой причине: не потому, что что-то сломалось, а потому, что это базовая практика, которая стоит дёшево. Это следующая развилка.»
