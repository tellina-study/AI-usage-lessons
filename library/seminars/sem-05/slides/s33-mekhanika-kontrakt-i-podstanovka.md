# Не имя вместо описания, а не та строка

## Assertion

Спецификация делает имя и описание обязательными, а документация Claude Code — рекомендательными; и когда фронтматтера нет вовсе, подставляется не имя вместо описания, а первая непустая строка файла.

## Visual

| Поле | Спецификация Agent Skills | Claude Code |
|---|---|---|
| name | обязательно; до 64 символов, строчные, цифры, дефисы | необязательно; дефолт — имя каталога |
| description | обязательно, непустое; до 1024 символов | необязательно; дефолт — первая непустая строка |
| прочие поля | — | все необязательны; неопознанное молча игнорируется |

## Speaker notes

«Второй вопрос механики — что вообще обязано быть в файле. Спецификация требует: имя и описание обязательны, у описания жёсткий лимит, и оно обязано называть и что скилл делает, и когда его использовать. Документация вашего инструмента говорит противоположное по тону: все поля необязательны, рекомендовано только описание. Это не смягчённый пересказ одного правила — это два контракта для двух путей распространения одного файла. Что сходит с рук локально, не пройдёт валидацию при выгрузке в общий каталог.

И вот что происходит, если фронтматтера нет вовсе. Условие, при котором он вообще читается, простое: открывающая строка из трёх дефисов обязана быть первой строкой файла. Иначе парсер фронтматтера просто не запускается, а весь файл считается содержимым.

В этом состоянии подставляются дефолты, а не пустота. Имя берётся от имени каталога. Описание — от первой непустой строки содержимого.

В этом репозитории курса двенадцать скиллов из тринадцати начинаются прямо с заголовка — фронтматтера у них физически нет. Проверяется одной командой, она на схеме. И у всех двенадцати первая непустая строка — это заголовок с именем скилла, а не то нормальное предложение, которое стоит строкой ниже и реально годилось бы как триггер.

Снаружи результат выглядит как "описание равно имени" — формулировка понятная, но неточная. Система не подставляет имя вместо описания. Она берёт не ту строку, и совпадает эта строка с именем только потому, что все двенадцать файлов по одной конвенции открываются заголовком. Начни автор файл прямо с предложения — дефолт сработал бы содержательно.

Тринадцатый скилл устроен иначе: у него есть настоящий фронтматтер с явным именем и описанием. Он же отвечает на вопрос, почему остальные двенадцать хоть как-то работают: только явным вызовом по имени команды, не автоматическим срабатыванием по смыслу. Это два разных канала, и один описания не требует вовсе.

И отдельной строкой, честно: обрезается ли ведущая решётка заголовка при подстановке в перечень — подтверждения не нашлось.»
