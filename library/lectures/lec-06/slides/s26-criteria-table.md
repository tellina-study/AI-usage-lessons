# Чем выше цена ошибки — тем меньше места вероятностному ИИ

## Assertion

Чем выше детерминированность задачи и цена ошибки, тем меньше в ней места вероятностному ИИ — для каждого критерия есть более правильный инструмент.

Строки (иконка per строка, ячейки single-line, ≥14pt): «Сертификационный расчёт» — нужны воспроизводимость и трассируемость / аттестованный детерминированный решатель + независимая верификация. «Коэффициент запаса» — задаётся нормой, не оптимизируется моделью / нормативное значение + инженерное обоснование. «Нормоконтроль ГОСТ/ASTM/ISO» — LLM галлюцинирует номера и допуски / нормативная база + нормоконтролёр. «Юр. ответственность» — ИИ не субъект ответственности / квалифицированный инженер с подписью. «Есть точный решатель» — аппроксимация хуже точного / прямой численный расчёт. «Безопасность жизни» — цена ошибки = жизни / нормированный расчёт + независимая проверка + НК с POD. «Единицы на стыке систем» — ИИ уверенно путает единицы / машинная проверка размерностей + единая СИ. «Изменение силовой схемы» — «по чату» без пересчёта = Hyatt / формальный change-request с независимым пересчётом. ## Speaker notes

Решающее правило одно: чем выше детерминированность задачи и цена ошибки, тем меньше в ней места вероятностному ИИ. Развернём его в таблицу. Для сертификационного расчёта нужны воспроизводимость и трассируемость, а LLM и суррогат дают разброс и не сертифицируемы — правильный инструмент это аттестованный детерминированный решатель с проверкой сходимости плюс независимая верификация. Коэффициент запаса задаётся нормой и ответственным инженером, а не «оптимизируется» моделью — правильно взять нормативное значение по стандарту с инженерным обоснованием. Нормоконтроль по ГОСТ, ASTM, ISO: LLM галлюцинирует номера стандартов, марки, допуски — нужна нормативная база и нормоконтролёр со сверкой по первоисточнику.

Юридическая ответственность: ИИ не субъект ответственности, подпись и accountability на инженере — ИИ максимум черновик под проверку. Если доступен точный детерминированный решатель, аппроксимация хуже и не нужна — прямой расчёт, суррогат только предварительный фильтр. Безопасность жизни — несущие конструкции, авиация, сосуды давления: цена ошибки это жизни, вероятностная модель не даёт гарантий — нормированный расчёт плюс независимая проверка плюс натурные испытания. Единицы измерения на стыке систем: ИИ уверенно путает единицы, как в Mars и Gimli — нужна машинная проверка размерностей и единая система единиц. Изменение силовой схемы «по чату» без пересчёта — это Hyatt; нужен формальный change-request с независимым пересчётом.

Резюме таблицы — операциональная форма миссии курса: ИИ в инженерии есть инструмент расширения вариативности и черновика, а не арбитра истины и носителя ответственности. Заметьте: это не запрет на ИИ, а указание его места. Детерминированная топологическая оптимизация в этой таблице нигде не запрещена — запреты касаются вероятностных классов там, где требуется гарантия.
