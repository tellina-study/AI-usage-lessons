# Памятка на вынос

## Assertion

Три механизма внутри модели — что помнить.

## Visual

3 равные Ocean rounded box колонки. Колонка 1 «Эмбеддинги = близость по смыслу, не по буквам» (иконка `layers`, MID): «Одинаковые слова могут означать разное — низкая близость несмотря на лексическое совпадение» / «Разные слова могут означать одно и то же — высокая близость несмотря на отсутствие общих слов» / «Полнотекстовый поиск иногда точнее семантического: точные ID, юридические цитаты, коды ошибок».

Колонка 2 «Внимание = статистическая корреляция, не понимание причинности» (иконка `scan`, TEAL): «Модель предсказывает референт через статистику совместной встречаемости токенов, а не синтаксический анализ или физическую модель мира» / «Иногда однозначного ответа не существует — честный результат модели тогда распределение вероятностей, а не единственный "правильный" ответ».

Колонка 3 «Сэмплинг = температура управляет балансом предсказуемость ↔ разнообразие» (иконка `shuffle`, DEEP): «T=0 — для задач, где важна воспроизводимость, но даже T=0 не даёт стопроцентной гарантии» / «T>0.7 — для задач, где ценно разнообразие» / «Правильная T — результат эмпирической калибровки, не универсальная константа».

Внизу текст курсивом: «Всё, что здесь написано, вы уже видели сегодня — рабочая версия на вынос».

## Speaker notes

Заранее подготовленный печатный раздаточный лист — компиляция того, что уже прозвучало на занятии, без нового материала.

Первое: эмбеддинги — близость по смыслу, не по буквам. Одинаковые слова могут означать разное, разные слова могут означать одно и то же, и полнотекстовый поиск иногда точнее семантического — там, где нужна точность, а не похожесть.

Второе: внимание — статистическая корреляция, не грамматический разбор и не понимание причинности. Модель предсказывает референт местоимения через статистику совместной встречаемости токенов. Иногда однозначного ответа не существует — тогда честный результат модели — распределение вероятностей.

Третье: сэмплинг — температура и top-p/top-k (альтернативные параметры отсечения хвоста распределения вероятностей) управляют балансом предсказуемости и разнообразия. T=0 для воспроизводимости, T выше 0.7 для разнообразия, и правильная температура — результат эмпирической калибровки, не универсальная константа.

Раздаём лист в конце раздела, коротко проговорив: всё, что здесь написано, вы уже видели сегодня — это компиляция того, что прозвучало на занятии, чтобы унести с собой рабочую версию.
