# Два механизма: авто-память и DECISIONS.md

## Assertion

Два параллельных механизма, не один: авто-память живёт вне репозитория, `DECISIONS.md` — git-трекнутый лог «почему» внутри него.

## Visual

Слева — файл целиком, реальный:

```markdown
# Decisions

Append-only log of why, in date order.

## 2026-09-20 — не подключаем библиотеку валидации форм
Форма — два поля (имя, email), хватает нативных `required`/`pattern` в `index.html`.
Сторонняя библиотека — лишняя зависимость и лишние килобайты в сборке ради этого объёма.
```

Справа сверху — дерево кейса 2.1, строка `DECISIONS.md` выделена gold:

```
AGENTS.md
CLAUDE.md
DECISIONS.md
index.html
package.json
src/main.js
tests/form.spec.ts
```

Справа снизу — узкая плашка: diff создания файла.

## Speaker notes

Два механизма, не один. Авто-память рантайма живёт вне репозитория, в каталоге памяти на машине разработчика: индекс из первых 200 строк или 25 КБ плюс тематические файлы, которые агент создаёт сам. Команда «запомни: не подключаем стороннюю библиотеку валидации» создаёт тематический файл именно там — в дерево справа он не попадает.

`DECISIONS.md` — второй механизм, git-трекнутый append-only лог в самом репозитории. Это реальный файл реального демо-репозитория, не пример, сочинённый для слайда, — и это стоит произнести вслух. Дерево справа показывает, что в репозитории добавился ровно один новый файл.
