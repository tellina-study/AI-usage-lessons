# diff-reviewer.md целиком

## Assertion

Строка ограничения инструментов короче всего остального в файле и делает больше всего.

## Visual

Слева — файл целиком:

```markdown
---
name: diff-reviewer
description: Независимый ревьюер diff'ов. Видит только сам diff и критерии приёмки, не рассуждения
  автора. Используй перед мержем любого нетривиального изменения. НЕ для методической критики
  текста — это отдельная роль.
tools: Read, Grep, Glob
---

# diff-reviewer

Ты не правишь код сам — только находишь проблемы. Начни ответ строкой:
`VERDICT: PASS | BLOCK`

Затем: что проверено (конкретно — какие файлы прочитаны), находки (что не так, где, почему важно).
Пустой список находок — валидный PASS.
```

Строка `tools: Read, Grep, Glob` подсвечена gold, подпись: «короче всего остального и делает больше всего».

Справа сверху — дерево ступени 6, `.claude/agents/diff-reviewer.md` выделен.

Справа снизу — плашка: вызовы инструментов, сделанные субагентом, по сообщённому поведению **не запускают хуки родительской сессии** — без индикатора, что проверки были пропущены.

## Speaker notes

Файл собран ровно из трёх ходов: описание из трёх частей, отнятые права, формат ответа.

Обратить внимание зала на строку `tools:` отдельно — она короче всего остального и делает больше всего.

Дальше — короткий блок механики. Субагент — это отдельный процесс с собственным контекстным окном, собственным системным промптом, собственным набором инструментов и собственными правами. Родительская сессия не видит промежуточные шаги — только итоговый результат. Это единственный механический эффект субагента: контекст задачи не смешивается с контекстом сессии, которая её поручила.

Файл роли коммитится в репозиторий — значит, вся команда пользуется одной и той же ролью, а не переизобретает её при каждом вызове. Это и есть вторая половина триггера.

Практический тест «нужен ли тут субагент вообще»: если промежуточные шаги задачи не нужны после её завершения — кандидат на субагента. Если нужны, потому что следующий шаг опирается на неявную логику предыдущего, — субагент не подходит, это обычный шаг в той же сессии.

И ограничение, о котором надо помнить после ступени хука: вызовы инструментов, сделанные субагентом, по сообщённому поведению не запускают хуки родительской сессии — без индикатора, что проверки были пропущены. Отнятые права у самого субагента здесь становятся не дополнительной аккуратностью, а единственным оставшимся ограничением.
