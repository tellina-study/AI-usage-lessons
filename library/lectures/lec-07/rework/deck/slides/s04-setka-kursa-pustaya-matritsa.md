## Видимый текст слайда

**Про каждый инструмент спрашиваем две вещи: какую задачу он решает и с какими данными работает.**

- **Классификация** — поставить метку из списка
- **Распознавание** — найти и опознать во входе
- **Поиск с генерацией** — найти и отранжировать, затем создать содержимое по найденному
- **Прогноз** — предсказать число

**Эти клетки заполняются в конце каждого раздела.** Образец:

| | текст | изображение | структурированные данные |
|---|---|---|---|
| классификация | null | null | null |
| распознавание | null | null | null |
| поиск с генерацией | null | null | null |
| прогноз | null | null | null |

Клетки медицины — те же, что были заняты в инженерии. Отличается цена ошибки и устройство процедур, которые её удерживают.

## Заметки лектора

Два имени — весь рабочий инструмент, которым курс называет каждый встреченный инструмент. Первое отвечает на вопрос, что система выдаёт на выходе: классификация, распознавание, поиск, генерация, прогноз, планирование. Второе — с какими данными она работает: текст, изображение, звук, видео, структурированные данные, код, комбинации нескольких видов сразу. Пара бывает составной, и это не оговорка: чат, который ищет в документах и пишет по ним ответ, решает две задачи подряд.

Зачем это нужно. Два имени задают поставщику два вопроса, на которые тот обязан ответить коротко. Если ответа нет или он звучит как «у нас комплексное решение на основе искусственного интеллекта», разговор о пригодности инструмента ещё не начался. По паре имён сразу видно, где искать опыт: распознавание на изображении — обкатанная область с готовыми мерами качества, а планирование на структурированных данных в медицинской практике встречается редко, и каждый случай придётся разбирать с нуля. И пара показывает подмену, которая стоит дорого: успех показывают в одной клетке, а продают инструмент для другой.

В конце каждого раздела по строкам встанут типы задач, которые на этой стадии встретились, по столбцам — виды данных, в клетках — короткие имена разобранных случаев. Карта делает видимым то, чего не видно на отдельных разборах. Пустая клетка в ней такое же содержание, как занятая: она говорит, что на этой стадии инструмент такого класса искать незачем, и экономит время, которое ушло бы на поиск.

Общую картину стоит держать в голове с первой минуты. Медицина занимает здесь четыре клетки, и все четыре — те же, которыми заканчивалась инженерная лекция: распознавание и классификация на изображении, прогноз на структурированных данных, поиск с генерацией на тексте. Совпадение клеток и есть результат: отрасли различает не класс модели, а цена ошибки и процедура вокруг человека. Чисел в этой раскладке нет ни одного — ни долей рынка, ни числа допущенных изделий, ни «лидеров».
