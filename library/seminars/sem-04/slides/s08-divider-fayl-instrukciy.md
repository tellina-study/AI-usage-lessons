# Раздел 1 · файл инструкций

## Assertion

Раздел 1 — файл инструкций: три отдельные развилки про один и тот же файл, в порядке, в котором реально растёт репозиторий.

## Visual

Крупный заголовок «Раздел 1 · файл инструкций» на Ocean-фоне. Под ним — три строки, без минут и без деталей содержимого:

- Кейс 1.1 · роль агента и репозиторий
- Кейс 1.2 · базовые процессы: гейты и цикл улучшения
- Кейс 1.3 · вложенные файлы по подпапкам

Внизу — узкий tag: «Один файл, три развилки».

Вверху — полоса разделов занятия; раздел 1 подсвечен gold.

## Speaker notes

Переход одной фразой, без пересказа содержания кейсов заранее: «Раньше этот раздел держался на одном примере. Сегодня — три отдельные развилки про один и тот же файл, `CLAUDE.md` он же `AGENTS.md`, в том порядке, в каком реально накапливается конфигурация демо-репозитория: сначала решаем, чего в файл не писать заранее; потом пишем первое реальное содержимое на реальной боли; потом решаем, стоит ли это содержимое дробить по подпапкам. Каждый кейс устроен одинаково: проблема, исследование, открытый вопрос, разбор.»
