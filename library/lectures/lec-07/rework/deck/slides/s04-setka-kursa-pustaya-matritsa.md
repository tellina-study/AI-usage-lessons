## Видимый текст слайда

**Про каждый инструмент спрашиваем две вещи: какую задачу он решает и с какими данными работает.** Шесть типов задачи на семь видов данных — сорок две клетки; на экране окно из двенадцати.

**Карта соберётся один раз, в конце.** Читать на ней будем **пустые клетки: куда за восемь разделов не зашёл никто.**

| | текст | изображение | структурированные данные |
|---|---|---|---|
| классификация | null | null | null |
| распознавание | null | null | null |
| поиск с генерацией | null | null | null |
| прогноз | null | null | null |

Клетки медицины — те же, что были заняты в инженерии. Отличается цена ошибки и устройство процедур, которые её удерживают.

## Заметки лектора

Два имени — весь рабочий инструмент, которым курс называет каждый встреченный инструмент. Первое отвечает на вопрос, что система выдаёт на выходе: классификация ставит метку из списка, распознавание находит и опознаёт во входе, поиск с генерацией сначала находит и ранжирует, а потом создаёт содержимое по найденному, прогноз предсказывает число, планирование строит последовательность действий. Названия эти курсу знакомы, и повторять их определения со сцены незачем — на слайде они стоят осями, а не словарём. Второе имя — с какими данными система работает: текст, изображение, звук, видео, структурированные данные, код, комбинации нескольких видов сразу. Пара бывает составной, и это не оговорка: чат, который ищет в документах и пишет по ним ответ, решает две задачи подряд.

Зачем это нужно. Два имени задают поставщику два вопроса, на которые тот обязан ответить коротко. Если ответа нет или он звучит как «у нас комплексное решение на основе искусственного интеллекта», разговор о пригодности инструмента ещё не начался. По паре имён сразу видно, где искать опыт: распознавание на изображении — обкатанная область с готовыми мерами качества, а планирование на структурированных данных в медицинской практике встречается редко, и каждый случай придётся разбирать с нуля. И пара показывает подмену, которая стоит дорого: успех показывают в одной клетке, а продают инструмент для другой.

Собирается карта один раз, и обещать стоит ровно это. По строкам встанут типы задач, которые за лекцию встретились, по столбцам — виды данных, в клетках — короткие имена разобранных случаев. Заполняться она по ходу не будет, и ждать этого не надо: занятых клеток за всю лекцию наберётся четыре, то есть восемь из двенадцати показанных останутся пустыми до последней минуты. Эти восемь и есть содержание карты. Пустая клетка говорит ровно столько же, сколько занятая: на этих стадиях инструмент такого класса искать незачем, и время, которое ушло бы на поиск, карта экономит заранее.

Общую картину стоит держать в голове с первой минуты. Медицина занимает здесь четыре клетки, и все четыре — те же, которыми заканчивалась инженерная лекция: распознавание и классификация на изображении, прогноз на структурированных данных, поиск с генерацией на тексте. Совпадение клеток и есть результат: отрасли различает не класс модели, а цена ошибки и процедура вокруг человека. Чисел в этой раскладке нет ни одного — ни долей рынка, ни числа допущенных изделий, ни «лидеров».
