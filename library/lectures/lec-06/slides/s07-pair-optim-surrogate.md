# Оптимизационный ML и суррогат/PINN — где граница

## Assertion

Оптимизационный ML и суррогат/PINN — узнать по границе: где ДА, где НЕТ, какая классическая альтернатива.

## Visual

Таблица 2 строки × 3 колонки в Ocean rounded box. Строка 1 — «Оптимизационный ML / топ-оптимизация» (иконка `sliders`): ДА — «снижение массы при заданной прочности, детали под аддитив»; НЕТ — «когда ограничения заданы неполно — оптимум под неверную постановку»; Альтернатива — «параметрическая оптимизация + расчёт по нормам». Строка 2 — «Суррогат / PINN» (иконка `gauge`): ДА — «быстрый прогон большого числа вариантов внутри обучающей области»; НЕТ — «экстраполяция за пределы обучения, разрывы полей, сертификация»; Альтернатива — «полный МКЭ/CFD с проверкой сходимости сетки». Каждая ячейка ≤2 строк текста, ≥14pt. Gold-акцент (`#F0AB00`) на колонке «Когда НЕТ» (главное для суждения).

## Speaker notes

Этот блок устроен как справочник: его не нужно удерживать в памяти целиком — он собирается по мере прохождения дальнейших частей. На этом этапе достаточно один раз пройти его, узнавая классы. Сам формат «когда подходит — когда не применим — классическая альтернатива» не украшение: он и есть операциональная форма центральной мысли курса, и он повторяется как якорь в каждой части.

Оптимизационный ML и топологическая оптимизация подходят там, где нужно снизить массу при заданной жёсткости или прочности, найти нетривиальную силовую схему, спроектировать деталь под аддитивное производство, где «органическая» форма изготовима. Не применим, когда ограничения заданы неполно: оптимизатор честно выдаст оптимум под неверную постановку и не заменит проверку на изготовимость и нормоконтроль. Классическая альтернатива — параметрическая оптимизация с ручным выбором сечений по сортаменту плюс расчёт по нормам; для типовых конструкций — нормативный расчёт без оптимизации вообще. Этот класс разбирается глубоко в части про генеративный дизайн.

Суррогатные модели и PINN подходят для быстрого прогона большого числа вариантов внутри обучающей области и предварительного отсева. Не применим: экстраполяция за пределы обучающего распределения, задачи с разрывами полей, финальные сертификационные расчёты. Классическая альтернатива — полный МКЭ или CFD-решатель с проверкой сходимости сетки. Этот класс разбирается глубоко в части про суррогаты.
