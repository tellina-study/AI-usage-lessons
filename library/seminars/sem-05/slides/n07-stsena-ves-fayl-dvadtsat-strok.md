# Весь файл инструкций — двадцать строк

## Assertion

Весь файл инструкций проекта — двадцать строк, три раздела: критерий «готово», граница про прод, порядок проверки и задачная память; строки про ветки в нём нет ни одной.

## Visual

```markdown
  # CLAUDE.md

  signup-landing: статический лендинг с формой заявки на демо-урок.
  Готово = `npm run build` код 0, `npx playwright test` зелёный, форма
  отправлена руками из собранного `dist/` — и заполненная, и пустая.

  ## Safety / scope boundaries
  - Никогда не запускать деплой на прод без явного запроса.

  ## Build, test, verify
  - To verify: открыть `dist/index.html` после сборки и отправить форму
    руками — с заполненными и с пустыми полями.
  - Один раз на машину, до первого `npx playwright test`: `npm ci`, затем
    `npx playwright install chromium`. Без второй команды падают все тесты
    сразу и не по делу.

  ## Задачная память
  - На многошаговую задачу — файл в `.tasks/active/`, до первой правки.
  - Договорённость или решение по ходу — в этот файл сразу, а не в конце сессии.
  - План сверять в начале и в конце сессии, дату ставить `date -u +%Y-%m-%dT%H:%M:%SZ`.
```

> **Цена:** показ заказчику завтра — и правка уезжает мимо ветки прямо в то, что ему покажут.

## Speaker notes

Это весь файл, целиком, двадцать строк. Не фрагмент и не пересказ — читайте и ищите, чего в нём нет.

В нём есть три разумных раздела. Критерий «готово» — сборка с нулевым кодом, зелёные тесты, форма отправлена руками. Граница — не деплоить на прод без явного запроса. Порядок проверки и задачная память. Файл написан не новичком: в нём даже оговорено, что без `playwright install chromium` тесты падают все сразу и не по делу.

И при этом — ни одной строки про ветки. Ни «коммить в отдельную», ни «в главную не коммить».

Что происходит дальше — три кадра справа. Агент правит валидацию формы, делает `git commit`, коммит ложится в главную ветку. Нарушения нет: правила, которое он мог бы нарушить, в файле не существует.

Цена под файлом. Показ заказчику назначен на завтра, и эта правка уезжает мимо ветки прямо в то, что он увидит.

Если из зала прозвучит «так допишите строку» — это ровно следующий ход, и мы его сделаем. Но не сразу: сначала посмотрим, чего такая строка стоит там, где она уже написана.
