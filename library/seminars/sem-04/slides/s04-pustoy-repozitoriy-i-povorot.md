# Первый прогон: от пустой директории до прототипа

## Assertion

Агент собрал работающий прототип по спеке без единого уточняющего вопроса — и структуру репозитория при этом выбрал сам, потому что `spec.md` её не описывает.

## Visual

Верхний ярус. Слева — реальный захваченный вывод до прогона:

```
$ ls -la signup-landing/
total 8
drwxr-xr-x 2 harness harness 4096 Sep 20 12:45 .
drwxr-xr-x 3 harness harness 4096 Sep 20 12:45 ..
```

Справа — постановка задачи дословно, по содержанию совпадающая с функциональной частью `spec.md`:

> «собери лендинг с формой заявки на демо-урок: статическая HTML-страница, сборка Vite (`npm run build` → `dist/`), поля формы — имя и email, тест на Playwright, который проверяет, что форма не отправляется с пустыми обязательными полями (`tests/form.spec.ts`)»

Средний ярус — строка из захваченной сессии, крупно, в gold-рамке:

> «Уточняющий вопрос не задавался. Все параметры задачи были однозначно выводимы из текста задачи, поэтому работа была начата сразу, без уточнений.»

Нижний ярус. Слева — что появилось в репозитории после прогона, под подписью «создано агентом»:

```
index.html
src/main.js
package.json
tests/form.spec.ts
```

Справа — блок команд из его же финального ответа:

```
npm install
npm run build          # → dist/
npm run test:e2e       # playwright test
```

## Speaker notes

«Директория пустая — это реальный вывод команды до прогона. Дальше агент получает задачу по спеке и за один проход отдаёт собранный проект: разметка, обработчик формы, манифест пакета со скриптами сборки и теста, тест на Playwright. Прототип рабочий — команды из его финального ответа отрабатывают.

Уточняющих вопросов не было ни одного; в захваченной сессии это зафиксировано прямо: все параметры задачи выводились из текста.

И здесь стоит остановиться на том, чего в этом тексте не было. Критерий приёмки был — мы записали его в спеку сами. А вот структура: как назвать файлы, где разместить обработчик, как разложить проект по папкам — в спеке этого нет и быть не должно, это устройство кода, а не требование к продукту. Эти решения агент принял сам и молча: `src/main.js`, `tests/form.spec.ts`, скрипты в `package.json`.

Прототип есть. Дальше с этим репозиторием предстоит работать не один день — и вот здесь начинается вопрос о конфигурации агента.»
