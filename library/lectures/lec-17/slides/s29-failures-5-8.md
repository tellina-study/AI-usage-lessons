# sNN — Провалы 5-8

## assertion

Провалы 5-8: переавтоматизация, действие без канарейки, научная галлюцинация, голос/видео-дипфейк мошенничество.

## slide_type

## visible

Сетка карточек из 4 карточек:

**5. Переавтоматизация в зонах вариативности.** Tesla 2018 — конвейер, производство;
Boeing 737 MAX 9 — авиапром. Урок: парадокс автоматизации (Бейнбридж, 1983) —
автоматизация ломает пропускную способность при высокой вариативности. Альтернатива:
Jidoka — усиление, не замена; Six Sigma + статистический контроль процесса остаются.

**6. Действие без канарейки и отката.** CrowdStrike — кибербезопасность; Cloudflare —
сетевая инфраструктура. Урок: широкий домен = большой радиус разрушения. Альтернатива:
канарейка 1-5% + телеметрия + откат в один клик + поэтапное развёртывание.

**7. Научная галлюцинация класса Galactica.** Meta Galactica — научный текст-генератор,
наука; галлюцинации цитат. Урок: в науке эталон — воспроизводимый эксперимент, а не текст.
Альтернатива: RAG-заземление в проверенные источники + рецензирование по чек-листу.

**8. Голос/чат-мошенничество и мультимодальный дипфейк.** Wendy's — общепит; Air Canada —
авиаперевозки; дипфейк финансового директора Arup на $25 млн в видео-конференции
(инженерный консалтинг, февр. 2024). Урок: шумная среда + сложная задача = AI ненадёжен;
видео+голос = новый вектор. Альтернатива: меню по правилам; C2PA подпись; проверка через
независимый канал для дорогих транзакций.

## speaker_notes

Провалы с пятого по восьмой.

Пятый — переавтоматизация в зонах вариативности. Tesla в восемнадцатом году при наращивании
производства Model 3: Маск признал, что чрезмерная автоматизация замедляет конвейер, и вернул
человеческую сборку на участках с высокой вариативностью. Это парадокс автоматизации,
описанный Бэйнбридж ещё в восемьдесят третьем. Альтернатива — принцип Jidoka из системы
Toyota: усиление, а не замена; статистический контроль процесса остаётся нормативным.

Шестой — действие без канарейки и отката. CrowdStrike выпустил обновление без канареечного
выпуска, восемь с половиной миллионов устройств парализованы. Cloudflare — каскад
конфигурации, пять с половиной часов до восстановления. Урок: широкий домен означает большой
радиус разрушения. Альтернатива — канарейка на одном-пяти процентах, телеметрия с ранним
предупреждением, откат в один клик и поэтапное развёртывание.

Седьмой — научная галлюцинация класса Galactica. Модель Meta прожила трое суток, генерируя
фейковые статьи с фейковыми цитатами. Урок: в науке эталон — это воспроизводимый эксперимент,
а не текст. Альтернатива — заземление в проверенные источники и рецензирование по чек-листу с
проверкой каждой ссылки.

Восьмой — голосовое и чат-мошенничество и мультимодальный дипфейк. Wendy's и Air Canada
показали ненадёжность чат-ботов. А в феврале двадцать четвёртого сотрудник Arup перевёл
двадцать пять миллионов долларов после видео-конференции с дипфейк-имитацией финансового
директора и коллег. Это уже не клонирование голоса, а видео плюс голос — новый вектор. Альтернатива:
меню по правилам, криптографическая подпись провенанса и обязательная проверка через
независимый канал для дорогих транзакций.
