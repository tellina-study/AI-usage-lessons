# Карта слайдов — Семинар 7

Таблица собрана из файлов слайдов, а не из плана: номер, блок, тип, заголовок экрана и минуты
взяты из фронтматтера и первой строки каждого файла. Границы блоков — из статической таблицы
сборщика деки (`build_sem07.SECTIONS`). Границы кейсов выведены по дивайдерам кейса — все
четыре несут один приём `case_divider_quote`.

Нумерация сквозная, `n01`…`n34`, без буквенных хвостов. Занятие открывает дугу из шести
семинаров про построение процессов на языковых моделях (`KONTSEPTSIYA-7-12.md`): сегодня
закрывается нижняя ступень лестницы — триггер, шаг, запись результата, получение значений
вместо прозы, поведение при отказе и разница между черновиком и опубликованной версией.

Занятие ведётся как живое демо с ноутбука ведущего; снимки холста — страховка, не замена
демо. Такт «наше решение» в каждом кейсе собирается на стенде на глазах у зала, и слайд при
этом самодостаточен: на нём принципиальная схема и таблица параметров, так что при отказе
техники занятие идёт без потерь и без переключения режимов.

Кейсов четыре плюс один концептуальный разбавитель, и все четыре — стадии ОДНОГО процесса:
кейс 1 собирает полный классификатор, кейс 2 сталкивает справочник с многотемьем и чужими
темами, кейс 3 добавляет повтор и ветку отказа, кейс 4 объясняет, почему собранное работает
не так, как выглядит. На выходе занятия — файл процесса, который студент ставит одним импортом.

Каждый кейс закрывается ДВУМЯ обобщающими экранами (требование владельца 2026-10-12):
«что переносится в любой инструмент» — принцип, живущий дольше интерфейса, — и «нюансы,
которые есть везде». Имена блоков стоят в этих экранах одной строкой внизу, а не составляют
их содержание: иначе занятие превращается в методичку по одному инструменту.
