# Сценарий 1 — проверка орфографии

## Assertion

Фоновый скрипт проверки орфографии — разминка.

## Visual

Левая Ocean rounded box карточка: иконка `file-code`, курсивный текст сценария («Раз в час фоновый скрипт автоматически проверяет орфографию во всех открытых файлах проекта и дописывает список ошибок в текстовый лог — без интерфейса, без диалога, без вашего участия в моменте проверки»), ниже Q1/Q2 текстом.

Справа компактный квадрант 2×2 (4 ячейки: Модель/Чат/Приложение/Агент), ячейка «Модель» выделена GOLD (остальные — нейтральный серый), под квадрантом gold callout с обоснованием «Q1 нет · Q2 нет — самый чистый случай раздела».

## Speaker notes

Прогоняем через чек-лист. Q1 — нет: никакого диалога и интерфейса, вход и выход — только файлы на диске. Q2 — нет: один проход «текст → список ошибок» без вызова внешних инструментов, без планирования, без многошаговой работы. Правильный ответ — модель, левый верхний угол квадранта, самый чистый случай раздела: нет ни взаимодействия с пользователем, ни самостоятельной работы с инструментами.

Это самый простой сценарий раздела — не задерживаемся на обсуждении дольше одной-двух минут, переходим к сценарию 2.
