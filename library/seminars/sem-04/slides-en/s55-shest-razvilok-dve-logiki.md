# Six decision points, two logics

## Assertion

The six decision points of today's session fell into two types: what is specific to the project (wait for a signal) and universal hygiene (set up right away, on day 0).

## Visual

| Case | Decision point | What we wrote down | When |
|---|---|---|---|
| 1.1 | The agent's role and a general description of the repository | Nothing — until the first real signal | on a signal |
| 1.2 | The basic processes: the "done" gate + the improvement loop | The gate line, as text, in CLAUDE.md | day 0 |
| 1.3 | Nested instruction files across subfolders | The rule of three addresses: a function → the code, a class of files → a path pattern, the project → the root | on a signal |
| 2.1 | A flat memory file (DECISIONS.md) | The decision written into the file + auto-memory | day 0 |
| 2.2 | Structured wiki memory | Separate files (ADRs) with cross-links | on a signal |
| 2.3 | Working task memory | A file per task + a rule in CLAUDE.md: an agreement goes into the log right away | day 0 |

Under the table, large:

> "Three decision points were waiting for a real signal. Three needed no signal at all — they were worth setting up right away."

## Speaker notes

"Let us look back over today. Six decision points, three in each of the two sections. In the section about the instruction file — what not to write in advance, how to write down the 'done' gate and the improvement loop, whether to split the file across subfolders. In the section about memory — a flat decisions file, structured wiki memory, the task memory of a single session.

In the right-hand column — two logics. Three decision points — 1.1, 1.3, 2.2 — are specific to the particular repository: there was no way to say in advance whether a general description of the structure, nested files or complex memory would be needed, so we honestly waited for a signal. The other three — 1.2, 2.1, 2.3 — are universal hygiene: the readiness gate, the decision log, task memory. Those we set up right away, without waiting for the pain, because the cost of doing it on day 0 is small while the cost of not doing it is unpredictable and arrives quietly.

And one more thing that has not gone anywhere: the gate line in CLAUDE.md and the decision log are both still text that the agent reads and can take into account — not a guarantee. That is a separate conclusion, and it holds regardless of whether we set them up right away or on a signal — and we will come back to it, for exactly a minute, in the next step."
