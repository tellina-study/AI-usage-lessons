# Разбор: куда вынести процедуру

## Assertion

Скилл — знание, которое агент сам подгружает по описанию-триггеру, состоящему из трёх частей: что делает, когда использовать, когда не использовать.

## Visual

Мелким шрифтом вверху — вопрос для контекста: «Куда вынести процедуру деплоя?»

Таблица разбора:

| Вариант | Где это работает | Почему здесь ещё рано — и что вместо |
|---|---|---|
| «Оставлю в файле инструкций — вдруг понадобится» | Нигде: ровно тот антипаттерн, который ступень называет по имени | Постоянный налог на контекст независимо от релевантности. Вместо: вынести туда, что грузится по требованию |
| «Вынесу в отдельный файл и сошлюсь импортом» | Организационно: файл станет читаемее | **Импорт не экономит контекст** — импортированный файл всё равно грузится целиком при старте. Налог не решён, он переехал |
| «Вынесу в файл и буду сам напоминать агенту его прочитать» | Пока вы помните | Требует человека в каждом цикле. Вместо: отдать решение о релевантности модели, но по явному описанию |
| «Сделаю это хуком» | Там, где правило нельзя нарушить ни разу | Путаница механизмов, и полезная: хук — механика, которую исполняет среда; скилл — знание, которое агент может учесть. Деплой нельзя «исполнить» за агента — его надо знать |
| **«Заведу скилл с описанием, по которому он срабатывает»** | **Именно то, что нужно** | **Не рано: файл инструкций уже платит за процедуру в девяти сессиях из десяти.** Ломается, если описание написано для человека, а не как триггер |

## Speaker notes

Разбор. «Оставлю — вдруг понадобится» — постоянный налог на контекст, и он не нейтрален: чем длиннее файл, тем ниже шанс, что сработает соседняя важная строка. «Отдельный файл плюс импорт» — здесь работает возврат: «Мы это обсуждали в первом разделе. Импорт не экономит контекст — импортированный файл грузится целиком при старте. Вы сделали файл читаемее, это хорошо. Но счёт за контекст остался прежним.» «Буду напоминать сам» — требует человека в каждом цикле.

«Сделаю это хуком» — самая продуктивная путаница занятия, её надо не поправить, а развернуть: «Отличный вопрос, давайте разведём. Хук — это механика: среда исполняет его сама, согласия агента не нужно. Скилл — это знание: агент может его учесть, а может нет. Теперь приложите к нашей процедуре. Можно ли "исполнить" деплой вместо агента хуком? Нет — деплой надо знать, там на каждом шаге решения. А обратно: можно ли оформить скиллом правило "не деплоить без явного запроса"? Тоже нет — скилл остаётся текстом, который можно не учесть. Мы уже видели, чем это кончается.»

Целевой ответ — скилл с описанием, по которому он срабатывает сам.
