# Вывод: иерархия обгоняет все остальные версии

## Assertion

Три попытки обогнать версию 1 своим способом — версия 3a, версия 4, версия 5 — каждая обгоняет
её. Ни одна не обгоняет версию 2.

## Visual

> **Вывод.** Версия 2 выигрывает у версии 1 по точности ответа. Версия 3a (семантика на щадящем
> пороге), версия 4 (рекурсивная резка) и версия 5 (соседние чанки) тоже выигрывают у версии 1,
> но не у версии 2 — умный на бумаге метод не обгоняет простой приём, который вообще не требует
> эмбеддинга текста для самой резки. Рекурсия впереди всех по поиску документа (100%), но позади
> по итоговой точности; соседние чанки дешевле версии 2 почти на треть по цене вызова ($0,0000367
> против $0,0000506 на вопрос), но тоже не обгоняют её по точности (80,6% против 84,7%).

## Speaker notes

Пять версий, три из них пробуют обогнать версию один своим способом — и все три обгоняют, но ни
одна не бьёт версию два. Это главный итог этого свода, прежде чем расходиться по отдельным тактам
за устройством каждой версии.

Версия два остаётся самым сильным измеренным приёмом этого кейса: восемьдесят четыре целых семь
десятых процента точности против семидесяти целых восьми десятых у версии один — и это без
единого дополнительного вызова эмбеддинга сверх того, что уже требуется для поиска. Версия три а
обгоняет версию один на щадящем пороге, но не версию два. Версия четыре находит документ лучше
всех — сто процентов без единого промаха — но платит за это целостностью куска, и итоговая
точность у неё только семьдесят пять процентов, середина пачки. Версия пять — промежуточный
результат: восемьдесят целых шесть десятых процента, дороже версии один, но на треть дешевле
версии два по цене вызова, — и тоже не обгоняет её.

Общий узор: иерархическая резка чинит дефект версии один самым прямым способом — отдаёт модели
весь документ целиком, и доля целых ответов почти совпадает с долей найденного документа по
построению. Остальные три приёма чинят тот же дефект частично, каждый со своей ценой. Какую из
пяти техник взять — вопрос не «которая лучше вообще», а при каких документах и по какой цене
каждая себя оправдывает; устройство каждой версии и её собственная граница применимости —
дальше, по одной за раз.
