# Пять усилений, которые ставят рядом с файлом инструкций

## Assertion

Рядом с файлом инструкций ставят пять механизмов, и различаются они тем, кто приводит каждый в действие: среда, сам агент, внешняя система, отдельная роль, порядок работы.

## Visual

> Рядом с файлом инструкций ставят пять механизмов. По строке на каждый — что это такое, кто приводит его в действие и переносится ли он на другой инструмент.

| Усиление | Что это | Переносится ли |
|---|---|---|
| Хук | Команда, которую **среда запускает сама** в заданный момент работы агента. | **Приём** — у всех. **Запись** — у каждого своя; у отдельных агентов механизма нет. |
| Скилл | Процедура в **отдельном файле**; агент открывает её сам. | **Открытый формат** — тот же файл читают десятки агентов. |
| MCP | **Model Context Protocol** — подключение к внешней системе; через него агент достаёт данные, которых в репозитории нет. | **Открытый протокол** — у него нейтральный владелец и общая спецификация. |
| Субагент | Отдельная роль с **урезанными правами**; её запускают на одну задачу и получают обратно только итог. | **Приём** — у всех. **Формат объявления** — у каждого свой. |
| Процесс | **Порядок работы, записанный файлами**: план, запись по ходу, проверка перед сдачей. | **Переносится целиком** — это обычные файлы, механизма не требует. |

## Speaker notes

Рядом с файлом инструкций можно поставить пять разных механизмов. Прежде чем выбирать между ними, договоримся, что каждый из них такое — по одной строке, без устройства.

Хук — команда, которую среда запускает сама, в заданный момент работы агента. Агента об этом не спрашивают.

Скилл — процедура, записанная отдельным файлом. Агент открывает её сам, когда она понадобилась.

MCP, Model Context Protocol — подключение к внешней системе. Через него агент достаёт данные, которых в репозитории физически нет.

Субагент — отдельная роль с урезанными правами. Её запускают на одну задачу и получают обратно только итог работы.

Процесс — порядок работы, записанный файлами: план, запись по ходу, проверка перед сдачей.

Третья колонка — привязано ли это к одному инструменту. Сегодня — факт. Переносятся три строки из пяти: у скилла и у доступа наружу формат опубликован, процесс — обычные файлы. У хука и субагента приём есть у всех, а запись у каждого своя. Почему граница здесь — скажу в конце.

Пять строк — пять разных ответов на один вопрос: кто приводит механизм в действие. У хука это среда, у скилла сам агент, у MCP внешняя система, у субагента отдельная роль, у процесса — заведённый порядок.

**Справка.**

*Если спросят, почему так коротко.* Здесь только обозначение. Устройство хука разберём перед первым кейсом, устройство скилла — перед четвёртым, и там будет по целому слайду на каждое. Сейчас хватит одной строки на инструмент: дальше она понадобится вся пятёрка сразу.

*Если спросят, чем хук отличается от процесса.* Хук срабатывает внутри одного действия агента и успевает вмешаться в него. Процесс живёт поверх всей работы и проверяется глазами и командами уже по её следам. Один механизм — момент, другой — порядок.

*Если спросят, почему MCP латиницей.* Это имя протокола, у него нет принятого русского имени. Раскрытие на слайде стоит ровно для того, чтобы буквы не остались тремя буквами.

*Если спросят, откуда третья колонка.* Проверка по документации поставщиков и текстам спецификаций, первое октября; семнадцать первоисточников, они перечислены в материалах. Разбор одного переноса целиком будет перед закрытием, на своём слайде.

*Если спросят, можно ли обойтись одним.* Можно, и большинство проектов так и живёт. Весь вопрос в том, каким и по какому сигналу, — это и есть содержание сегодняшнего занятия.

*Если прозвучит «а что из этого мы ставим».* Отвечаю, что про это говорим через слайд, и не называю ничего раньше времени: следующий слайд — вопрос, и ответ на нём даёт зал.

*Порядок строк.* Он тот же, что порядок карточек на следующем слайде и на повторе вопроса в конце. Менять его нельзя: на совпадении держится возврат.
