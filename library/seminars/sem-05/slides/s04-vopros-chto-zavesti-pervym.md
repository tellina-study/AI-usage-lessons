# Что завели бы первым

## Assertion

Выбор из пяти карточек: какое из пяти усилений завели бы первым, без единой детали о конкретном проекте — и тот же вопрос прозвучит сегодня второй раз.

## Visual

> Правило было прочитано — и всё равно нарушено. Перед вами пять усилений, которые превращают текстовую просьбу в нечто более надёжное.
> Если сейчас, без единой детали о конкретном проекте, можно завести только одно — какое? Держите свой ответ при себе: этот вопрос прозвучит сегодня ещё раз.

`хук` · `скилл` · `MCP` · `субагент` · `процесс`

## Speaker notes

Задать вопрос и замолчать. Два-три голоса, каждый зафиксировать вслух: «записал». По существу не комментировать, оценки здесь нет ни одной.

Ожидаемый разброс: «хук» как самое жёсткое, «MCP» из-за путаницы подключения с решением, «процесс» из опыта ревью. Ни один не ошибка.

Обещание про второй раз произнести дословно: на нём держится конец занятия.
