# Where to put a rejected decision

## Assertion

Choose where to write the rejected decision down — from the cards below — so that you do not explain it a third time.

## Visual

In a small font at the top — a one-line reminder: "The rejected validation library has resurfaced — the decision was born in conversation and was left nowhere, even with DECISIONS.md already set up."

The question verbatim, in a gold frame:

> "This is the second time in two weeks that you are explaining to the agent why there is no third-party validation library in this form — the very decision that was already rejected. Choose where to write this decision down — from the cards below — so that you do not explain it a third time, and justify why not in the instruction file we have just set up."

Below — five option cards:

`add it to CLAUDE.md` · `tell the agent "remember this"` · `write it in DECISIONS.md — it already exists` · `install a memory system` · `nothing — it will remember on its own`

There is no breakdown table and not a single number on this slide — the evidence and the breakdown are on the next one.

## Speaker notes

The question is read verbatim off the screen — the scenario and the diagnosis were already given on the previous slide, so do not retell them here, only the short one-line reminder at the top. The second half is deliberately built into the question — "and why not in the instruction file we have just set up" — without it the room will give an answer that is right in form and will not see that the layers are different. A pause, then 2–3 voices. The facilitator does not comment on the substance of the answers on this slide, only notes them out loud: "got it", "noted, let's move on". The breakdown, the numbers and the link to the evidence come on the next slide.
