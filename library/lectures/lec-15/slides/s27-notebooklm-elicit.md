# NotebookLM 17 миллионов. Elicit 138 миллионов статей. Каждая ссылка — проверить вручную.

## NotebookLM (Google, 2023, расширен 2024-2026)

RAG-инструмент для **персонального корпуса**. Студент загружает PDF (до ~50 документов) и:
- задаёт вопросы корпусу со ссылками на конкретные предложения
- генерирует сводки
- слушает аудио-обзор подкаст-стиля (добавлено 2024)

**17 миллионов+ активных пользователей в месяц** на конец 2025 [VFY-day-of].

**Польза:** 50+ источников за 1 час vs типичная 1 неделя ручного чтения.

## Elicit (Ought.io, 2021+)

RAG-инструмент для **обзора литературы**. База ~138 миллионов академических статей + 545k клинических исследований.

**Польза:** ускорение обзора литературы в **~4 раза** по валидированному пользовательскому исследованию [VFY-day-of].

## Consensus (Consensus.app, 2022+)

Похожий инструмент с фокусом на **прорецензированные прямые ответы**. Задайте вопрос «да/нет», получите ответ научного консенсуса со ссылками.

## Дополнительно

**Scite** — анализ контекста цитирования (какие статьи цитируют X положительно или отрицательно). **Semantic Scholar** — семантическая поисковая система по 214M статьям с богатыми метаданными. **PaperQA** — специализированный RAG для научных PDF.

## Где создают риски

(а) **Галлюцинации случаются и с RAG** — даже NotebookLM иногда придумывает «цитаты» внутри корпуса.

(б) **Подтверждающее смещение** — RAG не противоречит вашему нарративу, укрепляет.

(в) **Склонность доверять автомату** — психологическое смещение принять «авторитетный» ответ без проверки.

## Правильный режим использования

Это **отправная точка**, не финальный синтез. После каждого ответа — спросите: «Действительно ли я этому доверяю? Проверил исходный источник?». **«4 часа ручного чтения в неделю»** → **«1 час NotebookLM + 1 час проверки 5-10 ключевых утверждений»**.

## Speaker notes

NotebookLM от Google запущен в 2023, расширен в 2024-2026. RAG-инструмент для персонального корпуса: студент загружает PDF до примерно 50 документов, NotebookLM позволяет задавать вопросы корпусу со ссылками на конкретные предложения, генерировать сводки, слушать аудио-обзор в стиле подкаста — добавлено в 2024. К концу 2025 года 17 миллионов плюс активных пользователей в месяц.

Польза: NotebookLM позволяет обработать 50 источников за один час против типичной одной недели ручного чтения. Это измеримое улучшение производительности, особенно для систематических обзоров.

Технически NotebookLM использует архитектуру RAG: загруженные документы разбираются на чанки, эмбеддируются в векторное пространство, индексируются для поиска. При запросе вопрос эмбеддируется, топ-k чанков извлекаются, всё передаётся в Gemini для генерации.

Elicit — Ought.io. RAG-инструмент специально для обзора литературы. База 138 миллионов академических статей плюс 545 тысяч клинических исследований. Польза: исследования показывают, что Elicit сокращает время обзора литературы в 4 раза по валидированному пользовательскому исследованию.

Consensus — похожий инструмент с фокусом на прорецензированные прямые ответы. Полезно для быстрой ориентации в спорных темах.

Semantic Scholar — семантическая поисковая система по 214 миллионам статей с богатыми метаданными — сети цитирования, экспертиза авторов. Не RAG для ответов, но мощный для навигации.

Где NotebookLM создаёт риски. Галлюцинации случаются даже с RAG. Качество синтеза ограничено качеством исходных документов. Подтверждающее смещение — NotebookLM не противоречит вашему нарративу. Склонность доверять автомату — психологическое смещение принять авторитетный ответ без проверки.

Правильный режим. NotebookLM — отправная точка, не финал. Используйте для навигации, но проверяйте каждое важное утверждение ручным чтением того конкретного раздела статьи. Это превращает 4 часа ручного чтения в 1 час NotebookLM плюс 1 час целевой ручной проверки 5-10 ключевых утверждений — экономия 2 часа на статью при сохранении глубины.

Реальный рабочий процесс комбинирует: Semantic Scholar для широкой навигации → Elicit для конкретных вопросов → NotebookLM для глубокого погружения в корпус → ручное чтение топ-10 наиболее цитируемых. Экономия 50-70 процентов против чисто ручного, но каждая AI-цитата проверена через DOI.
