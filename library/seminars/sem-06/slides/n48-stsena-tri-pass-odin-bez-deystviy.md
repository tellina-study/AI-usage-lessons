# Три PASS выглядят одинаково. Один описывает то, чего не было

## Assertion

Три параллельных запуска роли вернули одинаково надёжные `PASS`. Через день один из них оказался описанием действия, которого не было: журнал вызовов показал, что инструмент проверки не вызывался ни разу.

## Visual

> Файл роли с урезанными правами из первого кейса уже работает, и формат ответа тоже устоялся: вердикт первой строкой, раздел «что проверено», находки.

1. Разработчик готовит более крупную правку — сразу три независимых изменения формы — и на каждое параллельно запускает диф-ревьюера, чтобы не ждать по очереди.
2. От каждого запуска приходит ровно одна вещь — финальный текст. Все три итога выглядят одинаково надёжно: вердикт `PASS`, раздел «что проверено» заполнен, находок нет. Правки уходят в показ.
3. Через день одно из трёх изменений ломает отправку формы на реальных данных — тот самый случай, который должен был поймать раздел «что проверено» третьего ответа.
4. Открывают журнал вызовов этой роли за тот прогон: в нём нет ни одного обращения к файлу, который вердикт называет проверенным.

> **Раздел «что проверено» описывает действие, которого не было. Сам инструмент для этой проверки роль в тот прогон не вызвала ни разу.**

## Speaker notes

Файл роли с урезанными правами из первого кейса уже работает, и формат ответа тоже устоялся: вердикт первой строкой, раздел «что проверено», находки. Разработчик готовит более крупную правку — сразу три независимых изменения формы — и на каждое параллельно запускает диф-ревьюера, чтобы не ждать по очереди.

От каждого запуска приходит ровно одна вещь — финальный текст. Все три итога выглядят одинаково надёжно: вердикт `PASS`, раздел «что проверено» заполнен, находок нет. Правки уходят в показ.

Через день одно из трёх изменений ломает отправку формы на реальных данных — тот самый случай, который должен был поймать раздел «что проверено» третьего ответа. Открывают журнал вызовов этой роли за тот прогон: в нём нет ни одного обращения к файлу, который вердикт называет проверенным. Раздел «что проверено» описывает действие, которого не было: сам инструмент для этой проверки роль в тот прогон не вызвала ни разу.

Если спросят, не противоречит ли это только что собранному формату: нет — формат соблюдён буквально, вердикт на месте, раздел «что проверено» заполнен текстом. Формата здесь хватает для разовой проверки — дело в другом: через канал, по которому родитель получает итог, прошёл только текст; сами действия, которые он описывает, — нет.

Если спросят, насколько это частый случай: источник разберём в этом же кейсе — шесть из примерно пятнадцати параллельных запусков в документированном случае, не единичный инцидент.
