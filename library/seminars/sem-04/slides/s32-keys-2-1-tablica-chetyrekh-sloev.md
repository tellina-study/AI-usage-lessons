# Четыре слоя записи

## Assertion

Разница между слоями не в формате, а в том, кто инициирует запись, кто её потом увидит и по какому механизму она вообще попадает в контекст.

## Visual

| | Файл инструкций | Авто-память | `DECISIONS.md` | Сложная система памяти |
|---|---|---|---|---|
| Кто автор | вы, заранее | агент, по ходу | вы, в момент решения | сервис: извлекает сам из хода работы |

Под таблицей — четыре строки: индекс памяти — только индекс · агент сам пропускает выводимое из кода · сжатие контекста переживают только файлы на диске · усложнение слоя само по себе результата не улучшает: на малых корпусах простой файл регулярно обходит внешние системы.

## Speaker notes

Один критерий различения, одной фразой: разница не в формате — первые три слоя все markdown, — а в том, кто инициирует запись, кто её потом увидит и по какому механизму она попадает в контекст. Файл инструкций пишете вы заранее, и он грузится сам. Авто-память пишет агент, для себя, на этой машине, без ревью. Журнал решений пишете вы, для команды, в репозиторий, через ревью — но он не грузится сам: агент открывает его по своей инициативе или по явной ссылке.

Четвёртая колонка — внешняя система памяти: векторная или графовая база, отдельный сервис. Там запись формирует не человек: сервис сам извлекает факты из хода работы и сам решает, что подать в контекст по запросу. Плюс — переживает смену машины, в отличие от авто-памяти. Минус — в репозитории не лежит ничего, значит ни истории изменений, ни ревью, а формулировку записи вы не контролируете. И выигрыш от неё не автоматический: на малых корпусах простой файл регулярно её обходит — замеры по этому на слайде провала.

Четыре детали кратко: индекс памяти — только индекс, за двести строк содержимое физически не попадает в сессию; агент сам пропускает то, что выводимо из кода; сжатие контекста переживают только файлы на диске — то, что сказано лишь в разговоре, при сжатии может исчезнуть; и усложнение слоя само по себе результата не улучшает. Третья деталь — прямой отклик на предыдущий раздел: расчёт «объясню агенту ещё раз по ходу работы» не работает даже внутри одной длинной сессии.

Теперь, с этой таблицей на руках, разбираем то, что выбрал зал.
