# 4. Космос для ИИ

**Зеркало всей лекции: не космос становится умнее с ИИ — ИИ физически переезжает в космос.**

По порядку:

**Starcloud** — первый датацентровый GPU в космосе
**Google Project Suncatcher** — спутник с тензорными процессорами

## Заметки лектора

Этот раздел завершает четыре типа вклада ИИ: от автономии действия, через управление на расстоянии и мышление за кульманом, к вопросу о физическом месте самой вычислительной инфраструктуры — зеркальному по отношению к Разделу 1, где машина переехала в космос, чтобы действовать там, где человека быть не может.

Два разбора по порядку: Starcloud-1 — первый графический процессор датацентрового класса Nvidia H100 в космосе, уже обслуживающий реальные запросы к открытой модели Gemma. Google Project Suncatcher — спутник размером с холодильник, оснащённый четырьмя тензорными процессорами, с планом довести констелляцию до 81 аппарата в едином лазерном кластере.

Почему этот раздел стоит последним, завершая лекцию, а не где-то в середине? Он логически зависит от материала всех трёх предыдущих разделов сразу: спрос на вычисления, который этот раздел обслуживает, создаётся ростом данных и ростом числа систем, разобранных в предыдущих разделах — марсоходы и экскаваторы генерируют телеметрию, телеоперируемые системы передают потоки видео, суррогатные модели и прогнозы сами требуют вычислительных мощностей. Этот раздел — ответ на вопрос «а где физически выгоднее выполнять всю эту вычислительную работу», который можно задать только после того, как показано, сколько этой работы вообще появилось.
