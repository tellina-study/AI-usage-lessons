# Модель и чат

## Assertion

Один проход без диалога — модель. Диалог без инструментов — чат.

## Visual

Две равные Ocean rounded box карточки. Левая: иконка `scan`, заголовок «YOLO-детектор людей в кадре», цветной badge «Модель» (MID), рассуждение «Q1 нет — нет диалога на каждый кадр. Q2 нет — один проход изображение → детекция без вызова инструментов», заметка «Прямая перекличка с сегодняшним утренним демо».

Правая: иконка `message-square`, заголовок «AI-чат для разовой консультации по тексту», badge «Чат» (LIGHT), рассуждение «Q1 да — диалог, уточнения. Q2 нет — модель работает с тем, что дал пользователь», заметка «Разминочный пункт — ожидаемо низкая дискуссия».

## Speaker notes

Ответ на первый инструмент — модель. Q1 нет, потому что нет диалога с пользователем на каждый кадр. Q2 нет, потому что один проход «изображение на входе — детекция на выходе» без вызова внешних инструментов.

Второй — чат. Q1 да — есть диалог, можно уточнить. Q2 нет — модель работает с тем, что вы ей дали, сама никуда не ходит за данными.

Если аудитория молчит при запросе объяснить голос — обращаемся к конкретному студенту, поднявшему руку за меньшинство: точечный вызов работает лучше повторного общего приглашения.
