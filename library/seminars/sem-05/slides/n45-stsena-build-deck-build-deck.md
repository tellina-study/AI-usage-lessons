# build-deck: build-deck

## Assertion

Двенадцать скиллов из тринадцати в этом репозитории показывают вместо описания собственное имя — а годное описание лежит строкой ниже и в перечень не попадает.

```
$ head -3 .claude/skills/build-deck/SKILL.md
# build-deck

Build/rebuild a PowerPoint presentation for a lecture using the
repo-first pipeline + visual loop + 3 QA agents.
```

> Тринадцать строк, из них двенадцать — имя вместо описания. Почему: фронтматтера в файле нет, и описанием становится его первая непустая строка — заголовок, который дублирует имя. Годный текст лежит третьей строкой того же файла и в перечень не попадает. Проверяется одной командой: `head -5 .claude/skills/*/SKILL.md` — она печатает первые пять строк каждого файла скилла, и по ним сразу видно, начинается файл с фронтматтера или сразу с заголовка.

## Speaker notes

Это перечень скиллов сессии, в которой сделано это занятие. Не пример и не макет — снимок с рабочей машины.

Читаем первую строку: `build-deck: build-deck`. Слева имя, справа описание, и они совпадают. Так же выглядят следующие шесть и ещё пять ниже. Выбивается одна — `pre-user-gate`: там написано, что скилл делает и когда его звать. Это единственный из тринадцати, у которого есть фронтматтер.

Теперь вторая карточка, и она важнее первой. Команда `head -3` печатает первые три строки файла. Первая — заголовок. Третья — нормальное человеческое описание.

Содержание есть. Оно лежит на строку ниже того места, откуда среда берёт описание. Фронтматтера нет — описанием становится первая непустая строка, а это заголовок, который дублирует имя.

Проверить может любой: `head -5` по всем файлам скиллов — она печатает первые пять строк каждого. Тринадцать выводов, двенадцать начинаются решёткой.

Если спросят, что такое фронтматтер: блок в самом начале файла между двумя строками из трёх дефисов, в формате «ключ: значение». Среда читает оттуда имя и описание. Нет блока — нечего читать, и описание берётся из первой строки текста.

Если спросят, почему авторы этого не заметили: потому что прямой вызов по имени работает и без фронтматтера. Набрал слэш, имя — скилл открылся. Ломается только автоматический выбор, а его отсутствие выглядит как «модель решила, что не нужно».

Если спросят, что делает звёздочка в `.claude/skills/*/SKILL.md`: оболочка подставляет вместо неё все имена каталогов внутри `skills`, и команда отрабатывает по каждому найденному файлу сразу.

Если спросят, почему это курс про себя: потому что проверяемо. Любой может склонировать репозиторий и повторить команду. Пример, который бьёт по автору, стоит дороже любого придуманного.

Если спросят, сколько это стоило: ничего и всё сразу. Скиллы работали — их звали руками. Автоматически за всё время не открылся ни один, и узнали мы это, когда стали готовить этот кейс.

Если спросят, чинится ли это разом по всем тринадцати: да, механически — дописать каждому файлу фронтматтер с именем и описанием. Работа на полчаса. Трудная часть другая: какой текст туда класть. Ровно ей и занят остаток кейса.
