## 2026-10-26 — фикс `s28`: золотой акцент восстановлен

Владелец лично осмотрел `s28.png` и подтвердил находку предыдущей записи
(«единственный кадр без обязательного золота»). Причина найдена чтением
кода, не угадана:

- `divider()` в `build_lec08.py` (строки ~462-515) рисует золотую полоску
  (`prims.rect(..., GOLD)`) **только** для блока тела с `kind == "head"`.
- `body_blocks()` в `tools/presentation-build/deckkit/slidefile.py`
  (строка ~148) относит абзац к `"head"` **только если он начинается с
  `#`** (настоящий markdown-заголовок).
- Четыре остальных дивайдера (`s10`, `s35`, `s43`, `s52`) открываются
  строкой `# N. Название раздела` — получают золото. `s28` открывался
  строкой `**Генератор разобран. Теперь — модель, которая не создаёт, а
  судит.**` — жирный абзац без `#` — попадал в ветку `"para"`, золота не
  получал.

**Правка:** в
`library/lectures/lec-08/slides/s28-r0-kak-ustroeno-raspoznavanie.md`,
раздел «Видимый текст слайда», первая строка переведена из жирного
абзаца в markdown-заголовок (`**...**` → `# ...`), сам текст фразы не
менялся. Рендер уже делает `kind=="head"` полужирным — двойного
выделения нет.
