# Лекция 5 — EN-паритет: что именно надо сделать (issue #212)

Спецификация оркестратора для EN-фазы. Собрана из фактического состояния
репозитория, а не из плана: состав RU-деки взят из константы `ORDER` в
`rendered/build_lec05.py`, состав EN — из `rendered/build_lec05_en.py` и
`slides-en/`.

**EN-паритет здесь — не перевод, а пересборка деки.** Это главное, что надо
понять до начала: RU-дека за Этап 6 сменила состав, а не только формулировки.

Самые крупные: s45a (1147), s13a (1145), s38a (1082), s31a (1051), s24b (1047).

## 4. Терминология

`glossary.en.yaml` перевыпущен 2026-10-03 под нынешний RU-канон (34 понятия
1:1). Переводчики обязаны следовать ему.

**Девять канонов не выбраны** — помечены `needs_owner_confirmation`, до решения
владельца действует **первый** вариант, последовательно, без смешения внутри
одной деки: golden set / reference dataset · autonomy scale / agency ladder ·
decision metric / primary metric · cost per token / cost per request ·
portfolio governance / portfolio management · failure drill / game day ·
the loop / the feedback loop · LLM-as-judge / LLM-as-a-judge · stop gate /
release gate.

Ловушка, названная в самом замке: имена, которые по-русски транслитерированы, в
английском **восстанавливаются к оригиналу**, а не транслитерируются обратно.
Дороже всего Уильям Деминг → **W. Edwards Deming**, не «William Deming».

Anti-anglicism-мандат к EN-артефактам **не применяется** — английский здесь
целевой язык. Обратная проверка применяется: непереведённых русских фрагментов
в EN быть не должно.

## 5. Порядок работ

1. **Дождаться закрытия RU-литправки** — иначе переводим текст, который ещё
   изменится. (Блокирует всё остальное.)
2. Перевод 21 `.md` → `slides-en/`, волнами по 3-4 агента; удалить 18 устаревших.
3. `check_point` в `_helpers_en.py`; затем `slides_band5_en.py` и
   `slides_band6_en.py`; затем s14a/s36c в band2_en/band3_en.
4. Переписать список сборки в `build_lec05_en.py` под RU `ORDER`.
5. `deck.en.yaml` + `deck-part2.en.yaml` — привести состав и `totals` к новым 56;
   снять предупреждение «EN SYNC PENDING (issue #212, phase F5)» из шапки
   `deck.en.yaml`, когда оно перестанет быть правдой.
6. `speech.en.md` / `speech-part2.en.md`.
7. Рендер: `rendered/render_en.sh` (путь починен — был зашит на чужой worktree).
8. Сверка RU↔EN: ни одного пропущенного слайда, ни одного русского фрагмента в
   EN, цифры и факты не потеряны при переводе.

решит иначе, это отдельная задача другого порядка величины.
