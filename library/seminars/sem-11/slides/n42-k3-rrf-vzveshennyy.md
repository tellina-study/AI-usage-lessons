# Как вес меняет победителя внутри той же формулы

## Assertion

Та же сумма очков из двух списков — только теперь один список взвешен сильнее другого. Смена веса может перевернуть порядок, даже если места в списках не изменились ни на одну позицию.

## Visual

> **Принцип словами.** В равном RRF очко документа из каждого списка весит одинаково. Во взвешенном — очко из списка по словам умножается на `w`, очко из списка по смыслу — на `1−w`, и только потом складываются. Чем больше `w`, тем сильнее тянет список по словам.

| Кандидат | Место по словам | Место по смыслу | Победитель при w=0,5 (поровну) | Победитель при w=0,75 (перекос к словам) |
|---|---|---|---|---|
| Кандидат А | 1-е | 5-е | — | **победил** |
| Кандидат Б | 4-е | 1-е | **победил** | — |

> Места кандидатов не изменились ни на одну позицию между двумя столбцами. Победителя поменял только вес.

## Speaker notes

Формула слияния — та же самая, что уже звучала на этом занятии: очко документа в каждом списке — единица, делённая на сумму константы и места, очки из обоих списков складываются, и наверх выходит документ с наибольшей суммой. Взвешенная версия добавляет к этой сумме один множитель: очко из списка по словам теперь умножается на вес `w`, очко из списка по смыслу — на остаток, единицу минус `w`. При равном весе, ноль целых пять десятых на каждую сторону, это ничем не отличается от обычного RRF — множитель просто не меняет баланс.

Два кандидата на кадре — учебный, придуманный пример; настоящий корпус появится дальше. Кандидат А стоит первым в списке по словам и только пятым в списке по смыслу: сильный сигнал по буквальному совпадению, слабый — по смыслу. Кандидат Б — наоборот, четвёртый по словам и первый по смыслу. При равном весе побеждает Б: его сильная первая позиция по смыслу перевешивает слабую четвёртую позицию по словам. Арифметика здесь честная: разрыв между двумя суммами небольшой, именно так обычно и выглядит реальное объединение.

Теперь сдвинем вес в сторону слов — три четверти голоса списку по словам, одна четверть списку по смыслу. Ни одно место в исходных списках не изменилось: кандидат А по-прежнему первый по словам и пятый по смыслу, кандидат Б по-прежнему четвёртый и первый. Но сумма очков теперь считается по-другому, и побеждает уже кандидат А — его сильная первая позиция по словам при таком весе перевешивает слабую позицию Б по словам.

Это и есть вся механика, которую дальше измеряет кейс: источник веса (откуда берётся число `w` для каждого конкретного вопроса) определяет, какой из двух кандидатов окажется первым, даже когда оба списка-источника остаются абсолютно теми же. Формула сама работает всегда одинаково — вопрос в том, откуда берётся число, которое в неё подставляют. Дальше — структура замера: то же самое проверяется на пятидесяти настоящих вопросах.
