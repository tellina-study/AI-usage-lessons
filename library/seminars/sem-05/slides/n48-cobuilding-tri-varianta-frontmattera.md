# Три варианта фронтматтера подряд

## Assertion

Три варианта фронтматтера подряд: без него описанием становится заголовок, с общей фразой скилл виден но не сработает, рабочий — три части в третьем лице.

## Visual

| Вариант | Что при этом происходит |
|---|---|
| фронтматтера нет вовсе | описанием становится первая непустая строка — заголовок `# deploy`, буквальный дубль имени. Срабатывание по смыслу невозможно; при этом прямой вызов `/deploy` работает, поэтому автор ничего не замечает |
| `description: Помогает с деплоем` | буквальный перевод официально запрещённой формулировки. Поле не пустое, фронтматтер годный, скилл виден с осмысленным на первый взгляд текстом — но не сказано **когда** и не сказано **когда не** |
| **рабочий: три части, третье лицо** | **сказано что делает, сказано по каким словам звать и сказано, для чего он не предназначен. Всё три — в одном поле, ключевой случай первым** |

```
официальные примеры «как не надо», дословно:

description: Helps with documents      → «помогает с документами»
description: Processes data            → «обрабатывает данные»
description: Does stuff with files     → «делает что-то с файлами»

официально одобренный, для сравнения:

description: Extract text and tables from PDF files, fill forms, merge
  documents. Use when working with PDF files or when the user mentions
  PDFs, forms, or document extraction.
```

```
.claude/skills/deploy/SKILL.md

---
name: deploy
description: Деплоит лендинг signup-landing на прод — сборка, smoke-тест
  формы, публикация, проверка прод-URL. Используй, когда пользователь
  просит задеплоить, выкатить или опубликовать сайт — не для обычных
  правок кода без деплоя.
---
```

## Speaker notes

Три варианта подряд, и ломаются они по-разному — в этом весь смысл показывать все три.

Первый: фронтматтера нет. Описанием становится первая непустая строка, а это заголовок. Ровно то, что мы видели на экране двенадцать раз. Коварство здесь в том, что прямой вызов через слэш продолжает работать — автор пробует, всё хорошо, и не узнаёт, что автоматически скилл не откроется никогда.

Второй: описание есть, но общее. «Помогает с деплоем» — это буквальный перевод формулировки, которая прямо приведена в документации примером «как не надо». Смотрите на карточку: три запрещённых примера, все три одинаково устроены — глагол плюс расплывчатое существительное. Поле не пустое, файл годный, а триггера нет: не сказано, когда звать, и не сказано, когда не звать.

Рядом — одобренный официальный пример для сравнения. Обратите внимание на его устройство: сначала конкретные действия, потом «используй, когда…» с настоящими словами запроса.

Третий вариант — наш, и собираем мы его именно по этому шаблону. Первое предложение: что делает, третьим лицом, без «я» и «вы». Второе: по каким словам звать — задеплоить, выкатить, опубликовать. И явное «не для обычных правок кода без деплоя».

Если зал предложит свои формулировки — берите их, порядок частей важнее слов.

Проверять потом надо в обе стороны: просим выкатить сайт — должен открыться; просим поправить опечатку в вёрстке — открываться не должен.
