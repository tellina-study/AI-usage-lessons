# Порядок снятия — Семинар 9

Материала **113 минут**, слот по умолчанию **90**. Снять нужно ≈23 минуты. Решение по слоту —
за владельцем; этот файл называет порядок заранее, чтобы на занятии его не выбирали на ходу.

## Чего снимать нельзя

- **Такт вопроса ни у одного кейса.** Голосование — не украшение: без него разбор превращается
  в лекцию, а занятие в монолог (цена пропуска замерена на Лекции 6 — 73 минуты одним голосом).
- **Такт границы** (`criteria_checklist_and_boundary`). Правило А7: граница предъявляется прямой
  формой, иначе кейс учит доверию вместо суждения.
- **n61 Кейса 5** — буквальный шов с С8. Если снимать Кейс 5 целиком (а его снимать нельзя),
  рвётся единственная измеренная перекличка между занятиями.
- **Введение и закрытие.** n04 открывает ось пустой таблицей, n76 закрывает её заполненной;
  n77 задаёт вопрос занятия дословно второй раз. Снятие любого из трёх оставляет ось без
  замыкания — болезнь §4.1 №4 канона.

## Если слот окажется больше 90

читается всё без снятия, с запасом ≈7 минут на вопросы зала.
