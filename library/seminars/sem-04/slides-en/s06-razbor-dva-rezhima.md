# Two types of decision, two different costs of getting it wrong

## Assertion

Both modes work — the question is which type of decision they are applied to: what is specific to the project waits for a signal, universal hygiene is set up right away.

## Visual

Two blocks side by side:

| Specific to the project — wait for a signal | Universal hygiene — set up on day 0 |
|---|---|
| repository overview | readiness gate |
| nested convention files | tracking of tasks and decisions |
| complex, multi-level memory | |

At the bottom — the demarcation:

> "Lecture 3 was about a thin agent — about refusing structural complexity: subagents, skills, external access. There a signal is required. Universal hygiene is a different category: here 'wait until it hurts' works against you."

## Speaker notes

"There is no single correct mode — there are two types of decision with different costs of getting it wrong.

The first type is what is specific to the project. Whether you will need it in this particular place cannot be known in advance: the answer depends on the specific repository. An overview of the structure, nested convention files, multi-level memory — these belong here. Waiting for a real signal here is not laziness but normal engineering practice: while there is no signal, there is nothing to write down.

The second type is universal hygiene. Setting it up is cheap, and the cost of not having it is unpredictable: you do not know at what moment it will be needed or what will have been lost by then. A readiness gate, tracking of tasks and decisions — these belong here. The signal here may never come: the shortfall shows up after the fact, not as one explicit event.

Separately — so as not to mix this up with Lecture 3. The thesis about a thin agent was about structural complexity: subagents, skills, external access. It still holds and still requires a signal. Universal hygiene is a different class of decision.

Six decision points lie ahead of us in the project. Which type each one belongs to we decide as we go, on the spot."
