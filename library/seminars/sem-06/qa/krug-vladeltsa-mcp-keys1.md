# Круг правок владельца — кейс 1 блока MCP («данных нет в репозитории») + база ступени

## По каждому замечанию

**1. «Нет разбора MCP, что это такое и как работает, описание MCP-сервера».**

Было: `n08` — одна таблица трёх примитивов («кто инициирует»), без разбора самого механизма и без
описания сервера.

Стало: `n08` оставлен коротким намеренно (словарь примитивов, та же таблица) и сразу за ним
вставлен новый слайд `n08a` — одностраничник, который и есть полноценный разбор: протокол, сервер
(отдельная программа, `stdio`-локальный процесс или `http`-удалённый сервис, кто его запускает),
что происходит при подключении (клиент сам спрашивает `tools/list`/`prompts/list`/`resources/list`,
без участия модели), что — при вызове (полное имя `mcp__<сервер>__<инструмент>` + аргументы), что
из этого попадает в контекст и чего это стоит (имена и инструкции сразу, схема — по требованию),
чем отвечает сервер (отдельный канал результата, подпись именем сервера в выводе). Источник —
`sem-05/research/mechanics-5-mcp.md` §1.1/§1.4/§2.1–§2.4, не выдумано.

**2. Выбор API / удалённый MCP / свой сервер в первом кейсе.**

Было: вопрос `n09` спрашивал «что проверить до подключения официального сервера» (пять карточек —
ничего/звёзды/токены/права/команда), разбор `n10` выводил порядок трёх проверок.

Стало: вопрос и разбор переставлены на выбор способа доступа, дословно по трём обязательным
вариантам владельца плюс два для полноты:

`вызвать API напрямую` · `подключить чужой сервер — удалённо` · `подключить чужой сервер —
локально` · `написать свой сервер` · `обойтись разовой командой`

Разбор `n10` (форма А7 не тронута) прямо называет, почему для ЭТОГО кейса (регулярный доступ
нескольких сессий к общему трекеру) разовая команда и свой сервер отпадают, прямой API не
масштабируется на такую частоту — и **прямо говорит, что между «удалённо» и «локально» оба
варианта законны**: свежий официальный пример для GitHub сейчас — удалённый http-сервис
(`mechanics-5-mcp.md` §1.6), а решение этого занятия — локальный процесс, потому что конфигурация
становится кодом в репозитории. Это не придуманное противопоставление — источник прямо пишет, что
стоит проговорить смену официального транспорта на занятии как живой пример.

Прежние карточки не потеряны без следа: «права» — со-сборка (`n11`/`n12`, не трогал), «токены» —
цена в контексте (`n14`, не трогал, и уже предвосхищена блоком 5 `n08a`), «официальность не
гарантирует поведение» — вошла ограничением строки «удалённо»; «звёзды сервера» как самостоятельный
критерий снят — он меньше всего работал на новый вопрос, и владелец не называл его в списке.

**4. Одностраничник по MCP.**

Решён тем же слайдом `n08a`. Рисовалка — функция в `rendered/make_figures_mcp.py` (секция

Настоящий PNG (`rendered/figures/mcp-n08a-mehanizm.png`) посмотрен и поправлен трижды до
текущего вида:
1. первая версия (сетка «2 колонки × 2 строки + 2 строки во всю ширину», холст 1600×992) имела
   наложение подписи на последнюю строку блока 1 — почи́нено увеличением высоты строки;
2. золотой акцент в первой версии был только текстом тёмного оттенка, не настоящим золотом —
   заменён на золотую плашку-рамку у блока 5 («золото не реже раза»);
3. **самое существенное** — при реальной сборке слайда (`build_sem06.py --block n08`, не просто
   просмотр PNG отдельно) приём `mechanics_with_figure` выдал предупреждение «СХЕМА ЗАЖАТА»: у

   выше порога). После починки `build_sem06.py` больше не выдаёт «СХЕМА ЗАЖАТА», схема встаёт на
   слайд во всю ширину — проверено повторным `qa_preview.py` на уже собранном слайде, не на
   отдельном файле схемы.

Красного в схеме нет.
