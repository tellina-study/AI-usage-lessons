# Он ничего не спросил

## Assertion

Агент не задал ни одного уточняющего вопроса — всё, чего он не знал, он решил за вас молча.

## Visual

Верхняя карточка — дословная цитата из захваченного диалога, крупно:

> «Уточняющий вопрос не задавался. Все параметры задачи… были однозначно выводимы из текста задачи, поэтому работа была начата сразу, без уточнений.»

Ниже слева — что он создал, ровно четыре строки:

```
index.html
src/main.js
package.json
tests/form.spec.ts
```

Ниже справа — блок команд из его же финального ответа:

```
npm install
npm run build          # → dist/
npm run test:e2e       # playwright test
```

Нижней полосой — его собственная фраза из отчёта, подсвеченная gold: **«Все 4 прогнал и они зелёные»**, с пометкой «запомните эту строку».

## Speaker notes

Агент собрал `index.html`, `src/main.js`, `package.json` и `tests/form.spec.ts`, прописал в `package.json` именованные скрипты сборки и теста, сам написал четыре теста вместо одного заказанного — и не задал ни одного уточняющего вопроса. Его собственную формулировку стоит процитировать дословно, она на экране.

Дальше — поворот, ради которого раздел и существует:

«Он ничего не спросил — и прямо написал почему: всё было выводимо из текста задачи. Заманчиво прочитать это как "значит, ему всё было понятно". Прочитайте иначе: всё, чего он не знал, он решил за вас — молча. Имя тестового скрипта, структуру файлов, формат отправки формы, сколько тестов написать. По каждому из этих решений он не ошибся — но и не спросил.

И посмотрите на арифметику. Из шести требований, которые вы только что назвали, в его контексте было три — те самые, которые видно в коде. Про остальные три — что считается "готово", чего нельзя делать без спроса, как убедиться, что заявка дошла, — он не знал ничего. И это его не остановило.

Обратите внимание на последнюю фразу его отчёта: "все четыре прогнал, и они зелёные". Запомните её. Мы вернёмся к ней в последнем разделе.»

Мысль, которую надо оставить в зале до конца занятия: настоящая боль не в том, что агент переспрашивает, а в том, что он не переспрашивает. Молчаливое решение стоит дороже вопроса, потому что вопрос виден, а решение — нет.
