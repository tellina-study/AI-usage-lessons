Consumer-тарифы обучаются на ваших данных по умолчанию. Samsung 2023 — 3 утечки за месяц.

**Две колонки (comparison):**

**Consumer-тарифы (по умолчанию):**
- ChatGPT Free / Plus → данные используются для обучения
- Claude → spaшивает с сентября 2025 (5 лет хранения при согласии)

**Enterprise / API-тарифы:**
- OpenAI Enterprise / Business / API (с марта 2023) → НЕ обучаются
- Anthropic Business → НЕ обучаются
- Google Workspace / Vertex AI → НЕ обучаются
- ZDR (Zero Data Retention) — провайдер не сохраняет вообще

## Speaker notes

Когда вы пишете запрос в облачный AI-сервис, ваш текст — а часто и приложенные файлы, изображения, голосовые — отправляется на серверы провайдера. Что с ними происходит дальше, зависит от тарифа.

**Здесь полезнее академическое определение AI** из §1.1: модель действует «рационально для достижения целей при имеющихся данных и ограничениях» — но и сами данные становятся ограничением, потому что не возвращаются к пользователю в неизменном виде. Цели провайдера и пользователя могут расходиться, и это инженерный риск.

**Consumer-тарифы (free и стандартные платные):**
- OpenAI ChatGPT Free и Plus используют пользовательские данные для дообучения по умолчанию; пользователь может отключить, но опция требует осознанного действия.
- Anthropic Claude с сентября 2025 спрашивает пользователя; при согласии — 5 лет хранения.
- Google Gemini в потребительских тарифах использует данные для обучения по умолчанию; часть переписки выборочно ревьюируется людьми и хранится до 3 лет (с обезличиванием).

**Enterprise- и API-тарифы**: OpenAI Enterprise, ChatGPT Business, OpenAI API (с марта 2023), Anthropic для бизнеса, Google Workspace, Google Cloud Vertex AI — данные **не используются** для обучения базовых моделей. Доступны соглашения **Zero Data Retention** (ZDR). Стандартом становится SOC 2, шифрование at rest и in transit.

**Канонический инцидент Samsung** (Bloomberg 2023): март-апрель 2023, инженеры полупроводникового подразделения в 3 эпизодах загрузили в consumer-ChatGPT проприетарный код, транскрипт корпоративного совещания и тестовые последовательности для отладки чипов. Поскольку consumer-ChatGPT на тот момент использовал данные для обучения по умолчанию, корпоративные секреты попали в датасет OpenAI. Реакция Samsung: запрет внешних генеративных AI + временный лимит 1024 байта на промпт. Через год запрет частично снят после внедрения внутренних AI и политики использования.

**Альтернатива — локальное развёртывание** (Llama 4, Mistral, DeepSeek-R1) через Ollama / LM Studio / vLLM. Устраняет утечку, но добавляет затрат: GPU, обновления, поддержка. **Breakeven** ~100K запросов/день — ориентировочно (зависит от модели, региона, тарифа).

**Регуляторика**: EU AI Act 2024/1689, постепенный ввод с 2024. **Стандартный tier — до 15M EUR / 3% мирового оборота**. **Верхний tier за prohibited practices** (social scoring, real-time биометрика в общественных местах) — до **35M EUR / 7%** (P2 ревизия — добавлено в s20). NIST AI RMF (добровольный). Российское регулирование AI на 2026 год — в стадии формирования.

**Практический вывод:** никогда не загружайте конфиденциальные данные в consumer-AI без явной проверки политики использования данных конкретного тарифа на момент использования.
