# Когда роли ещё нет, а когда она не нужна вовсе

## Assertion

Роли ещё нет, пока проверка разовая или задача не держит устойчивую форму. Роль не нужна вовсе, если критерий кодируется детерминированно — тогда естественное место для него хук или проверка в CI.

## Visual

| Роли ещё нет | Роль не нужна вовсе |

| разовая проверка — делегируйте встроенным субагентом, файл не нужен | критерий кодируется детерминированно (линтер, тест, скрипт) — не нужен ни субагент, ни модель вообще |
| задача формулируется заново каждый раз без устойчивой формы — роли ещё нет, есть обычная работа | естественное место для такой проверки — хук на входе или прогон в CI, не роль, которую нужно формулировать словами и потом поддерживать |
| «независимость» объявлена, но не проверена — если ревьюер на деле видит рассуждения автора, объявления недостаточно | — |

Обещанная проверка, на материале самого курса. **14** ролей в каталоге `.claude/agents/` · **13** не объявляют прав вовсе и потому имеют все · **1** объявила и не запустилась · работающих урезаний — **0 из 14**. Среди тринадцати есть роли, чья работа — только оценивать материал: право его править у них тоже есть.

> **Кастомная роль — решаем, по сигналу повторения. Интуиция говорила: чтобы поручить проверку отдельному агенту, нужно завести файл и настроить его. Проверка показала: делегировать можно без единой строки конфигурации, это уже бесплатно; заводить стоило роль с урезанным списком инструментов, само делегирование заводить не требовалось — и даже это урезание держится на синтаксисе настолько буквально, что одна неверная строка не ослабляет права — не даёт роли запуститься вовсе.**

## Speaker notes

Когда роль ещё не нужна. Разовая проверка — делегируйте встроенным агентом, файл не нужен. Задача формулируется заново каждый раз без устойчивой формы — роли ещё нет, есть обычная работа. «Независимость» объявлена, но не проверена — если ревьюер видит рассуждения автора, объявления недостаточно.

Когда роль не нужна вовсе. Критерий кодируется детерминированно — линтером, тестом, скриптом: не нужен ни субагент, ни модель. Место такой проверки — хук или прогон в CI.

Теперь обещанное. В каталоге ролей этого курса четырнадцать файлов. Тринадцать не задают поле со списком инструментов вовсе и потому имеют все инструменты, включая правку. Четырнадцатая — единственная, кто попытался, — не запускается. Работающих урезаний ноль из четырнадцати — в репозитории, по которому собрано это занятие. И среди этих тринадцати есть роли, чья работа — только оценивать материал.

Кастомная роль — решаем, по сигналу повторения. Интуиция говорила: чтобы поручить проверку отдельному агенту, нужно завести файл и настроить его. Проверка показала: делегировать можно без единой строки конфигурации, это уже бесплатно; заводить стоило роль с урезанным списком инструментов, само делегирование заводить не требовалось — и даже это урезание держится на синтаксисе настолько буквально, что одна неверная строка не ослабляет права — не даёт роли запуститься вовсе.

Если спросят, почему курс сам этого не делает: прямого ответа у меня нет — честный пробел называется вслух, не объясняется в оправдание. Открытый вопрос курса об этом зарегистрирован отдельно; если он закрыт до занятия, у этого места есть более сильная версия — различие между «было» и «стало» в одном и том же репозитории.

Если спросят, насколько это серьёзно: зависит от того, что именно критикующая роль делает с файлом, который пришла оценивать — технически возможность есть, использование не задокументировано ни в одну сторону.

Если спросят про цифры точнее: четырнадцать файлов всего, тринадцать совсем без поля, один — с полем, которое не работает; проверить обеими командами можно прямо на занятии.
