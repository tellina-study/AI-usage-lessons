# Разминка

## Assertion

Пять шагов вместо одного — какой критерий бьёт сильнее всего?

## Visual

Одна широкая gold-обведённая callout-карточка (иконка `help-circle`, DEEP), текст по центру крупным шрифтом: «Если задача требует пять шагов между запросом и ответом вместо одного — по какому из четырёх критериев это бьёт сильнее всего?». Внизу карточки — нейтральная (не gold) подсказка мелким курсивом: «Быстрый устный ответ всей аудиторией, без голосования поднятием руки».

## Speaker notes

Один быстрый вопрос всей аудитории, не для оценки, а для разогрева: если задача требует пять шагов между запросом и ответом вместо одного — по какому из четырёх критериев это бьёт сильнее всего?

Ожидаем ответ «шаги» или «контроль» — оба принимаются с кратким комментарием, не задерживаемся. Это разминка перед первым полноценным кейсом с голосованием по всем шести ступеням лестницы.
