# Where to put each piece

## Assertion

Where to put each of the two pieces of knowledge so that the agent gets it when it is needed and does not pay for it in the other sessions — a choice among five cards, more than one allowed.

## Visual

The question verbatim, in a gold frame:

> "In front of you are two pieces of knowledge: a convention for the whole `tests/` folder and a detail about a single function in `src/main.js`. Pick from the cards where to put each of them, so that the agent gets it when it is needed and does not pay for it in the other sessions."

One line below, in the same size:

> More than one card may be picked, and the two pieces of knowledge may be split across different cards.

Below — five option cards, visually equal:

`a nested instruction file in the folder itself` · `a rule with a declared path pattern in a shared rules directory` · `a comment next to the code itself` · `a separate document plus a pointer line in the root file` · `append it to the root instruction file`

Not a single number, no reference to a source. The slide carries no breakdown table and no target answer — those are on the following slides.

## Speaker notes

A pause, 2–3 voices — with not a single number on screen.

Say this before the vote, not after: more than one card may be picked, and the two pieces of knowledge may be split across different cards — the question does not call for one answer covering both.

Every option voiced is recorded the same way, including "I'll just drop it in somewhere and be done": "Noted, we'll come back to this in a minute."
