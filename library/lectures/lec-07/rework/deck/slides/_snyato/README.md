# Кадры, снятые при сведении деки к слоту

Дека шла 100,15 минуты при норме слота 75. Рез снимал **конспект лекции о самой себе** —
своды о сводах, карты, сопоставления и повторы внутри «Сборки». Ни один разбор не снят: все
восемнадцать пар «Пример N» / «Пример N, цена» на месте, все измеренные величины со своими
знаменателями тоже.

Файлы оставлены, а не удалены: формулировки отсюда будут нужны — часть содержания уехала на
соседние кадры, и смотреть, что именно уехало, надо по исходнику. Ссылаться на них честнее по
пути, который не выглядит действующим.

**Нумерация выживших кадров не поехала.** Снятый номер не переиспользуется: на идентификаторы
ссылаются манифесты, разборы прожарок и другие агенты.

## Восемь карт стадии → одна накопительная в «Сборке» (`s101`)

Сетка «задача × модальность» может занять за всю лекцию **четыре клетки** (`chapter.md` §0.10,
`chapter-part5b.md` §11.6). Последовательность шла 3 → 4 → 4 → 4 → 4 → 4 → 4 → 4 и не
заполнялась; у пяти карт из восьми занята **одна клетка из двенадцати** при курсовом пороге
заполнения 75%. Чинится это не раскладкой. Что в них было ценно — **восемь клеток, в которые
за восемь разделов не зашёл никто** — предъявлено на одной карте, и там это сильнее.

| кадр | причина |
|---|---|
| `s21-karta-stadii-otbor` | 3 клетки из 12; карта заведена и сразу не заполняется |
| `s34-karta-stadii-analiz` | добавила одну клетку к трём — 4 из 12, и дальше карта не растёт |
| `s51-karta-stadii-diagnoz` | ни одной новой клетки: разборы легли туда, где уже стояли прежние разделы |
| `s60aa-karta-stadii-nablyudenie` | ни одной новой клетки |
| `s64a-karta-stadii-vedenie-zapisi` | ни одной новой клетки |
| `s73a-karta-stadii-chem-uderzhivayut` | ни одной новой клетки |
| `s87a-karta-stadii-lekarstvo` | ни одной новой клетки; занятое место лежит вне окна сетки |
| `s96-karta-stadii-navyk` | итоговая карта; её работу делает `s101`, стоящий в «Сборке», а не в середине раздела |

## Восемь сопоставлений «Без модели и с моделью» → в заземление и свод стадии

Правая половина сопоставления — в какие шаги вошла модель — переехала строкой на кадр
заземления, рядом с перечнем действий стадии, которому она и отвечает. Левая половина
повторяла тот же перечень. «Три места, где не работает» стояли на своде стадии **почти
дословно**: у `s27` и `s33` все три совпадают, у `s55a` и `s60a` все три, у `s60d` и `s64` все
три. Измеренные величины, которые жили только здесь, перенесены: 11,7 против 3,6 процента
измерений — на `s23`; 35,7 → 26,2 из ста — на `s50`.

| кадр | причина |
|---|---|
| `s14a-bez-modeli-i-s-modelyu` | «что не получается» повторено сводом `s20`; счёт «три шага из семи» при четырёх шагах в теле |
| `s27-bez-modeli-i-s-modelyu-analiz` | все три «места, где не работает» стоят на своде `s33` |
| `s39-bez-modeli-i-s-modelyu-diagnoz` | независимость, избирательность, объяснимость — все три на своде `s50` |
| `s55a-bez-modeli-i-s-modelyu-nablyudenie` | все три на своде `s60a` |
| `s60d-bez-modeli-i-s-modelyu-zapis` | все три на своде `s64` |
| `s66a-bez-modeli-i-s-modelyu-uderzhanie` | «модель не вошла ни в одно действие» перенесено на заземление `s66`, остальное — на своде `s73` |
| `s79-bez-modeli-i-s-modelyu` | «четыре работы, где не работает» стоят на своде `s87`; счёт «один шаг из восьми» при двух в теле |
| `s91a-bez-modeli-i-s-modelyu-osmotr` | все три на своде `s95a`; счёт «один шаг из восьми» при двух в теле |

## Повторы внутри блоков

| кадр | причина |
|---|---|
| `s25-vernye-trevogi-v-dvukh-gruppakh` | счёт и его итог сведены на один кадр `s24`: разряд 8 против 79 и три способа поднять долю стоят теперь рядом с самой арифметикой, а не через кадр от неё |
| `s72-otzyvy-i-reestr` | второй подряд обзор надзора без формы разбора; отзывы, реестр и три механизма сведены на `s71` |
| `s95-potok-resheniya-do-i-posle` | три строки, все три уже стоят в блоке «что стало с работой» свода `s95a` |
| `s100-chto-my-voobshche-izmeryali` | лестница разрядов замера разнесена по месту применения: «исхода пациента нет ни у одного разбора ядра» — на `s102`, разряд под каждой ступенью участия — на `s103`, правило «на точности корпуса нельзя утверждать вред пациенту» — на `s99` |
