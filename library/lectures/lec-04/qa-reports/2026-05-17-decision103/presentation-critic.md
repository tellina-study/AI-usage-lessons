## По слайдам

### Slide s22a — «AI-slop как DDoS на внимание сопровождающих»
**Severity:** P2 (watch-item, не блокирует)
**Issue:** На gold-коннекторе оси асимметрии видим токен «× 1000+».
Формально это числовой токен на видимом слое. По существу — conceptual
order-of-magnitude самой оси асимметрии (core concept слайда: стоимость
генерации vs опровержения), зеркалит словесную формулировку «дешевеет в
тысячи раз» в вывод-плашке. Это НЕ волатильный вендор-стат (volatile-доли
×8/<5%/дата корректно в [FACT-CHECK] notes). Решение #100 («volatile —
только направление») по существу соблюдено: ось — это и есть преподаваемая
структура, а не метрика, которая устареет.
**Recommendation:** Принять как есть (axis-label концепта). Если
оркестратор/владелец хочет максимальной строгости видимого слоя — заменить
«× 1000+» на «×1000+ разрыв» → словесно «в тысячи раз» / «×разрыв» без
цифры. Не обязательно для показа; фиксирую для осведомлённости (No Extra
Content Rule — не правлю сам).
**Visual evidence:** PNG page 24 — gold-коннектор между двумя колонками
оси, текст «× 1000+» над словом «разрыв». Семантически работает как ось
асимметрии секунды↔часы (точно то, что требует бриф для gold-элемента).
