# Зачем субагенту отдельное контекстное окно

Контекстное окно — это ограниченное количество токенов, доступных LLM за один раз. Когда субагент получает **отдельное контекстное окно** (вместо встраивания в родительскую сессию), это даёт несколько практических преимуществ:

## Фокусировка на задаче

Субагент начинает с контекста конкретной задачи, без истории всей предыдущей работы. Если родитель обрабатывал 10 чтений файлов и 5 обсуждений, субагент видит только свой бриф. Это экономит токены и снижает шум.

## Параллелизм

Несколько субагентов могут работать одновременно, каждый имея собственный контекст. Если все они писали в одно окно родителя, им пришлось бы ждать очереди и конкурировать за токены.

## Свежесть памяти

После долгой сессии родитель может забыть детали из начала работы. Субагент с чистым окном лучше вспоминает контекст из только что полученного бриффа — нет «стирания» старой информации новой.

## Гибкость выбора моделей

Родитель может отправить разные задачи субагентам на разных моделях (Sonnet для контента, Haiku для механики). Каждый субагент использует свою оптимальную сумму токенов для своей задачи, не загромождая окно всем оборудованием одновременно.

**Компромисс:** теряется контекст из сессии родителя. Результаты субагента нужно явно собрать и передать обратно — это не происходит автоматически.
