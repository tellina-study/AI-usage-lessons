## 3. Структурные правила deck v3

### 3.1 Speaker notes — читаемый текст (#1)
- Каждый slide → 150-300 слов связного текста для студента (на основе §chapter v3.1 + speech-фрагмента).
- В конце notes — отдельный блок **«Лектору»** с pacing markers, fallback phrases, interactive cues.

### 3.2 Заголовки = hooks/topics (#3, #8 + cross-cutting)
- Каждый title раскрывает суть до прочтения.
- 0 «Тут должен быть хук», 0 «Worked example», 0 insider phrasing.

### 3.3 Никаких footer-tax (#21)
- 0 «Demo:», «Код:», «методичка §X», «Backup:», «Refs:».
- Ссылки на assets — в speaker notes.

### 3.4 Промежуточные dividers (#7, #10)
- 4 dividers всего: s10 (Раздел 3 entry), s14 (mini-divider «разберём подробнее»), s22 (Раздел 4 entry — теперь оформлен как divider), s30 (часть finale).
- Каждый divider — короткий (0.5-1 min), с маркером «Вы здесь» (Раздел N из 5).

### 3.5 5 новых схем (содержательные)
1. **s12 классификатор** — 2D диаграмма «задача × модальность» с примерами в ячейках.
2. **s13 квадрант контроля 3 способов** — 2×2 (X: контроль разработчика, Y: контроль пользователя), 3 точки (Модель / Чат / Агент) + задача снизу.
3. **s15 модель — схема инференса** — 5 блоков по горизонтали (Сырой вход → Препроцессинг → Модель → Постпроцессинг → Выход) + 4 примера.
4. **s16 цикл чата** — 6-шаговая loop-схема (User → System prompt + Chat history → LLM → New message → Append → Show user → loop) + 2 callout (контроль через системный промпт / ограничение контекстного окна).
5. **s18 архитектура агента** — Chat + Orchestrator + Memory + Tools, decision loop стрелки.
6. **s21 чек-лист квадрант** — 2 вопроса крупно сверху + квадрант 2×2 крупно снизу с 4 типами в углах.
7. **s27 4 спикера AGI** — таблица 4×4 (Спикер | Аффилиация | Прогноз | Material stake).

### 3.6 0 неестественных англицизмов (#2)
Во всех assertions, titles, captions, speaker notes, speech.

### 3.7 Все ссылки на чек-лист (#12)
После переделки s21 — обновить mentions «чек-лист s18» → «чек-лист s21», «4 вопроса» → «2 вопроса + квадрант» в speech и других slides.

### 3.8 Slide for slide-deck visual style
- Палитра LOCKED (Ocean Gradient, Teal, Gold).
- Visual motif Ocean rounded box на каждом content slide.
- Cover (s02) distinct.
- Dividers — minimalist (большое название раздела + roadmap-bar внизу).
