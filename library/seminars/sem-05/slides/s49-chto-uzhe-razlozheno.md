# Что за час стало проверяемым

## Assertion

Три карточки из пяти теперь раскладываются по артефакту, который можно открыть и проверить; две не раскладываются ничем — их ступени впереди.

## Visual

> Три карточки из пяти раскладываются теперь не по ощущению, а по артефакту: его можно открыть и проверить командой. Две не раскладываются ничем.

> «Две нижние строки сегодня не проверены ничем: занятие не сказало про них ничего, кроме того, что их ступени впереди. Делать вид, что сказало, мы не будем.»

## Speaker notes

Показать асимметрию, а не пересказать схему.

По трём верхним есть артефакт и команда: хук — файл в ветке и самотест, который печатает свои отказы; скилл — описание-триггер, по которому идёт выбор; доступ наружу — список прав, из которого лишнее вычеркнуто.

По двум нижним нет ни артефакта, ни команды, ни сигнала. Это не «пока не успели» — их ступени просто впереди.

Если на прошлом слайде кто-то из зала передвинул ответ на субагента или процесс, зафиксировать это и не опровергать: проверить его сегодня всё равно нечем, и это как раз то, с чем занятие заканчивается.
