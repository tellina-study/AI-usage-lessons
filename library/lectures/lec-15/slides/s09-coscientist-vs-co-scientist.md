# Coscientist (CMU 2023). Co-Scientist (DeepMind 2026). Не путайте.

## Coscientist (CMU, декабрь 2023)

**Кто.** Гэйб Гомеш и коллеги, Carnegie Mellon University.

**Где.** Nature, doi:10.1038/s41586-023-06792-0; Boiko et al., 2023.

**Архитектура.** Агентная система с GPT-4 **и Claude одновременно** в разных ролях. Использует инструменты — поиск литературы, расчёт стехиометрии, API роботизированной платформы Emerald Cloud Lab.

**Что делает.** Палладий-катализируемые реакции кросс-сочетания (Suzuki, Negishi). Это **классические** реакции синтетической химии, протоколы известны десятилетиями. Coscientist спланировал, подобрал условия, выполнил, проанализировал.

**Фаза цикла.** Design — планирование эксперимента для известной задачи. **Не открытие новой химии.**

## DeepMind Co-Scientist (Nature May 2026, [VFY-day-of])

**Кто.** Google DeepMind в сотрудничестве со Стэнфордом.

**Где.** Nature, май 2026 (статус verify к лекции).

**Архитектура.** **Multi-agent debate-and-rank.** Несколько LLM-агентов генерируют гипотезы, оценивают друг друга в дебатах, итоговая выбирается по ранжированию.

**Что делает.** Поиск терапевтических мишеней для фиброза печени (Стэнфорд).

**Фаза цикла.** Hypothesis — генерация гипотез. Слишком свежая для независимого аудита.

## Почему мы упоминаем Co-Scientist одной строкой

Статья мая 2026 — слишком свежая для аудита. Если будет отозвана, упоминание становится антипримером. Дебаты агентов — переосмысление рецензирования через AI, не научное открытие само по себе.

## Speaker notes

Здесь мы обязаны разграничить две системы с почти одинаковыми названиями, постоянно путаемые в популярной прессе.

Coscientist — это система Карнеги-Меллон Университета, разработанная под руководством Гэйба Гомеша, опубликованная в Nature в декабре 2023 года. Это управляемая LLM автономная лаборатория химии для задач планирования и выполнения синтеза. Архитектурно — агентная система, использующая GPT-4 и Claude одновременно, в режиме разных ролей агентов. Каждый агент может вызывать внешние инструменты: поиск литературы, расчёт стехиометрии, API роботизированной химической платформы Emerald Cloud Lab.

Что Coscientist умеет в 2023 году. Система выполнила палладий-катализируемые реакции кросс-сочетания — Suzuki, Negishi. Это классические реакции синтетической химии, для которых протоколы известны десятилетиями. Coscientist спланировал реакцию, подобрал условия на основе литературного поиска, выполнил синтез через облачную лабораторию, проанализировал спектры. С точки зрения химика-органика это демонстрация автоматизации известных протоколов, не открытие новой химии.

DeepMind Co-Scientist — через дефис, не путать — это система Google DeepMind, опубликованная в Nature в мае 2026 года, статус проверки к моменту лекции. Это архитектура дебатов и ранжирования нескольких агентов: несколько LLM-агентов генерируют гипотезы по заданной задаче, оценивают друг друга в раунде дебатов, и итоговая гипотеза выбирается по результатам ранжирования. Применение, заявленное в Nature, — сотрудничество со Стэнфордом по поиску терапевтических мишеней для фиброза печени.

Почему мы упоминаем Co-Scientist одной строкой, а не отдельным слайдом. Во-первых, статья вышла слишком свежей, чтобы независимый аудит дал нам данные для оценки. Во-вторых, есть структурный риск: если статья будет отозвана, упоминание становится антипримером. В-третьих, дебаты нескольких агентов как механизм — это переосмысление рецензирования через AI, а не научное открытие само по себе. Студенту полезнее увидеть Coscientist 2023, прошедший проверку временем, и понимать, что Co-Scientist — это инкрементальная итерация на ту же идею.
