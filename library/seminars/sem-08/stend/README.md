## Находка процесса: `waiting` ≠ обрыв

Статус `waiting` у execution многошаговой `Form` (узел `n8n-nodes-base.form`, `operation:
completion`) — это НЕ признак того, что данные не дошли. Вторая страница формы ждёт визита в
браузере; весь путь ДО неё (включая решение модели или `IF`-узла) выполняется полностью и
виден в `runData`. Прямое воспроизведение: `POST` на `formWaitingUrl` (адрес с подписью из
ответа на исходную отправку формы) переводит execution из `waiting` в `success` немедленно, без
повторного прогона (проверено на execution `41`). Полный разбор — `notes/mcp-limitations.md`
[#233-5].
