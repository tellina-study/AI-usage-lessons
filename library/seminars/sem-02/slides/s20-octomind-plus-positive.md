# Из жизни: фреймворк и класс задач для агента

## Assertion

Прямые вызовы API иногда дают больше контроля, чем абстракция, которая должна была его упростить.

## Visual

Две карточки. Левая (негатив): «Octomind — «Why we no longer use LangChain»» — более 12 месяцев LangChain в продакшене → отказ (17.06.2024): дебаг фреймворка дороже разработки фич, негибкие абстракции, сложно контролировать состояние агента → замена на прямые модульные вызовы LLM API. Правая (позитив): «Где агент необходим» — Deep Research-инструменты (поиск и синтез по многим источникам с уточнением запроса по ходу работы), coding-агенты (правка кода → запуск тестов → итерация по результату); в обоих случаях одного вызова физически недостаточно.

## Speaker notes

Негативный случай: Octomind — компания, разрабатывающая ИИ-агентов для end-to-end тестирования, — более 12 месяцев использовала фреймворк LangChain в продакшене, затем отказалась от него, пост от 17 июня 2024 года, парафраз, не дословные цитаты. Причины: негибкие абстракции фреймворка не подходили под их конкретный кейс, было сложно контролировать состояние агента, и в итоге команда тратила больше времени на дебаг самого фреймворка, чем на разработку фич продукта. Заменили модульными прямыми вызовами LLM API без фреймворка-посредника.

Открытый вопрос в зал: что здесь пошло не так?

Урок: популярность и удобство фреймворка на старте проекта не гарантирует, что он останется удобным при росте сложности продукта — иногда прямые вызовы API дают больше контроля, чем абстракция, которая должна была его упростить.

Позитивный случай, без выдуманных цифр — это качественная иллюстрация, не количественный кейс: класс задач, где многошаговый агентный цикл действительно необходим, а не опционален. Deep Research-инструменты — поиск и синтез по многим источникам с уточнением запроса по ходу работы — и coding-агенты — правка кода с последующим запуском тестов и итерацией по результату. В обоих случаях одного вызова модели физически недостаточно: нужна проверка промежуточного результата и решение, что делать дальше.
