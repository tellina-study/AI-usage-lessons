# sNN — Карта: первые четыре точки

## assertion

Первые четыре точки уже показывают структуру: смежное с IT — вверху-справа, регулируемая медицина — внизу-справа.

## slide_type

schema (schema_quadrant)

## visible

2D-плоскость с первыми 4 точками (по одной из каждого семейства курса):

- **Разработка ПО:** верхний правый. Текст/код — модальность фундаментальных моделей;
  компилятор даёт мгновенный эталон; объём гигантский; цена ошибки низкая.
- **Финансы и ритейл:** верхний-середина. Фрод (закрытый мир) высоко; скупка жилья роботом
  (iBuying, открытый мир) низко — Zillow показал почему.
- **Медицина:** нижний правый. Узкая визуализация — высокая применимость; автономия
  капнута FDA на L1 (советник).
- **Авиакосмос/оборона:** верхний-середина с потолком. Восприятие высоко, действие
  ограничено этически (дебаты о LAWS).

Подпись: «Уже видна структура: смежное с IT справа-вверху, регулируемая медицина
справа-внизу, у каждого домена свой потолок автономии.»

## speaker_notes

Начнём с четырёх стартовых точек, по одной из каждого семейства курса. Это канонические
успешные кейсы, каждый показывает чистую координату на карте.

Разработка ПО — верхний правый квадрант. Применимость высокая: текст и код — модальность, в
которой фундаментальные модели работают эффективно; компилятор даёт мгновенный эталон;
объём гигантский — миллиарды строк кода в день; цена ошибки автодополнения низкая. Автономия
тоже высокая, хотя в проде капнута на уровне узких задач.

Финансы и ритейл — верхняя середина. Применимость средне-высокая: для закрытого мира, как
детекция фрода, она высокая; для открытого мира, как покупка недвижимости, низкая — Zillow
показал почему. Медицина — нижний правый. Узкая визуализация даёт высокую применимость
благодаря AlphaFold и Aidoc, но автономия капнута регулятором на уровне советника: FDA не
разрешает AI ставить диагноз без врача. Авиакосмос — верхняя середина с потолком: восприятие
обстановки высоко, но действие ограничено этически, это дебаты о летальном автономном оружии.

После этих четырёх точек уже видна структура карты. Справа-вверху — то, что близко к IT.
Справа-внизу — регулируемая медицина (высокая применимость, капнутая автономия). И у каждого домена свой характерный потолок автономии.
Дальше добавим средний набор отраслей.
