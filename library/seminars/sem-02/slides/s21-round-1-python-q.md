# Раунд 1 — Python

## Assertion

Когда вышел первый стабильный релиз Python и кто его автор?

## Visual

Две одинаковые по формату Ocean rounded box карточки (А слева, Б справа — только
текст, никаких иконок или картинок, никакой цветной рамки на любом из вариантов).
Внизу нейтральная подсказка «2 раунда поднятия руки — подделка в А или в Б?» (без
gold-акцента, он появится только на слайде-ответе).

## Speaker notes

Вопрос: когда был выпущен первый стабильный релиз языка программирования Python и кто был его автором?

Вариант А: первый стабильный релиз Python 1.0 вышел в январе 1994 года, автор — Гвидо ван Россум, на тот момент сотрудник голландского института CWI. Вариант Б: та же дата почти, март 1995 года, тот же автор и институт, но добавлено — релиз был приурочен к внутренней конференции CWI по функциональным языкам.

Голосуем: два раунда поднятия руки — кто считает, что подделка в А, кто считает, что в Б. Оба варианта написаны автором методического комплекта — это не реальный вызов модели, но реалистично имитирует типичный уверенный ответ AI-чата.
