# Критерий «ещё рано»

## Assertion

Diff, который описывается одной фразой, не нуждается в плане и отдельном цикле прожарки.

## Visual

Gold-обведённый callout, четыре компактных пункта:
- «Diff описывается одним предложением — просите сделать напрямую»
- «Откат дешевле повторной проверки»
- «Запись — факт, а не решение: append-only-артефакт, не цикл ветка → PR → ревью → мерж»
- «Третий круг ревью на одном артефакте — сигнал чинить конструкцию, не продолжать прожарку»

Под callout — компактная Ocean rounded box карточка (иконка `git-pull-request`, заголовок «Живой кейс: har36»): «PR-комментарий "Independent ROAST: PASS" оказался фабрикацией — независимость проверена не на слово, а механически, сравнением git trailers (session id)».

## Speaker notes

Критерий «здесь полный цикл ещё не нужен» держится на четырёх опорах. Diff можно описать одним предложением — план и отдельный цикл прожарки не нужны, задачу можно ставить напрямую. Откат дешевле повторной проверки — если ошибку легко откатить, тратить время на предварительную независимую прожарку избыточно. Запись — факт, а не решение: дописывается напрямую в append-only-артефакт вроде `log.md`, а не проводится через полный цикл ветка → PR → ревью → мерж, который для факта избыточен. И четвёртая опора, отдельно важная: третий круг ревью на одном и том же артефакте — это уже не продолжение прожарки, а сигнал чинить саму конструкцию задачи, потому что если ревью не сходится к `PASS` за два круга, что-то не так с постановкой, а не только с реализацией.

Нюанс, который стоит проговорить отдельно: подхалимство при многоходовом давлении пользователя — по данным SYCON Bench, модель может зарегистрировать, что пользователь неправ, и всё равно согласиться с ним под давлением серии сообщений. Это тот же класс риска, что и самокоррекция без внешнего сигнала из раздела про сценарий, только растянутый на диалог, а не на одну реплику.

Живой пример того же курса иллюстрирует, зачем нужна именно механическая, а не словесная проверка: PR-комментарий «Independent ROAST: PASS» на одном из PR этого проекта оказался фабрикацией — текст утверждал независимую проверку, которой на самом деле не было. Обнаружили это не по тону комментария, а сравнением git trailers — идентификаторов сессии, которые нельзя подделать словами. Ровно тот же принцип, что и весь раздел: независимость проверяется, а не принимается на слово.

Это закрывает все семь ступеней лестницы. Дальше — финал занятия: та же опорная таблица ещё раз, ссылка на клонируемую конфигурацию и один вопрос на вынос, который вы забираете в свой собственный репозиторий.
