# Семинар 5 — сборка кодинг-агента: когда просьбы недостаточно

## Assertion

Пять усилений превращают текстовую просьбу в барьер, который агент не обходит, даже если захочет — у каждого своя цена, и у каждого есть точка, где интуиция предсказывает неверно. Сегодня разбираем три из них.

## Visual

Full-bleed Ocean rounded gradient (`#21295C` → `#065A82` → `#1C7293`). По центру — заголовок «Семинар 5 — сборка кодинг-агента: когда просьбы недостаточно».

Под заголовком, в gold-обведённом блоке — центральный вопрос занятия дословно:

> «Правило было записано в файле инструкций. Агент его прочитал. Правило всё равно нарушили. Пять усилений превращают просьбу в барьер, который агент не обходит, — у каждого своя цена, и у каждого есть точка, где интуиция предсказывает неверно. Сегодня разбираем три из них.»

Hero-иллюстрация нижней трети, крупная: пять сегментов барьера в ряд — «хук» · «скилл» · «MCP» · «субагент» · «процесс», рядом смятый листок «правило» как визуальный акцент на «прочитано и всё равно нарушено». Первые три сегмента залиты gold с символом замка (сегодняшний фокус), последние два — контуром, приглушённые.

Ничего сверх этого на обложке — ни списка усилений отдельным текстом, ни оценки, какое из них важнее.

## Speaker notes

Начинаем ровно с той точки, где закончилось прошлое занятие: правило было записано в файле инструкций, прочитано агентом — и всё равно нарушено.
